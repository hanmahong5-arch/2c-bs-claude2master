- 动态解析 Cloud Workstations 代理重定向 URI，修复 OAuth 流程；IDE 连接目录不匹配问题已解决。
- 容量错误增加上下文感知静默重试与可用性 TTL；取消或中止时回滚整个多轮请求，提升可靠性。
- 新增 eval 工具调用格式化与失败摘要；子代理在 agents 模式禁用时不再运行，修复启动时交接令牌回归。
