- 权限提示不再被刚发送消息后的按键或慢出现的提示抢先应答，harness 需把输入事件与提示生命周期严格绑定
- 共享网络家目录下配置写入失败不再静默成功，`/logout`、`mcp remove` 等会如实报错，harness 应把持久化失败当作一等状态
- `claude -p` 在 claude.ai 登录到期前 10 天输出 stderr 警告，并在 JSON 结果暴露 `credential_expires_at`，无人值守流程可提前续期
