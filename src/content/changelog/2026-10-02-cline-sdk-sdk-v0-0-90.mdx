- 流式 chunk 与 2 秒心跳不再持久化，只推给实时 UI；含义是 harness 应把「展示态」与「持久态」分离，避免高频事件污染存储。
- 仅写入变更实体并每约 300ms 批量提交一个事务，run 记录只存摘要而非完整 transcript；含义是状态存储需按实体粒度做脏标记与合并写。
- SQLite 团队存储升级到 schema v2 并一次性迁移压缩旧数据，team_events 每团队上限 2000 行/30 天，失败写入改为重试；含义是 harness 需内置迁移、保留策略与写失败重试。
