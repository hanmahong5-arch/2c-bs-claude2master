- Qwen 3.8 Max 是 2.4T 参数的 MoE 模型，激活参数 95B，上下文 1M，API 定价 $2/$6 每百万 token，开源权重下周发布。
- 官方宣称可自主编码超 10 天，芯片设计优化 500+ 轮，电商模拟 365 天，多模态视觉融入执行循环，而非仅输入。
- 第三方评测：Frontend Code Arena 第 4，Vision Arena 第 2，SWE-bench 87.3%，Vals Index 66.1，成本仅为 Opus 4.7 的约 2.3 倍。
- 对开发者：开源巨型模型与闭源差距缩小，长时任务和多模态 agent 能力增强，但部署需高算力，适合云 API 而非本地。
