- 更新流程改为在隔离候选状态中彩排核心与插件变更，验证通过才激活，并支持 2026.9.2 迁移与废弃更新记录恢复；含义是 harness 的升级路径需自带 rehearsal 与 rollback 语义，而非直接替换运行态。
- Node 运行时要求提升到 24.16.0+ 或 26.1.0+，Node 22/25 及更早 24.x/26.x 不再支持，理由是避免 SQLite 文本截断；含义是 harness 需在启动时校验运行时版本并给出明确拒绝路径。
- 多个 SDK 破坏性变更：exec-mode 与 comparator 助手迁至 execPolicy，approval 助手迁至 approval-native-runtime，搜索与目录结果回调改读 details.content / LsToolDetails.content；含义是插件侧 harness 集成需按新契约迁移，不能依赖旧别名。
