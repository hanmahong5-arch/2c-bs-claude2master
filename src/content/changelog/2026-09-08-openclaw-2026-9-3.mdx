- 更新流程更安全：核心与插件变更先在隔离候选状态演练，支持从失败更新中恢复，无需停止健康 Gateway。
- 性能提升：保留热提示缓存，减少冷会话更新和记忆搜索中的不必要工作，复用 worker 构建。
- 破坏性变更：要求 Node 24.16+ 或 26.1+，多个 SDK 别名和回调字段调整，需迁移。
- 技能 Workshop 改为 agent 持有集合，跨工作区持久化，Doctor 可安全处理缺失草稿建议。
- 新增浏览器标签实时查看、macOS 原生标签页、账户管理、会话分享、会议库、团队报告等功能。
