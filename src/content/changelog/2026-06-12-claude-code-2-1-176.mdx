- **会话标题根据对话语言生成**：会话标题现在会根据对话语言自动生成，`language` 设置可用于固定特定语言。这意味着 Agent 的界面交互可以更好地适应不同语言用户。
- **新增正则匹配的页脚链接设置**：添加了 `footerLinksRegexes` 设置，允许通过正则表达式在页脚行配置链接徽章。这为 Agent 的界面自定义和外部工具集成提供了更灵活的配置方式。
- **修复了模型选择与远程控制的关键问题**：修复了别名模型可能绕过 `availableModels` 限制的问题，并解决了远程控制连接时静默切换会话模型、断开连接提示不友好以及多账户登录时未断开连接等多个问题。这增强了 Agent 在多模型环境下的安全性和远程协作的稳定性。
