- 新增 `managedMcpServers` 设置，组织可统一配置 HTTP/SSE MCP 服务器，跳过命令型条目，便于集中管理。
- 新增 `--permission-prompts none`，无头环境自动拒绝所有提示，权限模式仍生效，适合无人值守。
- 修复并发会话互相覆盖配置、Bash 读取规则遗漏、OAuth 刷新导致缓存失效等问题，提升稳定性。
