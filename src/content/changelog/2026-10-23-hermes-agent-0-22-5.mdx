- **可插拔委派后端**：子代理可按模型映射或 profile 路由，并能在会话内切换，harness 需把委派策略从硬编码改为可配置层。
- **插件斜杠命令支持选项交互**：插件命令可要求用户选择，命令协议需支持多轮参数回传而非单次执行。
- **MCP serve 与 Singularity 后端移出核心转为插件**：核心瘦身，harness 需提供插件发现与安装入口，并在检测到其他 agent 时提示迁移导入。
