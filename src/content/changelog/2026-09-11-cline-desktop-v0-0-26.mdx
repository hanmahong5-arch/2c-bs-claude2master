- composer 现在显示当前分支的 GitHub PR：编号、合并状态、改动行数与 CI 检查，可点击跳转或展开查看日志，可见时每 30 秒刷新；依赖 `gh` CLI 登录与 GitHub.com origin，默认分支、detached HEAD 及不支持仓库自动隐藏，且不会替你 push 或提交 PR。含义：harness 可把外部 VCS 状态作为只读上下文注入，但需明确边界与降级隐藏条件。
- 删除排队中的 prompt 不再在 transcript 留下从未执行的消息：此前 sidecar 以「待处理列表缩短且头部变化」推断已开始，现改为只依赖 runtime 的真实 start 事件。含义：状态推断应基于显式事件而非列表形状的启发式。
- 从 checkpoint 恢复 fork 的会话不再卡在 Thinking：带种子历史物化的会话持久化时未传递状态，行与 manifest 写成 running 而实际空闲。含义：持久化状态必须与实时状态一致，否则恢复路径会永久挂起。
