- **Daemon 指纹防重连**：daemon 携带运行时构建指纹，升级后旧 daemon 会被重启而非复用，避免连接到过期代码。
  - 对 harness：确保 daemon 生命周期与代码版本一致，升级时需强制重启。
- **推理模型压缩修复**：summarizer 不再硬编码 1024 token 上限，默认 4096，并尊重模型的最大输出设置，空摘要时记录诊断。
  - 对 harness：需配置 max-output-tokens，并监控空摘要日志。
- **Vertex 模型更新**：新增 Fable 5，价格未知；自定义模型 ID 原样传递，路由到 Anthropic-on-Vertex。
  - 对 harness：处理未知成本，并支持自定义模型 ID 透传。
