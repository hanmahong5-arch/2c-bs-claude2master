- Hub 托管 Agent Plugins：从 `~/.agents/plugins/*` 的 `plugin.json` 发现并校验插件，`skills/` 暴露为 `plugin-name:skill-name`，`mcp.json` 启动 stdio/HTTP/SSE 服务且不写 `cline_mcp_settings.json`；工作区 `.agents/plugins` 不扫描，避免打开仓库即启动仓库控制的 MCP 服务。含义：插件加载与启用状态集中到 hub，客户端不再自带 loader。
- 流式失败重试：中途因瞬时 provider 错误断掉的模型回合最多重试 3 次并指数退避，但一旦已流出文本、推理、媒体或工具调用就不再重试，避免重复；模型调用 SDK 级重试从 2 次升到 5 次。含义：harness 需按“是否已产生可见输出”区分可重试边界。
- 流式不再被 hook 转发拖慢：每 chunk 的文本、推理、工具增量不再转发给远程 `onEvent` hook，其余事件不变；hub 事件日志改为 `synchronous = NORMAL`。含义：把逐 token 事件排除出能力往返，是保住流式延迟的关键取舍。
