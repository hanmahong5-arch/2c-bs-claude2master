- Claude Code 代理现在运行原生工具，不再接收无法桥接的工具定义；会话锚定工作目录，加载权限规则，工作区内文件编辑自动批准，命令执行仍受 Claude 设置约束。
- 工具调用 JSON 截断不再被静默修复，未终止字符串的载荷会被拒绝，避免参数错误。
- 严格提供商不再因消息内容仅含空文本部分而报错；流式工具调用索引非零或不连续不再导致崩溃。
- Hub 守护进程升级方向性：新版本 CLI 会附加到较新守护进程并提示更新，避免互相淘汰；Yolo 和沙箱会话不受影响。
- 修复守护进程关闭时客户端仍连接导致的错误退出；修复缓存密集型会话 token 统计虚高约 5 倍的问题。
