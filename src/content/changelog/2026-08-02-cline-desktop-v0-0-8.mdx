- 支持编辑对话中任意历史消息，应用会分叉会话、回滚工作区到该消息的检查点并重新执行，且恢复操作是事务性的，失败不会导致半回滚状态。
  - 对 agent harness 设计：这要求 harness 具备细粒度的状态快照和回滚能力，以支持交互式调试和分支探索。
- 检查点创建更可靠，覆盖重启、压缩、恢复会话等场景，恢复时回滚整个工作区而非仅对话。
  - 对 agent harness 设计：harness 需要持久化工作区状态，并确保恢复的原子性，避免部分恢复导致的不一致。
- 推理控制（如 effort、thinking budget）现在来自共享模型目录，每个模型只显示其支持的选项。
  - 对 agent harness 设计：harness 应通过统一的模型元数据来配置推理参数，避免硬编码或猜测。
