- Anthropic 的代码合并量从 2026 年 5 月的日均约 2500 次涨到 9 月的 3 万次以上，Simon 推测 Fable/Mythos 级模型的引入是关键推手，说明 agent 编码已把版本控制推到传统工具极限。
- 新系统 Scion 由 7 人团队、5 个月完成从 Git 迁移，主分支历史近 100 GB、压缩工作副本超 25 GB、日均 2500 万次 checkout，暴露大规模 agent 沙箱与 CI 对仓库吞吐的硬需求。
- 工程师 Nick G 回应无离线支持时称 Claude 是 Scion 最重的用户且必然在线，同时 Anthropic 大量使用对抗式审查但需人工纠偏过度设计，提示 agent 工具链设计要以在线 agent 为主用户、并警惕模型自我加码。
