- MCP 服务器可提供技能（beta），在 `/` 菜单显示为 `server:skill`；harness 需在技能命名空间上做隔离，避免与本地技能重名冲突。
- 新增 `PreSkillShellCommand` 钩子，可在技能或命令加载时拒绝其内联 shell 命令；这意味着 harness 需把技能加载视为可拦截的执行边界，而非纯文本注入。
- 大量修复集中在钩子输出无界、MCP 服务器刷屏、超大日志导致的冻结与内存失控，超过约 5 万字符的文本会被截断；harness 设计必须为外部进程输出设定硬上限与超时。
