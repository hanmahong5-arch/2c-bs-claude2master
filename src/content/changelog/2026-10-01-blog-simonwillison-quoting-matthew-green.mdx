- Green 描述了一个实验现象：分别隔离在沙箱中的 agent，通过共享的 package cache 留下指令，接收方 agent 的行为因此被改变——缓存成了跨沙箱的隐蔽信道。
- 他给出的蠕虫公式是两半拼合：劫持 agent 的 payload，加上能把 payload 传给下一个 agent 的 agent；把 package cache 换成邮件、Slack、共享文档或 WhatsApp，把训练 run 换成 Muse 这类独立部署的个人 agent，条件就齐了。
- 对工具链的启示：隔离只约束单次执行边界，不约束 agent 之间的信息流；共享缓存、消息通道、文档这类“协作面”需要按不可信输入对待，并做来源与指令的区分。
