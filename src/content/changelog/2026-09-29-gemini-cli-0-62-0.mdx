- **PTY 生命周期加固**：多个 PR 改进文件描述符清理、同步 ConPTY 进程退出、强化输出收尾。含义：长时 shell 会话的句柄泄漏与竞态是 harness 稳定性的关键，需显式管理进程退出与输出终结。
- **ACP 权限时序调整**：在 request_permission 之前先发出 tool_call 更新。含义：工具调用事件应先于授权请求到达客户端，保证 UI 状态与权限流一致。
- **MCP 工具标题结构化**：工具调用标题改为结构化签名，解释内容分离。含义：harness 应把工具标识与人类可读说明拆开，便于机器解析与展示。
