- MCP 工具结果可在到达模型前被扩展检查或替换，为 harness 提供中间层干预点。
- 可选 MCP 服务器发现新增可配置宽限期，harness 可调整启动等待策略。
- 插件目录合并仓库级配置，无效项目市场不再隐藏有效插件，harness 需处理配置冲突。
- 修复模型切换时工具可用性和推理努力保持正确，harness 需同步模型状态。
- 远程沙箱强制使用执行器真实主目录、OS 和路径约定，harness 需传递环境上下文。
