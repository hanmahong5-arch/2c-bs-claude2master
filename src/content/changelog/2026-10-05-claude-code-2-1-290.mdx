- `turn.step` 结果新增 `serverToolUses`，列出 API 自身（advisor）执行的工具调用及其 id、名称、输入与起止时间；harness 可据此把模型发起的调用与服务端调用分开记账。
- 插件 hook 的 `tool.check` 事件新增 `agentId`，可区分 subagent 与主会话的权限检查；同一 hook 能按来源做不同裁决。
- `tool.check` 读取的问题与裁决新增 `ceiling`，标明组织对该工具要求的审批级别；hook 可在不硬编码策略的情况下对齐组织上限。
