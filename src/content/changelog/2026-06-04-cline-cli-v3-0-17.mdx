- **修复交互式 CLI 会话卡死**：当 Hub 重启后，CLI 能检测过期会话并恢复待处理消息，避免“会话未找到”错误，确保 agent 交互的连续性。
- **解决 Hub 关闭竞争条件**：修复了 Ctrl+C 和 Hub 关闭时出现的“hook dispatch failed”及 WebSocket 错误，提升了 agent 系统在关闭过程中的可靠性。
- **增强 Telegram 连接器安全性**：新增 `--allowed-user-id` 标志以限制授权用户，强化了 agent 在外部渠道的访问控制。
