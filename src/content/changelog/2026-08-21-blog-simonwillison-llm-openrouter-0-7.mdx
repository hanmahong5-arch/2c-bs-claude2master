- 插件更新至兼容 LLM 0.32，并改用 OpenRouter 的 Responses API 实现，使推理模型（如 o1 系列）在工具调用和流式输出上表现更稳定。
- 新增 Shell、WebFetch、WebSearch 三个服务端工具，可通过 `-T` 选项启用，扩展了 CLI 的自动化能力，例如直接让模型执行 shell 命令或抓取网页。
- 对开发者而言，这展示了插件生态如何快速跟进上游 API 变化，并利用服务端工具减少客户端往返，提升 agent 任务效率。
