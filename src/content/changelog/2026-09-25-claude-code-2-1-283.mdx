- 新增 `x-claude-code-prompt-id` 网关提示头（需 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`），网关可按单条用户提示聚合请求；harness 侧意味着请求分组不再依赖自建关联 ID。
- 新增 `availableModelsMatch: "exact"` 与 `deniedModels` 托管设置，前者让未列出的新模型版本保持被阻断，后者可单独封禁模型；模型可见性从“允许列表”变成可精确钉版本的双向控制。
- 新增 `/doctor prompt-audit`，审计 CLAUDE.md、skills、agents 与 commands 中面向旧模型的提示写法；提示资产开始被当作需要随模型迭代而迁移的配置。
