- **更新 VS Code 扩展依赖**：修复了 `@xmldom/xmldom`、`basic-ftp` 等包的安全问题，提升了开发环境的安全性。
- **解决直接/传递依赖漏洞**：通过更新多个依赖包，减少了潜在的安全风险，确保了系统的稳定运行。
