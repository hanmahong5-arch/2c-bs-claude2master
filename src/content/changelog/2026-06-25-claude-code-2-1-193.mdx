- `autoMode.classifyAllShell` 设置可将所有 Bash/PowerShell 命令路由至自动模式分类器，而不仅限于任意代码执行模式。对 agent harness 设计意味着：需要支持更细粒度的命令执行策略配置。
- 新增 `claude_code.assistant_response` OpenTelemetry 日志事件，默认跟随 `OTEL_LOG_USER_PROMPTS` 设置，可通过 `OTEL_LOG_ASSISTANT_RESPONSES` 独立控制。对 agent harness 设计意味着：需考虑可观测性数据的合规与可配置性。
- 新增自动内存压力回收空闲后台 shell 命令（可通过 `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1` 禁用）。对 agent harness 设计意味着：需实现资源感知的后台任务生命周期管理。
