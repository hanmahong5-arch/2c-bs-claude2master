- 插件现在会读取 LLM 的默认模型，因此启动 Datasette Agent 时不再需要显式指定 `-s plugins.datasette-agent.default_model`，一条 `uvx --with datasette-agent datasette content.db --internal internal.db` 即可跑起来。对开发者的含义：本地试用 agent 的启动成本进一步降低，少一个必填配置项。
- 这次改动被作者定位为底层 datasette-llm 插件的一次小型用户体验改进，而非功能扩展。含义：工具链的易用性往往靠这类小修补累积，而非大版本。
- 作者提到 Datasette Agent 还有一批大升级在筹备中，本次只是过渡期的小改动。含义：关注该项目的开发者可以预期后续会有更大变化，当前配置方式可能还会调整。
