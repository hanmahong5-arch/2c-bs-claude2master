- 模型回退时轮换会话 ID，避免状态化 API 错误，确保 agent 连续运行。
- 强制 Google 认证走 HTTPS，防止明文泄露，增强凭证安全。
- 禁用上下文管理时过滤思考片段，历史记录更干净，减少 token 浪费。
- 文件钥匙链强制标签长度校验，防止无效标签，提升配置可靠性。
