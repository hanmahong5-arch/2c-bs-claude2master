- 发布说明与 changelog 内容相同但分两种格式：人类可读的网页版和纯 Markdown 版，后者明确面向 AI agent 与工具。含义：harness 应优先抓取机器可读的 changelog 源，而非解析渲染后的页面。
- 本次含 166 commits、113 PR、64 位贡献者，并附 npm 包完整性哈希与 release SHA。含义：harness 可用 integrity 与 SHA 做供应链校验，而不只依赖版本号。
- 插件 ClawHub 发布被推迟到独立恢复流程，本次未发布也未验证，完整发布仍不完整。含义：harness 需把“部分发布”当作一等状态处理，不能默认 tag 即全量可用。
