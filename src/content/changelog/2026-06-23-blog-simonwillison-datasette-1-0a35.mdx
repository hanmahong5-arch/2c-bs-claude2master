- 新增“创建表”界面和 JSON API，支持定义列、主键、自定义类型、非空约束、默认值及外键，简化数据库结构管理。
- 新增“修改表”界面和 JSON API，支持添加、重命名、重新排序、删除列，以及更改类型、约束、主键和外键，并包含删除表功能，提升表结构灵活性。
- 新增模板上下文文档，列出核心页面可用变量，并作为稳定 API 直至 2.0，文档由数据类定义生成并附带测试，确保准确性和可维护性。
