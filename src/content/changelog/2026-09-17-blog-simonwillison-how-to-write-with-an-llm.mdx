- Thomas Ptacek 的第一条规则是：LLM 建议的任何一个词都不能直接用，Simon Willison 认为这条规则能帮人保持写作纪律，因为 LLM 生成的文字带有一种奇怪的“味道”。
- Simon Willison 自己不让 LLM 代写博客内容，只用于事实核查、拼写语法检查和偶尔的同义词查询，并公开了自己的校对 prompt。
- 文中还展示了 Thomas 自建的 LLM 校对工具截图，并给出一个 prompt 供读者搭建自己的工具，对开发者而言这是把 LLM 限定在工具链辅助位、而非内容生成位的具体做法。
