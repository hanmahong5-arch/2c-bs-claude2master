- 修复：显式配置远程环境变量时，启动远程 stdio MCP 服务器会保留 `SYSTEMROOT`、`TEMP`、`TMP`，不再被覆盖。含义：harness 注入远程 env 时应做合并而非替换，避免抹掉执行器启动所需的基础变量。
- 场景：Unix 主机连接 Windows executor 时，Windows 侧启动环境得以保留。含义：跨平台 harness 需区分「宿主环境」与「用户配置环境」两层。
- 版本：该修复通过 #51121 回移到 0.160。含义：补丁级回移说明环境变量丢失会直接导致 MCP 进程启动失败，属于高优先级修复。
