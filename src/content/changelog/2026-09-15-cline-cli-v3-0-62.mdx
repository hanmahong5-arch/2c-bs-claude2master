- 流中断的模型回合现在最多重试 3 次并退避，但已输出过的回合不重试，避免重复内容；harness 需区分「未产出」与「已产出」状态。
- Agent Plugins 改由 Hub 管理，`~/.agents/plugins/*` 被校验并暴露为 `plugin-name:skill-name`，MCP 服务器无需改 `cline_mcp_settings.json`；工作区 `.agents/plugins` 故意不扫描，防止打开仓库就启动仓库控制的 MCP。
- 流式输出不再经 Hub 节流，此前每个 token 都要带完整会话副本往返；同时 checkpoint 用持久快照索引跳过未变文件，避免大未跟踪目录阻塞消息。
