- 他把当下拒绝关注 LLM 的计算机科学家，比作在刚开园的侏罗纪公园里坚持说遗传学没意思的遗传学家：技术已经摆在眼前，回避本身才是问题。
- 这个类比暗示 LLM 带来的变化不是可选项，而是整个领域环境已经改变，研究者需要先承认它存在，再决定如何应对。
- 对 agent 与工具链开发者而言，含义是别把 LLM 当成一时热度绕开，而要把它当作新的默认前提去评估风险与机会。
