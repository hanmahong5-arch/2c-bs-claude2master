- 新增 `hermes gateway migrate --backends`，可将旧 serve/dashboard 后端迁移到 gateway，并在 dashboard 的 System 页显示卡片；这意味着 harness 的后端切换不再需要手工重建配置。
- 新增 `hermes plugins config`，可在终端直接编辑插件设置；插件配置因此成为 harness 的一等接口，而非散落的文件。
- gateway 客户端会声明自身身份，插件可据此判断是哪个客户端发起的 turn；多客户端场景下，harness 可按来源做差异化策略。
