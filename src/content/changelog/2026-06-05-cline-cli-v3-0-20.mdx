- 插件包装器现根据来源命名（如 npm 包名、Git 仓库、远程文件名等），而非不透明哈希值。
- 这意味着在 agent harness 设计中，插件管理界面可直接展示可读标识，提升调试与维护效率。
- 开发者能快速追溯插件来源，简化多环境部署时的依赖追踪。
