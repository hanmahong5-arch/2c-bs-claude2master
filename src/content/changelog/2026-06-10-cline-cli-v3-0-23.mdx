- **修复 Vertex AI 与 Azure Foundry 配置**：确保在 GCP 和 Azure 平台上的 API 调用稳定可靠，意味着 Agent Harness 能更无缝地集成主流云服务。
- **支持配置代理作为子代理工具**：允许将已配置的 Agent 作为工具嵌套调用，为设计分层、模块化的智能体工作流提供了核心能力。
- **将 OAuth 管理集中至 SDK 并修复 Fable 5 推理错误**：统一了身份验证管理，同时解决了特定模型下的运行中断问题，使底层框架更健壮、易于维护。
