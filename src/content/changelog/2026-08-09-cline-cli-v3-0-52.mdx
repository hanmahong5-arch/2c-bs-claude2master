- `cline mcp uninstall` 命令可移除已安装的 MCP 服务器，简化 MCP 管理。
- 计划任务复用已保存的 provider 设置，无需单独配置，降低配置负担。
- TUI 中 MCP 工具结果以可读文本显示，二进制负载不再被破坏，且畸形负载不再导致渲染崩溃，提升调试体验。
- 中断后队列中的提示词得以保留，会话上下文在中断后保持，恢复时状态一致，增强 agent 的韧性。
- 挂起的 MCP 服务器不再阻塞会话创建，未配置的 stdio 服务器有 30 秒初始化预算，避免无限等待。
- LiteLLM 请求改用 Chat Completions，修复代理兼容性；网络中断在模型输出前自动重试，提高可靠性。
