- Simon 指出，开源软件“自由查看和修改”的理想，过去因时间成本而难以实现，多数人依赖他人代为修改。
- 他认为 LLM 改变了这一局面：现在他常让 Claude 克隆 GitHub 仓库并解释工作原理，将过去的高摩擦变为零成本挑战。
- 他让 Codex 或 Claude Code 自动构建项目，十分钟后查看结果，这种流程让修改软件变得可行，尽管他尚未习惯性修改，但已看到一年前不存在的路径。
- 对开发者而言，这意味着 AI 辅助编程正将开源参与门槛降至新低，未来更多开发者可能直接修改工具链，而非仅依赖上游维护。
