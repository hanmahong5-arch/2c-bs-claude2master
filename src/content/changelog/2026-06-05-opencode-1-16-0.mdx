- **新增托管工作区克隆**：保留脏文件和未跟踪文件，确保开发环境一致性，意味着 Agent 可以在更真实、未净化的代码库上下文中工作。
- **新增会话在目录间移动**：支持将活动会话在不同工作区和目录间迁移，为 Agent 提供了更灵活的任务上下文切换能力。
- **新增通过 AWS Bedrock 的 OpenAI 模型支持**：扩展了模型后端选项，使 Agent 可以利用企业级的云基础设施进行推理。
