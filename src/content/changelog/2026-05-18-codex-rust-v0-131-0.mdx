- **TUI 新增数据驱动的服务层命令、混合令牌用量显示和响应式 Markdown 表格**，使界面信息更丰富，操作更直观，意味着 agent harness 需更注重实时状态反馈与交互设计。
- **插件工作流支持市场 CLI 命令、版本感知共享和默认启用的钩子**，强化了插件的分发与管理流程，意味着 agent harness 需内置更完善的插件生命周期与协作机制。
- **远程工作流新增守护进程管理的远程控制、运行时启用/禁用 API 和注册表支持的环境**，提升了远程操作的灵活性与可控性，意味着 agent harness 需支持动态环境配置与远程资源管理。
