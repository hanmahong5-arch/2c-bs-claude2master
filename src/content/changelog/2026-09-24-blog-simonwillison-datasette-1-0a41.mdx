- 本版本由 Alec Garcia 贡献，为 Datasette 加入 OpenTelemetry 支持，意味着数据服务的调用链与性能指标可以被标准可观测性工具采集，对自建数据 API 的开发者来说，排查慢查询多了一条通用路径。
- 作者把 Datasette 里所有模态对话框重构成单个 Web Component，并为其补上文档，供其他插件复用；插件作者不必再各自实现弹窗，前端交互层因此更统一。
- 这两项改动都落在 1.0a41 这个 alpha 版本里，说明 Datasette 1.0 仍在迭代中，关注其插件生态的开发者需要留意 API 与前端组件的变动。
