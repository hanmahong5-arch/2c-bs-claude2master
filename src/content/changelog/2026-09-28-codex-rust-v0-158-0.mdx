- 全屏 TUI 新增可配置的选中即复制与右键粘贴，复制转录内容保留 Markdown 格式；harness 需把剪贴板行为当作可配置项而非硬编码。
- 支持需要预注册 OAuth client secret 的 MCP 服务器，并可用 `codex mcp add --oauth-client-secret` 配置；harness 的 MCP 接入要能承载密钥型凭据。
- 提权命令默认启用终端输入审批，仅运行时授权不再触发多余审查；harness 应区分持久授权与单次运行时授权。
- 修复 Windows 沙箱路径与凭据、Linux 嵌套可写根启动，并保留 Git 元数据保护；跨平台沙箱语义需显式建模。
