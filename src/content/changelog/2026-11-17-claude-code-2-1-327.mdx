- `/install-github-app` 改仓库前先确认，`mcp add-json` 支持从 stdin 读 JSON 避免 token 进命令行；harness 应把敏感凭据走非命令行通道。
- `/status` 汇总损坏的 agent/skill/command 文件、无效 hook matcher 等；harness 需要一处集中暴露配置失效点，而非静默忽略。
- 修复恢复会话丢消息、`/export` 覆盖文件、`/rewind` 静默失败；harness 的会话持久化与破坏性操作必须可确认、可诊断。
