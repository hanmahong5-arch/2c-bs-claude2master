- 改进了跨提供商的max output token处理，包括网关路由、OpenAI供应商和推理模型。
  - 含义：agent需统一处理不同模型的token限制，避免输出截断。
- 修复了以UTF-8 BOM开头的frontmatter和用户指令文件的解析问题。
  - 含义：agent应兼容Windows编辑器保存的文件，确保元数据正确读取。
- 完整变更日志见链接。
  - 含义：可追踪底层SDK的细节调整。
