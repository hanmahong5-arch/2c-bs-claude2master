- 新增 `claude plugin eval`：对插件跑评测套件并输出 JSON/HTML 评分报告，意味着插件质量可被回归验证，harness 需把插件当作可测单元而非黑盒。
- 新增 `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`（1–256）提高单次 Workflow 并发 agent 上限，说明 fan-out 场景的调度上限应由配置暴露而非硬编码。
- 修复输出 token 截断后自动续写那一轮 prompt cache 被部分失效，以及中断后恢复会话改变早期上下文重发的问题，提示 harness 的续写与恢复路径必须保持缓存前缀稳定。
