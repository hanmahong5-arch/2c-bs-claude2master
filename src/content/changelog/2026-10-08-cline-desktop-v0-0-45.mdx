- SSH 远程连接自 0.0.38 起因 `SyntaxError: Invalid character` 失败，现已恢复；harness 需对远程环境初始化做容错，避免单点解析错误阻断整个会话。
- SSH 环境下 git 分支标签轮询从每 5 秒两次登录改为每 30 秒一次，切换分支仍即时更新；说明高频远程探测应降频并保留事件驱动的即时反馈。
- 关闭 reasoning 不再在 GPT-6 Astra、Claude Fable 5 等模型上报 400；harness 需按模型能力动态裁剪参数，而非统一开关。
- 模型目录刷新新增 Claude Haiku 5.5，多个 provider 默认模型改为它；默认值变更意味着 harness 应显式固定模型而非依赖 provider 默认。
