- **Perplexity 收入跃升**：CEO 称年化收入已达 10 亿美元，年初不足 2.5 亿、8 月超 7.5 亿，Computer 产品贡献部分增长；按同类 agent 实验室估值倍数推算约值 300–500 亿美元。对开发者的含义是 agent 产品的付费意愿正在被验证。
- **Qwen4-Max 正式上线**：最高推理档 Intelligence Index 从 34 升到 43，单任务平均成本从 10.02 美元降到 3.27 美元，输出 token 减少约 39%；总参数维持 2.4T，每 token 激活参数降 25% 至 71B。含义是同等预算下可跑更多 agent 任务。
- **推理栈转向 agent 自动优化**：Together 放弃手工调优的 megakernel，改由 agent 搜索可融合的 GPU 算子组合，Llama 3.2 1B 在 B200 上吞吐提升 28%；另有团队称 agent 找到的优化让 B300 单步快 10%。含义是性能调优正部分交给 agent 完成。
