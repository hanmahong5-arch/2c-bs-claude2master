- 当前 AI 已从聊天机器人进化到 agentic 系统，能自主完成数小时人类工作，例如 GPT-5.6 Sol 在 Codex 中可检查全书 195 条参考文献并给出详细批注。
- 高 stakes 场景（如医疗、法律咨询）必须用最先进模型（Claude Opus/Fable 或 ChatGPT GPT-5.6 Sol 高思考级别），因为错误率更低；低 stakes 场景免费模型即可。
- 使用 agent 时权限设置至关重要：默认应要求审批再执行发送、购买、删除等操作，同时需防范 prompt injection 攻击（agent 读取恶意指令）。
