- 修复了使用 LLM 网关或自定义 base URL 时的提示缓存问题，确保这些场景下缓存正常工作，减少延迟和成本。
- 新增内置“简洁”输出风格，Claude 直接给出结果，跳过开场白和叙述，但工作质量不变。可在 /config 的输出风格中选择。
- 对 agent harness 设计：缓存修复意味着自定义网关配置下可依赖缓存，优化 token 使用；简洁风格可减少冗长输出，提升交互效率，适合需要快速响应的场景。
