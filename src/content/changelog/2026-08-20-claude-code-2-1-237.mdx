- 修复了使用 LLM 网关或自定义 base URL 时 prompt 缓存失效的问题，确保这些场景下缓存正常工作，提升响应速度并降低成本。
- 新增内置 "Concise" 输出风格，Claude 直接给出结果，跳过前言和叙述，但工作完成度不变。可在 /config 的 Output style 中选择。
- 对 agent harness 设计的影响：若使用自定义网关，需注意缓存修复带来的行为变化；简洁风格可减少 token 消耗，适合高频交互场景。
