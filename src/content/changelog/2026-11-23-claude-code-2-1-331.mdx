- Code Mode 支持 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 与 AWS 上的 Claude Platform，终端会话即可用；harness 需按云厂商区分脚本执行与权限边界。
- `claude_code.llm_request` trace span 新增 `gen_ai.usage.*`、`gen_ai.response.model`、`gen_ai.operation.name`，其中 input_tokens 含 prompt cache；harness 可据此做成本与缓存命中观测。
- 插件 manifest 新增 `optionalDependencies`，依赖随插件安装但可单独禁用或卸载；harness 的插件生命周期管理需区分必需与可选依赖。
