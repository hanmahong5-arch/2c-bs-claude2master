- 通过单一 Gateway 连接 Discord、iMessage、Signal、Slack、Telegram、WhatsApp 等 20+ 渠道，官方插件一键安装。这意味着 agent harness 需要抽象出统一的 channel 接口，让 prompt 设计不必为每个平台重复适配。
- 支持多智能体路由，每个工作空间或发送者拥有隔离会话，群聊通过 @提及激活。这要求 prompt 中明确 session 标识和路由规则，避免上下文污染。
- 内置媒体处理（图片、音频、视频、文档）及生成能力，支持语音转录和 TTS。agent harness 需提供统一的 media I/O 抽象，prompt 中可声明模型支持的媒体类型。
