- **AscendGYM 基准**：深圳团队发布面向华为 Ascend NPU 的内核优化基准，让 agent 在保证正确性的前提下自动改进内核性能；测试中 Opus 5 得分最高但更耗 token，GPT-5.6 更省 token。含义：出口管制下，这类工具是中国用 AI 自我改进算力底座的路径。
- **SciResearch-Eval**：LLNL 让 agent 自主设计实验、在可能失真的模拟器上报告 95% 置信区间；只有 GPT-6 Astra 与 Claude Fable 5.2 在默认设置下可靠。含义：agent 需具备"诚实的不确定性"，否则下游无法分辨错误。
- **Noeri 新实验室**：Yejin Choi 与 Carlos Guestrin 创立，融资 1.1 亿美元，主张由多个依托专有数据的专门模型定义前沿，而非单一巨型模型。含义：agent 编排与持续学习成为差异化方向。
