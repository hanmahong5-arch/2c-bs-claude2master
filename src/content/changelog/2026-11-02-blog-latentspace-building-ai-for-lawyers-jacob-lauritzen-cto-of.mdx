- 客户文件几乎全是保密数据，Legora 无法读 trace，只能由 3 名工程师加 3 名律师搭建 RL 环境复现真实工作（如万份文件的数据室尽调），再按业务领域画热力图。含义：agent 团队要把 eval 从“看日志”转为“造环境”。
- 生产环境把失败归为 10–20 种已知 failure mode，用廉价 LLM 检查并挂在 feature flag 后；基础设施全在 Azure，因为律所早期不接受 AWS/GCP。含义：合规约束会直接决定技术选型。
- 产品围绕 projects、agent、Tabular Review、lists 几个原语搭建，法律工程师不写代码即可配置新产品，FDE 才写代码进生产且不碰客户数据。含义：少原语加配置层，是 agent 产品规模化的可行路径。
