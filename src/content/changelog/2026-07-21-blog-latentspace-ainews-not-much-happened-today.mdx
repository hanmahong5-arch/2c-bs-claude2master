- Kimi K3 在 agent 和前端任务上表现突出，DesignArena 排名第一，Arena 排名第四，接近闭源前沿模型，且推理成本更低，意味着开源模型在 agent 场景已具备竞争力。
- 美国考虑限制中国开源模型，但技术界普遍反对，认为开源模型是安全必需品——Hugging Face 在安全事件中因商业 API 限制而使用自托管 GLM-5.2，证明开源对防御性安全至关重要。
- 研究转向系统级泛化：RLM 通过精心设计的 harness 实现任务长度 8-32 倍泛化，表明归纳偏置正从模型参数转移到编排层，agent 设计正从模型中心转向系统中心。
