- 文章基于对科学家的调研，梳理他们在研究流程中愿意让 AI agent 介入与不愿放手的环节，说明自动化边界取决于任务的可验证性与责任归属。对 agent 设计者的含义：能力宣传之外，需按任务风险分级设计人机协作。
- 科学家对 agent 的信任与其能否核查输出直接相关，不可验证的环节更倾向保留人工判断。对工具链的含义：可追溯的日志、引用与复现步骤是进入科研场景的前提。
- 文章呈现的分歧说明科研界尚未形成统一标准，采用程度因领域与个人而异。对开发者的含义：面向科研的 agent 产品需支持可配置的自主程度，而非一刀切全自动。
