- 该版本包含与 0.65.5 相同的安全修复，并带来新功能与大量 bug 修复，其中不少来自为 1.0 稳定版做 issue 梳理的努力。对开发者的含义：升级时安全补丁与功能改进可一并拿到，但需留意 1.0 前的行为变化。
- 插件现在可通过新的 `datasette.add_background_task()` 方法启动和管理后台任务（致谢 Alex Garcia）。对工具链的含义：插件生态从请求内同步逻辑扩展到长时任务，适合做索引、抓取等异步工作。
- Datasette 已迁移到 httpx2，用于内部 `datasette.client.get()` 等方法。对 agent 的含义：内部 HTTP 客户端换代意味着依赖该接口的插件与自动化脚本需要验证兼容性。
