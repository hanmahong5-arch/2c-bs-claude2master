- 未发送的 prompt 在切换会话后保留，侧栏 New 回到草稿，Cmd/Ctrl+N 才开新会话：harness 需把草稿状态与会话生命周期解耦，而非绑定当前视图。
- Customize → Connectors 加入搜索、刷新、Installed 与 Suggested 组合，并显示连接器为会话新增的工具数：工具发现与安装应可检索、可预览增量，避免按目录总数误导上下文预算。
- Agent teams 在长会话与队友流式输出时保持速度，首次打开自动压缩既有团队数据：多 agent harness 需内置状态压缩与流式并发路径，否则长会话会拖慢协作。
