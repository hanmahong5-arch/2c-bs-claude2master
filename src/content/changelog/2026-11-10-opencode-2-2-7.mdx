- **SDK 端点不再等待插件加载**：`agent.list` 只返回已加载的 agent，`integration.list`、`vcs.init`、`rpc.call` 等不再最多阻塞 5 秒，改为监听 `*.updated` 事件刷新。含义：harness 需按事件驱动补齐插件提供的条目，不能假设首次调用即完整。
- **MCP 登录与工具调用更健壮**：多客户端并发刷新 token 或 token 端点短暂失败不再登出；工具结果不符合自身 output schema 时不再报失败。含义：harness 应把认证刷新做幂等，并区分“执行成功”与“结果校验失败”。
- **`read` 支持负 `offset` 与近似文件名提示**：`-50` 读末 50 行，越界返回末行与总行数；找不到文件时提示大小写、扩展名或拼写相近的路径。含义：文件读取工具可设计为容错返回而非抛错，减少 agent 的无效重试。
