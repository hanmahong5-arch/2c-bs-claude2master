- 新增 `PreModelSwitch`/`PostModelSwitch` 钩子事件，可拦截或注释模型切换；`SessionStart` 恢复钩子提供会话陈旧度和重新缓存成本。
- 前台子代理的工具调用和结果现在实时流式传输到 Remote Control 客户端，后台子代理仍仅显示状态。
- `/usage` 新增花费限制条，状态行新增 `rate_limits.spend_limit` 字段；`/cost` 新增每会话提示缓存行（命中率、未命中、重新缓存令牌、冷/热），状态行脚本可匹配 `prompt_cache` 对象。
- 修复了文件工具在权限检查后跟随符号链接交换导致的越权读写问题，以及插件命令路径穿越、项目设置启用详细追踪等安全漏洞。
- 改进了 Bash 命令输出文件在沙箱中的创建和读取方式，防止重定向或替换。
