- 新增 `CLAUDE_CODE_AUTO_MODE_MODEL`，仅控制客户端自动模式分类器所用模型，不影响服务端自动模式；harness 可把分类判定与主推理模型解耦，按成本单独选型。
- `/config` 新增 Idle compaction 开关，空闲压缩后的提示会说明如何关闭；harness 应把上下文压缩做成可配置策略，而非固定行为。
- fork 子代理在 `claude -p`、Agent SDK、桌面端与 VS Code 默认开启，可用 `CLAUDE_CODE_FORK_SUBAGENT=0` 关闭；主会话子代理固定后台运行，子代理自身的 Agent 调用默认前台，harness 需按层级区分并发与阻塞语义。
