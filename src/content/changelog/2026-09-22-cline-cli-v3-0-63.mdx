- 上下文压缩不再静默退化为截断：摘要器此前沿用会话启动时解析的 access token，主循环每轮刷新后 token 轮换导致 401，失败被截断兜底吞掉，OAuth 与 cline-free/* 模型上最明显；摘要器现在跟随会话当前凭证与模型。含义：压缩路径的凭证与模型必须与主循环同源，否则降级会伪装成成功。
- 压缩触发改用 provider 实际 token 用量而非字符估算，并给摘要器更大输出预算。含义：密集内容（反汇编、图片转储、压缩源码）token 密度远高于估算，估算型阈值会让会话撞上真实上限却不触发压缩。
- 子代理工具调用改为并发执行，审批与 hook 仍按序，父级仍等全部结果；已批准委派后子代理不再重复请求审批。含义：并发会让多个子进程同时抢同一 stdin，一次 y 可能批准多个待定操作，审批必须与并发模型一起重新设计。
