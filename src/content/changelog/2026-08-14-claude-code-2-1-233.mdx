- 新增 GitLab MR URL 支持，`--worktree` 和 agents 视图可显示 `!N`，方便跨平台协作。
- 新增 `CLAUDE_CODE_TOOL_MEMORY_LIMIT` 内存 cgroup 限制，防止构建失控拖垮会话，对资源隔离有参考价值。
- 修复 MCP v2 长连接被服务器超时断开的问题，对 serverless 环境下的订阅稳定性有借鉴意义。
- 修复 Windows 路径绕过 UNC 校验的 NTLM 凭据泄露漏洞，安全加固值得关注。
- Todo 工具在 Opus 4.8 等新模型上默认禁用，需显式开启，模型能力差异需适配。
