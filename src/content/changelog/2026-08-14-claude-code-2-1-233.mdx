- 新增 GitLab MR URL 支持，`--worktree` 和 agents 视图可显示 `!N`，方便跨平台协作。
- 新增 `forward_user_identity` 网关设置，可传递用户身份头，便于代理按用户计费。
- 新增 `CLAUDE_CODE_TOOL_MEMORY_LIMIT` 内存 cgroup 限制，防止失控构建拖垮会话。
- 修复 MCP v2 长连接被服务器超时断开的问题，提升稳定性。
- 修复 Windows 路径绕过 UNC 验证的 NTLM 凭据泄露漏洞，增强安全性。
- 注意：Todo 工具在 Opus 4.8 等新模型上默认禁用，需显式开启。
