- Bun 1.4 是 Rust 重写后的首个稳定版，新增 Bun.WebView，支持通过 macOS WebKit 或 CDP 控制 Chromium，实现浏览器自动化。
- Simon Willison 用 Claude Code 构建了原型服务，可加载网页并执行 JavaScript，灵感来自其 shot-scraper 工具。
- 该服务运行完整 Chrome 处理复杂页面需 192-256MB 内存，为开发者提供了轻量级浏览器自动化方案的参考。
