- Agent SDK 钩子新增 `onFailure: "block"`：回调失败时阻断动作而非放行，harness 应把失败默认视为拒绝，避免静默降级。
- Web 或 shell 工具调用发送账户邮箱前会先询问：harness 需在工具层预留敏感数据外发确认点，而非事后审计。
- OTel 指标、事件与 span 新增 `anthropic.plan`、`seat_type`、`provider`、`custom_base_url`：harness 可据此按套餐与接入方式切分可观测性维度。
