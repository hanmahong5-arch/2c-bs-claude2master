- 会话恢复更可靠：`--resume` 不再丢压缩刚恢复的文件与上下文，也不再漏存回合末尾回复；含义是 harness 需把「恢复」当作可重放的状态机，而非一次性读取。
- 超时与长对话处理变化：中途 API 超时改为从部分响应继续，thinking-only 响应重试；长对话在零 token 用量时改为自动压缩而非报错。含义是 harness 应区分「可续写」与「必须重试」的失败类型。
- 权限与安全边界收紧：`bash -c`/`sh -c` 内的危险 `rm` 不再静默放行，PreToolUse 匹配失败时直接阻断调用。含义是 harness 的默认失败姿态应是拒绝而非放行。
