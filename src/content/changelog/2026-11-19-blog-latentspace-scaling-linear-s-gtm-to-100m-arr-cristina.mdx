- Linear 2025 年 5 月上线 MCP server，如今超过一半的新建 issue 由 agent 创建（一年前仅 3%）。含义：agent 已成为产品的一等用户，接口设计要按 agent 的调用方式来做，而不是只给人用。
- Cristina 认为 SaaS 若只做成「数据库 + MCP server」就是商品化，因此同时盯 agent 使用量和 app 使用量两条线。含义：工具链要保留人回来查看和协调工作的理由，否则容易被替代。
- 公司从未招过 SDR，AE 自己做外联；支持回复由 AI 起草、人工决定发出。含义：销售与支持的人力结构可以围绕 AI 重新设计，但关键判断仍留在人手里。
