- PSF 负责 Python 背后的知识产权、运营 PyPI、赞助核心开发者冲刺并支持社区活动（含每年 PyCon US），还雇有一支精简团队维持运转——对依赖 Python 的工具链与 agent 项目而言，PyPI 的稳定就是供应链的底座。
- 募捐面向公司或个人：如果公司或工作受益于 Python，博主建议今年考虑捐赠——对开发者的含义是，上游非营利的可持续性最终会传导到自己的构建与发布流程。
- Developers in Residence 项目现已包含三名安全开发者（新加入 Brett Smith），专注加固 Python、PyPI 及更广生态——对 agent 与工具链的含义是，包索引与运行时层面的安全投入直接降低依赖风险。
