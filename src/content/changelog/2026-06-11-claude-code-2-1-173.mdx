- **Fable 5 模型名称后缀自动剥离**：修复了带 `[1m]` 后缀的模型名称未标准化问题，Fable 5 默认包含 1M 上下文，后缀现被自动移除。这意味着 agent harness 在处理模型标识时需注意版本后缀的隐式含义。
- **Windows 沙盒依赖误报修复**：解决了 Windows 上沙盒启用时出现的虚假“sandbox dependencies missing”启动警告。这表明跨平台 agent 环境检测逻辑需区分真实缺失与误报。
