- 工作区是唯一工作目录，文件工具和上下文都基于它；绝对路径仍可逃逸，需启用沙箱隔离。
  *含义*：Agent 的“家”就是文件系统根，设计 prompt 时要明确路径边界和安全策略。
- 内置 AGENTS.md、SOUL.md、USER.md 等文件，每会话加载，分别控制操作指令、人格语气、用户身份。
  *含义*：将行为规则、角色设定、用户信息拆成独立文件，比单一大 prompt 更易维护和复用。
- memory/ 每日日志 + MEMORY.md 长期记忆，仅主会话加载 MEMORY.md，避免注入共享上下文。
  *含义*：记忆分短期（每日）和长期（精选），通过文件系统管理，减少 token 浪费并支持检索。
