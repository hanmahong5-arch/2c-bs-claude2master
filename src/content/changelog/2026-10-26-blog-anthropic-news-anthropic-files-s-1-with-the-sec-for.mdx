- 公司已向 SEC 提交 Form S-1 注册声明，拟发行 Class A 普通股并在纳斯达克全球精选市场挂牌，代码 "ANT"；对开发者而言，这意味着模型供应商进入公开市场审视周期，采购与合规评估会多一层财务披露维度。
- 发行股数与价格区间尚未确定，文件明确注册声明尚未生效，生效前不得出售证券或接受购买要约；对依赖其 API 的团队，短期产品节奏不受公告约束，但需留意后续招股书披露的客户集中度与算力成本结构。
- 承销与招股书副本渠道由 Goldman Sachs 与 Morgan Stanley 对接，公告本身不构成出售要约；对工具链选型者，供应商治理与信息披露透明度将成为长期可查的公开信号。
