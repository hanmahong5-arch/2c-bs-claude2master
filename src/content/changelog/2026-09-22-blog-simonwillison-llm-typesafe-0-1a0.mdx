- 新插件 `llm-typesafe` 为 LLM 工具链加入 TypeSafe AI 的 Jev 模型，安装后设置 API key 即可调用，把「是/否」判定、多选分类、打分三类问题变成结构化输出。
- 判定类问题返回形如 `{"type": "noul", "noul": 0.99}` 的置信度结果，例如判断某条消息是否明确要求退款，适合做 agent 的前置路由或风控闸门。
- 选择与打分问题通过 `-o answer_type choice/score` 加 `-o criteria` 传入候选类别或评分标准，可把工单分派、报告可复现性评估等判断交给模型并拿到受约束的答案。
