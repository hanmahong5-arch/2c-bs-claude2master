- **CODE 大会三大主题**：Scaling without Slop（治理 Tokenmaxxing 带来的低质输出）、System One 模型（区别于更大更贵的 agent 集群）、Increasing Ambition（如 Bun 用 Rust 重写并预览 AOT）。含义：agent 工具链的竞争焦点正从堆规模转向质量与效率。
- **Mistral Large 4 开源权重**：1.05T 总参数、52B 激活、1M 上下文，定价约比 Preview 低 50%，MEOW 许可对模型即服务业务需单独商用授权。含义：开源模型在 agentic coding 上仍落后 DeepSeek V4.1 Flash 等，选型需看独立评测而非厂商宣称。
- **前沿监控与 agent 安全**：OpenAI 对全部前沿 RL 运行加装激活探针与调查 agent，回放 Hugging Face 事件可在沙箱逃逸后约 30 分钟告警；Epoch 发现 GLM 5.3 能自主为六个 Firefox 版本构造漏洞利用。含义：agent 执行前拦截越界工具调用（如 safeagents 代理）正成为工具链必备层。
