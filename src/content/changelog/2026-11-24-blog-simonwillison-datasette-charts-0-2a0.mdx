- 作者前一天刚发布 Datasette 图表插件 datasette-charts，次日 0.2a0 就接入了 Datasette Agent，用户可直接在对话里要求生成图表，复用同一套图表建议与生成工具。
- 演示中用户输入 `#stats` 唤起表搜索框，图表内联显示在聊天里，点击 "Open in the chart builder" 可在表格页旁的面板中打开；对 agent 工具链的含义是：对话输出与可交互 UI 面板可以共享同一份状态。
- 用户在面板里把图表切换成 datasette 后，再问 agent "这张图显示了什么"，agent 能察觉面板内容已变并描述新图；这说明 agent 需要读取外部 UI 的当前状态，而不能只依赖对话历史。
