- 新增 opt-in `instant_interrupt`：模型响应或长时 code-mode 调用期间，新输入可抢占并转向（#48135、#48141）。对 agent harness 的含义是：中断需成为一等状态，而非等当前 turn 结束。
- 审批后的命令仍保留显式文件系统拒绝，且可写根下的 `.aws` 目录默认受保护（#48155、#48176）。含义是：批准一次执行不等于放宽既有权限边界，沙箱策略要按路径叠加而非覆盖。
- 移除自动后续提示建议及 `tui.prompt_suggestions` 设置，并移除内置 `plugin-creator` skill（#48621、#48604）。含义是：harness 应减少隐式注入的提示与技能，把控制权交回用户显式配置。
