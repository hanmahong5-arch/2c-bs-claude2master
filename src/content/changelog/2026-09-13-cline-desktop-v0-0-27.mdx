- 登录过期错误只渲染一次：此前 hub 的无详情 `run.failed` 先弹气泡，send RPC 再覆盖错误横幅，导致模糊气泡叠详细横幅；现在失败只显示一次并在详情到达时原地升级。含义：harness 需对同一失败做去重与状态升级，避免多源错误覆盖。
- 凭证失败带修复动作：Cline provider 显示 **Sign in to Cline**，其他显示 **Open model settings**，本地 CLI provider 仍指向其 CLI；启动失败的会话也获得同样提示。含义：错误应附带可执行修复路径，而非仅报错。
- 登出现在真正生效：登出移除 provider 条目，但运行时每次命令都从经典扩展存储的凭证重新导入缺失 provider，导致看似又登录；Cline Pass 登出此前完全无效。含义：harness 需区分持久凭证来源，避免隐式重导入。
