- 推理设置（effort 级别、启用/禁用）现在跨 AI SDK 提供商（含 Ollama）可移植解析，替代了各提供商的 thinking 覆盖，显式禁用优先。
  - 对 harness 设计：统一推理配置接口，减少 provider 特判。
- agent 运行的 `sdk.error` 遥测归因到实际使用的模型，并去除事件属性中的 undefined 值。
  - 对 harness 设计：错误监控更准确，便于定位模型问题。
- 从 models.dev 刷新模型目录，新增 `meta/muse-spark-1.2-contributor`（Cline 提供商）。
  - 对 harness 设计：模型列表更新，可支持新模型。
