- 它是什么：disktree 是一个磁盘占用可视化工具，用树图（treemap）呈现文件系统，帮你定位并删除占满磁盘的内容，面向 Omarchy 环境。
- 为什么值得关注：Rust + GPUI 实现，1362 star，属于近期新建且增长较快的项目；树图交互是排查磁盘占用的直观方式，比纯命令行 du 更易上手。
- 参考价值：对 agent / 工具链 / 后端开发者而言，可作为 Rust + GPUI 桌面 GUI 的实践样例，也可参考其磁盘扫描与树图布局的实现思路。
