- OpenRouter 宣称自动处理 fallback 并为每次请求挑选最划算的选项，但 Mohamed Moustafa 指出这带来一系列问题：不同供应商运行不同的服务软件与优化配置，同一个 OpenRouter 端点返回的模型行为可能并不一致。
- 差异具体到能力层面：某些供应商对视觉模型甚至不具备视觉能力，reasoning effort 选项的处理方式也各不相同，这意味着同一 model ID 的实际表现取决于被路由到谁。
- 作者给出的解法是用 `provider.only` 参数控制路由到哪个供应商，并用 `/endpoints` 方法查询某个 model ID 可用的供应商列表，把不确定性收回到自己手里。
