- **引入 Claude Fable 5 模型**：这是一个 Mythos 级别的模型，能力超越以往所有公开模型，现已开放使用。这意味着 Agent 可以利用更强大的底层推理和生成能力。
- **修复会话保存问题**：解决了从 VS Code 集成终端或继承环境变量的 shell 启动时，会话无法保存转录文本的问题。这确保了 Agent 的工作流程和状态能够被可靠地记录和恢复。
- **修复 --resume 功能**：修复了在上述环境下会话无法出现在 --resume 列表中的问题。这提升了 Agent 的持久性和可中断/可恢复性。
