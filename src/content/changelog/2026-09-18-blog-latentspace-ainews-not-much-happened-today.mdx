- **Claude Code Projects 把多会话编排产品化**：单次对话可派生并行云会话、跨线程传递上下文，用户离开后仍继续运行；Anthropic 内部称其为更高层的 coordinator 抽象。含义：agent 工具链正从「聊天+工具」转向以协调器为中心的长时程运行时。
- **Jev 被当作「AI if 语句」而非聊天模型**：社区用它做 LLM-as-judge、harness 路由、结构化输出，Cloudflare 已通过 AI Gateway 提供。含义：把高频低难决策下沉到小型判别式模型，可让前沿模型专注难推理。
- **Theo 反驳用 Jev 做逐行历史压缩**：压缩不只是过滤，丢弃隐藏推理会损害模型，改写历史还会使缓存前缀失效。含义：分类、记忆管理与推理保留应在 agent 运行时设计中明确分离。
