- 市场改为双栏浏览，左列表右详情，支持分类筛选，便于发现和比较工具。
  - 对 harness 设计：UI 信息架构优化，提升工具发现效率。
- 停止会话会终止所有子代理和队友任务，并持久化取消状态，避免后台孤儿进程。
  - 对 harness 设计：需要实现级联取消和状态同步机制。
- 文件附件可拖放到聊天输入任意位置，降低操作门槛。
  - 对 harness 设计：交互区域扩大，需处理拖放事件边界。
- Cline 提供商模型从实时目录刷新，新模型无需更新应用即可使用。
  - 对 harness 设计：模型列表动态化，需支持运行时更新。
- 401/403 响应归类为认证错误，区分 API 密钥问题与提供商故障。
  - 对 harness 设计：错误处理需细化，便于用户诊断。
- 修复 Langfuse 追踪在发布构建中未初始化的问题，并适配 AI SDK 7。
  - 对 harness 设计：确保遥测在优化构建中正常工作。
- 模型目录更新，新增 TokenGo 和 Volcengine Ark，调整约 36 个提供商的默认模型。
  - 对 harness 设计：默认模型变化可能影响行为，需关注兼容性。
