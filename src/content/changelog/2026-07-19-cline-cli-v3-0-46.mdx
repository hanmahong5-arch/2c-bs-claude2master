- 修复了CLI对Cline API `insufficient_credits`（402）错误的识别，现在能准确检测额度不足。
  - 这意味着agent在额度耗尽时能获得明确的“添加额度”提示，而非通用错误，便于用户快速采取行动。
- 当检测到额度不足时，CLI会显示“add credits”卡片。
  - 这为agent提供了更友好的用户反馈路径，避免因错误信息模糊导致用户困惑。
