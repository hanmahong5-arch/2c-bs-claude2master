- Anthropic 宣布 Claude Cowork 与聊天合并为同一个 Claude，先向 Pro 和 Max 用户开放，未来几周在网页、桌面和移动端逐步推送。对开发者的含义是：面向 Claude 的集成不必再区分 Cowork 与普通聊天两个入口。
- 作者指出合并后 Claude 可在你合上笔记本后继续处理任务，例如中午要交的报告。这意味着 agent 的持久化后台执行正成为通用助手的基础能力，而非编程工具专属。
- 作者将此与 OpenAI 几周前把 Codex 桌面应用改名为 ChatGPT 相提并论，并坦言自己原本打算梳理 Cowork 与 Claude 边界的写作计划因此作废。对工具链而言，各家正把编码 agent 收编进统一助手品牌，选型时需重新评估产品边界。
