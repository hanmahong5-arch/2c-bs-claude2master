- 作者发现，在 macOS 上让编码代理使用 Blender 非常简单：只需安装完整的 Blender 应用，然后通过自然语言提示词（如“使用已安装的 Blender 渲染一个骑自行车的鹈鹕场景”）即可驱动其 Python API 生成图像。
- 通过后续提示词（如“添加背景和更多趣味”、“让它变得更好”）可以迭代优化生成结果，这表明编码代理能够理解并执行复杂的图形渲染任务，而无需用户手动编写脚本。
- 这一工作流程对开发者意味着，编码代理可以成为强大的创意工具，将自然语言指令转化为具体的视觉输出，从而降低 3D 渲染和图像生成的门槛，并可能催生新的自动化内容创作方式。
