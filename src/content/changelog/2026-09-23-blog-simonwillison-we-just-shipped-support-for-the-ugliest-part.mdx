- Cloudflare 多年来在缓存时忽略图片以外请求的 Vary 头，导致按 `accept: text/html` 返回 HTML、否则返回 JSON 的站点可能把 JSON 缓存后喂给要 HTML 的访客。含义：依赖内容协商的 API 在 CDN 后面长期不可靠，缓存层对 Vary 的支持是工具链里容易被忽略的坑。
- 作者表示自己等这个 Cloudflare 功能等了很多年，但即便功能上线，他仍决定不用这种模式。含义：基础设施补齐能力不等于最佳实践改变，开发者对可预测性的偏好可能独立于工具限制。
- 他更倾向让 URL 明确决定返回格式，在自己的应用里加 `.json` 后缀来提供 JSON。含义：显式 URL 约定比隐式请求头协商更易调试、缓存和测试，对 agent 调用接口也更友好。
