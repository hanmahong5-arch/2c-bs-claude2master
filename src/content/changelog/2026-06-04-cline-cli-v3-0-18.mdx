- **修复 Slack 频道提及**：回复现在会发布在原始消息的线程中，确保对话连贯性，对需要维护上下文完整性的 agent harness 设计至关重要。
- **修复任务取消指示器**：任务取消时指示器立即清除，提供更清晰的用户反馈，这对构建响应迅速、状态明确的 agent 系统有直接影响。
- **同步 Fireworks AI 模型注册表并更新 SDK**：刷新了捆绑的模型目录以匹配当前平台产品，并强制 Cline Hub 重启以使用最新 SDK 代码，确保 agent harness 能始终访问最新、最稳定的模型和功能。
