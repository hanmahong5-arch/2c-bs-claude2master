- ARTEX 是一个用 Go 编写的 AI 自主渗透测试系统，把渗透测试流程交给 agent 自主执行，替代人工逐步操作。
- 值得关注的点在于它来自百度 agent+ 攻防挑战赛并拿到冠军，属于有实战评测背书的安全 agent 项目，而非纯 demo；Go 实现也便于部署成服务。
- 对做 agent 的开发者，它提供了一个安全攻防场景下的自主任务编排参考；对后端和安全工具链方向，可观察 agent 如何接入渗透测试工具链。
