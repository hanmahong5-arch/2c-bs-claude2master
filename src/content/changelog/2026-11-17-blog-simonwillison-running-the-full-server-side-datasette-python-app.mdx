- 新版用 Service Worker 拦截请求，把 Datasette 页面路由到 Web Worker 里的 Pyodide 实例；每个标签页用随机 session ID 前缀隔离，避免多标签共享同一实例。对 agent 工具链的含义：浏览器内可复现完整服务端环境，演示和调试不必再起服务器。
- URL 参数可指定 PyPI 上的 Datasette 版本、GitHub commit/tag、100 多个 SQLite 版本，以及任意插件 wheel。含义：bug 复现和功能演示可以做成一条可分享链接，天然适合作为 agent 的可验证产物。
- 作者用 lite.datasette.io 链接对比 1.0a42 与 1.0a43 的分页 bug，并新增 ?sqlite= 参数加载 163 个 WebAssembly 编译的 pysqlite3 版本。含义：依赖版本矩阵测试可下沉到浏览器端，降低环境搭建成本。
