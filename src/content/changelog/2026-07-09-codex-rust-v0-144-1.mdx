- 修复了 GitHub 返回紧凑或重排序的发布元数据时独立安装失败的问题。
  - 含义：agent 的安装流程需要兼容不同格式的元数据，避免因外部 API 变化而中断。
- 确保 macOS 包安装时，`code-mode` 主机与 `codex` 可执行文件一同暴露。
  - 含义：agent 的部署应确保所有必要组件（如主机二进制）正确暴露，避免功能缺失。
- 当配套主机二进制不可用时，回退到嵌入式运行时以保持代码模式工作。
  - 含义：agent 应具备降级策略，在依赖组件缺失时仍能提供核心功能。
