- 修复 MCP SSE 连接在服务器错误响应后陷入重连循环的问题，提升 agent 与外部工具通信的稳定性。
- 修复 provider 模型配置中交错推理字段（如 `reasoning_text`）的解析，确保自定义字段正确生效。
- 桌面端外部链接改为系统浏览器打开，避免应用内嵌浏览器干扰 agent 工作流。
- 修复会话标签页状态过期、文件树标签裁剪、调试 gutter 标签错位等 UI 问题，提升桌面端操作可靠性。
