- Claude Sonnet 5 成为 Claude Code 默认模型，原生支持 1M token 上下文窗口。
  - 设计含义：Agent 可处理更长对话历史或代码库，需注意 token 消耗与延迟。
- 促销定价为 $2/$10 每百万 token，持续至 8 月 31 日。
  - 设计含义：低成本窗口鼓励更频繁的上下文重用，但需监控预算。
- 需更新至 v2.1.197 才能使用新模型。
  - 设计含义：版本锁定确保兼容性，升级前需测试现有 harness 集成。
