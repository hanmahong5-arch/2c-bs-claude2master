- 新增 `sandbox.filesystem.disabled` 设置，可跳过文件系统隔离但保留网络出口控制，为 agent 提供更细粒度的沙箱配置。
- 修复长会话中消息归一化成本随轮数二次增长导致的卡顿，agent 在持续交互中应避免 O(n²) 复杂度操作。
- 修复 OAuth 令牌过期后自动模式拒绝命令的问题，agent 需处理令牌刷新并重试授权请求。
