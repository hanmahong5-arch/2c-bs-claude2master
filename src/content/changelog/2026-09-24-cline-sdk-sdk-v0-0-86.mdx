- 文本轮次在输出 token 上限被截断时，每次运行获得一次 compact-and-retry，再走原有 nudge-and-retry；含工具调用的轮次不重放。含义：harness 需为本地 OpenAI 兼容服务的上下文上限单独设计恢复路径，而非只依赖请求的 max_tokens。
- Hub 启动失败原因不再被吞掉，`ensureCompatibleLocalHubUrl` 会附加 cause，新 hub 等待从 8 秒延长到 15 秒。含义：harness 的启动超时应按平台冷启动实测值设定，并保留可诊断的错误链。
- 会话重命名改为 `session.update` 独立传 `title`，不再整体替换 metadata；终端错误作为仅展示的历史条目持久化，且不进入压缩与模型上下文。含义：harness 需区分展示态与模型可见态，避免 UI 状态污染上下文。
