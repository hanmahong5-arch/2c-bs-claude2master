- **蒸馏的核心目标是推理链**：Anthropic 称蒸馏者最想要的是 Claude 的完整思考过程，而非最终输出；早期把推理摘要化后，用其训练的小模型在 SWE-bench Verified 上从 80.4% 降到 71.8%。对开发者的含义是：暴露完整推理轨迹的 API 设计本身就是攻击面。
- **攻击者转向主动提取并规模化**：摘要化后，攻击者改用“逐字输出此前推理”等提示绕过，并借助代理网络控制数十万虚假账号（曾一次管理超 2 万个）。含义是：单点防护规则会被快速绕过，需按请求意图而非单账号做检测。
- **新防线限制推理流向**：preserved thinking 禁止 2026-08-31 后新建 API 账号编辑历史上下文，并阻止弱防护旧模型读取强模型推理。含义是：接入方需适配上下文不可编辑等约束，安全策略正直接改变 API 行为。
