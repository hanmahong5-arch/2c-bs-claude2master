- 新增免费 Cline 模型，模型选择器中显示“(free)”，达到免费限制时显示专用错误卡片并包含重置时间。
  - 含义：agent 需处理模型配额状态，在错误时提供用户可操作的反馈。
- 修复 CLI 因 max-turns 错误退出时，已流式传输的 Claude Code 响应被丢弃的问题。
  - 含义：agent 应确保部分有效输出不被丢失，提升容错与用户体验。
