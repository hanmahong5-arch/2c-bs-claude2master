- 新增 OAuth 预注册客户端支持，并强制安全 token 传输，弃用 Gemini OAuth。
  - 对 harness 设计：需确保 OAuth 流程符合安全规范，并注意 provider 兼容性。
- 修复上下文超限错误处理，包括字节大小限制和显式禁用思考。
  - 对 harness 设计：需统一错误分类，并针对模型能力调整请求参数。
- 引入 unrolled agent loop 状态机，并泛化以支持多种 agent 类型。
  - 对 harness 设计：可复用状态机简化循环控制，提升可扩展性。
