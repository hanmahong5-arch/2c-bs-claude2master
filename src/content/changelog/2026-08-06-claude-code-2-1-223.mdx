- 新增 `owner/*` 通配符支持，可批量允许或阻止 GitHub 组织下的所有 marketplace 仓库，简化策略配置。
- 修复多个权限绕过漏洞，包括 Bash 命令隐藏、动态 import 逃逸沙箱等，提升 agent 执行安全性。
- 自动压缩逻辑更新，对未知模型 ID 强制限制上下文窗口，避免会话无限增长。
- `/review` 改为 `/code-review` 别名，并支持记忆上次使用的审查级别，提升工作流效率。
