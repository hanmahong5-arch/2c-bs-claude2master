- 全面采用 ACP（Agent Communication Protocol）管理会话、配置和扩展，为 agent harness 提供统一通信接口。
- 新增图像读取工具、模型交互查看、缓存 token 追踪，提升 agent 感知和成本控制能力。
- 支持 OpenAI GPT via Bedrock、MLX 本地推理、多个新 provider，扩展 agent 模型选择。
- 新增 `/status`、`/model` CLI 命令，支持 deep link 和会话导入，改善 agent 交互与可移植性。
