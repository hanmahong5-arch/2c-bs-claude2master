- npm 包根目录新增单个 `THIRD_PARTY_NOTICES.txt`，覆盖所有平台二进制：harness 分发多平台产物时，合规文件可集中管理而非按平台拆分。
- 内置模型目录刷新，OpenAI 选择器不再列出上游标记为 deprecated 的 id，含 `gpt-4o`、`gpt-4.1`、`gpt-5`、`o3`、`o3-pro` 等：harness 的模型清单应以上游目录为准动态过滤，避免硬编码过期 id。
- `gpt-5.3-codex-spark` 不再对 ChatGPT 订阅列出：同一模型在不同鉴权方式下可见性不同，模型选择逻辑需按订阅类型区分。
