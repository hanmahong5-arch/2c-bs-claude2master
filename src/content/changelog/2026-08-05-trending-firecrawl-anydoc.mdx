- 它是什么：anydoc 是一个 Rust 库，可将 Word、PPT、Excel、OpenDocument、RTF、EPUB、CSV 和 PDF 转换为干净的 Markdown，并提供 Node.js 和 Python 绑定。
- 为什么值得关注：项目上线即获近 2000 star，解决文档转换痛点，尤其适合 AI 数据预处理和知识库构建。Rust 实现保证高性能和内存安全，多语言绑定降低使用门槛。
- 参考价值：对 agent 和工具链开发者而言，可作为文档解析层，为 RAG 或自动化工作流提供结构化文本；其架构设计也值得 Rust 库作者借鉴。
