- **新增 `/usage` 用量分类统计**：清晰展示技能、子代理、插件及 MCP 服务器的成本驱动，便于资源管理与优化。
- **修复多项安全沙盒漏洞**：包括 PowerShell 权限绕过、git worktrees 沙盒白名单过宽、变量追踪失效等问题，提升了代码执行环境的安全性。
- **优化界面交互与修复工具缺陷**：`/diff` 视图支持键盘滚动、Markdown 渲染任务列表、修复思维指示器状态、参数提示显示等多项问题，提升了用户体验与工具可靠性。
