- smolmachines 提供基于 Firecracker 的微虚拟机，用于安全运行不可信 Python 和 JavaScript，限制 CPU、内存、网络和文件系统访问。
- 在 Claude Code for web 环境中因缺少嵌套虚拟化而无法运行，但通过 GitHub Actions 的 /dev/kvm 支持成功执行测试，展示了灵活变通。
- 对开发者而言，这为执行用户提交的数据转换任务提供了安全沙箱方案，但需注意环境依赖（如 KVM）和资源限制。
