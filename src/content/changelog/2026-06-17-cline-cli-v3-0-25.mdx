- **新增 ClinePass 支持**：模型选择器现可选用 ClinePass 模型，扩展了模型集成选项，意味着 Agent Harness 设计需支持灵活的多模型切换机制。
- **引入 MCP 服务器插件支持**：插件安装时可授权 MCP OAuth，增强了插件安全性，要求 Agent Harness 集成时需考虑 OAuth 流程自动化。
- **优化工具调用与输出管理**：鼓励并行工具调用以加速任务执行，并限制 bash 命令和文件读取的输出大小，这要求 Agent Harness 设计需平衡并发性能与上下文限制。
