- **Claude 用于刚果埃博拉应急**：一种无确认疫苗的罕见埃博拉毒株正在刚果（金）传播，全球卫生组织用 Claude 尽快响应。含义：高风险公共卫生场景已把模型纳入实际工作流，对 agent 的可靠性与可审计性要求更高。
- **Claude Code 从内部 CLI 长成编码 agent**：文章由研究者、工程师和早期用户讲述其从内部命令行工具到 Anthropic 编码 agent 的经过。含义：编码 agent 的产品形态往往源于内部自用工具，工具链设计值得参考。
- **火星车首次 AI 辅助规划行驶**：Claude 帮助 NASA 毅力号在火星行驶四百米，被称为另一颗行星上首次 AI 辅助驾驶。含义：长延迟、不可干预环境下的规划能力，是 agent 落地的重要验证场景。
