- 已在其他 Cline 应用运行的任务改为附加到该运行，不再启动无法停止的第二个实例；应用中途关闭时等待请求会明确失败。含义：harness 需把任务所有权与失败语义显式化。
- `cline hub status` 与 `cline doctor` 对冻结 Hub 的健康检查 3 秒超时并报告未运行。含义：外部依赖探测必须有硬超时，避免 harness 整体挂起。
- 仅流式输出 reasoning 后断连的回合现在会重试，模型请求最多重试 3 次（原 5 次）。含义：重试判定应基于已产生内容，并设上限控制成本。
