- **agent 已成主要生产者**：Linear 2025 年 5 月上线 MCP server，如今超过一半的 issue 由 agent 创建（一年前仅 3%）。含义：工具链要为 agent 设计一等公民接口，而非只服务人类点击。
- **警惕沦为「MCP 上的数据库」**：Cristina 认为若产品内 agent 工作流不如外部，用户就没理由打开 app；她同时盯 agent 用量与 app 用量两条线。含义：agent 集成要保留人类回来看与协调的界面。
- **AI 预算与一年期合同**：买家开始签一年合约和付费试点而非三年，部分「一夜 $100M ARR」实为少数三四千万美元大单。含义：续约季将检验哪些 ARR 是真的。
