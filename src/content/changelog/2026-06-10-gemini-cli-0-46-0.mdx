- **修复 PTY 调整大小导致的本地崩溃**：增强终端模拟器在尺寸变化时的健壮性，意味着 Agent 工具链需要处理更稳定的子进程 I/O。
- **防止无效编辑器配置引发垃圾邮件循环**：当 `preferredEditor` 设置无效时，避免系统陷入重复错误提示，要求 Agent 环境配置具备验证与优雅降级机制。
- **实验标志存在时自动切换至 GA 模型**：简化了模型版本的升级路径，提示 Agent 框架应支持基于标记的无缝功能切换。
