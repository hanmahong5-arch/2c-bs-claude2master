- uv init 现在默认创建 src/ 布局的项目，而非在根目录放 main.py，这鼓励更规范的 Python 项目结构。
- 新项目自动配置 uv_build 后端，支持 wheel 和 tar.gz 构建，简化了发布流程。
- 设置脚本别名 uv-run-uv-init 执行 main()，方便快速运行项目，对开发者意味着更一致的开发体验。
