- 使用 `osascript -e 'tell application "Safari" to count tabs of every window'` 即可获取每个窗口的标签页数。
- 该命令返回每个窗口的标签页数列表，而非总数，适合快速查看分布。
- 对开发者而言，这种小技巧展示了 AppleScript 在浏览器自动化中的潜力，可扩展为更复杂的标签管理脚本。
