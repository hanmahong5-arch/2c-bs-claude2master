- GPT-Live-1 在 API 中提供自然、全双工的语音对话能力，即双方可同时听说，而非传统轮流式语音交互。对 agent 的含义是语音代理可以像真人通话一样被打断和插话，交互延迟与轮次管理的设计需要重做。
- 该模型带来更强的指令遵循能力，并支持自定义音色。对工具链的含义是语音 agent 的提示词与音色配置可纳入版本化管理，便于按场景复用。
- 同时支持电话（telephony）场景。对开发者的含义是语音 agent 可直接接入电话通道，客服、外呼等场景的落地路径被缩短。
