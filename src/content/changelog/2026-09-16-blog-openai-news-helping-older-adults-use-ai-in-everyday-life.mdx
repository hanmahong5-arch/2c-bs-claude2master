- OpenAI 与 AARP 合作，在美国 10 座城市为 1000 名老年人提供免费的 ChatGPT 线下实操工作坊，目标是建立日常可用的 AI 技能。对做 agent 和工具链的人来说，这意味着真实用户里存在一批需要强引导、低门槛交互的人群，产品不能默认用户懂 prompt。
- 课程强调“安全地”使用，说明面向非技术用户的 AI 落地，信任与风险提示是和功能同等重要的组成部分。做面向大众的 agent 时，护栏和解释性交互不是可选项。
- 选择线下、动手的工作坊形式而非纯线上文档，暗示技能习得依赖陪伴式教学。对开发者工具而言，onboarding 和示例场景的设计质量，可能比 API 能力本身更决定采用率。
