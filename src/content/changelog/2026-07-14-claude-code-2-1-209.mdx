- 修复了 `/model` 等对话框在 `claude agents` 后台会话中被阻塞的问题，原因是回退了一个过于宽泛的防护。
- 这意味着 agent 在后台运行时，用户仍可正常与对话框交互，不会因防护误判而卡住。
- 设计含义：agent 的 UI 交互路径需要更精细的权限控制，避免全局防护影响核心功能。
