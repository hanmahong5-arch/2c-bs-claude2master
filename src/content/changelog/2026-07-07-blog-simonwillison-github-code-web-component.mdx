- 该组件将GitHub URL转换为raw.githubusercontent.com链接，通过fetch()获取文件内容，并显示指定行号范围的代码。
- 目前不支持语法高亮，但提供了轻量级嵌入方案，适合文档或博客中引用代码片段。
- 对开发者而言，这种模式简化了代码分享，无需依赖第三方服务或后端渲染，可直接在静态页面中使用。
