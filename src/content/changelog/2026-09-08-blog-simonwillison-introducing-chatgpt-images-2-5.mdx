- OpenAI 图像生成模型已生成超 30 亿张图片，新版本提升多轮指令遵循能力、响应速度，并更好地保持参考照片中的主体。
- API 新增两个模型 ID：gpt-image-2.5-sunburst 和 gpt-image-2.5-flare，前者适合编辑精度要求高的场景，后者适合快速日常生成。
- Simon 升级了开源 CLI 工具 openai_image.py，支持传入参考图片，通过 uv 命令即可实现“添加一只研究图表的浣熊科学家”等创意编辑，展示了工具链的灵活性。
