- 作者先用 ChatGPT Images 2.5 生成一枚以剧集 Pluribus 为主题的法贝热彩蛋图片，再把它贴进 Codex 的 GPT-6 Astra，让它调用本地 Blender skill 建模，跑了 17 分 51 秒产出多个 .blend 文件。含义：图像生成 + 编码 agent + 本地工具 skill 已能串成一条从概念图到 3D 资产的流水线。
- 他把之前随手 vibe-code 的 Blender 查看实验整理进自己的 tools 集合，现在可以在浏览器里直接查看这个 Pluribus 模型。含义：agent 产出的中间产物需要轻量查看器，否则人无法验收。
- 文中提到 skill 文件是他自己按某种方式创建的，并链接了相关 TIL。含义：把本地能力封装成可复用 skill 文件，正成为让 agent 稳定调用 Blender 这类工具的关键做法。
