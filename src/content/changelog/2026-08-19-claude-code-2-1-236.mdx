- 新增 `ANTHROPIC_DEFAULT_MODEL` 环境变量，设置新会话默认模型，`/model` 可覆盖并持久化。
  - 对 harness 设计：提供更灵活的模型配置入口，需区分默认与覆盖逻辑。
- 跨会话 `SendMessage` 支持 `notify_when_idle`，请求另一会话空闲时通知，一次性且无需轮询。
  - 对 harness 设计：实现跨会话协作需考虑异步通知机制和生命周期管理。
- 沙箱在 macOS 上通配符读拒绝规则优先于允许区域，覆盖目录内容且防重命名绕过。
  - 对 harness 设计：安全策略需处理规则优先级和绕过防护。
