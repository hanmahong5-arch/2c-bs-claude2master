- Lobsters 完成从 MariaDB 到 SQLite 的迁移，CPU 和内存使用下降，站点响应更快，VPS 成本减半。
  - 对开发者：SQLite 在中等规模 Web 应用中可作为主数据库，降低运维复杂度。
- 迁移后 Rails 应用运行在单台 VPS 上，主数据库文件仅 3.8GB，另有缓存、队列和反滥用数据库。
  - 对工具链：SQLite 的轻量特性适合单机部署，减少分布式数据库的维护开销。
- 迁移 PR 仅增删 735/593 行代码，基于多个前置 PR，展示了渐进式迁移的可能性。
  - 对 agent：SQLite 的简单性使自动化运维和迁移更易实现，适合资源受限场景。
