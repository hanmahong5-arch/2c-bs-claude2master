- TUI 新增 `/export` 将完整对话导出为 Markdown，可复制到剪贴板或存为新文件。
  - 对 harness 设计：对话记录可导出，便于审计和复用。
- `codex exec fork` 支持会话分叉，TUI 恢复选择器可归档/恢复会话。
  - 对 harness 设计：会话管理更灵活，支持分支工作流。
- 新增 Amazon Bedrock Runtime 内置 provider，支持 AWS profile、region 和 GPT-5.6 路由。
  - 对 harness 设计：多 provider 支持，需考虑配置和认证的抽象。
- Hooks 现在可异步运行命令并调用 MCP 工具。
  - 对 harness 设计：hooks 能力增强，可集成外部工具，但需注意异步生命周期管理。
- 修复：模型切换不再留下陈旧指令，恢复会话保留工作目录和审批策略，MCP 服务器在 OAuth 重新认证后自动恢复。
  - 对 harness 设计：状态一致性提升，减少中断。
