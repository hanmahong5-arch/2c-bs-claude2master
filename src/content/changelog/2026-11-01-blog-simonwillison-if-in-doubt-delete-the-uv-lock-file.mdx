- 作者的项目多为库，本不该提交 uv.lock；但 `uv run pytest` 会留下被 .gitignore 忽略的本地 lock 文件，它可能把依赖钉在没有 Python 3.15 wheel 的旧版本上。含义：本地生成的 lock 文件会悄悄污染工具链行为，需要纳入排查清单。
- 文中实例：`watchfiles==1.1.1` 构建失败，报错指出配置的解释器版本 3.15 高于 PyO3 支持上限 3.14。含义：解释器升级与原生扩展的兼容窗口错位，是 agent 自动跑测试时常见的假故障源。
- 处理方式很直接：删掉该文件后重跑 `uv run pytest`，问题通常消失。含义：对自动化脚本而言，可把“清理本地 lock 再重试”作为低成本的一步，而非直接改依赖声明。
