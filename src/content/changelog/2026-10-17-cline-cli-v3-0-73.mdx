- 修复 GPT-6 模型（如 `gpt-6-sol`、`gpt-6.1-sol`）在 OpenAI 与 Azure OpenAI 兼容端点上的请求：此前 Cline 发送 `max_tokens` 而非 `max_completion_tokens`，导致所有请求被拒。含义：harness 需按模型族切换 token 上限参数名，硬编码单一字段会直接阻断新模型接入。
- 未选择模型时，Cline provider 默认回到 Claude Sonnet 5.5，并重新位列推荐榜首。含义：默认模型策略应可随推荐列表更新，而非固定写死。
- 刷新模型目录，新增 CommandCode 与 Reflection 两个 provider，并调整 302.AI、Eden AI、Prime Inference、CoreWeave、NanoGPT、Pioneer、Scaleway 的默认模型。含义：provider 与默认模型需作为可更新配置管理，避免与代码耦合。
