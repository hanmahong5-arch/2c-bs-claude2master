- 同账号并发 feature-flag 轮询现在共享同一在途请求，失败会传播以便重试，切换账号不再等待旧请求；含义：harness 的缓存新鲜度必须在网络完成后才标记，否则竞态调用会读到默认值。
- Windows 上新增 `disableCurrentDirectoryExecutableSearch()`，在进程启动时设置 `NoDefaultCurrentDirectoryInExePath`，阻止工作区里伪造的 `rg.exe` 等在审批前被执行；含义：宿主应在任何 spawn 之前调用，覆盖所有子进程。
- 压缩触发改用 provider 上报的输入 token 数，取 `max(估算, 实际)`，默认摘要输出预算从 4096 提到 8192；含义：密集内容下估算会低估真实占用，harness 需以实际用量为触发依据。
