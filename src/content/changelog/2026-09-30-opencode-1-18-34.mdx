- 模型请求现在携带命名空间的 session 与 parent-session 身份头，harness 可据此把子 agent 调用归属到正确会话，便于审计与限流。
- 本地编译的 macOS 二进制会重新签名，确保在 macOS 27+ 上可靠运行，本地构建的 agent 运行时不再因签名失效被系统拦截。
- macOS CLI 发布二进制改用 Developer ID 签名，分发链路更稳定，harness 安装脚本可依赖签名校验而非绕过 Gatekeeper。
