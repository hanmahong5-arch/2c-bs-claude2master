- Claude Sonnet 5 会话不再使用对话中期的系统角色来发送 harness 提醒。
- 这意味着 harness 的上下文管理策略需要调整，不再依赖系统角色注入。
- 开发者应确保 harness 的提醒机制通过其他方式（如用户消息）实现。
