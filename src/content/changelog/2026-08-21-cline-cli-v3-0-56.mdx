- 支持图像生成的模型可在对话中直接产出媒体，TUI 保存临时文件并打印路径，HTML 导出内嵌图片，ACP 客户端接收图像内容。
- Skill 斜杠命令改为通过 skills 工具加载，不再展开到消息中，历史记录显示原始命令，指令只传给模型一次；工作流和 zen 模式仍展开。
- 非聊天模型（图像、语音等）从模型选择器和 ACP 列表中移除，`--model` 拒绝此类模型。
- 修复多个问题：TUI 对话框颜色不随主题变化、账户对话框选择箭头、provider 执行工具活动被丢弃、`PreToolUse` 的 `contextModification` 未生效、`PostToolUse` 钩子输出和取消控制被忽略、`run_commands` 的 ENOENT 错误、PowerShell 命令错误处理、Gemini 自定义基础 URL、远程 hub 的 `cline schedule` 命令授权。
- 使用量显示计费网关成本，模型目录更新，新增多个提供商。
