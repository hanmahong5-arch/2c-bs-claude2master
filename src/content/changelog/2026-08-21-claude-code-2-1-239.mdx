- 成本估算现包含 1.1× 美国数据驻留溢价，影响 /cost、状态行和预算限制。
- Bedrock、Vertex 等新增全屏渲染器，新安装默认全屏。
- 修复 Bedrock 代理剥离 Content-Type 导致重复计费，以及代理下 SSO 启动挂起。
- 修复 JetBrains 终端中 Edit/Write 延迟 5 秒，以及 Esc 竞态导致会话空闲。
- 修复 WebFetch 内存保留过期内容，以及远程 MCP 服务器重连失败。
- 新增 /claude-api upgrade 迁移 anthropic 0.x 到 1.x，超时使用 anthropic.Timeout。
