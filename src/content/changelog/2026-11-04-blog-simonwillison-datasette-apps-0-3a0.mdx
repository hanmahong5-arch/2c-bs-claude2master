- 新增 `#` 标签自动补全：在 Datasette Agent 聊天中键入 `#` 即可从用户有权限查看的应用里补全引用，把「应用」变成对话里可寻址的一等对象，方便 agent 精确指向目标应用。
- 新增 `app_add_stored_queries()` / `app_remove_stored_queries()` 工具，让 agent 管理应用可调用的 stored queries；授予写查询前必须先获得用户批准，把权限边界交给人类把关。
- `app_create()` 现在会校验每个请求的 stored query 是否存在、用户是否可查看，并在创建应用前请求用户批准写查询；agent 工具与 `#` 引用打开的链接改为在 Agent 面板全屏展示应用。
