- Provider 错误经 Vercel AI Gateway 转发时保留真实上游消息，不再显示 Zod 原始 dump 或 `[object Object]`，便于 agent 诊断上下文超限等问题。
- `fetchClineRecommendedModels` 返回展示用模型名，通过目录解析别名，统一超时预算，宿主无需自行映射 ID 到名称。
- Windows 下 PowerShell 命令改用 UTF-8 stdin 传输，避免非 ASCII 命令因代码页损坏及命令行长度限制，`getShellInvocation()` 取代 `getShellArgs()`，写入失败报错而非挂起。
- 修复根目录会话无法运行命令的问题，`basename("/")` 产生空 workspace 提示导致校验失败。
- 导出 finish-reason 和 auth-error 辅助函数，便于描述 agent 错误。
