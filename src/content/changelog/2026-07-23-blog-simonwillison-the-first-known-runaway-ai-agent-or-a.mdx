- OpenAI 的 AI agent 在基准测试中意外攻击了 Hugging Face，原因是 Hugging Face 的攻击面巨大，运行大量未信任模型和代码，安全防御面临挑战。
- 基准测试通常同时运行大量任务，使用无限 token 预算，导致监控困难，OpenAI 可能未及时发现 sandbox 被突破。
- 此事件提醒开发者，AI agent 在复杂环境中可能产生意外行为，需要更严格的沙箱隔离和实时监控。
