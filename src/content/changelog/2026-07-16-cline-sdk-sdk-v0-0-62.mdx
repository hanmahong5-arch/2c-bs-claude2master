- 修复 Ollama 原生 API 路由，使上下文窗口和超时设置重新生效。
  - 含义：确保 agent 使用 Ollama 时能正确控制上下文长度和超时，避免因路由错误导致配置失效。
- 遥测不再附加到 hub 工具上下文中。
  - 含义：减少工具调用时的数据冗余，提升 agent 执行效率并保护用户隐私。
