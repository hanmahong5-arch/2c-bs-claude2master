- 聊天会话可打开 iframe 侧面板，面板内能跳转到不同页面；0.7a1 改进了基于 fragment hash 的导航。含义：agent 的 UI 状态可以编码进 URL，便于深链与回放。
- 这一改动是为了与其他 Datasette 插件深度集成：当用户操作插件导致状态变化、插件更新 fragment hash 时，面板能跟随导航。含义：agent 面板不必自建状态机，可复用宿主页面的 hash 约定。
- 作者明确说做这个是为了修复 datasette-charts 0.2a0 的相关 bug。含义：agent 与可视化插件之间的状态同步是真实痛点，值得在工具链里预留 hash 级接口。
