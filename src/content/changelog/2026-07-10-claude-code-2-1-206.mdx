- `/cd` 新增目录路径建议，与 `/add-dir` 行为一致，减少手动输入。
- `/doctor` 可建议裁剪 `CLAUDE.md` 中代码库可推导的内容，保持文件精简。
- `/commit-push-pr` 自动允许推送到配置的远程仓库，简化 git 操作。
- 后台 agent 在更新后立即升级，避免旧会话升级延迟。
- 修复了过期登录、MCP 超时、OAuth 重认证、`/model` 选择器错位等多项问题。
