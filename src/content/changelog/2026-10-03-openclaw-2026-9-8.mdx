- 发布说明与 changelog 同源双格式：面向人用可展开页面，面向 AI agent 用纯 Markdown，说明 harness 需要能消费结构化变更日志而非只读渲染页。
- 验证链路被完整列出：npm 包、registry tarball、integrity 哈希、release SHA 与多条 CI run 链接，意味着 agent 可据此做供应链校验而非信任标签。
- Telegram 集成检查被发布负责人豁免（source QA、Package Acceptance、published-package E2E 未运行），Android APK 因版本号 2026.8.2 与发布列车 2026.9.8 不匹配而跳过，提示 harness 应显式记录被跳过的验证项。
