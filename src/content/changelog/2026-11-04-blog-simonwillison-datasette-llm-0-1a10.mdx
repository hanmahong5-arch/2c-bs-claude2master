- 版本 0.1a10 修复了一个 bug：可用 LLM 模型集合没有被正确限制为配置中列出的那些，导致 agent.datasette.io 演示站受影响。对搭建 agent 的开发者来说，模型白名单必须由配置强制生效，否则演示环境可能暴露或调用预期外的模型。
- 该问题出现在 Simon Willison 自己的 agent.datasette.io 演示站上，说明这类配置约束的缺陷在真实 agent 部署中容易被忽略。含义是：上线前应显式验证模型列表与配置一致，而不只依赖默认行为。
- 发布说明极短，只点明修复范围与受影响站点，并标注 datasette、llm 两个 tag。对工具链维护者的含义是：小版本修复也应写清影响面，方便下游判断是否需要升级。
