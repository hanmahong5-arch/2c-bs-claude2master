- Linux 专有 NVIDIA 驱动下，应用窗口不再空白：检测到 NVIDIA 驱动时自动关闭 WebKitGTK 的 DMA-BUF 渲染器，混合 GPU 系统可通过 `WEBKIT_DISABLE_DMABUF_RENDERER=0` 保留渲染器。对 agent harness 的含义：环境检测与自动降级是保证跨平台稳定运行的关键。
- Linux `.deb` 和 `.rpm` 包现在包含应用信息，GNOME Software 和 KDE Discover 能显示 Cline 的图标、描述并列入已安装。对 agent harness 的含义：包元数据完整有助于用户发现和管理，降低部署摩擦。
- 本次更新聚焦 Linux 桌面端兼容性与包管理体验。对 agent harness 的含义：底层平台适配直接影响 agent 工具的可访问性和用户信任。
