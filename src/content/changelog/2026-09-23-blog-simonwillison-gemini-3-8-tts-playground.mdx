- Google 发布 gemini-3.8-flash-tts 与 flash-lite-tts，内置 2000+ 音色，并支持用 30 秒音频样本创建自定义声音。对做语音 agent 的团队来说，声音定制门槛被压到一段录音。
- API 可直接定义多角色对话，每个角色配不同音色和风格指令。这意味着多说话人播客、配音类 agent 不必再自己拼接多个 TTS 调用。
- 作者用 GPT-6 Astra 凭 API 的开放 CORS 策略 vibe code 出 BYOK 试玩页；1 分 18 秒音频约 20 秒生成，成本 2.74 美分。对工具链的含义是：前端直连模型 API 已足够便宜可行。
