- 子代理 frontmatter 新增 `autoCompactWindow`，可让子代理比主对话更早自动压缩；harness 需支持按代理粒度配置上下文窗口，而非全局统一。
- 新增 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`，让所有 workflow agent 跑在同一模型上，其他子代理保持各自模型；harness 需区分 workflow 与普通子代理的模型路由。
- Read 工具新增 `allow_large` 选项，可在上下文有余量时一次读取超限文本文件；harness 需把大小限制从硬约束改为可协商的调用参数。
