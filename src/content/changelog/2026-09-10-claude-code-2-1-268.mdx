- 网关新增 `pricing:` 配置，登录客户端通过托管设置拿到相同费率，`/cost` 与遥测和消费计量一致；harness 需把成本口径统一到网关侧，而非客户端估算。
- 修复符号链接目录（macOS `/etc`、`/tmp`、`/var`，Linux `/bin`）上的 deny/ask 规则在按真实路径给出时不生效，以及 Bash 忽略符号链接路径写法的 deny 规则；权限检查必须对路径做规范化后再匹配。
- WebFetch 在服务器保持连接不结束时不再无限挂起，300 秒后失败，可用 `CLAUDE_CODE_WEBFETCH_DEADLINE_MS` 覆盖（0 关闭）；工具调用需要显式超时上限，避免 agent 循环被单个请求卡死。
