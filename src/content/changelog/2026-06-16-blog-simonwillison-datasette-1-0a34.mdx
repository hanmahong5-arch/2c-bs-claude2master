Simon Willison 宣布了 Datasette 1.0a34 版本，核心更新是在其 Web 界面中引入了对数据表的插入、编辑和删除行操作。

*   **新增 UI 数据操作功能**：用户现在可以直接在表格页面和单行详情页进行完整的 CRUD 操作，无需依赖 SQL 查询或外部工具。
    *   *对开发者的含义*：这降低了非技术用户直接与数据库交互的门槛，使 Datasette 更接近一个轻量级、自包含的数据管理平台。
*   **功能灵感源于 Datasette Agent**：此次更新的直接推动力来自为 Datasette Agent（AI 聊天代理）添加的 SQL 写入支持，这凸显了聊天界面能写而主 UI 不能写的矛盾。
    *   *对工具链的含义*：这表明 AI 驱动的交互方式正在反哺和重塑传统工具的用户体验设计，促使功能对齐与体验统一。
*   **长期缺失的核心能力补全**：作者认为此功能“早该实现”，标志着 Datasette 向一个功能更完备的数据库工具迈出了关键一步。
    *   *对 Agent 的含义*：当 AI 代理能通过自然语言操作数据时，为其提供一个直观、一致的可视化操作界面变得至关重要，这构成了人机协作的基础设施。
