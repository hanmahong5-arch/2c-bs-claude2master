- 新增可配置的 rollout token 预算，跨 agent 线程跟踪使用量，在耗尽时自动中止 turn，并给出剩余预算提醒。
  - 含义：agent harness 需要支持 token 预算的全局配置与线程级跟踪，并在预算耗尽时强制中断执行。
- 支持多 agent 委托模式，可在线程和 turn 级别配置为禁用、仅显式请求或主动委托。
  - 含义：harness 需提供灵活的委托策略配置接口，并能在运行时动态切换。
- 新增索引化 web 搜索模式，允许实时搜索但限制直接页面访问为服务器批准的 URL。
  - 含义：agent harness 需集成搜索能力，并实现 URL 访问控制策略。
