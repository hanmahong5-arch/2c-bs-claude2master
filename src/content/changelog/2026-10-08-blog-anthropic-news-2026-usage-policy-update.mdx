- 新增「禁止欺骗性活动」章节，整合虚假账号、影响力操作等规则，并明确禁止构建相关工具和基础设施。对 agent 开发者而言，涉及多账号自动化或内容分发的功能需重新评估合规边界。
- 高风险场景（健康、金融、法律等）要求保留有权限的人类复核，并告知受影响者 AI 参与；连接硬件的自主物理行动需可被操作员观察和停止。这意味着 agent 在关键决策链中必须设计 human-in-the-loop 与紧急制动机制。
- 明确禁止持续恶意对待模型，Claude 可在 Claude.ai 和 Claude Code 中终止极端滥用对话。对工具链而言，交互日志与滥用检测可能成为产品设计的一部分。
