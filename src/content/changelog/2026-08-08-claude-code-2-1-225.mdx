- 新增网关消费限额支持，超限时显示具体额度、重置时间和操作者消息，需网关同步更新。
  - 对 agent harness：需处理限额通知并调整任务调度。
- `claude agents` 对不受信任目录增加工作区信任提示，与 `claude` 行为一致。
  - 对 agent harness：需在启动时处理信任确认流程。
- 修复 OAuth token 被短期 token 覆盖导致 headless 会话中断，以及 MCP OAuth 在 macOS 上因 keychain 超时出现 401 错误。
  - 对 agent harness：需确保 token 管理稳定，避免会话中断。
- 修复自动模式中安全过滤拒绝被计入连续阻止限制，模型被告知继续而非重试。
  - 对 agent harness：需区分安全拒绝与普通限制，优化重试策略。
- SendMessage 现在可按名称启动远程控制会话，且已确认的收件人不会被同名的本机会话替换。
  - 对 agent harness：需支持跨机器会话寻址与身份确认。
