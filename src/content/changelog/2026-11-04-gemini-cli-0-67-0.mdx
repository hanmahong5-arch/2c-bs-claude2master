- **IDE 伴生进程经 exec stdio 桥接进容器沙箱**：沙箱内 CLI 也能拿到 IDE 上下文；harness 需把 IDE 通道当作可跨边界转发的独立传输层。
- **非交互模式处理终止信号，取消后阻止工具执行**：取消成为硬边界；harness 应在每个工具调用前检查取消状态，而非只停流。
- **新增 models 命令与 --list-models 发现模型**：模型清单可运行时查询；harness 不应硬编码模型名，改为动态枚举。
