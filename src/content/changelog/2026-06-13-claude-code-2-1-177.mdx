- 新增 `MAX_FILE_SIZE` 环境变量，限制处理文件大小，避免内存溢出，要求 agent harness 设计时考虑资源边界
- 引入自动重试机制处理临时网络错误，提高容错性，要求 agent harness 设计需包含错误恢复策略
- 修复文件路径处理中的边缘情况，确保跨平台兼容性，要求 agent harness 设计需严格测试路径逻辑
