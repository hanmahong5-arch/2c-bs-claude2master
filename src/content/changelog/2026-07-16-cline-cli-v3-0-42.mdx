- 修复了Ollama原生API路由问题，使上下文窗口和超时设置重新生效。
- 这意味着agent在使用Ollama时能正确应用配置的上下文窗口限制，避免因路由错误导致的截断或超时。
- 对于harness设计，需确保API路由逻辑正确传递参数，避免类似配置失效问题。
