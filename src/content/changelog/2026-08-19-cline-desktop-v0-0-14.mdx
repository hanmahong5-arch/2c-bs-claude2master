- 新增 macOS 原生通知，任务完成或需输入时提醒，可后台运行。
- 支持语音输入，通过麦克风按钮转写，使用已配置的模型。
- 命令输出流式显示，保留终端颜色，可滚动，支持后台运行。
- 支持图像生成模型，图片内联显示。
- 完成的任务折叠为摘要，展开可看详情。
- 推理轨迹和工具行动画展开，尊重减少动态设置。
- 问题卡片重新设计，支持多选和快捷键。
- 设置中 Web 搜索开关说明更清晰，显示可用提供商。
- 助手 markdown 渲染统一，桌面与云端一致。
- 悬停操作浮动，会话卡片简化。
- 新增 Cline Code Beta 应用，独立安装。
- 修复事件流卡住、Yolo 模式误用、命令执行错误等问题。
