- 首 token 延迟降低约 80%（从 4.3 秒降至 0.9 秒），推理模型默认流式输出思考过程。这意味着 agent 启动和响应更快，用户等待感大幅减少。
- 智能审批默认启用：LLM 自动评估标记命令，用户可定义拒绝规则和原因。这减少了人工审批疲劳，同时保持对危险命令的控制。
- 新增可插拔 SecretSource 接口，支持 Bitwarden 和 1Password 获取密钥。API 密钥不再需要明文存储，提升了安全性。
- 子代理任务返回实时转录文件，后台委托结果持久化（即使进程重启也能恢复）。这使多 agent 协作更可靠、可观测。
- 网关新增持久化投递账本，确保最终响应在网关崩溃后重新投递。消除了消息丢失的 P1 问题。
