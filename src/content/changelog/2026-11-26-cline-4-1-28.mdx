- OpenAI provider 不再列出上游标记为 deprecated 的 ID，包括 `gpt-4o`、`gpt-4.1`、`gpt-5`、`o3`、`o3-pro` 等；harness 需按目录动态校验模型名，避免硬编码失效。
- `gpt-5.3-codex-spark` 不再对 ChatGPT 订阅列出；订阅与 API 的可用模型集合需分开建模，不能共用一份清单。
- 新增 Concentrate 与 Prima Labs 两个 provider；provider 注册应做成可扩展表，新增来源不改调用逻辑。
