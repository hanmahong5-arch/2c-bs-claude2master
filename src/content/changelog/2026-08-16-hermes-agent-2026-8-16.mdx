- 桌面应用新增多网关 Connections 注册表、profile 作用域刷新、MCP 健康检查和 deep links，提升多环境管理能力。
- CLI 增强：Windows 更新探测、Kitty 键盘协议支持、chat -c 加固，改善终端交互稳定性。
- 网关支持持久化模型路由、/loop 完成、Telegram DM 主题，并针对 LiteLLM Claude 启用 prompt caching，优化长对话性能。
- 安装器在 Linux 和 Windows 上更健壮，降低部署失败风险。
