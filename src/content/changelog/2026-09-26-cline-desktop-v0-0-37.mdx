- 设置新增 About 页：显示版本与渠道，提供检查更新、重启更新按钮，并列出近期版本 release notes 与 GitHub 链接，还含报告问题入口。对 agent harness 的含义：更新与问题反馈路径集中，便于追踪运行时版本差异。
- 更新后一次性 What's new 弹窗：首期覆盖 SSH remotes、worktrees、composer 中 PR 状态、并行 sub-agents，可在 About 页 Highlights 重看。对 agent harness 的含义：新能力通过内置提示暴露，降低发现成本。
- macOS 上 Help → Export Diagnostics… 直接打开诊断导出，无需进设置查找。对 agent harness 的含义：诊断入口更短，故障排查更快。
- Amazon Bedrock 上经 inference profiles 访问的 OpenAI 模型，设置 reasoning effort 时不再报 Unknown parameter: 'reasoningConfig'。对 agent harness 的含义：推理参数在代理路径下更稳定。
