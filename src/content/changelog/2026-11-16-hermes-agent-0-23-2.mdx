- 修复 Desktop/TUI 在 todo 或 memory 调用旁流式输出后 Stop 按钮不消失的问题（#156553），harness 需把「工具调用结束」与「流式收尾」解耦为独立状态机。
- Telegram 等编辑流式聊天中途崩溃不再重复显示「Recovered reply」，且 `program_id` 这类含键前缀的词恢复按时显示（#156546），流式分片需按词边界而非字符缓冲。
- Desktop 启动并恢复上次会话时不再丢失或打乱用户输入（#156615、#156642），重连后回复只完整显示一次（#156611），会话恢复与输入队列需隔离。
