- IPO 以每股 83 美元发行 11.27 亿股 A 类股（含承销商全额行使 1.47 亿股超额配售权），Anthropic 实收约 916 亿美元，11 月 19 日在纳斯达克以 "ANT" 挂牌。含义：模型公司进入公开市场，融资节奏与披露义务将影响其 API 定价和长期路线图的可见度。
- 同步完成的私募中，AMD、Broadcom、Google、Micron、Microsoft、NVIDIA、TSMC 七方以同价认购 3.13 亿股 N 类股，合计约 260 亿美元。含义：算力与芯片供应方以股权绑定模型厂商，开发者的工具链底层将更受这几家硬件路线牵动。
- 两笔合计毛募资约 1195 亿美元，其中 2364 万股由现有股东出售，Anthropic 不获这部分收益。含义：这是资本结构事件而非产品发布，文章未提及任何模型或 API 变更，不应据此推断能力升级。
