- 它是什么：Claude Code 插件，用 Jev 决策替代压缩摘要。每次工具调用和结果在一次快速请求中评分，过时的被丢弃或截断，保留的内容保持原文。
- 为什么值得关注：解决长会话中压缩摘要丢失细节的问题，通过评分机制保留关键上下文，提升 Claude Code 的长期记忆准确性。
- 对 agent / 工具链 / 后端开发者的参考价值：为 agent 上下文管理提供新思路，可借鉴评分与截断策略优化工具调用历史处理。
