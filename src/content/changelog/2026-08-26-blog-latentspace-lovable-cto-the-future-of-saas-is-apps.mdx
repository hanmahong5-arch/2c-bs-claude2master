- Lovable 正将应用转化为“能力”，通过 MCP 服务器暴露给 ChatGPT、Claude 等 Agent 调用，实现一个应用双接口（人类 UI 与 Agent 接口）。
- 公司愿景是构建“数字大脑”，统一连接内部工具与工作流，Agent 可异步执行任务并返回结果，减少人工切换应用。
- 安全是关键挑战，Lovable 通过“权限图”和加密凭证网关，确保用户身份与源系统权限在 Agent 调用中不被泄露。
