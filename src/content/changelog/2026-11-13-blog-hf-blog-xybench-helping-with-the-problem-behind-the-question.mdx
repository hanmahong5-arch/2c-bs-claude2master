- **问题重述是独立能力**：XYBench 把「用户问的问题」和「用户真正需要解决的问题」拆开评测，模型要先判断提问本身是否偏离目标，再决定怎么答。对 agent 的含义是：直接照字面执行指令，在真实任务里往往是错的。
- **基准覆盖多种偏差类型**：文章围绕提问中隐含的错误前提、模糊目标等情形设计测试项，而不是只测最终答案对不对。对工具链的含义是：评测要加一层「意图校验」，不能只看输出质量。
- **对开发者的直接启示**：在 prompt 或 agent 流程里显式加入澄清与重述步骤，比让模型硬答更可靠。这意味着产品设计上要允许 agent 反问，而不是追求一次成型。
