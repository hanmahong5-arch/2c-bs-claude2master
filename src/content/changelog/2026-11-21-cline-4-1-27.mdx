- `read_files` 结果不再被截到 8k 字符，改为按工具自身上限（2000 行或约 48k 字符）完整送入模型；harness 设计上可减少分页读取与重复调用，但需自行控制上下文预算。
- 推理强度选择现在会真正保存并下发，"None" 也会生效，原生 OpenAI 提供方会按模型能力裁剪档位；harness 不应假设关闭推理一定被接受，需按模型能力映射参数。
- 保存 API key 或 base URL 后模型列表会刷新，失败（如 key 被拒）在模型选择器中报错；harness 应把凭据变更后的列表刷新与错误暴露纳入配置流程。
