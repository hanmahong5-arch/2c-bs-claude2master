- `/rewind` 现在支持从 `/clear` 之前恢复对话，避免丢失上下文。
- 停止后台 agent 后不再复活，任务面板的停止操作永久生效。
- MCP 能力发现与 OAuth 请求自动重试瞬态网络错误，提升可靠性。
- 流式响应 CPU 使用率降低约 37%，通过将文本更新合并为 100ms 间隔实现。
- 沙箱网络权限对话框允许“是”后会话内不再重复提示，减少干扰。
