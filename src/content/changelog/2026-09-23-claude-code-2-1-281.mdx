- Claude apps gateway 新增 Bedrock `assume_role` 与 `guardrail: {id, version}`，并支持 `telemetry.resource_attributes`：上游凭证与合规策略从 agent 侧下沉到网关，harness 不必再自己实现跨账号 STS 与请求级护栏。
- 新增 `"attribution": false` 隐藏 commit/PR 署名，且旧版 CLI 会跳过含该键的 settings 文件：配置格式的向后兼容需要 harness 显式处理，不能假设旧客户端会忽略未知字段。
- 修复恢复会话时重发被改写的历史（并行工具调用、MCP 输入、工具搜索结果）导致 API 丢弃先前推理，以及恢复中断于工具调用的会话时告知结果未知：会话持久化必须保存可重放的原始形态，恢复语义要显式区分“未完成”。
