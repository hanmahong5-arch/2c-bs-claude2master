- 2026 年每月合并 PR 从不足一年前的水平涨到 2.2 亿，提交量超三倍达每月 73.8 亿，且大部分增长集中在下半年——对 agent 工具链意味着吞吐瓶颈正从写代码转向评审与合并环节。
- 新仓库创建速率今年翻倍至每月 3030 万，说明 agent 降低了从零起项目的门槛，开发者工具需要更重视脚手架、初始化与依赖治理。
- 报告方法论用微调多语言 embedding 模型按 NAICS 给仓库分行业，并用 LLM 从用户 profile 提取国家码以校正 VPN 偏差——这提示数据分类本身已可交给模型流水线，但需公开方法以接受审视。
