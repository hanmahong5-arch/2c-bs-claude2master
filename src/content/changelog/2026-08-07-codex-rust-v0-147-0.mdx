- 支持便携式 Agent 插件安装，并可跨本地、个人、工作区和远程目录搜索插件。
  - Harness 可动态发现并加载插件，扩展 agent 能力。
- 会话可按持久化、手动排序的分节组织，长对话支持增量浏览。
  - Harness 需管理分节元数据，优化长上下文导航。
- 新增 `--approve-for-me` 标志，实现自动审查的审批流程。
  - Harness 可配置自动审批策略，减少人工干预。
- 支持 MCP 2026-07-28 协议，包括分页发现、多轮请求和非阻塞服务器启动。
  - Harness 需适配新协议，提升 MCP 集成效率。
- 修复了命令显示和回放历史中秘密和完整 bearer token 的泄露问题。
  - Harness 应确保敏感信息在日志和 UI 中脱敏。
