- Peter Gostev 用 GPT-5.6 Sol 构建了 DOOMQL，核心思想是让 SQLite 成为游戏引擎，而非仅数据存储。
- 游戏通过一个巨大的 SQL 递归 CTE 查询实现光线追踪，所有移动、碰撞、敌人、战斗和像素渲染均由 SQL 驱动。
- 作者利用 Datasette Apps 插件创建 HTML+JS 应用，实时显示游戏画面和迷你地图，展示了 SQLite 作为实时渲染引擎的潜力。

对开发者而言，这证明了 SQL 在非传统场景（如游戏引擎）中的强大能力，并展示了 AI 辅助编程如何快速实现复杂创意。
