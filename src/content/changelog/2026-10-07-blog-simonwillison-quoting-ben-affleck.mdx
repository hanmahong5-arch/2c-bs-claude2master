- 阿弗莱克自述从胶片转数字时代起深入视觉特效流程，能写「挺烂的 Python 脚本」——说明 ML 工具链的门槛已低到非专业程序员也能上手干活。
- 他描述张量就是图像的数字翻译：批次号、帧号、每帧每像素的 RGB 值——这正是今天 agent 处理多模态输入时的底层数据形态。
- 他提到用卷积神经网络做边缘检测与特征提取，例如识别窗台位置以便抠绿幕——这类「识别模式再替换」的流水线思路，与当下工具调用式 agent 的分解任务方式一脉相承。
