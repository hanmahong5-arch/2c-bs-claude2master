- ChatGPT Work 新增 Data agent，用户可用自然语言连接公司数据、挖掘洞察并构建交互式仪表盘。对 agent 开发者的含义：数据分析正被包装成对话式 agent 的标准能力，而非独立 BI 工具。
- 官方强调三件事：连接企业数据、发现洞察、生成可交互 dashboard，全部由 AI 驱动。对工具链的含义：数据接入层与可视化层可能被同一 agent 打通，减少中间 ETL 与报表配置环节。
- 面向对象是“everyone”，即非技术员工也能直接对数据提问。对开发者的含义：企业内数据消费的入口从 SQL/BI 客户端转向自然语言，权限与数据治理会成为新的集成重点。
