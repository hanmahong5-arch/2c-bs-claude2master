- 新增 `codex agents` 交互式仪表盘，可搜索、启动、打开、重命名和停止任务，并支持自定义快捷键。
  - 对 agent harness 设计：任务管理从 CLI 转向可视化仪表盘，需考虑状态同步与快捷键配置。
- 新增 `codex queue` 命令，可向现有本地或远程会话发送消息，且队列消息能可靠唤醒空闲会话。
  - 对 agent harness 设计：支持异步消息投递，需处理会话命名冲突和消息语义保持。
- 扩展 Vim 编辑能力，支持字符替换及 `cw`、`c$`、`cc` 等变更动作。
  - 对 agent harness 设计：TUI 编辑体验增强，需适配不同编辑模式。
- `codex doctor` 新增诊断项，覆盖端点保护、网络/代理故障、桌面应用状态和更新连接。
  - 对 agent harness 设计：诊断能力扩展，便于排查环境问题。
- SDK 支持传递精确 CLI 配置覆盖，并可选择 `max` 或 `ultra` 推理强度。
  - 对 agent harness 设计：SDK 灵活性提升，需确保配置覆盖与推理强度参数正确传递。
