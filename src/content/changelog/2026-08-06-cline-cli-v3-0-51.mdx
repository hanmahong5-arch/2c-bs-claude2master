- 推理强度设置现在跨提供商一致生效，不再依赖各提供商的思考覆盖，包括 Ollama，且关闭推理的请求在所有提供商都被尊重。
  - 对 agent harness 设计：统一推理控制可简化跨模型行为管理，但需注意不同模型对推理支持的实际差异。
- Cline 提供商新增 `meta/muse-spark-1.2-contributor` 模型可选，并刷新了模型目录。
  - 对 agent harness 设计：模型目录更新需同步到 harness 的模型选择逻辑，确保新模型可被正确调用。
- 错误遥测现在报告运行中实际使用的模型。
  - 对 agent harness 设计：错误报告包含模型信息有助于诊断问题，harness 应确保遥测数据准确传递模型标识。
