- Azure GPT-5.5+ 启用推理时请求失败已修复，确保 agent 在 Azure 上使用推理模型稳定。
- 桌面端大图片或附件草稿导致 composer 卡顿已优化，提升 agent 交互流畅度。
- 项目搜索现在匹配所有已知项目，而非仅前五个，扩大 agent 可访问项目范围。
