- ChatGPT Work 是 OpenAI 面向知识工作的代理产品，基于 Codex harness，运行在云端微VM上，可连接 Slack、邮件、日历等数百种插件，生成文档、表格、网站等成品。
- 其核心设计是持久化工作区：每个任务有独立目录，状态同步到持久存储，但线程间不共享工作目录，依赖 ChatGPT 产品层（如压缩摘要、Personal Context 工具）获取上下文，文件与对话分离存储。
- 对开发者而言，Work 展示了代理从编码工具向通用知识工作平台的演进，其架构（云VM、持久化、外部记忆）为构建复杂代理系统提供了参考，但线程隔离和记忆外部化也带来上下文管理的新挑战。
