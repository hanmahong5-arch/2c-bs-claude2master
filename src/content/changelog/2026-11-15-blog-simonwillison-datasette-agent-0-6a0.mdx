- 新版本在 Datasette 首页直接嵌入 agent 提问框，用户无需跳转插件页面即可对数据发问，降低了数据问答的入口成本。
- 支持 hash-mentions（# 引用）表与已保存查询，让提问能精确指向具体数据对象，对 agent 而言意味着上下文注入从模糊描述变为显式引用。
- 本次发布定位为「累积的小修复」，说明该插件仍在快速迭代期；对工具链开发者，接入时需关注版本变动而非期待稳定 API。
