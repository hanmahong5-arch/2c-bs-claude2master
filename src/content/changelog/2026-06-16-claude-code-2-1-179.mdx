- **修复流式连接中断**：部分响应现在会被保留，而非显示原始错误，同时运行工具时的加载动画不再卡住。这意味着 Agent 在遇到网络波动时能提供更连贯的用户体验。
- **解决 WSL2 鼠标滚动问题**：修复了在 Windows Terminal 和 VS Code 中 WSL2 下鼠标滚动的回归问题。这确保了开发者在混合环境中的界面交互保持顺畅。
- **优化大型目录的权限检查**：修复了沙盒中 `denyRead`/`allowRead` 通配符覆盖大型目录树时，导致 Bash 工具描述巨大并使会话不可用的问题。这防止了配置错误引发的前端性能崩溃。
