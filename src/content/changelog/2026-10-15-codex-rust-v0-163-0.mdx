- 只读工具（skill、memory、会话历史查询）可并行执行，harness 需区分只读与有副作用调用以安全并发调度。
- `/config` 支持跨类别搜索偏好并即时应用可热改设置，harness 需标注哪些配置变更需重启。
- 中断一个 turn 会同时停止活跃 Code Mode cell 及其嵌套工具调用，harness 需把取消信号沿嵌套调用树传播。
