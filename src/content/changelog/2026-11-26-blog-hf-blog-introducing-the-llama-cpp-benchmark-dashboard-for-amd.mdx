- llama.cpp 新增面向 AMD Ryzen CPU 与 Radeon GPU 的基准测试看板，集中展示不同模型与量化配置下的推理性能数据。对 agent 开发者而言，这意味着选型 AMD 本地推理硬件时有了可对照的公开参考，而非只靠零散跑分。
- 看板按硬件与模型组合组织结果，便于横向比较同一模型在不同 AMD 平台上的表现差异。工具链层面，这降低了为本地 agent 挑选量化方案与硬件的试错成本。
- 该看板由 ggml-org 维护并随 llama.cpp 生态更新，属于持续积累的基准数据而非一次性发布。对长期维护本地推理栈的团队，可作为回归对比的基线来源。
