- 他用 Claude Opus 5.5 以「让它好玩很多」这类模糊提示迭代出四款真正愿意玩的浏览器游戏，说明「趣味」开始成为可被提示词调用的能力，对 agent 的评测维度应从能否生成转向是否好玩。
- 四款游戏全部用 HTML/JavaScript 与 three.js 在浏览器内运行，其中 Tree Appreciator 一次提示即成型，意味着前端与 3D 资产的生产门槛被进一步压低，工具链可围绕单文件可玩原型设计。
- Battle Drones 已支持 2–4 人联机、回放、随机地图，并能让不同 LLM 对局，提示多模型协作与自动对战的 agent 编排会成为新实验场；他同时指出 GPT-6 Astra 能造游戏但「趣味感」仍不及 Opus 5.5。
