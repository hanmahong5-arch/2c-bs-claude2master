- 新增内置 Google Cloud Vertex AI 提供商（`model_provider = "gcp"`），模型目录同时加入 GPT-6.1 Terra；harness 需把提供商选择与模型目录解耦，避免硬编码单一后端。
- 新配置默认启用 memory v2，并支持导入外部 agent 记忆；harness 设计上要把记忆层做成可迁移、可版本化的独立组件。
- 修复中断或切到 Plan 模式后排队 agent 消息仍重启工作的问题，并让模型未找到错误直接终止重试；harness 需明确中断语义与终态错误分类。
