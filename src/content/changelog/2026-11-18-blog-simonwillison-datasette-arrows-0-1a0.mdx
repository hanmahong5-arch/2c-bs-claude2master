- Datasette 1.0a43 让插件可通过 `register_output_renderer()` 实现流式导出格式，核心已支持流式 CSV/TSV，百万行数据无需全部载入内存。含义：导出大表不再受内存限制，插件作者也能复用同一套分块输出模式。
- Simon 坚持「发布新插件能力必须附带一个使用它的插件」，于是有了 datasette-arrows 0.1a0。含义：新 API 有真实用例背书，开发者可直接参考实现。
- 该插件由 Claude Fable 5.2 建议选用 Apache Arrow 流式格式，并几乎一次成型地写出。含义：AI 辅助可快速产出插件原型，但选型判断仍来自作者。
