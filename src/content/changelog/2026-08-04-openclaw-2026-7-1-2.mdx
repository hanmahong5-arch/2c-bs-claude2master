- 修复 npm 插件更新：接受新版 npm 客户端返回的单元素数组元数据，使官方插件能正常安装和更新到修正版本 (#108336)。
- 对 agent harness 的含义：插件元数据解析需容忍 npm 客户端格式差异，避免因数组包装导致更新链路中断。
- 对 agent harness 的含义：官方插件跟踪机制依赖元数据兼容，harness 应把此类解析容错纳入更新流程。
