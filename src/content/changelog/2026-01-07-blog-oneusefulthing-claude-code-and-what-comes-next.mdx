博主 Ethan Mollick 通过 Claude Code 演示了 AI 编程工具的突破性能力。他仅用一条指令，就让 AI 自主工作 74 分钟，创建并部署了一个能实际销售产品的网站。

- **自主长时任务执行**：AI 能连续工作超过一小时，自我纠错并生成数百个代码文件，最终交付可运行的程序。这意味着 agent 可以处理更复杂、耗时的开发流程，减少人工干预。
- **上下文压缩机制**：当 AI 的上下文窗口满载时，它会自动暂停、压缩对话并做笔记，然后清空内存继续工作，类似电影《记忆碎片》的设定。这解决了 LLM 的长期记忆限制，使工具链能支持更长时间的自动化任务。
- **技能模块化调用**：AI 通过“技能”模块动态加载特定任务的指令和工具集，例如网站创建或 Excel 处理，无需人工持续提示。这对开发者意味着可以构建更灵活、可复用的 AI 工作流，降低提示工程复杂度。
