- 推理控制（effort/budget/on-off）由 models.dev 目录驱动并统一编码，Anthropic 强制模式显式处理，越界预算自动钳制。
- MCP 客户端现在遵循 per-server timeout 配置（默认 60s，范围 1-3600s），替代硬编码限制。
- 新增会话分叉和用户运行消息 API，支持编辑早期提示并恢复历史；`readLiveMessages` 可读取常驻会话内存转录。
