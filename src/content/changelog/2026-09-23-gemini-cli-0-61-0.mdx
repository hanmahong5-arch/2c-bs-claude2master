- **修复间接提示注入**：阻止通过构建文件修改和不可信 flag 触发的间接 prompt injection。含义：harness 需把构建配置与外部参数当作不可信输入，而非仅校验用户对话。
- **加固沙箱边界**：强化文件系统边界并隔离运行时状态。含义：agent 执行环境的文件可见范围与运行时状态应默认隔离，避免跨任务污染。
- **保留显式版本化 Flash 模型 ID**：不再覆盖用户指定的带版本模型标识。含义：模型选择层应尊重显式配置，避免隐式回退导致行为漂移。
