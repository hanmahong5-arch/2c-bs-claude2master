- 修复了一个边缘情况：当表被外键引用且定义了破坏性 ON DELETE 动作（CASCADE、SET NULL、SET DEFAULT）时，在事务中调用 table.transform() 会因无法修改 PRAGMA foreign_keys 而静默删除或修改数据；新版本抛出 TransactionError 阻止此类操作。
  *含义*：开发者需注意在事务中执行表变换时外键约束的潜在副作用，避免数据意外丢失。
- 提供了关于外键和事务的详细文档及变通方案，帮助用户理解问题并找到替代方法。
  *含义*：工具链应提供清晰的错误信息和文档，指导用户规避复杂约束下的陷阱。
- CLI 和 Python API 文档现在互相交叉引用，方便用户在不同接口间切换。
  *含义*：良好的文档设计能降低学习成本，提升开发者体验。
