- **`/code-review --fix` 自动应用审查建议**：将代码审查发现的复用、简化、效率建议直接应用到工作树，`/simplify` 命令现在调用此功能。这意味着 Agent 可以更主动地执行代码优化。
- **技能可设置 `disallowed-tools` 前端禁止工具**：技能激活时可移除特定工具，增强了 Agent 在执行特定任务时的安全与资源控制。
- **`SessionStart` 钩子支持重载技能和设置会话标题**：钩子可返回 `reloadSkills: true` 并设置 `sessionTitle`，使技能安装和会话定制无需重启，提升了 Agent 环境的动态配置能力。
