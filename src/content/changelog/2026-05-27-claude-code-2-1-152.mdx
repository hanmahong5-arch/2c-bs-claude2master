- **`/code-review --fix` 自动应用审查建议**：将代码复用、简化和效率建议直接应用到工作树，`/simplify` 命令现在调用此功能，意味着 Agent 能更主动地执行代码优化。
- **技能可设置 `disallowed-tools` 前端元数据**：在技能激活时移除特定工具，为 Agent 工具链提供了更精细的权限控制。
- **新增 `SessionStart` 钩子能力**：可设置会话标题、触发技能重载，使技能安装和会话定制能在同一会话中即时生效。
