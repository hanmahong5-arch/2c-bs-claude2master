- **`/code-review --fix` 自动应用审查建议**：将代码复用、简化和效率建议直接应用到工作树，`/simplify` 命令现在调用此功能，意味着 Agent 可以更主动地执行代码优化。
- **技能可设置 `disallowed-tools` 前端参数**：在技能激活时移除特定工具，为 Agent 工具链提供了更精细的权限控制。
- **新增 `MessageDisplay` 钩子事件**：允许在显示助手消息时转换或隐藏文本，增强了 Agent 输出的可定制性和交互控制。
