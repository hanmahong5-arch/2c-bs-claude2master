- 安装体积从 ~640MB 降至 ~285MB：Claude Code 和 Codex 提供者变为按需加载，减少 agent 环境初始化的资源占用。
- Kimi K3 作为 ClinePass 模型可用：扩展了 agent 可调用的模型选项，增加灵活性。
- 团队运行中 spawn 工具不再暴露给队友，出错队友运行报告为失败而非完成：提升 agent 协作的安全性和错误可见性。
