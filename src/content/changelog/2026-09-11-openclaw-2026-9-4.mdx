- **可回滚的失败更新**：schema 与配置检查通过时，保留旧包并恢复旧配置与服务；数据库迁移仍需预更新备份。含义：harness 应把「更新失败」建模为可恢复状态，而非终态。
- **插件统一工作区**：内置与 ClawHub 插件可在 Control UI 中统一发现、安装、配置与授权。含义：插件生命周期需要单一入口，减少 agent 运行时对分散配置的依赖。
- **预置云会话与终端问答**：符合条件的本地项目或公开 GitHub 仓库可复用预置 worker，TUI 支持键盘选择、自由文本与多问题提示。含义：harness 需区分「准备态」与「运行态」资源，并为交互式澄清提供原生通道。
