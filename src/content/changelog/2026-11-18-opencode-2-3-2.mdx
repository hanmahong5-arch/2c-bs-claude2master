- GPT-6.2 的 Responses `instructions` 字段不参与缓存，OpenCode 改为把系统提示词作为首条 developer 消息发送，覆盖 OpenAI、Copilot、Zen、Azure、OpenRouter 等路由；含义是 harness 应把提示词放在可缓存的消息前缀里，而非依赖厂商特殊字段。
- 在 GitHub Copilot `gpt-6.2-sol` 上，单步未缓存输入从约 14,000 token 降到 3；含义是缓存命中率应作为 harness 的一等指标来验证。
- `/responses/compact` 压缩路径现在读取同一缓存前缀；含义是压缩逻辑需与主请求共享前缀，否则会破坏缓存。
