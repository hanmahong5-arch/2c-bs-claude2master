- Agent 插件现由共享 Hub 发现和运行，`~/.agents/plugins` 下的包通过 `plugin.json` 验证，其技能和 MCP 服务器自动启动，设置中可单独管理。
  - 对 harness 设计：插件发现和生命周期集中化，需考虑 Hub 的权限和隔离。
- 修复了“Hub 已更新”对话框反复出现的问题，构建不匹配提示仅在应用更新暂存后显示，且“稍后”选项跨会话保持。
  - 对 harness 设计：版本比较需基于实际功能而非构建指纹，避免误导用户。
- 登录时在应用内显示设备确认码，便于与浏览器核对。
  - 对 harness 设计：安全流程需提供清晰的用户反馈，减少中间步骤的困惑。
