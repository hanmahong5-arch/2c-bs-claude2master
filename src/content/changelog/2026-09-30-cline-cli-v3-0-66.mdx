- 二进制改用 Bun 1.4.2 构建：macOS 27 不再启动即杀进程，x64 版本可在无 AVX2 的 CPU 上运行。含义是 harness 的运行时基线要跟着工具链走，别把宿主 CPU 特性当默认前提。
- Hub 在 Windows 系统代理（Clash、v2ray、企业代理）下可启动：此前 loopback 发现请求被走代理，健康 hub 被判不可达并报 "No compatible hub runtime is available"。含义是本地发现流量必须显式绕过代理，否则健康检查会误判。
- 发送 prompt 后立刻按 Esc 现在能停止该轮：此前在轮次初始化阶段到达的 stop 被忽略，agent 继续后台工作。含义是停止信号要在整个生命周期内可接收，不能只在稳定态生效。
