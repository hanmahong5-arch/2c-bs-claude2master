- **模型发布即 API 发布**：Opus 5.5 同时强调质量与单位成本，官方称运行成本低于前代，具体节省取决于工作负载与缓存上下文的使用；跨轮保留 thinking blocks 可防止推理被提取用于蒸馏，但新要求可能打断客户已有的 harness。含义：升级模型不只是换权重，接入层与成本模型要一起评估。
- **脑与手分离**：Managed Agents 把会话日志与 harness 同执行代码的 sandbox 解耦，sandbox 按需创建、失败不拖垮整个会话；早期把整个编码 agent 放进 sandbox 会拉高首响延迟。含义：设计 agent runtime 时先问哪些部分必须存活、哪些执行不可信代码。
- **凭证不进 sandbox**：生成的代码运行在不持有服务凭证的 sandbox 中，凭证单独保存并经代理附加，同时限制 sandbox 流量出口。含义：隔离与网络控制应作为架构属性，而非事后补丁。
