- **定位是子代理而非主力**：Anthropic 把 Haiku 5.5 定位为搭配 Opus 5.5 / Sonnet 5.5 的 subagent，负责摘要、压缩、数据库查询等高并发低成本任务，官方说法是「Opus 做重思考，Haiku 做高吞吐」。对 agent 工具链意味着分层调用可以更激进地拆模型。
- **分层定价与成本信号**：100K token 以下输入/输出为 $0.10/$0.50 每百万 token，超过后跳到 $0.50/$2.50；同日 Sonnet 5.5 缓存读取价减半。对开发者的含义是 prompt 长度本身成了成本变量，上下文管理直接影响账单。
- **独立评测暴露 token 消耗**：Artificial Analysis 给出 Intelligence Index 43，略高于 GPT-6 Luna 的 38，但 max effort 下每任务约 162k 输出 token，约为 Luna 的三倍。对 agent 的含义是「更便宜」不等于「更省」，多步循环里 token 效率可能抵消单价优势。
