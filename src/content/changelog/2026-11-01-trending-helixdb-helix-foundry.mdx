- 它是什么：Helix Foundry 连接企业数据源，由 agent 起草本体（ontology），再整体载入 HelixDB 成为一张可探索、可提问的图。
- 为什么值得关注：把「数据接入 → 本体建模 → 图加载」串成一条流水线，省去手工建模；支持托管（foundry.helix-db.com）或本地自部署，Go 实现，近 2k star。
- 参考价值：对做 agent 数据层、知识图谱工具链和后端存储的开发者，是「agent 自动生成 schema 再落库」的一个可借鉴范式。
