- 服务器启动等待时间从固定1秒改为最多30秒轮询端口，确保 shot-scraper multi/video 在服务器启动慢时也能正常工作。
  - 这意味着自动化截图流程更可靠，减少因服务器延迟导致的失败。
- 新增 --js-file 选项，支持从本地文件、标准输入或 GitHub 用户名/脚本加载 JavaScript，替代 --javascript 内联字符串。
  - 开发者可以复用外部 JS 文件，提升脚本管理和协作效率。
- shot-scraper javascript 和 html 命令新增 --timeout 选项，与其他命令保持一致。
  - 统一超时设置降低使用复杂度，避免因命令差异导致的配置错误。
