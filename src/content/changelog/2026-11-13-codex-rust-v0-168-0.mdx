- TUI 新增 Sessions → Model providers 浏览，并可为新会话选默认提供方；已打开/恢复的会话仍用其保存的提供方。含义：harness 需把「默认配置」与「会话级配置」分离存储，切换默认不能污染存量会话。
- `features.tui_workspace` 开启后可在主对话旁开侧边会话，拖动分隔条调整、`leader z` 缩放聚焦面板。含义：多会话并行成为一等 UI 形态，harness 需支持焦点切换时的 transcript 交互与事件排空。
- 音频模型可附加录音，后续轮次跳过已确认被拒的录音，并用片段时长做预算以保留更多短录音。含义：附件需带拒绝状态与时长元数据，上下文预算按实测时长而非固定配额分配。
