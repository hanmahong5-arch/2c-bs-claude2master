- 子代理被限流或服务器错误中断时，现在会保留部分工作并通知父代理，而非静默失败
- 后台代理在Linux上因损坏worker记录每50秒自杀的bug已修复，冷启动SSH macOS问题也已解决
- 子代理面板中空闲代理折叠为可展开摘要行，避免占用空间；`/model`等命令在子代理视图下会提示作用于主代理
