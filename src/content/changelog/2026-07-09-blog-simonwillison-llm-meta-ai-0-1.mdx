- 新版本 llm-meta-ai 0.1 允许用户通过 LLM 命令行工具调用 Meta 的 muse-spark-1.1 模型，扩展了模型选择范围。
- 该插件简化了与 Meta 模型的交互流程，开发者无需手动处理 API 细节，降低集成门槛。
- 此举意味着 LLM 生态进一步开放，支持更多供应商模型，为 agent 工具链提供灵活的后端选项。
