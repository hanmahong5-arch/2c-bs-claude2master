- Grok 4.5 是 xAI 首个专为编码和智能体训练的模型，定位 Opus 级但更快、更省 token、成本更低，瞄准编码智能体工作流市场。
- 定价 $2/百万输入 token、$6/百万输出，远低于 GPT-5.6 和 Opus 4.8，缓存命中再降 75%，开发者可大幅降低推理成本。
- 在 Artificial Analysis 编码智能体指数中得分 76，与 GPT-5.5 持平，但每任务 token 消耗低 60% 以上，处于能力与成本的帕累托前沿。
