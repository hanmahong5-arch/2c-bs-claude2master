- GSA 新协议给政府伙伴 Claude Enterprise、Claude for Government 和 Claude API 打 4 折，说明政府采购渠道正成为模型厂商的独立分发面。
- Cognizant 把 Claude 嵌入自家平台并培训 3 万余名员工，TCS 覆盖 56 国 5 万员工，系统集成商正成为 agent 落地的事实中间层。
- 阿尔伯塔省政府自 2025 年起用 Claude Code（Opus 与 Sonnet）审查系统、找漏洞并修复，是代码 agent 进入生产运维的公开案例。

对开发者的含义：企业侧入口越来越依赖咨询与集成伙伴，工具链需考虑被嵌入他人平台的集成方式。
