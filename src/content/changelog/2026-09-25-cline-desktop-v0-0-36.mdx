- 本地连接检查不再走系统 HTTP(S) 代理，Clash/v2ray/企业代理下不再报 "No compatible hub runtime is available"，已有豁免保留：harness 应把本地回环流量与外部请求分流，避免自检被代理劫持。
- 主窗口超出屏幕时自动缩小到可用区域并居中，1080p 150% 缩放下设置与账户控件不再被推出屏幕：harness 的窗口尺寸计算需以缩放后的可用工作区为准。
- 插件斜杠命令（如 `/goal`）改为工作区打开时即加载，首次加载慢或失败会在后台重试，不再被当纯文本发给模型：命令注册应在会话初始化阶段完成，而非首次输入时惰性触发。
