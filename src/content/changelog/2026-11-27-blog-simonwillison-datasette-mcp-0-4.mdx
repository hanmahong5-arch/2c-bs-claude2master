- 这次发布是 datasette-mcp 0.4，核心改动是修复与 Datasette 1.0a44 的兼容性，属于跟随上游 alpha 版本变化的维护性更新。
- 该插件属于 Model Context Protocol 生态，作用是把 Datasette 的数据能力通过 MCP 暴露给支持该协议的模型与客户端。
- 对 agent 工具链的含义：上游 alpha 版本频繁变动时，MCP 适配层需要持续跟进，接入方应锁定版本并关注兼容性说明。
