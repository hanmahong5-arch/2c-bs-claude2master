- 新版本允许 Replacements 对象包含非字符串值，这些值会被识别并用于结构替换，增强了压缩的灵活性。
- 支持基于对象的合并操作，condense_json() 会识别相似对象并存储更新或删除键的指令，uncondense_json() 可应用这些合并，减少重复数据。
- 使用 Hypothesis 属性测试库添加了往返测试，确保压缩与解压的可靠性，对开发者而言，这意味着更稳健的 JSON 处理工具。
