- 升级到 OpenAI Python 库 3.x，并将 HTTP 客户端依赖从 httpx 切换到 httpx2，修复了兼容性问题。这意味着基于 llm 的工具链需要适配新的依赖，但换来更稳定的 API 支持。
- `llm embed` 和 `llm embed-multi` 现在支持 `--key` 参数，Python 方法也接受 `key=`，允许为每次调用传递独立的 API 密钥，而不改变共享模型状态。这对多租户或密钥轮换场景很有用，插件开发者需注意兼容性回退。
- `llm prompt -t/--template` 可重复使用，按顺序组合模板，实现模型配置与提示分离。例如，先保存一个带高推理选项的模型模板，再保存一个生成 SVG 的提示模板，然后组合执行。这为复杂工作流提供了模块化复用能力。
