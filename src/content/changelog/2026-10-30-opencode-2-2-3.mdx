- 新增内置 Claude Agent 提供方：安装 Claude Code 并 `claude auth login` 后，在 `/connect` 选择即可复用其登录与模型，`OPENCODE_CLAUDE_PATH` 可覆盖可执行文件；含义是 harness 可把外部 agent 的认证与模型层当作可插拔后端。
- 桌面端长会话优化：流式回复与长对话的渲染工作量显著下降，并修复时间线增长、缩放滚动与 DOM observer 性能问题；含义是长上下文 harness 需把渲染成本与 token 增长解耦。
- 托管策略拆分：`integration.use` 只管集成账户，新增 `mcp.use`、`skill.use`、`plugin.use` 分别管控 MCP、技能与插件，旧前缀规则自动转换；含义是权限模型应按能力面细分而非单一开关。
