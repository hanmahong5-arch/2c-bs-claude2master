- 新增 `writes` 应用审批模式，声明只读操作自动放行，写操作才弹审批，减少 agent 执行时的中断次数。
- MCP 工具现在无需实验性 opt-in 即可请求交互式认证，agent harness 可更灵活地处理外部工具的身份验证流程。
- 全局 pnpm 安装的 Codex 被自动检测，诊断和更新使用正确的包管理器，避免 agent 环境配置错误。
- Ultra 推理模式下，高多 agent 并发会触发警告，帮助用户控制 token 消耗，agent harness 可据此调整并发策略。
- 修复了 Windows 沙箱中可写根目录的删除权限和主运行时访问，确保 agent 在沙箱内文件操作的正确性。
- 粘贴的终端控制序列不再破坏 TUI 渲染或对话历史，agent 的终端交互更稳定。
