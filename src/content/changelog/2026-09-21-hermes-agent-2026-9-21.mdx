- 这是补丁版本，把 v0.21.3 以来的约 1812 个已合并 PR 汇总成稳定 tag，供 Docker 镜像、Hermes Cloud 等下游消费；完整整理版说明推迟到 v0.22.0。含义：下游 harness 可锁定此 tag 复现，但别把它当功能基线。
- 窗口内新增 host 级 gateway 单例锁与 rendezvous 记录，Desktop 改为附着到已运行的后端而非再起一个。含义：多入口 harness 需要显式所有权与发现机制，避免重复进程争抢状态。
- CLI 新增 `--format stream-json` 结构化 JSONL 输出，另有 `mcp.discovery_concurrency` 限制 MCP 发现连接数。含义：可编程输出与并发上限是 harness 被外部编排器集成的两个前提。
