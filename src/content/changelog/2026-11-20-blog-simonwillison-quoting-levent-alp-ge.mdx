- Levent Alpöge 声称与 Claude 合作找到了黎曼猜想的证明，并称该方法可推广到广义黎曼猜想，甚至有望覆盖扩展黎曼猜想——这是作者本人的声明，尚无同行验证，工具链读者应把它当作待核实的输入而非结论。
- 他称双方在无假设的前提下形式化了论证，意味着若成立，产出是可机器检验的形式化证明而非自然语言草稿；对 agent 工作流的含义是：形式化验证器可能成为数学类 agent 产出的关键验收环节。
- 他自述在接近终点时被 Claude 远远甩开，用“飞、舞、闪耀”形容其表现；这属于主观叙述，不构成能力基准，开发者不宜据此推断模型在一般任务上的水平。
