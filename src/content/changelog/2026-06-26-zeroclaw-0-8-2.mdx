- **A2A agent discovery** (#7763)：agent 可通过网关描述和发现彼此，实现 agent 间互操作；设计上需考虑跨 agent 身份认证与权限隔离。
- **Universal ingress policy layer** (#7997)：所有入站消息在模型处理前经过 SOP 策略层，默认 Loop 行为；agent harness 应统一入站安全过滤，避免绕过。
- **Durable run/task control plane** (#8217)：基于 SQLite 的持久化运行状态、指标和子 agent 监督；agent harness 需支持状态持久化与故障恢复。
