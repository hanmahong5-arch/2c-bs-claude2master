- 开关是 per-agent 的 `memory.search.rememberAcrossConversations`：个人安装默认开启，但需 `session.dmScope` 未设或为 `main` 且无 binding 覆盖；任何 DM 隔离配置都会默认关闭它。含义：harness 的记忆能力应做成显式可覆盖的配置项，而非隐式全局行为。
- 隐私边界固定：只有私聊与持久显式 UI 会话可互相召回，群组/频道既非来源也非目标，其他 agent 的 transcript 永不入选。含义：检索范围要在设计期写死，别留给 prompt 或模型自行判断。
- 检索是有界阻塞步骤，无意图跳过或搜索不可用时不注入上下文，只加一条隐藏结果说明；超时与空结果沿用原行为。含义：召回失败要显式告知主模型“没跑成”，而不是静默降级成空上下文。
