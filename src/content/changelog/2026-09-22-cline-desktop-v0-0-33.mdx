- 新线程可选 Worktree 模式：从当前分支切出 `cline/<id>` 分支并在 `~/.cline/worktrees/` 下运行，agent 不再改动你的工作树；删除任务会一并清理 worktree 与分支。含义：harness 可把「隔离执行环境」做成会话级默认选项，而非依赖用户手动 stash。
- 桌面端自动压缩此前从未真正生效（sidecar 只注册了 checkpoint 未注册 compaction），长会话直接耗尽上下文。含义：opt-in 特性需要在每个宿主端显式接线，否则静默失效。
- 模型输出 token 触顶且未发起工具调用时，改为最多重试 3 次并提示简洁，大输出上限模型获得更大默认预算。含义：harness 应把「无工具调用的截断」视为可恢复状态而非终止条件。
