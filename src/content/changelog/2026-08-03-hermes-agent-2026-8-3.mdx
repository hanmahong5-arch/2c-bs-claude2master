- 新增流式语音对话，支持打断、唤醒词和免提控制，跨 CLI、桌面及网关平台。
  - 对 agent harness 设计：需处理实时音频流、打断事件和低延迟 TTS 合成。
- 实现 A2A v1.0 协议，支持与其他 agent 发现、通信和协作。
  - 对 agent harness 设计：需标准化 agent 间通信协议，支持异构系统集成。
- 桌面应用升级为平台，支持 artifacts 实时预览、插件 SDK 和全局快捷入口。
  - 对 agent harness 设计：需提供可扩展的 UI 框架和沙箱环境，确保安全运行生成内容。
