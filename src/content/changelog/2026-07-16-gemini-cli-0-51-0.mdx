- 安全修复：强制敏感路径黑名单大小写不敏感，并修复 VSCode HITL 漏洞。
  - 含义：agent 路径过滤更严格，防止绕过攻击。
- 沙箱加固：macOS 沙箱中 `~/.gitconfig` 设为只读，防止配置篡改。
  - 含义：限制 agent 环境副作用，提升隔离性。
- 核心修复：保留现代模型的字符串转义序列，并清除历史中的思维泄漏。
  - 含义：确保 agent 输出准确，避免内部推理泄露。
