- Guardian 审批现在会遵循通过模型元数据提供的 Node REPL 策略。
- 这意味着在 Node REPL 环境中，Guardian 的审批行为将更符合预期。
- 对 agent harness 设计而言，需确保模型元数据中的策略被正确传递并应用于审批流程。
