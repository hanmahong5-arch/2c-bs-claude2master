- Bedrock 推理响应不再被缓存为不可重放的空消息，避免会话中断。
- Azure 提供商可通过 Azure CLI 使用 Microsoft Entra ID 登录，无需 API 密钥，简化认证流程。
- V1 读取支持的 V2 配置字段，混合配置环境下更兼容。
- 桌面端：归档会话立即从首页列表消失，提升界面反馈。
