- 首次启动的 ClinePass 弹窗不再宣传 $4.99 首月优惠，该促销即将结束。
  - 对 harness 设计：需移除或更新相关促销 UI 逻辑，避免误导用户。
- Hub 事件日志磁盘上限设为 64 MiB，超出后丢弃最旧事件并回收空间，修剪在卷和定时器上运行。
  - 对 harness 设计：需实现日志轮转和容量控制，防止无限增长。
- 模型目录刷新，新增 AgentRouter 和 Opper 提供商，更新模型列表和价格；Aki.io 和 NanoGPT 的默认模型变更。
  - 对 harness 设计：需同步更新模型配置，注意默认模型变化可能影响用户预期。
