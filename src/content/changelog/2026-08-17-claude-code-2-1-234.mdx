- 新增 `CLAUDE_CODE_PROJECT_DIR_NAME` 环境变量，可自定义会话转录目录名，便于多会话主机管理。
- 新增 `selection:clear` 键绑定动作，可清除应用内文本选择，提升键盘操作效率。
- 新增 GitLab MR 徽章，显示在 footer 和 statusline，需 glab CLI 认证。
- 安全加固：拒绝 Windows NT 命名空间路径，防止 NTLM 凭据泄露。
- 修复长会话自动模式网络权限重复检查问题。
- 修复会话级权限答案在后台子代理提示中丢失的问题。
- 修复非流式响应缺少 thinking/text 字段导致的崩溃。
- 修复特殊 Unicode 序列导致 markdown 渲染缓慢。
- 修复 `SendMessage` 拒绝从 `ListAgents` 复制的收件人问题。
- 修复 git 远程主机误检测问题。
- 修复 MCP 诊断泄露密钥问题。
- 修复 `strictKnownMarketplaces` 接受不匹配的 SCP 源。
- 修复全屏复制丢失字符、水平线渲染、shell 命令计数等问题。
- 修复权限对话框被关闭、队列命令发送错误等问题。
- 修复接受全屏渲染器后丢失权限模式。
- 修复 `/tui` 重启丢失工具规则。
- 修复信任提示缺少仓库范围警告。
- 修复 IDE diff 标签关闭导致权限提示错误。
- 修复远程控制文件上传问题。
- 修复登录后陈旧令牌提醒泄漏。
- 修复权限预览中凭据掩码可隐藏命令等问题。
- 修复跨会话消息被丢弃问题。
- 远程控制：账户切换立即停止会话。
- 远程控制：同步权限模式和模型信息。
- 远程控制：支持手机端 effort 选择。
- `SendMessage` 和 `ListAgents` 报告会话列表过长。
- 过期凭证提示登录。
- 改进转录：用户提示渲染 markdown。
- 改进错误信息，包含响应详情。
- 改进自动会话标题为短名称。
- 降低 `claude-api` 技能上下文成本。
- `/permissions` 和 `/add-dir` 可在工作中打开。
- `/goal` 在错误时自动清除，后台任务超时检查。
- `setup-token` 拒绝多余参数。
- Esc 不再清除鼠标选择。
- 移除冗余的自动模式分类器行。
- 移除默认队友模型设置。
- 调暗运行工具头的时间计数器。
- 后台任务通知使用 system-reminder。
- Mantle 跳过启动探测。
- Windows 启动不再卡在重命名重试。
