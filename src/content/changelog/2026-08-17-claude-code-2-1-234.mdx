- 新增 `CLAUDE_CODE_PROJECT_DIR_NAME` 环境变量，可自定义每会话配置目录的短名称，便于宿主管理。
- 新增 `selection:clear` 键绑定动作，可清除应用内文本选择，适用于代理视图。
- 新增 GitLab 合并请求徽章，显示 MR 状态（草稿/待处理/通过）。
- 安全加固：拒绝 Windows NT 命名空间路径，防止 NTLM 凭据泄露。
- 修复自动模式在长会话中重复检查网络访问的问题，以及会话级权限答案丢失等。
