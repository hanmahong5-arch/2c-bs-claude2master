- **MCP 配置头字段全部按 secret 处理（ACP 通道）**：不再区分敏感与否，所有 header 一律脱敏。harness 设计含义：配置注入层需默认最小可见，日志与回显路径要统一走脱敏。
- **工具审批改为可选（Make tool approval optional for execution）**：执行前审批不再是硬性环节。harness 设计含义：审批策略需可配置化，并保留无审批时的审计与回滚钩子。
- **goose-agent 新增 compaction 与 MCP extension 操作**：压缩与 MCP 扩展管理成为 agent 侧一等操作。harness 设计含义：上下文压缩应作为可调用操作暴露，而非隐式行为。
