- Bash 允许规则中通配符在子命令前（如 `Bash(git * main)`）会匹配选项插入，现启动时警告。
  - 设计 harness 时需注意规则匹配的边界，避免意外授权。
- 超长单行 diff（如 base64）导致严重卡顿，现截断显示并标记。
  - 渲染长内容时需考虑性能，避免阻塞 UI。
- 新增 Auto 模式标签页于 `/permissions`，可查看编辑分类器规则。
  - 提供更细粒度的权限控制，便于自动化场景。
- 修复 MCP 工具调用被中断时误报为“完成无输出”，现明确报错。
  - 工具调用状态需准确传递，避免误导模型。
- 修复 `--strict-mcp-config` 会话提示批准未加载的服务器，导致后台会话卡住。
  - 配置加载逻辑需与实际使用一致，避免启动阻塞。
