- 插件不再直接跑在 hub 进程内，改为 worker 执行；若当前构建无法运行插件，`cline config tools`、`cline hub plugins` 和会话启动警告会明示，而非静默在 hub 内执行。含义：harness 需把插件执行环境与主进程隔离，并显式暴露降级状态。
- provider 错误中断流式响应时，Cline 最多重试 3 次才判定该轮失败。含义：harness 的流式管道要支持可恢复的中断重试，而非直接终止 turn。
- 失败的模型请求会记录 provider 的 request id。含义：harness 的日志层应透传上游请求标识，便于跨系统追踪。
