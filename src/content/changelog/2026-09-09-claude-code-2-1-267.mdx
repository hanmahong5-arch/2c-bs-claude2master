- 新增 `maxEffortLevel` 设置，可在顶层或 `modelSettings` 下按模型限制所有 provider 的 effort 上限，用户仍可选更低级别；harness 需支持按模型覆盖的硬上限，同时保留用户下调空间。
- 新增 `--system-prompt-snapshot off`，让每次请求重新渲染系统提示而非复用会话记录；harness 应把提示快照与实时渲染做成可切换路径，便于迭代提示文本。
- 大量修复围绕 prompt-cache 复用与恢复会话：MCP/插件工具中途加入、模型切换、`/compact` 后恢复等不再重写工具列表或丢弃早期思考；harness 需把工具定义与系统提示记录一次并稳定重放，避免缓存失效。
