- 多部分工具输出改为有界，并淘汰较旧的多模态 inlineData，PDF 内联数据与遥测缓冲不再长期驻留内存；harness 需假定历史图像/附件会被回收，不能依赖其长期可读。
- 配额重试不再持续数小时，重试时会通知 ACP 客户端，且 60 秒 API 头超时可通过 model.requestTimeoutMs 或 GEMINI_API_HEADERS_TIMEOUT_MS 覆盖；harness 应显式设置超时并处理重试事件。
- 无头中止时会杀掉子进程、记录被取消的工具并保留信号退出码，ACP 流中重试不再拼接文本；harness 需按取消语义清理工具状态，而非只读最终文本。
