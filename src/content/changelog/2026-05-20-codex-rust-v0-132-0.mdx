- **Python SDK 支持原生认证与简化文本 API**：新增 API 密钥登录、ChatGPT 浏览器/设备码流程，以及更易用的纯文本输入和 `TurnResult` 返回。这意味着 agent harness 可以更安全、更便捷地集成身份验证，并简化纯文本交互的数据处理。
- **自动化执行支持结构化输出与远程执行器认证统一**：`codex exec resume` 新增 `--output-schema` 以保持会话上下文并强制 JSON 输出，远程执行器注册改用标准 Codex 认证。这使得自动化流程在恢复时能维持结构一致性，并减少认证管理的复杂性。
- **TUI 启动加速与多会话可靠性提升**：终端能力探测改为批处理以加快启动，修复了多会话中 MCP 调用标记和回复路由问题。这改善了 agent harness 的交互响应速度和跨会话操作的稳定性。
