- 聊天中 Mermaid 代码块现在渲染为图表，支持放大预览和移动端重试，对 agent 输出可视化有直接帮助。
- 新安装可检测现有 Claude Code/Codex 登录并快速启动，降低首次使用门槛，适合快速验证 agent 行为。
- `openclaw skills library` 支持个人技能库与 ZIP 导入，便于在共享网关上按身份隔离技能，提升复用性。
- `openclaw update` 增加回滚与配置保留机制，失败时由内置 triage agent 处理，减少更新中断风险。
- 网关启动恢复能力增强，坏 cron 行隔离、内存优化，提升长时间运行的稳定性。
