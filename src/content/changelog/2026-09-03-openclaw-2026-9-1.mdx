- `openclaw update` 在更新后 Doctor 失败时回滚 npm 候选版本，并保留配置与密钥引用；含义是 harness 的升级路径必须自带失败回退，而不是让 agent 在坏版本上继续跑。
- Gateway 启动在负载和大规模 agent 名单下可恢复，畸形 legacy cron 行被隔离而非阻塞启动，本地模型服务成为 OOM 首选牺牲对象；含义是 harness 的启动依赖应可降级，单条脏数据不应拖垮整个运行时。
- 委派系统 agent 提议配置变更或 Gateway 重启时，审批卡片投递到原始频道（含 Telegram 主题）并带请求者标题；含义是审批流必须回到发起会话，否则 agent 会静默卡死。
