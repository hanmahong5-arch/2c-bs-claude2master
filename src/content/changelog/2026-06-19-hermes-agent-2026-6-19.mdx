- **新通道：iMessage 与 Raft**：Hermes 通过 Photon 支持 iMessage（无需 Mac 中继），并作为外部代理加入 Raft 网络，扩展了 agent 的触达范围。
- **桌面应用成熟化**：可重绑定快捷键、原生通知、子代理监控窗口、VS Code 主题安装等，使桌面成为主力交互界面。
- **子代理后台运行**：`delegate_task(background=true)` 异步执行任务，不阻塞主对话，适合耗时操作。
- **图像编辑能力**：`image_generate` 支持基于源图像的编辑（如改色、去背景），统一了生成与编辑接口。
- **自动化蓝图**：通过问答式配置定时任务，无需学习 cron 语法，降低自动化门槛。
- **记忆工具批量操作**：`memory` 支持原子性批量增删改，避免多轮交互失败。
