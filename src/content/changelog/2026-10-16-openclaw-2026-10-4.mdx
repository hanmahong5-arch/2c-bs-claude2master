- Gateway 在电脑睡眠或系统时钟跳变后继续运行，不再因心跳过期而重启（#170790）。对 agent harness 的含义：长时任务不应把墙钟时间当作唯一存活依据。
- 手动 `/compact` 会先结算当前 run 再压缩，而不是中止并丢弃待处理请求（#166163）。对 agent harness 的含义：压缩上下文应作为可等待的结算步骤，而非中断信号。
- Tlon 群组 DM 不再把其他参与者当作 owner，关闭了冒充 owner 的路径（#165801）。对 agent harness 的含义：多参与者会话中 owner 判定必须基于明确身份，而非消息作者。
