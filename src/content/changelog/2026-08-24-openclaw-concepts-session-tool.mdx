- 提供 sessions_list、sessions_history、sessions_search 等工具，支持跨会话发现、读取和搜索，且输出经过安全过滤（剥离思考标签、工具调用 XML、凭据等）。
  - 对 harness 设计：工具输出需内置安全边界，避免泄露内部细节。
- sessions_send、sessions_spawn、sessions_yield 支持跨会话消息、后台子代理及等待结果，实现复杂编排。
  - 对 prompt 设计：可引导 agent 分解任务，利用子代理并行处理。
- 工具受 profile 和策略控制，如 coding 含全套编排，messaging 含 spawn 生命周期，且可用 /tools 检查。
  - 对 harness 设计：工具权限需分层可配置，确保最小权限。
