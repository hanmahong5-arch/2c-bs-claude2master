- GitHub PR 审查上下文现在包含 PR 编号和 URL，便于追踪。
- 修复多处 RTL 布局问题，包括标签页、抽屉、调整大小和标题栏交互，并统一方向图标和抽屉位置。
- 无标题会话回退到生成名称，避免空白显示；markdown 解析移出主线程，提升渲染响应性。
- 桌面端 UI 文案本地化扩展，新增 RTL 支持、区域感知复数规则及更多语言。
