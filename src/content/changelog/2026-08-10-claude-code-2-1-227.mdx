- 修复了会话以过期登录令牌启动时，功能标志未按用户订阅层级评估的问题，避免 Max 用户被错误提示启用 Fable 的用量积分。
  - 对 harness 设计：需确保订阅状态在会话生命周期内正确传递，避免因令牌过期导致功能误判。
- 修复了在 GitHub 托管运行器上，`claude-code-action` 中所有 Bash 命令因 `allowed_non_write_users` 而失败的问题。
  - 对 harness 设计：需注意 CI 环境下的权限配置，确保命令执行不受非写入用户限制。
- 修复了 `/tui` 将对话回退到首条消息之前的问题。
  - 对 harness 设计：需确保 TUI 状态管理正确处理回退操作，避免丢失会话上下文。
- 改进了斜杠命令菜单：蓝色仅标记选中行，匹配字符加粗而非变色，保留 emoji 或重音字符。
  - 对 harness 设计：需关注终端 UI 渲染细节，提升可访问性和视觉清晰度。
- 性能改进：减少文件未找到建议和 at-mention 大小检查时的事件循环阻塞。
  - 对 harness 设计：需优化异步操作，避免阻塞事件循环，提升响应速度。
