- 文章把多智能体系统分成 swarms、flocks、gangs 等形态，讨论不同协作结构对任务分工的影响；对开发者的含义是：先选协作拓扑，再谈模型选型。
- 训练环节强调多 agent 之间的交互数据与反馈如何用于改进系统，而不是单 agent 各自调优；这意味着工具链要能记录跨 agent 的调用轨迹。
- 评估部分给出多智能体系统的评测思路，关注整体任务完成而非单个 agent 表现；落地时评测集应按协作场景设计。
