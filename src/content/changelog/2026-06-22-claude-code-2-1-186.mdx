- 新增 `claude mcp login/logout` 命令，支持 SSH 下 `--no-browser` 完成认证，无需打开交互菜单。
  - 设计含义：为 agent 提供无头环境下的 MCP 认证能力，便于远程或自动化部署。
- `!` bash 命令默认触发 agent 自动响应输出；可设置 `"respondToBashCommands": false` 恢复仅上下文行为。
  - 设计含义：agent 对 shell 命令的响应从被动变为主动，需考虑用户控制开关。
- 后台子代理的权限提示现在显示在主会话中，并标明请求 agent，Esc 仅拒绝当前工具。
  - 设计含义：提升多 agent 协作时的安全可见性，避免自动拒绝导致功能受阻。
