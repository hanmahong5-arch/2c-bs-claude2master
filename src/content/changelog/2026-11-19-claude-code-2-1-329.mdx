- 信任对话框现在标明文件夹的 hooks 声明位置；harness 需把 hook 来源作为可审计元数据暴露给用户。
- 托管设置中 hooks 加载失败时，在 Claude Desktop 等非交互宿主中给出会话内警告；无终端场景也要有可见的失败通道。
- Code Mode 可在开启 OpenTelemetry 事件与指标时启用，脚本内每次工具调用都会上报事件；可观测性不再与代码执行模式互斥。
