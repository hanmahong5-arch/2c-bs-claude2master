- Computer Use 已「180 度不同」：agent 学会自我调试并从失败中恢复，结合截图、accessibility tree、DOM、Playwright 与生成代码，部分任务已快于普通人。含义：agent 工具链需同时接入视觉与结构化接口，而非只靠截图。
- OpenAI 一周内做出 Decisions API，目前只是 Luna 的封装，团队无包袱地克隆他们认可的模式。含义：API 层竞争窗口极短，快速跟进比原创更现实。
- 新开发者栈包含 async tool calling、mid-turn steering、WebSockets、UltraFast 推理、prompt caching、pre-warming、compaction 与 Agents API。含义：长时运行 agent 的上下文压缩与缓存预热正成为基础设施标配。
