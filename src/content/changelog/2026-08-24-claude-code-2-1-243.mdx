- `/usage` 新增 Loops 分解，显示每轮循环的运行次数、token 数等，便于发现失控的循环任务。对 agent harness 设计：可监控子任务资源消耗。
- 新增 `modelPicker` 设置，可定制 `/model` 选择器，支持任意模型 ID（包括 Vertex/Bedrock）。对 agent harness 设计：允许限制或推荐模型列表。
- 新增 `promptCacheTtl` 和 `subagentPromptCacheTtl` 设置，可分别控制主对话和子代理的缓存时长。对 agent harness 设计：可优化成本与延迟。
- 新增 `modelPricing` 托管设置，使用组织合同价计算成本。对 agent harness 设计：成本报告更准确。
- 修复远程 MCP 服务器断线后无法恢复的问题，现在会自动重连或报告失败。对 agent harness 设计：增强外部工具连接的稳定性。
