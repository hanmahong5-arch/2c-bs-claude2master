- Poolside 的 Model Factory 每月运行 1–2 万次实验，通过流式数据直接注入训练、不可变数据与版本化代码实现可复现实验，将模型迭代从六个月缩短至五到八周。这意味着模型开发正从手工作坊转向自动化工厂，工具链必须支持高速实验与数据溯源。
- Eiso 认为 MCP 和传统工具调用“愚蠢”，未来 agent 应直接写脚本而非从预定义工具中选择，最小化 harness、使用容器并赋予模型自由。这暗示 agent 架构应从工具编排转向脚本生成，降低中间层复杂度。
- 池侧坚持从头训练模型而非蒸馏更大模型，并认为强化学习将提前进入预训练阶段，next-token prediction 仍未能充分提取网络知识。这对预训练范式提出挑战：RL 与 curriculum design 的融合可能成为下一波效率提升的关键。
