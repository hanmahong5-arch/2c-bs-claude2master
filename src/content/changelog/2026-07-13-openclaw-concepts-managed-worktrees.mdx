- 每个工作树位于 `<state-dir>/worktrees/<repo-fingerprint>/<name>`，分支名为 `openclaw/<name>`，基于请求的 base ref 创建。
  - 含义：Agent 任务获得隔离的 git 工作区，避免分支冲突和临时目录残留。
- 通过 `.worktreeinclude` 文件（gitignore 模式）将选中的忽略/未跟踪文件复制到新工作树，不会覆盖已有文件。
  - 含义：允许 Agent 任务携带必要的本地配置（如 .env），同时保持仓库整洁。
- 删除工作树前会创建包含跟踪和非忽略未跟踪文件的快照提交，保留 30 天可恢复；脏工作树或含未推送提交的工作树不会被自动删除。
  - 含义：Agent 任务的工作状态可安全回滚，避免意外丢失修改。
