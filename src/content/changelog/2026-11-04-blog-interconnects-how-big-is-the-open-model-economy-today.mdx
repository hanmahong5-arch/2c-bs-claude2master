- 作者以 Baseten、Fireworks、Together AI 等开源模型推理初创公司为风向标，结合 OpenRouter 的开源模型 token 占比，来估算开源推理市场规模；这些公司的命运与开源推理品类直接绑定，比超大规模云厂商的披露更能反映该品类走势。
- 公开数据显示这些平台的 token 量呈近指数增长：Fireworks 称其定制模型日服务超 40T token，该垂直业务自今夏增长逾 2 倍，作者预计其秋季总量将远超 100T。对 agent 开发者而言，这意味着开源模型推理供给与吞吐正在快速扩张。
- 作者把开源推理 token 量与 Google 财报披露的全平台及 API token 量叠加对比，以判断开源部分相对闭源巨头是否只是零头；但他强调现有测量极不精确，平台指标噪声大、初创营销数据与公开评测都不完美。这提示工具链选型时需谨慎对待厂商自报数据。
