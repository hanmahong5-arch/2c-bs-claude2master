- Simon Willison 用 GPT-5.6-Sol 构建了 CORS Chat，一个用于测试兼容 OpenAI Responses 协议的聊天端点的 Web UI，已在 LM Studio 和 OpenRouter 上验证。
- 该工具支持浏览器端持久化对话，并可导出为 JSON，方便调试和分享。
- 一个亮点是能识别流式生成的 SVG 图像并逐步渲染，展示了处理多模态流式输出的可能性。
- 对开发者而言，这提供了一个轻量级、可复用的测试工具，降低了验证本地或远程 LLM 端点的门槛。
