- **更新默认跟随 tagged release**：源码安装从追 main 每个 commit 改为只更新到最新 `vX.Y.Z`，已更新的安装不会被回退；想继续追 commit 需 `hermes update --set-channel main`。含义：harness 的版本基线从「最新代码」变成「已发布快照」，可复现性优先于新鲜度。
- **桌面端可选更新通道**：Settings ▸ About ▸ Updates 新增 Stable releases / Every commit 开关，更新弹窗显示当前通道。含义：把升级策略暴露为运行时配置，而非写死在安装脚本里。
- **推理内容在 resume 后保留**：签名 thinking 在 `hermes chat --resume` 和下一次 gateway turn 时重放，Bedrock Converse 推理模型在恢复会话时不再被拒。含义：会话恢复需持久化并校验推理块，而不只是消息历史。
