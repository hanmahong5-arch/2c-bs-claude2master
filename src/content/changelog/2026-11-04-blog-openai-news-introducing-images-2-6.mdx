- 生成速度提升，并新增 GIF 创建能力：图像产出从静态图扩展到动图，意味着内容流水线需要把动图格式纳入产物与缓存策略。
- 编辑精度提高：局部修改更可控，对 agent 而言，多轮「生成—修改」循环的返工成本下降，更适合把图像步骤串进自动化流程。
- 覆盖 ChatGPT、Codex 与 API，且 API 增加新控制项：同一能力在三处对齐，开发者可在 Codex 与 API 侧用参数约束输出，减少后处理胶水代码。
