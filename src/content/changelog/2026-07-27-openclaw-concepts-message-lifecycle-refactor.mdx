- 核心不变式：核心决定消息应存在后，发送意图必须先持久化再调用平台，平台回执必须在成功后提交，实现至少一次恢复。
  - 对 agent harness 设计含义：消息发送的持久化与平台调用分离，确保崩溃后能恢复发送状态。
- 引入 `sendDurableMessageBatch` 封装渲染、发送、提交/失败步骤，返回 `sent`/`suppressed`/`partial_failed`/`failed` 四种结果。
  - 对 agent harness 设计含义：标准化发送结果枚举，让上层逻辑能根据结果决定重试或降级。
- 接收上下文通过 `ack()`/`nack(error)` 和可配置的确认策略（如 `after_durable_send`），控制何时确认事件已处理。
  - 对 agent harness 设计含义：将确认时机与下游发送绑定，避免确认后崩溃导致回复丢失。
