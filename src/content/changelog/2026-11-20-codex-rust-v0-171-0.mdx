- 模型目录新增 GPT-6.2 Sol 与 Astra，Sol 成为默认目录选择；harness 需把默认模型从硬编码改为目录驱动，避免切换时行为漂移。
- TUI 工作区默认启用，侧栏支持可搜索文档预览、图片预览与子代理记录；harness 设计需把子代理输出当作一等可观测对象，而非仅主对话。
- 新增 `codex exec --remote <ADDR>` 在既有 app server 上启动或恢复非交互会话，另有 `/rc`、`/remote` 管理远程控制与配对码；harness 需区分本地与远程会话生命周期，并保证草稿、排队输入随原线程恢复。
