- **GDK agent loop 跑在 wasm32**：agent 循环可编译到 wasm32 目标，意味着 harness 核心逻辑可脱离原生运行时部署，扩展与沙箱边界更灵活。
- **工具结果连续性与上下文保持修复**：OpenAI 兼容工具图片输出时保持 tool results 连续，且跨 reply 生命周期保留 session context，说明 harness 需把工具消息顺序与上下文生命周期当作硬约束。
- **自动压缩落在工具边界**：unrolled agent loop 在工具边界触发 auto-compact，提示压缩策略应绑定工具调用点而非任意 token 位置，避免截断正在进行的工具链。
