- 支持从剪贴板直接粘贴图片到 composer，简化多模态输入。
- 打开非 git 文件夹不再显示 git 术语，欢迎建议根据实际内容调整，对非代码项目更友好。
- 修复会话模型覆盖、diff 路径解析、失败 turn 错误显示等问题，提升调试与上下文准确性。
- MCP 服务器挂起不再阻塞会话创建，stdio 服务器有 30 秒初始化预算，远程 SSE 支持 OAuth 授权。
- 中断后队列提示保留，会话上下文持久化，网络中断自动重试，增强 agent 任务韧性。
