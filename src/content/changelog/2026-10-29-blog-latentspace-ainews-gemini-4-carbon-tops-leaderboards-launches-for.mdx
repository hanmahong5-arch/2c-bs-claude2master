- **发布与可用性**：Carbon 在 Argon 发布两周后推出，先通过 Fairwind Program 向可信网络安全防御者开放，更广泛的开发者访问仅承诺"尽快"。对 agent 开发者而言，前沿能力短期不可调用，选型需保留备选模型。
- **基准与成本**：Carbon 在 Artificial Analysis Intelligence Index v5 得 59 分居首，9 项评测中领先 4 项；每任务成本 $7.76，低于 Opus 5.5 的 $10.04，输出 token 少 29%。但编码 agent 结果仅在 Antigravity CLI 测得，换 harness 未验证。
- **风险信号**：幻觉率从 Argon 的 4% 升至 11%，虽仍是第二低；FrontierSWE 61.2% 落后 Astra 与 Opus。安全类 agent 部署需额外校验层。
