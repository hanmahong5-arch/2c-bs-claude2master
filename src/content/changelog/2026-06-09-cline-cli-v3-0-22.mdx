- **新增 Claude Fable 5 模型支持**：为 Agent 工具链引入了新的高性能模型选项。
- **修复 MiniMax M3 思考控制路由**：确保该模型的特定功能在网关间正确传递，提升了多环境部署的可靠性。
- **两项更新均聚焦于模型集成**：强化了框架对不同供应商模型及其高级功能的兼容性与稳定性。
