- **TUI 支持会话存档**：可通过 `/archive` 或 CLI 命令存档/恢复会话，防止意外恢复或分叉。这意味着 agent harness 需要管理会话生命周期状态。
- **远程控制改用服务器令牌**：远程执行注册支持 `CODEX_API_KEY`，websocket 连接使用短生命周期服务器令牌替代 ChatGPT 令牌。这降低了长期凭证风险，要求 harness 适配新的认证流程。
- **TUI 增强内容交互**：Markdown 表格在拥挤时转为键值对记录，并保留 OSC 8 元数据使网页链接可点击。这表明 agent 输出需要适应更结构化的渲染以提升可读性。
