- Muse Glimmer 是 Meta 推出的多模态 AI 模型，支持文本、图像、音频等输入，并可在本地设备运行，强调隐私与离线可用性。
- 该模型具备 agentic 能力，能自主规划任务并调用工具，例如通过 API 操作外部应用，为开发者构建智能体应用提供新选择。
- 模型开源，允许开发者自由定制和部署，降低了对云端 API 的依赖，对工具链和本地 AI 生态有积极影响。
