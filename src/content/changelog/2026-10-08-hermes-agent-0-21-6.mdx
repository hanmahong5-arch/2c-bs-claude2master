- 仪表盘认证加固：伪造 `X-Forwarded-For` 可重置登录限流、未认证请求可无限写审计日志、`/auth/` 无请求体大小限制、原生登录可重定向到非回环地址导致会话劫持。含义：agent harness 的认证边界必须把代理头和重定向目标当作不可信输入。
- git filter 加固：自动 git 调用（工作区快照、子代理 worktree、kanban、`hermes -w`）会在首个提示前执行不可信仓库配置里的 `clean`/`smudge`/`process` 程序。含义：harness 在读取用户仓库前应先隔离或禁用仓库自定义 filter。
- 邮件网关发件人加固：`From` 头里的带引号显示名可让攻击者邮件冒充白名单发件人。含义：白名单校验应基于解析后的地址而非原始头字符串。
