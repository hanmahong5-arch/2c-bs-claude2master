- Auto mode 在 Bedrock/Vertex AI/Foundry 上默认可用，无需 opt-in；可通过 `disableAutoMode` 关闭。
- 修复流式响应中长列表/表格/代码块导致的终端冻结和按键延迟问题。
- 修复插件 shell-form 命令中 `${user_config.*}` 注入漏洞，建议改用 exec 形式或环境变量。
- 修复非交互式运行中远程管理设置被永久记录为已同意而未显示安全确认对话框。
- 修复自动更新器覆盖自定义启动脚本/符号链接，`/doctor` 现在会报告外部管理的启动器。
