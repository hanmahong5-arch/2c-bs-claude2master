- 修复 `--continue`/`--resume` 重发历史消息导致 API 丢弃早期 reasoning，以及 `--tools` 变更后丢失 extended thinking；harness 需保证恢复时上下文逐字节一致。
- Bash 权限规则中段 `:*` 此前在 settings 文件被跳过、仅 `--allowedTools` 生效，现统一生效并给出匹配警告；权限来源不一致是 harness 的隐蔽风险。
- 托管设置中布尔锁键拼错、嵌套值非法此前会整块失效，现锁仍生效且启动时点名；配置校验失败应降级而非静默放行。
