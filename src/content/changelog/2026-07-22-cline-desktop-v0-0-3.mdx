- 聊天记录中的推理部分状态文本从冗余描述简化为“Thinking”。
- 移除了脑部图标，减少视觉干扰。
- 对 agent harness 设计而言，状态显示应保持简洁，避免不必要的信息和图标，使用户能快速理解当前状态。
