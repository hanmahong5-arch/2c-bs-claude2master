- 新增 `sqlite-utils migrate` 命令，支持对已有 SQLite 数据库执行 schema 变更，如添加、重命名、删除列或修改类型。
  - 这意味着开发者无需手动编写迁移脚本或依赖 ORM，即可安全地演进数据库结构。
- 迁移基于检测当前 schema 与目标 schema 的差异自动生成，并支持回滚操作。
  - 对 agent 工具链而言，这降低了动态数据管理的门槛，使自动化流程能更可靠地维护持久化状态。
- 该版本还改进了 CLI 交互，如 `--csv` 和 `--nl` 输出格式，以及更清晰的错误提示。
  - 这些细节优化让 sqlite-utils 更适合作为数据管道中的通用组件，便于集成到各种脚本和 agent 工作流中。
