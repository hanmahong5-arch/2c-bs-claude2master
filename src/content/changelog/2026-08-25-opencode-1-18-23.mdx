- 修复 Cloudflare AI Gateway 对第三方提供商的路由，非 Workers 模型现可通过 REST API 正常工作。
- 修复 Anthropic 模型通过网关时，将点号模型 ID 转换为连字符形式，确保兼容。
- 修复会话感知提供商的父会话 ID 请求头问题，并修复 GitHub 不可变 OIDC 令牌认证。
