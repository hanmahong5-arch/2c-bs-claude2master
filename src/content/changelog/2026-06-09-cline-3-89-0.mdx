- **新增 Claude Fable 5 模型支持**：为 Agent Harness 提供了新的、可能更强大的模型选项，扩展了其处理复杂任务的能力。
- **修复 MiniMax M3 思考控制**：确保通过网关调用时，模型的思考控制功能稳定可靠，提升了多模型集成的健壮性。
- **清理 Codex 模型列表**：移除了过时或不必要的 Codex 模型，简化了配置界面，使开发者能更清晰地选择合适模型。
