- 巴克莱计划 2026 年底让 Claude Code 覆盖 50% 开发者，2027 年扩展到多数软件工程师，用于加速开发、改造遗留系统。对工具链的含义：大型受监管企业的编码 agent 采购已从试点转向规模化指标。
- 内部 Colleague Knowledge Assistant 自 2025 年上线，基于 RAG 架构，已有超 1.6 万名同事使用、处理逾百万次搜索。对开发者的含义：企业级 RAG 助手的价值锚点是客服响应速度，而非模型本身。
- 全球市场业务用 Claude 对每日约 12 万封客户邮件做分类、信息补全和路由判断，减少人工处理。对 agent 的含义：邮件分流这类高重复、需判断的流程，是金融场景里最先落地的 agent 形态。
