- `claude plugin install` 新增 `--marketplace <source>`：必要时先加市场（走与 `marketplace add` 相同的策略检查）再装插件，harness 可把「来源解析 + 策略校验 + 安装」收敛为单步。
- Agent 工具新增 `effort` 参数，可按指定档位运行子代理；子代理不再只能继承默认强度，编排层可按任务难度分配算力。
- 新增 `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS`，为 529 重试设置更长退避基数；同时修复沙箱命令可读 `/ultrareview` 暂存副本、UNC 路径绕过读权限提示等安全问题，重试与隔离策略都需要显式配置。
