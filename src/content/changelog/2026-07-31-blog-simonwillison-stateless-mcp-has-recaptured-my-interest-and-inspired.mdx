- 无状态 MCP 将原本需要两次 HTTP 请求的会话初始化与工具调用合并为一次，无需维护会话 ID，简化了客户端和服务端实现，也更适合可扩展的 Web 应用。
- 作者用 Codex 构建了 mcp-explorer CLI 工具，可交互式列出、检查和调用 MCP 工具，展示了无状态协议下工具开发的便捷性。
- 作者还发布了 datasette-mcp 插件，为 Datasette 实例添加 MCP 端点，使 agent 能通过 SQL 查询数据库，并强调 MCP 比任意 shell 访问更易审计和控制，适合敏感应用。
