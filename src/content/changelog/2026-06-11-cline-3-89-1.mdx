- **修复 Anthropic 提供商在 VS Code 1.123+ 的兼容性**：更新后的 Node 24 运行时破坏了捆绑的 Anthropic SDK，现已修复。这意味着 Agent Harness 需要确保核心 SDK 与宿主环境的运行时版本保持兼容。
- **支持 DeepSeek V4 推理格式**：现在能够正确处理 DeepSeek V4 的推理输出格式。这表明 Agent Harness 的设计必须能灵活适配不同模型供应商特定的响应结构。
- **维护多环境下的提供商稳定性**：此次更新集中于修复特定环境下的中断问题，强调了在复杂工具链生态中，Agent Harness 需要具备对底层依赖变化的快速响应和隔离修复能力。
