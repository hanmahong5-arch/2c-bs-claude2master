*   **修复 Termux 重载循环**：防止移动终端环境下的无限重启与重绘循环，意味着 agent 在非标准终端中也能稳定运行。
*   **过滤内部会话上下文**：恢复会话时自动清理内部元数据，避免历史污染，保障 agent 上下文管理的纯净性。
*   **强制工具顺序执行**：确保 `update_topic` 工具串行运行，防止并发冲突，这对依赖确定执行顺序的 agent 流程至关重要。
