- CLI/TUI 支持 OSC 7577 程序恢复协议，会话中断后可续接；harness 需把恢复状态当作一等公民而非重放日志。
- 本地网关启动前增加有界默认插件预检（Desktop/Docker/CLI），插件故障在启动期暴露；harness 应把插件健康检查前移，避免运行时静默失败。
- 插件 OAuth 条目可固定 redirect URI，且 profile 重命名/移动/删除后插件工作仍绑定正确 profile；harness 的凭据与作用域解析需以稳定标识为锚。
