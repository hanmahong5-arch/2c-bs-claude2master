- AWS 发布官方 emulator，可在本地克隆多个 AWS 服务跑测试，无需申请付费 API key；对 agent 与 CI 工具链意味着云端依赖测试的成本和门槛下降。
- 该项目用 Rust 编写，由“一大群 agent”协作完成，前三周产生 29,684 次 commit；这为 agentic engineering 提供了一个可观察的大规模协作样本。
- 目前 macOS 和 Windows 上运行仍需 Docker，作者希望未来能改为单个二进制；对跨语言测试套件而言，单文件分发才是真正可嵌入的形态。
