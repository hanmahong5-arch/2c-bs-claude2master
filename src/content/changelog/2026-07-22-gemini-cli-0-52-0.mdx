- 修复 `write_file` 和 `replace` 工具对 JSON/IPYNB 文件跳过 LLM 修正，避免意外修改格式。
  - 含义：agent 处理结构化文件时更可靠，减少数据损坏风险。
- 简化计划模式写入策略，支持相对路径。
  - 含义：agent 在计划模式下使用路径更灵活，降低配置复杂度。
- 无 Code Assist 层级时显示清晰提示；项目配额错误附带设置指引。
  - 含义：agent 在权限或配额不足时提供可操作反馈，提升调试体验。
