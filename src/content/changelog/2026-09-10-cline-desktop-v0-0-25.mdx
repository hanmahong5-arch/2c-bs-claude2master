- Codex 订阅模型列表只保留计划可用项：GPT-4o、GPT-4.1、chatgpt-image-latest 被移除，gpt-5.4 系列退役，默认切到 gpt-5.6-terra，且按后端真实 400K/272K/128K 预算封顶。含义：harness 的模型选择器必须与后端能力对齐，不能直接继承 API 的 1.05M 上限。
- Windows 更新不再报 "Error opening file for writing"：安装器会先按完整路径停掉常驻的 Cline Hub daemon，再执行安装。含义：harness 若让子进程比主程序活得更久，安装/升级流程必须显式处理它，且要避免误杀并行渠道。
- 发送在回合开始前失败时，提示词与附件会回到输入框，并与等待期间新加的内容合并；若已开始输入则不覆盖。含义：乐观 UI 需要可回滚的草稿状态，而不是直接清空。
