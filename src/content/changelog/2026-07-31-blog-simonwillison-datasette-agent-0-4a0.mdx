- 新版本引入 `context.browser_task()` 机制，允许 agent 工具直接在用户浏览器中执行自定义 JavaScript，为插件开发提供了新的交互方式。
- 该机制简化了 Datasette Agent 插件的开发，使工具能够与浏览器环境深度集成，例如实现调试循环等高级功能。
- 对开发者而言，这意味着可以构建更强大的本地数据工具，将 LLM 能力与浏览器端操作结合，提升自动化与交互效率。
