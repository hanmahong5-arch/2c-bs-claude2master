- 工作树隔离会话及子代理现无法对主检出执行破坏性 git 命令，文件编辑与 Bash 在所有会话类型中均受隔离。
- PreToolUse 自动允许钩子不再绕过后台代理任务（摘要、压缩、重命名）中的工具限制，增强安全边界。
- `/usage` 现仅将实际消耗工具结果的请求计入 MCP 服务器份额，避免过度归因，利于成本监控。
- 启动连通性检查现使用与 API 请求相同的代理感知传输，避免 HTTPS 代理后挂起，提升部署兼容性。
- `SendMessage` 长摘要自动截断而非拒绝，防止发送失败，提升跨会话通信可靠性。
