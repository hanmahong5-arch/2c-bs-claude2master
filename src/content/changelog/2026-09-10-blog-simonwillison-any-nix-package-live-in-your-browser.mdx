- trynix.dev 用 qemu-wasm 在浏览器内跑 x86_64 Linux 虚拟机，可启动过去 13 年的任意 Nix 包，且包是 URL 可寻址的（如 `?pkg=python3@3.6.2` 点 Load 即得交互 shell）。含义：复现旧环境不再依赖本地容器或远程机器，浏览器即沙箱。
- 作者 Farid Zakaria 在此之上做了 trynix-preview：一个 GitHub Action，会在 PR 上评论一条链接，点开就能在浏览器里启动该 PR 的构建。含义：代码审查从读 diff 变成直接进真实运行环境验证。
- 整个方案没有服务器，只有浏览器。含义：对 agent 与工具链而言，环境启动成本被压到一条 URL，可把"可运行环境"当作可分享的链接嵌入工作流。
