- Claude Code 2.1.277 起，若目录中没有 CLAUDE.md，会自动查找并使用 AGENTS.md。含义：同一份项目指令文件可被多个编码 agent 复用，减少为每个工具重复维护配置。
- 该支持基于 Claude Code mods 实现，mods 是即将推出的 harness 自定义机制，AGENTS.md 只是内置 mod 之一。含义：项目指令层正从硬编码行为变成可插拔模块，开发者可自行构建定制版本。
- Thariq Shihipar 给出了该 mod 的源码，并指向更多 mods 的集合。含义：指令加载逻辑可被审查和替换，工具链的配置行为不再是黑盒。
