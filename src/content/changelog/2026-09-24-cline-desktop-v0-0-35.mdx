- Linux 首发：每版提供 x64 `.deb` 与 `.rpm`，Open folder 走原生 GTK 选择器，更新后台下载、点 Restart now 才安装，无 AppImage。含义：harness 需按平台拆分打包与更新路径，避免安装时弹密码。
- 插件斜杠命令不再当纯文本发给模型，而是执行插件 handler、显示回复，仅在命令要求时开启一轮；启用的命令进入斜杠菜单，skills/workflows 取自当前会话工作区（含 worktree），坏插件不再拖垮所有斜杠提示。含义：命令路由要区分「本地执行」与「模型轮次」。
- 设置新增 Diagnostics 行，Export 把版本、系统、设置、近期 sidecar/hub 日志与所选会话 manifest 写成一个文本文件到 Downloads，并剥离 API key、凭证形态值、prompt 与 home 路径。含义：可观测性输出需内置脱敏，才能安全外发。
