- 网关登录新增已登录账号确认：凭据保存前需用户确认，`/status` 可见。含义：harness 的凭据写入路径应加入显式确认点，而非静默落盘。
- 新增 send-now 键（ctrl+enter 或 ctrl+x ctrl+s）：中断当前回合并一次性发送所有排队消息，未送达前显示为灰色。含义：队列消息需要可见状态与批量投递语义，harness 应区分「已排队」与「已接收」。
- claude.ai 账号启用的 skills 与 plugins 会同步到终端会话，可用 `syncClaudeAiSkills: false` 或 `syncClaudeAiPlugins: false` 退出。含义：harness 的能力集来源不再局限于本地，需设计远程同步与本地覆盖的优先级。
