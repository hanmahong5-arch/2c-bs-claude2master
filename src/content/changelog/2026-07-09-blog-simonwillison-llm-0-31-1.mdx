- 修复了 OpenAI Chat Completion 端点中，某些提供商的工具调用因空参数引发 JSON 错误的 bug。
- 该 bug 在测试 llm-meta-ai 时被发现，凸显了跨提供商兼容性测试的重要性。
- 对于开发者而言，此修复确保了 llm 工具链在处理不同 API 时的稳定性，减少集成风险。
