- 新增图表标注能力：datasette-charts 0.3a0 支持在渲染出的图表上叠加线条、阴影区域和文字标签，也可三者组合使用，让图表从单纯展示数据变为能直接说明结论。
- 内置图表构建 UI：作者提供了 Datasette Lite 在线示例，用户可在浏览器里直接调整标注参数，无需本地部署即可试用新功能。
- 与 Datasette Agent 联动：安装 Datasette Agent 后，agent 能根据自然语言提示自动构建带标注的图表，作者在 agent.datasette.io 演示了对比两类标签内容的场景，说明数据可视化正成为 agent 可调用的工具能力。
