- 发布窗口含约 620 个已合并 PR、326 个已关闭 issue，覆盖 CLI、安装器、Microsoft Store、Docker 与 Hermes Cloud；对 harness 的含义是：多分发渠道需统一版本基线，避免各端行为漂移。
- MCP 进度通知以实时工具进度流式呈现；对 harness 的含义是：长任务应把中间进度暴露给调用方，而不是只返回最终结果。
- 新增 `post_compaction` 插件钩子，以及插件可声明 OAuth 客户端、由 Hermes 完成登录与刷新；对 harness 的含义是：压缩后与鉴权生命周期都应有可插拔的扩展点。
