- Codex Cloud 在 DevDay 后改版：环境可发布一次、在隔离实例中并行跑多个任务，并能在公司内共享；本地任务也可让 Codex 推分支、转交云端线程。含义：agent 执行位置正变成可切换的后台资源，工具链需支持本地与云端的上下文交接。
- 语音被 OpenAI 的 Guo 当作控制面而非单一输入通道：用它管理线程、查看进度、从其他应用取数据、新建任务；Kundel 则用语音在路上与自己的 dot 沟通并启动 PR。含义：语音交互的价值在于调度多个 agent，而不只是听写。
- 个人 agent dots 对 Codex 重度用户仍显别扭，Guo 列出三种用途：安全网（提示遗漏）、委派接收端（多在 Slack 使用）、无处不在的存在；Kundel 常从 dot 而非直接提示 Codex 开始任务。含义：个人 agent 与主 coding agent 分工不同，需明确各自职责边界。
