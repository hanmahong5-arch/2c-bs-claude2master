- 改进了 ClinePass 的入门流程，新增模型选择前的中间步骤，降低用户认知负担。
  *含义*：agent 的认证/订阅流程设计需考虑分步引导，减少一次性信息过载。
- 订阅界面变为可选中，并统一“ClinePass”拼写，UI 文案更清晰。
  *含义*：交互元素的可选性提升用户控制感，一致术语减少 agent 与用户沟通时的歧义。
- 集成 SDK v0.0.54，上下文压缩更精准，错误信息更明确。
  *含义*：底层 SDK 的改进直接提升 agent 的上下文管理能力和调试体验。
