- `/verify` 和 `/code-review` 技能不再自动触发，需手动调用。
  - 含义：agent 需显式请求验证或审查，减少不必要的自动执行。
- 用户可通过 `/verify` 或 `/code-review` 命令主动启用这些技能。
  - 含义：设计上更强调用户控制，agent 仅在收到指令时执行特定任务。
- 此变更影响工作流自动化程度。
  - 含义：agent harness 需支持命令触发机制，而非全自动执行。
