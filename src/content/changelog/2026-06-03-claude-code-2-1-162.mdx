- `claude agents --json` 现在包含 `waitingFor` 字段，显示等待会话被阻塞的原因（如权限提示），这有助于开发者诊断 Agent 的阻塞状态。
- 修复了 WebFetch 权限规则未应用于内置预批准域的问题，明确规则现在优先于自动允许，这强化了 Agent 工具调用的安全边界控制。
- 修复了在流转 JSON/SDK 会话开始时发送中断信号被静默丢弃的问题，现在能正确中断并给予反馈，这确保了 Agent 交互的响应性和可控性。
