- MCP 工具调用路由从随机 uid 改为 server name，重启和服务器列表变化后路由稳定。
- 对 harness 设计：工具路由应基于稳定标识符，避免内存中临时 ID 导致状态不一致。
- 移除 McpHub 中残留的 server-key 机制，简化内部逻辑。
- 对 harness 设计：清理废弃机制，减少维护成本和潜在 bug。
