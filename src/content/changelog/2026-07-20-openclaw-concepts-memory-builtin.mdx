- 内置引擎使用 SQLite 存储记忆索引，支持 FTS5 关键词搜索和任意提供商的向量搜索，默认使用 OpenAI 嵌入。
  - 含义：agent harness 应默认提供无依赖的记忆方案，降低上手门槛。
- 索引将 MEMORY.md 和 memory/*.md 分块（400 token，80 token 重叠）存储，文件变更触发 1.5 秒防抖重索引，配置或提供者变更自动重建。
  - 含义：设计 prompt 时需考虑记忆分块与自动更新机制，确保检索内容时效性。
- 混合搜索结合关键词与向量，支持 CJK 三元组分词和可选 sqlite-vec 加速，无 sqlite-vec 时自动回退到内存余弦相似度。
  - 含义：混合搜索是平衡精度与覆盖度的实用策略，回退机制保证鲁棒性。
