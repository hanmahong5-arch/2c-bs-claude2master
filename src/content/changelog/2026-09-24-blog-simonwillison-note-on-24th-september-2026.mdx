- 他基于长期使用编码 agent 的经验指出，agent 确实能做出惊人的成果，但前提是使用者具备极高的纪律性与知识储备。这意味着团队引入 agent 时，真正的瓶颈往往不是模型能力，而是工程规范与判断力。
- 文章的核心判断是：agent 让软件工程变得「更难」而不是更轻松。对工具链的启示是，agent 的价值释放依赖配套的约束机制，而非单纯堆叠自动化能力。
- 他把这一结论归因于自身持续实践，而非理论推演。对开发者的含义是，评估 agent 时应把学习成本与纪律要求计入，而不是只看它能生成多少代码。
