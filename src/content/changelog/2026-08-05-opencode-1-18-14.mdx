- xAI 登录简化为单一设备码流程，更适合无头/远程环境。
  - 对 agent harness 设计：减少交互步骤，利于自动化部署。
- 保留结构化流式错误，兼容提供商可重试；增加瞬时错误重试。
  - 对 agent harness 设计：提升鲁棒性，减少手动干预。
- 远程工作区不再转发宿主目录，提示从远程根解析。
  - 对 agent harness 设计：确保路径一致性，避免混淆。
