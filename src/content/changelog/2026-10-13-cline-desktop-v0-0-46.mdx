- 左侧新增对话大纲，列出每条已发送 prompt，悬停预览、点击跳转；长会话定位不再靠滚动，harness 需维护可索引的 prompt 时间线。
- 插件加载或运行出错时在聊天中显示状态行，标明插件名与错误，不再静默丢失其工具；工具注册失败必须对 agent 可见，否则会静默降级。
- 定时任务修复：排队运行不再永久 pending，模型调用失败（如模型下线）标记为 failed 并带错误，停机后只跑最近一次错过的执行；routine 编辑器只列当前可用模型。
- 截图等图片不再计入 token 估算，避免自动压缩过早触发；自动压缩在目录无上下文窗口时改用所选模型的窗口。
