- 修复交互会话因内部布局错误停止重绘、Windows 下 git 找不到、/tui 回退模型等多项 bug，提升稳定性。
- 强化 claude.ai 同步技能：不再遮蔽本地命令或 MCP 提示，描述净化，且本地不执行 `!` 命令或展开 `@` 文件，对 harness 设计意味着需严格隔离外部技能的执行权限。
- 改进跨会话消息显示（内联展示发送者和内容），并优化 Vertex AI 凭据失败快速失败、压缩进度提示，对 harness 设计意味着需关注异步任务状态反馈和凭据错误处理的及时性。
