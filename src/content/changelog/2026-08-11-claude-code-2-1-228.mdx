- 修复多种 UI 和会话问题：布局错误导致重绘停止、TUI 模型回退、跨会话消息无收件箱等。
- 强化 claude.ai 同步技能：不再遮蔽本地命令或 MCP 提示，描述被清理，且不执行 `!` 命令或展开 `@` 文件，提升安全性。
- 改进跨会话消息显示：发送者和内容内联展示，远程控制会话显示会话名作为发送者。
- 优化 Vertex AI 凭据处理：过期或缺失凭据快速失败，避免长时间重试。
- Write 工具规则调整：新模型可覆盖未读文件，与 Edit 工具一致。
