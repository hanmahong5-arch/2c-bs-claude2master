- 弱模型（如 DeepSeek）发出的格式错误的工具调用（参数类型错误、JSON 截断）现在被优雅处理，不再报错而是继续执行，提高了 agent 对低质量模型的容错性。
- 计划/行动模式切换对模型可见，模型能感知到会话中模式的变化，有助于 agent 理解上下文切换。
- 修复了计划/行动模式通知在发送给模型的提示中被丢弃的问题，确保模式信息始终传递。
- 修复了在空会话中切换模式可能触发意外重启的竞态条件，提升了 agent 启动稳定性。
