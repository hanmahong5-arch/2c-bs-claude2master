- **含义**：Agent harness 设计必须确保思维链（Chain of Thought）的原始完整性不被意外篡改，尤其是在与不同模型版本交互时。
- **含义**：需要建立对模型输出格式（特别是结构化思维块）的版本兼容性检查和防护机制。
- **含义**：错误处理应能区分 API 错误是源于内容修改还是其他原因，以进行精准修复。
