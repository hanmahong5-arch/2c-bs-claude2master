- 这是 LLM 的 bugfix 版本，版本号 0.37.1，说明作者在稳定版线上做小步修复而非功能扩张；对依赖该 CLI 的 agent 脚本而言，升级风险低、可优先跟进。
- 发布说明明确列出 Steven Huang、Tao An、Arjan Mossel、XQ 四位贡献者；对开发者意味着该项目已形成外部补丁流入的协作模式，选型时可评估社区活跃度。
- 原文仅给出发布条目与标签 llm，未展开具体修复内容；对工具链维护者的含义是：需自行查阅仓库提交记录才能判断是否影响自身用法，不能只依赖发布公告。
