- ClinePass 提供商现已对所有用户启用，不再需要功能标志。
- 这意味着所有用户都可以使用 ClinePass 作为默认提供商，无需回退到标准 Cline 提供商。
- 对 agent harness 设计的影响：简化了提供商选择逻辑，所有 agent 可直接使用 ClinePass，无需条件判断。
