- **桌面应用无缝切换**：CLI 线程可直接移交至 Codex Desktop（macOS/Windows），Windows 工作区启动直达桌面，无需手动确认。这意味着 agent harness 设计需支持跨进程的无缝上下文传递。
- **图像路径暴露给模型**：本地图像附件和独立生成的图像保存路径现在可被模型读取，使后续编辑和文件引用更可靠。这要求 agent 在处理文件时能准确解析和传递系统路径元数据。
- **推理努力选择更灵活**：TUI 为缺失 `Alt` 键的终端提供备用快捷键，模型定义的推理级别按广告顺序流动。这提示 agent 的交互层需适配不同终端环境并尊重模型的能力声明。
