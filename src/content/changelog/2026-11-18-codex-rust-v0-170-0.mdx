- 权限更新与子线程不再丢失既有沙箱限制，会话设置入口统一归一化权限；harness 应把权限视为会话级不变量，而非可被子任务覆盖的局部状态。
- MCP OAuth 在取消、登录、登出时的凭据竞态被修复，刷新改为可取消安全；harness 需为工具凭据设计幂等写入与取消语义。
- 超大 WebSocket 请求立即回退 HTTP 且不重试，并遵守服务端声明的大小上限；harness 的传输层应显式区分可重试与不可重试失败。
