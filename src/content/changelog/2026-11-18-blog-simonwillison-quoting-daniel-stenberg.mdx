- 三周内 curl 主线合并 300+ 提交、修复 200+ bug 并处理若干漏洞，同期 AI agent 把 18.5 万行 C 转成 34 万行 Rust——含义：agent 产出的代码量不等于项目维护量，评估 agent 应看合并进主干的真实修复数。
- Stenberg 指出这些 Rust 重写版本不包含那 200 个 bugfix，且后续每月仍有约 200 个新修复——含义：一次性“vibe-porting”会迅速落后于上游，工具链需要持续同步上游补丁的机制。
- 他把这些重写称为“clones”，质疑它们能否跟上——含义：对开发者而言，移植类 agent 任务的价值取决于能否持续追踪并吸收原项目的安全修复。
