- Claire Vo 的 ChatPRD 免费试用被有组织滥用：有人反复注册试用、再用促销码续期，把额度转接到她的 agent 上，替一个 Roblox / Fortnite 地图工作室批量生成地图。含义：agent 产品的免费额度一旦可被程序化调用，就会变成可转售的算力渠道。
- 她观察到 agent 里高频出现“骑自行车的鹈鹕”SVG 提示词，这类提示词常被用来探测底层模型身份。含义：公开 agent 的日志会暴露上游模型，也会被当作模型指纹工具。
- 她最终决定彻底取消免费试用。含义：对做 agent 与工具链的开发者来说，防滥用成本可能高于试用带来的转化，额度设计需要从一开始就考虑身份与限流。
