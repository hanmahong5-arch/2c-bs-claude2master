- 回滚了模型更新：本次补丁版本撤销了此前的模型变更，说明模型升级会直接影响 harness 行为，需要可回退的版本策略。
- 回滚 MCP 默认版本选择更新：默认版本选择逻辑被还原，意味着 MCP 版本协商是 agent harness 的敏感环节，默认值变更需谨慎灰度。
- 定位为 patch release：仅做修复不做新功能，提示 harness 设计应把模型与 MCP 版本解耦为可独立回滚的配置项。
