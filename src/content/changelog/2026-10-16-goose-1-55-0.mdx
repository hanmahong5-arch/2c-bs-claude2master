- **W3C trace context 从 ACP prompt 传播到 MCP tool call**：跨层调用可串联追踪，harness 设计需在 prompt 与工具边界透传 trace 头。
- **子代理绑定父级的 hooks、mode 与 approvals**：子代理不再独立配置策略，harness 需把权限与钩子作为可继承的会话上下文。
- **删除旧 agent loop，移除后台子代理与 orchestrator**：执行路径收敛为单一循环，harness 设计应减少并行编排分支，降低状态分叉。
