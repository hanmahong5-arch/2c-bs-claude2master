- **Beam 开源模型**：Reflection 发布 501B 总参数 / 23B 激活的 MoE 模型 Beam，Apache 2.0 权重本月放出，宣称 SWE-bench Verified 80.9 分。对开发者意味着美国本土从零训练的开源权重又多了一个选项，但独立分析认为其水平大致在 GLM-5.2 附近。
- **订阅价值对比**：SemiAnalysis 测试发现 Claude 订阅提供的 API 等价价值是 OpenAI 方案的 5 倍以上，按任务成本调整后收窄到 1.3–2.9 倍。这提示工具链选型时不能只看标价，要按模型与 token 类型的实际 credit 成本核算。
- **多 harness RL**：Hugging Face 用捕获代理把 10 个未修改的 harness 变成 RL 环境，同一权重在 Mini-SWE-Agent 下得 62%、Claude Code 下仅 33%。说明 agent 评测结果高度依赖 harness，开发者需要固定环境才能比较模型真实能力。
