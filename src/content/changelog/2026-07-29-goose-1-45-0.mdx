- 新增稳定的事件消息标识，便于 agent 追踪和调试事件流。
- 支持最新 Gemini 模型及 Opus5 自适应思考，扩展 agent 可用的推理能力。
- 可配置 GOOSE_DOCS_ROOT 实现离线文档访问，适合隔离环境部署。
- 允许禁用内置技能，让 agent 只加载自定义工具集。
- 修复动态模型发现、DeepSeek v4 API 及 Grok 支持，确保模型选择器准确。
- 改进 ACP 工具调用处理，保留工具输出并修复链式摘要。
