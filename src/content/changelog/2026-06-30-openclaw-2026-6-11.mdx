- 修复了 Telegram、Discord、WhatsApp 等 30+ 渠道的消息错发、卡顿、重连丢失问题，确保回复准确到达目标对话。
  - 对 agent harness 设计意味着：多通道消息路由和重试逻辑需要更健壮的会话绑定和超时处理。
- 改进了 OpenAI、OpenRouter、Gemini 等模型的设置失败、流式中断和 fallback 行为，减少模型不可用时的无声失败。
  - 对 agent harness 设计意味着：模型选择、fallback 链和流式状态管理需要更清晰的错误传播和重试策略。
- 修复了会话压缩后上下文丢失、记忆搜索超时、跨 agent 访问权限提示不清晰等问题，提升长期对话连续性。
  - 对 agent harness 设计意味着：会话存储、压缩和记忆系统需要更严格的状态一致性和资源清理机制。
