- 插件对任意表或 SQL 查询定义多种图表类型（内置 D3、Observable Plot、topojson-client），并用启发式规则判断哪些图表适合当前数据；顶部建议缩略图本身就是真实数据渲染的。含义：可视化选型可以交给工具自动完成，减少人工试错。
- 与旧插件只画当前页最多约 100 行不同，新插件把每张图编译成 SQL，用 GROUP BY、时间分桶和窗口函数聚合整个结果集（可达数百万行），每次查询结果上限 5000 行。含义：图表正确性依赖查询下推，而非前端抽样。
- 大表建议图表时用采样避免评估全量结果集，图表状态存于 URL 的 #fragment，可收藏和分享。含义：可复现的分享链接对协作和调试有价值。
