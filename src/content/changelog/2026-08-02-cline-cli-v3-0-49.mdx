- 检查点恢复现在会完整回退工作区，删除任务后创建的文件，但保留 .gitignore 路径，这对构建产物管理很重要。
- Ollama 响应启动超时从 30 秒延长至 5 分钟，并重试空响应，适合本地大模型冷启动场景。
- 修复了 Windows 下 PowerShell 命令的 UTF-8 传输，避免非 ASCII 命令失败，对跨平台 harness 有参考价值。
