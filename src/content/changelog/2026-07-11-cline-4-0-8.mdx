- GCP Vertex 提供商新增更多模型选项，扩展了可用模型范围。
  - 对 agent harness 设计意味着：需支持动态模型列表，便于集成新模型。
- 模型下拉菜单增加自由输入选项，允许用户指定自定义 Vertex 模型。
  - 对 agent harness 设计意味着：需提供灵活的模型配置接口，支持用户自定义模型标识符。
