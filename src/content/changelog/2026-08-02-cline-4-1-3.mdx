- 修复合并包导致会话失效：旧窗口刷新 token 会挤掉新会话，现在保留当前会话并提示重载。
  - 对 harness 设计：多窗口共享 token 需谨慎，应隔离或协调刷新。
- 恢复可靠检查点：回滚现在能重放整个工作区，而非部分文件。
  - 对 harness 设计：检查点需覆盖完整状态，避免部分回滚造成不一致。
- 保留设置编辑：在 provider 配置加载完成前的修改不再丢失。
  - 对 harness 设计：异步加载时需合并用户输入，避免竞态覆盖。
