- Write 工具遇到超大 CLAUDE.md 或 @ 引用文件时，不再只看开头就覆盖，而是要求先读全文或原地编辑；harness 设计上应把「读全再写」做成工具级约束，而非依赖模型自觉。
- prompt 与 agent hooks 每会话最多并发 24 个（含子代理），另有最多 12 个超时等待槽，timeout 小于 1 秒按 1 秒计；说明 hook 调度需要显式的并发与超时预算，避免子代理放大负载。
- Bedrock、Vertex、Foundry、Mantle 上无法识别的模型名（自定义部署名、推理配置 ARN）改用短系统提示，拒绝回退也覆盖这些名字；harness 需为未知模型名保留降级路径与开关。
