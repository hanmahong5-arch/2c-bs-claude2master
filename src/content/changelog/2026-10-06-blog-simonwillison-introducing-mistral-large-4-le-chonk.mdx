- Mistral Large 4 预览版为 1 万亿参数、490 亿激活参数，在自家 3800 块 NVIDIA Grace Blackwell GPU 集群上训练，目前仅通过 API 提供，开放权重承诺月底放出。对开发者的含义：短期只能走 API 集成，权重发布节奏需纳入部署规划。
- 模型只支持 "none" 和 "high" 两档推理级别，且 "high" 档输出 2717 token 反而少于 "none" 档的 3275。对 agent 工具链的含义：推理档位粒度粗，成本与质量权衡空间有限，需自行在调用层做路由。
- Artificial Analysis 得分 38，略低于 552B 的 DeepSeek 4.1 Flash，但远超前代 Large 3 的 9 分。对开发者的含义：它并非前沿级模型，但已回到落后前沿约六个月的可用区间，值得作为中端备选评估。
