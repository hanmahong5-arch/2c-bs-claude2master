- **AINews v3 与社区合并**：作者 swyx 三年每工作日亲写 AINews，订阅超 20 万，但 Discord 因自我推广垃圾信息变冷清；计划把 Discord 与 AINews 的「待办任务」合并，并探索迁移到 Beehiiv 和新主页。对开发者含义：技术资讯与社区正从分散渠道收敛为一体化分发。
- **决策模型成新品类**：TypeSafe 的 Jev 用 RL 训练、返回带概率的类型化决策而非推理文本，论文称每 1K 次判断 0.044 美元、中位延迟 152ms，比 GPT-6 便宜约 277 倍，但 JudgeBench 落后 14.5 分；低置信度升级到 Astra 的级联可保住 99% 准确率、成本仅 57%。含义：廉价「System One」判断器适合嵌入 agent 工具链做路由与重排。
- **Agent 基础设施更新**：LangChain 在 Interrupt 发布 Managed Deep Agents 0.8（用户与 agent 记忆、访问策略、沙箱文件 API）与 smithtune CLI（把 trace 转成后训练数据集）；Perplexity 的 Rust 检索引擎 Photon 把内部 p99 从约 800ms 降到约 65ms，机器少约 20%、每文档数据多 2.5 倍。含义：记忆、评测与检索正成为 agent 栈的标配组件。
