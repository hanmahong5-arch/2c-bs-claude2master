- 新增托管 Git worktree 工具，可在受信任本地项目中创建和列出 worktree（#50148）：agent harness 需把工作区生命周期纳入工具层，而非依赖外部脚本。
- 命令中心支持用 `p` 钉选任务并归入共享 Pinned 组（#51500）：harness 需维护跨会话的任务优先级状态，并考虑服务端同步。
- TUI 支持 `/copy`、`Ctrl+Insert` 复制选区，鼠标滚轮速度可通过 `tui.mouse_scroll_speed` 调节（#50434、#50215、#50209）：harness 的交互层应把复制与滚动视为可配置的一等能力。
