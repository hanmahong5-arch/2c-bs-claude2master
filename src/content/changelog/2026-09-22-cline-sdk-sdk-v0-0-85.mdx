- 命中输出 token 上限且未产生可用工具调用时，运行不再直接失败，而是最多连续重试 3 次，并追加提醒要求精简回复、拆分大任务；计数在工具调用有进展或每次运行开始时重置，耗尽后仍报原有错误。含义：harness 需把「模型没来得及行动」与「任务失败」区分开，并保证 turn-finished 在每次恢复迭代前发出以配对事件。
- 默认输出额度改为随模型缩放：无请求上限与调用方默认值时用 max(32000, floor(maxOutputTokens*0.3))，只升不降，约 106,667 token 以下模型无变化，128,000 token 模型从 32,000 升到 38,400。含义：harness 的默认预算应随模型能力自适应，同时预期大输出模型单轮成本与延迟上升。
- 模型目录刷新：provider 仍为 209，模型从 6,188 增至 6,237；Cline Pass 新增 mimo-v2.6-flash 与 mimo-v2.6-pro，10 个未在 builtins.ts 固定默认模型的 provider 默认模型变更。含义：未固定模型的调用方需预期默认模型漂移。
