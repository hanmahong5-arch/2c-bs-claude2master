- **阻止未授权的破坏性 Git 和 IaC 命令**：自动模式下，若用户未明确要求，代理无法执行 `git reset --hard`、`terraform destroy` 等高风险命令，防止意外数据丢失。
- **改进配置与交互体验**：`/config` 指令支持 `--help` 查看键值，且切换设置更直观；移除了启动时的“设置问题”提示，需主动运行 `/doctor` 诊断。
- **修复多项子代理与界面错误**：解决了 WebSearch 在子代理中返回空结果、TUI 在 Windows Terminal 下渲染错乱、后台任务被意外终止等问题，提升了系统稳定性。
