- **PowerShell 命令解析改为异步**：core 与 cli 不再同步解析 PowerShell 命令，避免 UI spinner 冻结；harness 中任何阻塞式命令解析都应移出主线程。
- **版本推进至 0.71.0**：nightly 版本号 bump 到 0.71.0-nightly.20261118；harness 需关注版本号与 changelog 的对应关系。
- **GCP 开发 worker 推送到私有制品库**：发布流程调整；harness 的构建产物分发路径需同步核对。
