- 作者将2022年GPT-3和DALL-E生成的游戏概念截图直接喂给Claude Fable 5，要求其独立构建完整游戏，结果成功生成可玩的3D游戏，并部署到GitHub Pages。
- 关键技巧：通过GitHub Pages实时预览Claude Code的中间成果，并赋予其OpenAI API密钥用于生成纹理，弥补了Claude自身图像生成能力的不足。
- Claude自主添加了巡逻狗等游戏机制，并利用Playwright进行自测，修复了移动端可见性问题，展示了AI在复杂任务中的自主迭代能力。
- 对开发者而言，这验证了AI代理可独立完成从设计到部署的全流程，但需通过外部工具（如GitHub Pages）辅助监控和干预，提示未来工具链需强化代理的可观察性和可控性。
