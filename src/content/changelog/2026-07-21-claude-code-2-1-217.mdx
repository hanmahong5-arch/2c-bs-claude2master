- 新增 emoji 短代码自动补全（如输入 `:heart:` 插入 ❤️），可通过 `emojiCompletionEnabled` 设置关闭；对 agent 输入体验更友好。
- 修复 MCP 工具输出截断后仍保留完整结果导致的内存泄漏；agent 长会话内存更稳定。
- 限制并发子代理数（默认 20，`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` 可调），并禁止子代理默认嵌套；防止 agent 无限扇出，资源可控。
