- GitHub Models 提供统一 API 和模型 playground，最大优势是 GitHub Actions 可直接用环境中的 GitHub API key 执行提示，简化了构建流程。
- 退役原因未公布，但作者推测是编码代理模式导致免费或补贴 token 成本过高，难以维持。
- 作者改用 OpenAI API key 并设置月度限额，用 GPT-5.6 Luna 生成 README 摘要，说明开发者需灵活调整工具链以应对服务变动。
