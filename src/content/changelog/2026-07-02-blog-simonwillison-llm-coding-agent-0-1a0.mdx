- 项目基于 LLM 库的代理框架，通过两个提示（写 spec 和 TDD 构建）由 Fable 5 自动生成，展示了 AI 辅助开发的能力。
- 实现了六个工具（编辑、执行命令、列出文件、读取、搜索、写入文件），支持 `--yolo` 和 `--allow` 等模式，可灵活控制代理权限。
- 提供 Python API `CodingAgent`，允许开发者以编程方式运行编码任务，如修复测试，扩展了 LLM 在工具链中的集成深度。
