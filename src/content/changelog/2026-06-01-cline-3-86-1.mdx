- **修复了 `@` 文件提及失败的问题**：当工作区索引或内置 ripgrep 二进制文件不可用时，现在会保持文件搜索回退机制。这意味着 agent harness 在受限或更新后的开发环境中应具备更强的文件定位能力。
- **解决了特定环境兼容性问题**：特别针对 VS Code Remote SSH 和某些 VS Code 更新后的场景进行了修复。这表明 agent harness 需要更稳健地处理不同 IDE 和远程开发配置的差异。
- **增强了文件搜索的容错性**：通过保持回退机制，确保核心功能在依赖缺失时仍能工作。这提醒 agent harness 设计应优先保证基础功能的可用性，即使在非理想环境下。
