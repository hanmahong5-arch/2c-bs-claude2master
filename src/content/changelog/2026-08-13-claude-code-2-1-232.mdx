- 子代理 fork 默认开启，继承完整对话与缓存；交互式会话中非队友代理默认后台运行。
  - 对 harness 设计：需适配子代理并发与缓存复用，管理后台任务生命周期。
- 输入 @ 可提及另一会话，SendMessage 直达同名会话；会话命名自动去重。
  - 对 harness 设计：需实现跨会话消息路由与命名冲突处理。
- 新增 GitLab 令牌脱敏、插件市场支持 GitLab URL、配置别名。
  - 对 harness 设计：需扩展凭证保护与市场解析逻辑。
- 多项安全修复：PowerShell 权限绕过、Git Bash 符号链接、嵌套仓库信任等。
  - 对 harness 设计：需加强沙箱与路径验证，防止权限提升。
