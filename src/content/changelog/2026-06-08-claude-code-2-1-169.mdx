- 新增 `--safe-mode` 标志，用于禁用所有自定义配置以进行故障排查，意味着在复杂环境调试时能快速隔离问题源。
- 新增 `/cd` 命令，允许在不中断会话提示缓存的情况下切换工作目录，这对需要在不同项目间保持上下文的 Agent 工作流设计至关重要。
- 修复了企业 MCP 策略在重连等场景下未强制执行的漏洞，并解决了 macOS 上每轮对话初期的 UI 卡顿，提升了 Agent 平台的安全性与响应可靠性。
