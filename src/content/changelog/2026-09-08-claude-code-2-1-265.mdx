- 新增 `--plugin-dir` 指向文件夹时热加载子插件，支持运行时增删，便于动态扩展。
- 工具结果落盘新增 1GB 上限，超限截断并在预览中提示，需注意长输出管理。
- 修复子代理恢复时工具列表和系统提示变化导致缓存失效，提升恢复效率。
- 修复后台会话空闲超时误终止，以及远程控制结束信号提前发送的问题。
- 修复插件路径符号链接检查绕过漏洞，增强安全性。
