- **代码模式可直接调用独立网页搜索**：包括嵌套 JavaScript 工具调用，接收纯文本搜索结果，意味着代理能在代码执行中实时获取外部信息。
- **工具输入模式保留 `oneOf` 和 `allOf`**：大型模式在压缩时保持更浅的结构，提升与复杂 MCP 工具的兼容性，使代理能处理更丰富的模式定义。
- **`codex doctor` 增强本地报告细节**：包含编辑器和分页器环境信息，同时 JSON 输出中隐藏原始值，便于代理调试时保护敏感数据。
