GitHub COO Kyle Daigle 在访谈中深入探讨了 AI 代理（agents）的兴起对 GitHub 平台及整个软件开发生命周期带来的根本性挑战与机遇。

*   **AI 代理导致代码提交量激增**：2026 年 AI 生成的代码提交量增长了 1400%，这对围绕人类开发者速度设计的 GitHub 基础设施（如 CI/CD、数据库）造成了巨大压力，并引发了公开的稳定性问题。这意味着**平台和工具链必须为 AI 规模重新设计，以处理数量级增长的计算和协作负载**。
*   **“微技能”工作流与公司情境整合**：GitHub 正通过 WorkIQ、MCP 等工具将 AI 深度集成到 Slack、Teams、邮件等现有工作流中，强调细粒度的“微技能”而非庞大的“巨型技能”。这表明**AI 代理的发展方向是成为理解公司全域情境、无缝融入现有流程的助手，而非孤立的新工具**。
*   **AI 重塑开源协作与信任机制**：随着大量 AI 生成的“低质贡献”和“随意复刻”涌现，传统的 Pull Request 和代码审查模式面临挑战，可能演变为“提示词请求”和 AI 辅助审查。这要求**开发者和维护者必须建立新的信任与质量评估框架，以维护开源项目的社会契约和可持续性**。
