- 作者观察到 Bluesky 上也开始出现大量自动回复机器人，和 Twitter 一样烦人；但 Bluesky 有免费可用的 API，这让调查机器人变得可行。含义：开放 API 不只是开发便利，也是平台可审计性的基础。
- 工具检测的信号包括：回复与同一账号发帖间隔仅数秒、账号从不发原创内容/图片/链接而只回复高粉丝用户、以及回复中带问号。含义：这些是纯行为特征，不依赖内容语义，适合做成轻量规则型 agent 检测器。
- 该工具由 Opus 5.5 以 vibe coding 方式生成。含义：模型能力已足以让个人开发者快速产出针对具体平台 API 的小工具，检测与反检测的对抗成本都在下降。
