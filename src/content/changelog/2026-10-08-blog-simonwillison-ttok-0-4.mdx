- ttok 是作者用 OpenAI 开源 tiktoken 库写的 CLI token 计数工具，沉寂两年后发布 0.4 版本，修复了 Click 警告并更新了 CI——对依赖长期维护工具链的开发者来说，这类小工具的持续维护值得关注。
- 新增 `--list-models` 命令，可直接列出可用模型，方便确认当前支持的模型范围。
- 支持通过 `uvx` 直接运行，例如 `cat file.txt | uvx ttok` 即可统计文件 token 数，无需预先安装，适合快速嵌入 agent 或脚本的 token 预算估算流程。
