- 支持在终端用 `@` 引用其他 Codex 任务，可让 agent 读取、创建或发送消息，便于多任务协作。
  - 对 harness 设计：需在 agent 上下文中解析任务引用，并管理跨任务通信。
- `/copy` 新增响应目标选择器，可复制完整响应、代码块或引用块。
  - 对 harness 设计：需提供结构化输出选择能力，并保持与终端交互的一致性。
- 新增 `Interrupt` 钩子，可在顶层回合被中断时运行命令或 MCP 处理器。
  - 对 harness 设计：需定义中断生命周期，并允许自定义清理或恢复逻辑。
- 未受信任的项目不再提供项目级 `AGENTS.md` 指令，且权限更改后仍强制管理 deny-read 规则。
  - 对 harness 设计：需区分信任级别，并确保安全策略在动态权限变化中持续生效。
- 修复了 Unix 下因分离进程持有终端或输出缓冲导致的关闭挂起问题。
  - 对 harness 设计：需管理子进程的终端和输出资源，避免阻塞退出流程。
