- 文章介绍 NVIDIA 在 Hugging Face 上发布 Cosmos 3 系列开放模型，定位为交互式世界模拟（interactive world simulation）。对 agent 开发者而言，这意味着世界模型能力可通过开放权重直接接入工具链，而不必自建模拟环境。
- 标题强调“open models”，说明权重与模型卡在 Hugging Face 上公开可获取。对工具链的含义是：可复现的基线更易搭建，评估与微调流程能围绕公开模型展开。
- 主题聚焦“交互式”模拟，即模型需响应输入而非仅生成静态视频。对开发者的含义是：若要做具身或仿真类 agent，需关注其交互接口与时序一致性，而非只看生成画质。
