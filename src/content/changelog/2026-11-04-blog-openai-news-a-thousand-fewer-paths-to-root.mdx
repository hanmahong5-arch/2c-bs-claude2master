- OpenAI 构建了一条自主流水线，完成漏洞的发现、验证与补丁生成，目标锁定 Linux 内核的本地权限提升问题，最终覆盖 948 个漏洞。对 agent 工具链的含义是：发现、复现、出补丁可以串成一条端到端自动链路，而不只是单点扫描。
- 流水线强调“验证”环节，说明仅靠模型报出可疑点不够，还要有可执行的确认步骤才能进入补丁阶段。对开发者的含义是：给 agent 设计安全任务时，验证器与判定标准是核心组件。
- 产出物是补丁而非漏洞列表，意味着流程终点落在可提交的修复上。对工具链的含义是：安全 agent 的交付形态应包含 diff 与回归验证，方便接入现有评审流程。
