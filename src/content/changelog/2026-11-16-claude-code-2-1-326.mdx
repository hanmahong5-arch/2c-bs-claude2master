- Bash 权限检查收紧：部分删除/覆盖类命令（`find -delete`、`cat a > b`、`sort -o`）不再被误记为搜索或读取，且更多命令会先询问或在无人应答时拒绝；对 harness 意味着工具调用摘要必须按真实副作用分类，不能只按命令名归类。
- 沙箱默认写入范围缩小：macOS/Linux/WSL 下沙箱命令不再默认写入部分敏感 home 目录，需 `sandbox.filesystem.allowWrite` 显式放开；harness 设计应把可写路径作为显式策略输入，而非隐式继承。
- 权限钩子与 SDK 重写命令仍留在沙箱内，除非审批方传 `dangerouslyDisableSandbox: true`；这意味着审批层需要能区分“放行”与“解除隔离”两种语义，避免审批即逃逸。
