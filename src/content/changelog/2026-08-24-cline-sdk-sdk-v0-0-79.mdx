- 事件日志磁盘上限 64MiB，旧事件优先删除并 vacuum，每追加 16MiB 即触发清理，避免 SQLite 无限膨胀。
  - 对 harness 设计：需考虑事件日志的存储上限与清理策略，防止长期运行导致磁盘占用失控。
- 修复 `task.completed` telemetry 在多数交互会话中丢失的问题，现在每次会话结束都会精确发送一次。
  - 对 harness 设计：确保 telemetry 事件在会话所有退出路径中可靠发送，避免数据缺失。
- 模型目录更新，新增 AgentRouter 和 Opper 提供商，调整模型列表与价格，Aki.io 和 NanoGPT 的默认模型变更。
  - 对 harness 设计：需动态获取模型目录，避免硬编码默认模型，以适应提供商和默认值的变化。
