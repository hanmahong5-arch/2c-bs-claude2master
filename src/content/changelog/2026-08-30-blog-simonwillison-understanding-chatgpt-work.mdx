- ChatGPT Work 分云端和本地桌面两版，云端版可通过浏览器或手机访问，本地版更像 Codex 换皮，面向非开发者。
- 云端版支持代码执行并联网，可克隆 GitHub 仓库、装依赖、访问任意网站，远超 Claude 的受限容器，对开发者意味着更强大的自动化工具。
- 内置无头 Chrome 浏览器，可加载网页、填表、截图，甚至运行 JavaScript 提取 DOM 内容，类似 shot-scraper 但可移动端使用，简化了网页抓取与交互。
