- 作者认为 2025 年底 agent 突然变好用，是模型能力与 harness（模型外的工具、环境、上下文等）两条曲线交叉的结果，而非单一因素。
- 从 ReAct 到 AutoGPT 再到 Claude Code，harness 经历了从过度自主到人机协作再到重新赋权的过程，Claude Code 的成功在于抓住了模型能力超越 harness 的时机。
- 当前 harness 与模型开始共同训练，RL 进入 harness 内部，模型吸收 harness 能力，未来 harness 将转向管理人类注意力。
