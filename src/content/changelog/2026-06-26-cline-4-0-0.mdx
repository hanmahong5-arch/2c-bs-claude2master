- 引入 SDK 驱动的 VS Code 扩展运行时，任务、工具、Plan/Act 模式、MCP、检查点等均通过共享 SDK 会话层协调。这意味着 agent harness 需适配 SDK 会话管理，统一状态与错误处理。
- 新增 Customize 市场，支持发现和管理 Skills、MCP 服务器、插件，含安装/卸载、启用/禁用、搜索过滤。agent harness 可集成市场接口，实现动态能力扩展。
- 聊天支持消息排队与编辑重发，当前轮次中提交的消息进入队列，可取消。agent harness 需处理并发消息队列，确保用户输入不丢失。
