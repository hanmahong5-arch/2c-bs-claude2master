- 支持并行工具调用，多个工具可同时执行，减少等待时间。
- 对 agent harness 设计：需处理并发结果合并与冲突解决。
- 新增工具结果缓存，避免重复调用，提升性能。
- 对 agent harness 设计：需考虑缓存失效策略与一致性。
- 改进工具错误处理，提供更详细的错误信息。
- 对 agent harness 设计：需增强错误恢复与重试机制。
