- Clay 把 Sculptor 从工具循环重构成跑在 Pi harness 上的 coding agent，在云沙箱里调 Clay CLI，并新增 Audiences 数据层打通 CRM 与 Gong 记录。含义：agent 能力瓶颈常在工具面太窄和看不到业务数据，而非模型本身。
- Jeff 认为多数公司后训练太早：先用开源权重模型替换 Opus，再针对自家工具与查询做后训练；只有当推理支出达到 1000 万至 1 亿美元量级，节省才值得。含义：工具链团队应先优化推理成本结构，再谈自训模型。
- Clay 未用 Temporal 或 LangGraph，靠 BullMQ 加 Postgres/ClickHouse 自建调度，并用 LangSmith 排查“每行一个 agent”带来的推理尖峰，还做了限流与暂停恢复。含义：规模化 agent 产品的难点是公平调度与供应商故障处理。
