- MCP 工具输出超出上下文时，agent 现在拿到预览加一个链接，可用 `read_files` 分页读取剩余内容。含义：harness 需要把"截断"变成可寻址的分页资源，而不是丢弃数据。
- `providers.json`/`models.json` 里的自定义 provider 在运行任务时不再报 `Unknown or disabled provider`。含义：provider 注册表必须同时覆盖选择器 UI 与执行路径，避免两套解析逻辑分叉。
- 保存 provider 凭据失败时错误就地显示，不再静默失败；Linux 状态栏自动批准图标改用常见等宽字体含有的字形。含义：配置写入与状态展示的失败要显式暴露，否则 agent 会在错误前提下继续运行。
