- condense-json 通过一个替换表（replacements）将 JSON 中重复出现的字符串或子串替换为特殊语法 `{"$r": ...}`，从而压缩数据体积。
- 该库支持 `condense_json` 和 `uncondense_json` 双向转换，可逆操作，便于存储和恢复原始数据。
- 作者已将其用于 LLM 生成的 SQLite 日志中，以减少存储占用，体现了在工具链中优化数据持久化的实际价值。
