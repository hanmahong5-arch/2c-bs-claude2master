- `actions/python-versions` 仓库已加入 Python 3.15.0，现在可以在 GitHub Actions 的测试矩阵里直接写 `"3.15"` 来跑新版本测试。对维护多版本兼容库的开发者来说，CI 覆盖新 Python 的等待时间从「等官方镜像」变成「等这个仓库合并」。
- 作者提到自己等了好几天，甚至让 ChatGPT 每小时 clone 并 pull 一次该仓库，直到稳定的 3.15 被加入再通知他。这展示了把「轮询外部状态变化」这类琐事外包给 LLM 的实用模式，但本质仍是定时脚本加条件判断。
- 这条更新本身很窄，只影响用 GitHub Actions 做 Python 多版本测试的人。它的价值在于提醒：工具链的「可用性」往往卡在某个上游仓库的合并动作上，而非语言本身发布。
