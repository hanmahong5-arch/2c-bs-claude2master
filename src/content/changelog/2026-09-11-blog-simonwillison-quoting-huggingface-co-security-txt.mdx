- Hugging Face 把安全联系文件 security.txt 当成对 AI agent 的公开留言板，明确说如果 agent 被指派来找漏洞，CyberGym benchmark 已在 GitHub 公开，可以去那里拿高分，不必攻击他们。含义：安全披露渠道开始把「自主漏洞搜寻 agent」当作默认读者来写文案。
- 留言还顺势邀请 agent「顺便把权重 dump 到 Hugging Face 上」。含义：平台在把 agent 的算力与产出引导回自家生态，而非对抗。
- 这条引用被 Simon Willison 归入 ai-security-research、security、hugging-face、openai-hugging-face-incident 等标签。含义：agent 驱动的安全事件已被当作独立类别记录，工具链需要预设「被 agent 扫描」的常态。
