- **P0/P1 问题全部关闭**：约 700 个最高优先级问题在 12 天内解决，repo 中零 P0/P1 遗留。对 agent harness 设计意味着：团队承诺持续保持零积压，确保核心稳定性。
- **Mixture-of-Agents 成为一等模型**：MoA 预设作为可选模型出现在所有模型选择器中，并显示每个参考模型的推理过程，聚合答案实时流式输出。对 agent harness 设计意味着：多模型协作成为原生能力，无需额外配置。
- **代理可自我验证工作完成**：`/goal` 引入完成合约，代理通过运行项目检查而非模型断言来判断任务完成，并记录验证证据。对 agent harness 设计意味着：任务完成判断从“模型认为”转向“证据证明”，提升可靠性。
