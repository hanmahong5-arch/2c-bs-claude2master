- 新增 prompt-cache 生命周期控制器：长工具调用期间保持预热，空闲会话在 1h 缓存过期前压缩，`prompt_caching.cache_ttl` 默认 `auto`；harness 需把缓存 TTL 当作可调度资源而非固定配置。
- 压缩时归档被丢弃的工具结果，且主动工具结果裁剪默认开启；harness 设计要保证裁剪可追溯，避免上下文丢失后无法复盘。
- 存储层拆到持久化接口后接 SQLite 后端；harness 的会话与缓存状态可换后端，测试与迁移成本下降。
