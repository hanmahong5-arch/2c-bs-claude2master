- **重命名 `/simplify` 为 `/code-review` 并支持指定审查力度**：为代码审查任务提供了更明确的意图和可配置的粒度。
- **修复 Windows PowerShell 及 MCP 分页等多项工具链问题**：提升了在 Windows 环境及与 MCP 服务器交互时的可靠性与用户体验。
- **修复多代理会话中模型设置未转发等后台任务问题**：确保了复杂会话（如多代理、后台任务）中配置的一致性和权限管理的正确性。
