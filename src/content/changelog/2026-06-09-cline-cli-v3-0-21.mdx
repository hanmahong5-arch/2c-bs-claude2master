- **新增全局自动更新设置**：允许用户在 CLI 启动时控制自动更新，为 agent harness 设计提供了更灵活的环境配置管理。
- **支持 Vertex AI ADC 凭证**：工具调用现支持 Vertex AI 应用默认凭证，简化了 agent 在 Google Cloud 上的身份验证集成。
- **修复会话路由与消息重放问题**：改进了连接器线程会话路由和 Bedrock 空消息处理，增强了 agent 在多会话场景下的可靠性。
