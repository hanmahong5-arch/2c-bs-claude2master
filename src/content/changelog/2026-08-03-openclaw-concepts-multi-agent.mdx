- 每个 agent 有独立 workspace、agentDir 和 SQLite 会话库，绑定 channel account 到 agent 实现消息路由。
- 不要跨 agent 复用 agentDir，否则认证和会话状态冲突；OAuth 凭据默认不跨 agent 复制。
- 技能和插件存储可按 agent 隔离，如 Memory Wiki 设 scope 为 agent，避免知识共享。
