- `cline hub drain` 停止接收新变更工作，`--off` 解除；`hub upgrade` 排空后重启，中断时自动恢复，避免拒绝工作。
- 会话在 hub 重启后存活，客户端重连时按事件 ID 去重重放，确保不重复投递。
- 修复自定义 OpenAI 兼容模型因推断能力列表导致工具调用被静默禁用的问题。
- Langfuse 追踪现在携带会话和客户端身份，便于分组和版本追踪。
- 模型目录更新，影响多个提供商的默认模型选择。
