- 核心：改进与新版 MCP 服务器和 OAuth 流程的兼容性；修复 SDK 会话过期后 MCP 服务器重连，支持并发请求；`mcp debug` 现在会使用配置的 OAuth 回调端口；停止向新版 Gemini 模型发送已弃用的采样默认值。
  - 含义：agent 需处理 MCP 会话过期后的自动重连，并确保 OAuth 回调端口配置生效。
- 桌面：新增快捷键打开项目选择器；标签页键盘导航遵循可见顺序；打开文件时展开带尾部分隔符的 Windows 文件夹；集成需要关注时服务器状态显示蓝色；提供商连接状态更改后立即刷新；Linux 包安装 AppStream 元数据；本地桌面运行使用频道数据库；防止从主页关闭项目时冻结；防止右侧面板加载时冻结会话视图。
  - 含义：agent 需适配桌面端新的导航和状态刷新机制，确保与 MCP 服务器交互的稳定性。
- 社区贡献：修复核心中 MCP 环境字段；修复 Linux 包中 AppStream 元数据安装。
  - 含义：agent 需注意 MCP 环境字段的正确性，并支持 Linux 平台的元数据安装。
