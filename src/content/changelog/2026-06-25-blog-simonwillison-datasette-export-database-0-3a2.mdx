- 插件 `datasette-export-database` 0.3a2 修复了 `pyproject.toml` 中错误地将 Datasette 依赖锁定为 `==1.0a27` 的问题，改为 `>=1.0a27`。
  - 对开发者：依赖版本应使用宽松范围（如 `>=`）而非精确锁定，避免无意中阻断与其他版本的兼容性。
- 该插件允许用户从 Datasette 实例导出整个 SQLite 数据库文件。
  - 对工具链：导出功能增强了 Datasette 作为数据发布平台的能力，便于用户获取原始数据进行离线分析。
- 此版本被作者称为“令人尴尬的小版本”，但修复了实际使用中的兼容性问题。
  - 对开发者：即使微小修复也值得发布，维护依赖兼容性是插件生态健康的关键。
