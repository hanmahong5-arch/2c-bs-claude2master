- Simon 让 ChatGPT Work 用 OSM 数据规划从家出发的 5K/10K 环线，27 分钟后拿到可视化、GPX 和 GeoJSON 文件。含义：agent 已能端到端完成多工具地理任务，输出可直接落地。
- 它用 Nominatim 定位地址、Overpass 下载本地道路数据，再本地计算环线。含义：这类任务依赖公开地理 API 组合，工具链选型比模型本身更关键。
- 他抱怨看不到实际运行的代码，且线程被压缩后无法再取回。含义：任何使用 compaction 的 LLM 系统都应保留压缩前文本并通过工具调用暴露，否则开发者无法审计 agent 行为。
