- 新增 `claude self-hosted-runner`，可将自有机器或容器作为 Claude Code 会话的运行环境（Team/Enterprise 计划）。
  - 对 harness 设计：需支持自定义执行环境，并管理会话生命周期。
- 新增 `archive` 插件源，支持从 HTTPS zip 安装插件，可选 SHA-256 固定。
  - 对 harness 设计：插件管理需支持非 git/npm 来源，并验证完整性。
- 新增跨会话 `SendMessage`，会话间可互相发送消息，并通过 `ListAgents` 发现其他会话。
  - 对 harness 设计：需实现跨会话通信机制，并处理消息投递失败。
- 修复沙箱凭据掩码选项（如 JWT 解码、AWS SigV4 重签名）仅在特定设置下生效。
  - 对 harness 设计：需正确配置网络终止和设置来源，确保安全功能生效。
- 修复长项目路径（>200字符）导致会话目录串扰的问题。
  - 对 harness 设计：需处理路径哈希冲突，确保会话隔离。
- 移除每会话 200 子代理上限，但保留并发和深度限制。
  - 对 harness 设计：需调整资源管理策略，支持长时间运行会话。
