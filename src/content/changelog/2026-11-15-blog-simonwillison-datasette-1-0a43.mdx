- 内置 TSV/CSV 导出与插件可通过新的 `Response.stream()` 一次性流式输出整张表，1.0 里程碑完成度达 53%；对处理大表的 agent 工具链意味着更低内存占用与更快首字节。
- 修复一处私有存储查询可泄露标题与 SQL 的安全问题（已发 GitHub advisory，但不能执行该查询）；提醒开发者把查询元数据也纳入权限边界。
- 作者最兴奋的是极小的改动：用 `@view-transition` 与 `view-transition-name` 为多页应用加上跨文档视图过渡，Safari/Chrome 已支持，Firefox 预计 162 版落地；说明渐进增强的 CSS 仍能显著提升传统服务端渲染工具的体验。
