- 插件升级到 0.19，兼容 Datasette 1.0a42；对仍在跟进 1.0 alpha 的开发者，这意味着老插件需要持续跟进核心版本变化。
- 新增对 datasette-leaflet 的依赖，确保请求 OpenStreetMap 瓦片时带上 referrer 头；对依赖第三方瓦片服务的工具链，这类合规细节会影响服务可用性。
- 文中用加州 PG&E 电厂地图示例，同时展示 Datasette 重新设计的分面（facets）功能；对做地理数据浏览的 agent 工具，分面与地图结合是可直接复用的交互模式。
