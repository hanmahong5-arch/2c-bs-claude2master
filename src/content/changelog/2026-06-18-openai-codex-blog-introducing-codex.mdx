- **并行处理与沙盒执行**：Codex 为每个任务创建独立的云沙盒环境，预加载代码库，可并行处理多项任务。这意味着设计 prompt 时需确保任务描述清晰、独立，以便代理高效分配资源。
- **通过 AGENTS.md 文件引导**：用户可在仓库中放置 AGENTS.md 文件，指导 Codex 如何导航代码库、运行测试及遵循项目规范。这强调了为代理提供结构化上下文（类似项目指南）能显著提升其输出质量与合规性。
- **安全与验证机制**：Codex 在禁用互联网的隔离容器中运行，并通过引用终端日志和测试结果提供可验证的行动证据。这要求 prompt 设计需考虑任务的可观测性，并明确用户审查环节，确保安全可靠。
