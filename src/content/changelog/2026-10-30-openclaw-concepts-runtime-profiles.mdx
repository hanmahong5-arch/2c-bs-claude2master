- 运行时 profile 由独立产物的不可变 bootstrap 事实决定，manifest 仅作 fallback；用户设置、文件名后缀、OS 都不参与选择。含义：harness 应把执行模式当作进程级不可变契约，而非可运行时切换的开关。
- AOT 宿主中 Node Code Mode 的 node:vm 代码按解释执行，每进程只发一次性能提示；QuickJS 执行器不会被静默替换。含义：降级要显式告知且限频，避免逐 cell 刷警告。
- AOT 编译本身不禁止 eval/Function/VM 源码，--disallow-code-generation-from-strings 默认不启用；诊断应靠解析与静态检查而非执行探针。含义：安全边界靠权限与审批，不靠执行模式。
