- llm 0.35 版本新增对 OpenAI GPT-6 Astra 模型的支持，该模型是 GPT-6 系列的一部分。
- 对于开发者而言，这意味着可以通过 llm 命令行工具快速调用最新模型，简化了集成流程。
- 该更新体现了 llm 项目持续跟进前沿模型的能力，为 agent 工具链提供了及时的基础设施支持。
