- OpenAI 构建了名为 Pando 的 Git 兼容后端，目标是支撑 Codex 所开启的开发规模。含义：当 agent 大规模自动提交代码时，传统 Git 托管会成为瓶颈，后端需要重新设计。
- 文章强调 Pando 是“Git 兼容”而非另起协议，意味着现有工具链和开发者习惯可以延续。含义：agent 工具链接入新基础设施时，兼容性比全新 API 更能降低迁移成本。
- 该后端是围绕 Codex 带来的开发量而设计的，说明代码生成能力正在反向推动底层基础设施演进。含义：开发者评估 agent 工作流时，需把版本控制与托管层的承载能力纳入考量。
