- 基于 Grok Build 的 Rust 代码和 AlexanderGrooff 的 Go 库，分别编译为 WebAssembly，实现 Mermaid 到 ASCII 的转换。
- Go 版本支持颜色输出，比 Rust 版本功能更完整，适合终端或纯文本环境展示图表。
- 通过 WebAssembly 在浏览器中运行，无需后端服务，为开发者提供轻量级图表渲染替代方案。
