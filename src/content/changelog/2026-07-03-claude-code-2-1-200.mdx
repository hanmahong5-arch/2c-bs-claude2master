- AskUserQuestion 对话框默认不再自动继续，可通过 `/config` 设置空闲超时。这意味着 agent 需要更明确地等待用户输入，设计上需考虑用户响应延迟。
- 默认权限模式改为 Manual，CLI、VS Code、JetBrains 均统一。agent 在未获许可时不能自动执行操作，需显式请求。
- 修复了后台会话在睡眠/唤醒后静默停止、崩溃后 daemon.lock 导致 agent 无法重启等问题。agent harness 需更健壮地处理进程生命周期和锁文件。
