- Desktop v2 迁移完成，包括新布局升级处理和首次启动引导，意味着 agent 需要适配新 UI 布局。
- 新增新旧布局切换设置，过渡期内 agent 可兼容两种布局，需根据用户选择调整交互。
- 修复远程会话自动接受权限、终端标签聚焦、时间线同步等多个 bug，提升 agent 在远程和本地环境下的稳定性。
