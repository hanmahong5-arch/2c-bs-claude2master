- 桌面首启改为引导式设置对话，跑在免费试用模型 `nous/welcome` 上（每 OS 用户一次），无需 API key；含义是 harness 可把「配置」变成一次可被 agent 驱动的会话，而非静态表单。
- 新增 Connectors：Gmail、Linear、Notion 等托管应用经 Nous 工具网关接入，首次使用自动创建免费 connectors-only 身份，支持同一应用多命名账号；含义是工具接入从「先建账号再配 MCP」变为「同轮内登录即可用」。
- 本地模型一键化：自动安装并维护 llama.cpp（CPU/CUDA/Metal/Vulkan/ROCm），按 GPU 与内存给目录模型打分并选最高质量可容纳版本，支持 Hugging Face GGUF 断点续传；含义是 harness 需把硬件探测与运行时选择纳入自身职责，而非交给用户。
