- 新增环境变量 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` 可禁用全屏鼠标点击/拖拽/悬停，保留滚轮。设计含义：为需要纯键盘操作或防误触的场景提供细粒度控制。
- 修复钩子匹配器对带连字符标识符（如 `code-reviewer`）的误匹配，改为精确匹配；需用 `mcp__brave-search__.*` 匹配 MCP 服务器所有工具。设计含义：避免因模糊匹配导致意外触发，提升钩子路由的确定性。
- 修复 macOS 语音听写因默认输入设备变更而捕获静音、以及日语/中文/泰语等无空格语言自动提交不触发的问题。设计含义：确保语音输入在设备切换和不同语言下可靠工作，提升多语言用户体验。
