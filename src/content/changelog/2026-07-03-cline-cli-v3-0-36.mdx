- 修复了计划模式中`switch_to_act_mode`工具直到回合结束才生效的问题：模型会继续使用计划模式工具（无文件编辑器）并通过shell命令编辑文件。
- 切换至执行模式现在会立即结束计划模式运行，并使用完整的执行模式工具集自动继续执行已批准的计划。
- 标签页模式切换与回合完成竞态时，不再自动启动未批准的计划执行。
