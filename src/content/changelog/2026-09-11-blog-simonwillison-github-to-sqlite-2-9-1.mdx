- 该版本为 github-to-sqlite 2.9.1，核心改动是修复与 sqlite-utils 4.x 的兼容性（对应 issue #85）：依赖库大版本升级常破坏下游工具，维护者需及时跟进上游变更。
- 工具标签为 github 与 sqlite：它把 GitHub 数据抓取并落库到 SQLite，对 agent 与工具链而言，本地 SQLite 是低成本、可离线查询的结构化数据层。
- 这是一次小版本补丁发布，而非新功能：说明在依赖生态快速演进时，兼容性修复本身就是维持工具可用性的关键工作。
