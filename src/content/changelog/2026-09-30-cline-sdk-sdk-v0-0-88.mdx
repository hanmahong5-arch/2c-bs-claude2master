- Stop 不再丢失：`LocalRuntimeHost` 在 run 建立后补发 abort，并在新 turn 开始时清除残留的 between-turns abort 标记，避免上一轮的取消误杀下一轮提示。含义：harness 需把「取消意图」与「运行实例」解耦存储，否则准备阶段的取消必然丢失。
- 内容过滤不再被当成空响应：新增 `AgentModelFinishReason` 的 `content-filter`，AI SDK 与 ApiHandler 适配器都做映射，run 失败时给出被过滤提示并建议改写，`sdk.error` 事件携带 finish reason。含义：harness 应把 finish reason 作为一等状态透传到事件层，而不是折叠成空文本。
- 会话恢复恢复可用：0.0.87 引入的重复启动守卫会以「session already exists」拒绝已有 session ID，阻断桌面与 TUI 恢复，现已回退，云端控制器改为把初始 thinking 与 reasoning-effort 偏好存进 session metadata。含义：幂等守卫要区分「重复创建」与「恢复已有会话」。
