- 两周做出 Clef：Chen 称 Clef 直接复制 TypeSafe AI 的 Jev，而 Jev 本身花了两年才诞生，她把这归功于对方把 API schema 摸清了。含义：System One 范式的接口一旦定型，复刻成本极低，工具链会迅速商品化。
- 新模型 Clairic 做“提取”：针对 LLM 处理非结构化输入时易幻觉、返回畸形 JSON 的问题，用一次前向传播抽出带类型的值（如发票号）。含义：结构化抽取这类任务不必再走自回归大模型，小模型毫秒级返回更划算。
- 造模型是为了去风险：Chen 提到闭源的 Jev 跑不了、中国开源模型有监管风险、模型实验室的昂贵许可证都是隐患，团队主要做 post-training 而非从头预训练。含义：依赖第三方模型的 agent 栈需评估许可与合规风险，后训练能力比预训练更现实。
