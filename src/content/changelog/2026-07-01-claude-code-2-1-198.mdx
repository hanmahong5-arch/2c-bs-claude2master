- Claude in Chrome 现已正式可用，Chrome 扩展用户可直接使用。
- 后台 agent 新增 `Notification` 钩子（`agent_needs_input` / `agent_completed`），agent harness 可据此实现异步通知或状态轮询。
- 新增 `/dataviz` 技能，含可运行的色板校验器，agent harness 可集成图表与仪表盘设计指导。
