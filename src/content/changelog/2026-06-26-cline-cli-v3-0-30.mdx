- 状态栏新增 token 计数，与成本并列显示，便于监控 token 消耗。
- 新增 SAP AI Core 提供商支持，扩展模型接入选项。
- 改进 OpenRouter 推理禁用行为与提示缓存，提升推理稳定性。
- 修复“ERROR: EMPTY CONTENT”错误及 CLI 运行时打包问题，增强可靠性。
