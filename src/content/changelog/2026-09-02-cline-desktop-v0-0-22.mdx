- 新增从 Claude Code、Codex、opencode 导入历史会话，可批量选择并转为可恢复的 Cline 会话，导入后使用当前配置的 provider 和 model。
- 定时任务在侧边栏折叠为单行，显示运行次数，展开后按最新优先列出，便于管理。
- macOS 语音输入修复，需添加麦克风权限描述。
- Web 搜索默认开启；市场详情面板改为点击打开。
- 修复 Dify、SAP AI Core 等模型工具调用被静默禁用的问题，以及空能力列表导致图片读取丢失的问题。
