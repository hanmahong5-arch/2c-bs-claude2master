- 新增 Claude Fable 5.1 模型，默认使用，1M 上下文，价格 $10/$50 每百万 token，缓存读取 $0.25。
  - 对 agent harness 设计：需适配新模型参数与成本结构。
- 新增 `timeFormat` 和 `timeZone` 设置，支持 12/24 小时制及 strftime 格式。
  - 对 agent harness 设计：可自定义时间显示，便于日志与界面。
- 新增 Containment Escape 规则，自动模式不再自动批准云元数据获取等操作。
  - 对 agent harness 设计：需明确环境预期，避免意外批准。
- 新增 `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` 强制所有子代理使用指定模型。
  - 对 agent harness 设计：可统一子代理模型，简化管理。
