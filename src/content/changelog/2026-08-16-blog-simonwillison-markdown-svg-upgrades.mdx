- 工具支持粘贴 Markdown 或通过 URL 加载 Gist，渲染 SVG 并生成可书签的页面，方便分享 Markdown 转录。
- 新增 PNG/JPEG 标签页，在浏览器内将 SVG 转为位图，解决不支持 SVG 的平台分享问题。
- 新增 MP4 标签页，检测 SVG 动画并估算时长，用 ffmpeg.wasm 在浏览器内合成视频，突破平台限制。

对开发者而言，这展示了纯前端处理复杂媒体格式的可行性，也提示了工具链中“格式转换”作为通用需求的潜力。
