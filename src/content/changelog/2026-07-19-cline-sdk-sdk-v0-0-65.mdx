- Claude Code 和 Codex 提供者 SDK 改为可选对等依赖并按需加载，大幅减小安装体积，agent harness 需确保依赖声明正确。
- 团队运行中 spawn 工具不再暴露给队友 agent，agent harness 需调整权限模型，限制子 agent 的工具访问。
- 团队运行中出错的任务现在报告为失败而非完成，agent harness 需更新状态处理逻辑以区分失败与成功。
