- Paul Ford 认为浏览器是极其强大的应用软件，而调用这份能力的成本几乎每天都在下降。对 agent 与工具链的含义：越来越多能力可以留在浏览器内完成，不必自建原生客户端或重型后端。
- 这条判断出自他的文章《The Web Is More Than Enough》，标题本身就在主张 Web 已经够用。对开发者的含义：选型时先问 Web 能否满足，而不是默认上更复杂的方案。
- Simon Willison 以引用形式转述这句话，并打了 browsers、web-development 等标签。对工具链的含义：浏览器作为运行时的地位值得被当作一等基础设施来对待。
