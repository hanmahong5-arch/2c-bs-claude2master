- DeepSeek V4-Flash 0731 通过后训练将 Terminal-Bench 从 56.9 提升至 82.7，架构和规模未变，表明后训练优化可显著提升 agent 能力，对开发者意味着应重视微调和工具适配。
- 模型 API 定价 $0.14/$0.28 每百万 token，缓存命中折扣 98% 至 $0.0028，性能接近 GPT-5.6 但成本低 60%，推动价格战，开发者可更经济地集成高性能模型。
- 开放权重 MIT 许可，支持 256 路由专家、1M 上下文，并集成 DSpark 推测解码，量化版本可本地运行，促进开源生态和本地部署，降低对闭源 API 的依赖。
