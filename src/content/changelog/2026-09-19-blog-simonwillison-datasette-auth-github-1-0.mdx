- 作者在 agent.datasette.io 上运行该插件时发现登录会话持续不了多久，原因是插件设置 cookie 时没有带 Max-Age 参数，导致浏览器会话结束就失效，在 Mobile Safari 上尤其频繁。
- 修复在 #80 中完成，作者借此把插件正式升到 1.0，理由是它已存在较长时间，且同时针对 Datasette 0.65.x 和 1.0ax 做过测试。
- 作者提到自己正努力把稳定的插件更及时地提升到 1.0 版本。对维护工具链的开发者来说，这意味着长期停留在 0.x 的依赖未必不稳定，但版本号本身会影响使用者的信任与选型判断。
