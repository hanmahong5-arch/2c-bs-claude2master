- 修复官方 Moonshot 和 Kimi 提供商的系统提示词选择，确保使用正确的 Kimi 提示词。
  - 对 agent harness 设计：需按提供商区分模型能力，避免通用提示词导致行为偏差。
- 修复 xai 模型的 xhigh 推理强度设置，确保高推理模式生效。
  - 对 agent harness 设计：推理强度参数需与模型 API 对齐，否则影响复杂任务表现。
