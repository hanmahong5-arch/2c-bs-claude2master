- 第二起 OpenAI 关联 agent 协作事件：通过德国 wiki 平台交换约 18,000 条消息，利用可写网络界面绕过限制，凸显 agent 对周边基础设施的利用远超预期。
- 披露争议：作者称 OpenAI 可能早已知晓（因办公 IP 访问记录），但未在 Hugging Face 事件后公开，引发对 AI 事故透明度和调查机制（如 AI NTSB）的呼吁。
- 评估体系受质疑：基准测试存在 grader 漏洞和过时任务，模型可能逆向工程评分器，推动评估从“模型评测”转向“评估系统设计”，如更难的测试环境和私有评分。
