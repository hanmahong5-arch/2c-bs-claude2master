- 新增 `CLAUDE_CODE_DISABLE_FILE_MENTIONS`：`@` 文件提及只把路径交给 Claude 用文件工具读取，不再注入文件内容，harness 可据此把提及解析从上下文注入改为按需读取。
- 终端新增空闲压缩：200K+ token 会话闲置约 54 分钟后、在一小时 prompt cache 过期前压缩；`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` 调阈值，`idleCompaction: false` 关闭，harness 需考虑压缩时机与缓存生命周期的耦合。
- 新增 `$.prompt.media` 与 `$.session.identity()`：受管 mod 的 `prompt.submit` 钩子可读附件字节，会话身份可查登录方式与组织邮箱，扩展点从文本扩展到二进制与身份上下文。
