- 一个 skill 就是一个含 SKILL.md 的文件夹，附带脚本和参考资料，用来教 agent 特定任务或领域知识；Anthropic 做 Claude Code 时发现通用能力够用但缺业务流程知识，于是把它做成可复用的目录结构。对开发者的含义：技能可以像文件一样被编写、分发和版本化，不必绑定某个平台。
- 自 2025 年 12 月发布标准以来，已有 70 多个 agent 平台集成，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code；累计发布 100 万个 skill、安装近 2.8 亿次。对工具链的含义：跨平台技能生态已经形成规模，选型时要考虑格式兼容性。
- Anthropic 把名称、logo、GitHub 组织和 agentskills.io 域名捐给 AAIF，由 Anthropic、Google、OpenAI 等公司的工程师以个人身份维护，并提出版本化发布、正式提案流程和技能安全指南的路线图。对 agent 开发者的含义：标准治理转向社区，后续规范变化值得跟踪。
