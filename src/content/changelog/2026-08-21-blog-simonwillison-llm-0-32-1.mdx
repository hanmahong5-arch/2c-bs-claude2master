- OpenAI Python 库移除了对 httpx 的依赖，导致 LLM 因传递依赖而失效，0.32.1 通过固定 openai<3 临时修复。
- 对开发者而言，依赖传递性风险凸显，需主动声明直接依赖，避免隐式依赖断裂。
- 未来 0.33 版本将迁移至 httpx2，提示工具链需紧跟上游库变化，及时适配新 HTTP 客户端。
