- 自 v0.18.0 以来合并约 667 个提交，涉及 990 个文件，包含 Windows 安装器自愈、仪表板与网关修复、WhatsApp 仪表板配对、MCP 和提供者修复等。
  - 对 agent harness 设计意味着：需要为频繁的补丁发布准备自动化测试和回滚机制，确保基础设施稳定性。
- 此版本为基础设施驱动的补丁标签，完整变更日志将在 v0.19.0 中发布。
  - 对 agent harness 设计意味着：版本发布策略应区分补丁和功能发布，补丁聚焦稳定性，功能变更集中记录。
- 更新方式包括 `hermes update` 和 `pip install -U hermes-agent`。
  - 对 agent harness 设计意味着：支持多种更新路径，需确保升级脚本的健壮性和向后兼容性。
