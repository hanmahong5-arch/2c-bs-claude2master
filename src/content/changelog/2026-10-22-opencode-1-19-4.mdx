- Bun 运行时升级至 1.4.4，包含 Brotli、TLS、HTTP/1.1、HTTP/2、HTTP/3、WebSocket 与 fetch 的安全修复：harness 的网络栈安全依赖内置运行时版本，升级即降低攻击面。
- 根证书更新至 NSS 3.131.1：证书信任链随运行时更新，harness 调用外部 API 时无需自行维护证书配置。
- 本次仅涉及运行时与证书更新，未提及 API 或行为变更：升级风险低，适合作为常规安全补丁纳入发布流程。
