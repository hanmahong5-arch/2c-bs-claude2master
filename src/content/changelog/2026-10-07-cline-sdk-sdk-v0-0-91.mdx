- 结束原因缺失或无法识别时不再当作成功完成，`AgentModelFinishReason` 新增 `unknown`；无工具活动时保留部分响应并追加一条隐藏用户消息重试一次，第二次仍未知则判定失败。含义：harness 需把「完成信号」与「内容产出」解耦，并给重试设硬上限。
- 队列中的用户消息现在在每个请求边界消费，包括首次迭代。含义：消息注入点从轮次末尾前移到每次请求前，避免首轮排队消息被吞。
- Stdio MCP 服务器默认初始化预算从 3s 提到 10s，显式 `timeout` 仍可覆盖。含义：Windows 上经 cmd.exe 启动 npx/uvx 常需 3-6s，过短超时会静默丢会话，启动预算应按最慢启动路径设定。
