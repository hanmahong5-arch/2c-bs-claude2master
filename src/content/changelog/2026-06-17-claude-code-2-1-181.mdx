- **新增 `/config key=value` 语法**：允许在提示符中直接设置任何配置项（如 `/config thinking=false`），适用于交互模式、`-p` 参数和远程控制。这意味着 Agent Harness 的设计需要支持运行时动态配置注入。
- **改进长段落流式显示**：文本现在逐行显示，而不是等待第一个换行符。这对 Agent Harness 的实时反馈和用户体验设计提出了更高的流式处理要求。
- **修复 Write/Edit 在云同步文件夹的问题**：解决了网络驱动器和云同步文件夹中生成 0 字节或截断文件的问题。这表明 Agent Harness 在处理外部文件系统时需要更强的鲁棒性和事务完整性。
