- 企业 MCP 控制现在应用于 Customize 市场：当远程配置禁用市场时，MCP 条目被隐藏；配置了 allowlist 时，仅显示允许的 MCP 服务器。
  - 对 agent harness 设计：需确保市场与远程配置同步，避免泄露未授权工具。
- 修复了自定义 OpenAI 兼容模型在能力列表为空时无法调用工具的问题。
  - 对 agent harness 设计：需处理能力列表缺失的兼容性，确保工具调用稳定。
