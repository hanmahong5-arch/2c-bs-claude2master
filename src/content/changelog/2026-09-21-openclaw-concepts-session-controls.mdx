- 用 `/active-memory status|off|on` 只切换当前会话，不动 `plugins.entries.active-memory.config.enabled` 等全局配置；全局形式需 owner 或 operator.admin，且只写 config.enabled 而保留插件 enabled，以便之后还能开回来。含义：harness 应把「本次会话临时状态」与「持久配置」分成两条写入路径，避免调试动作污染部署配置。
- 默认注入的是隐藏的 untrusted prompt prefix，正常回复里看不到；开 `/verbose on` 会在回复后追加状态行（status、elapsed、query、summary 字符数），`/trace on` 追加 debug 摘要，`/trace raw` 才显示原始 `<active_memory_plugin>` 前缀。含义：诊断信息作为 follow-up 追加而非前置气泡，且按粒度分级暴露，是 prompt 注入类功能可观测性的可复用设计。
- 阻塞式子 agent 的 transcript 默认在运行结束后删除，需参考 Transcript persistence 才能保留。含义：临时中间上下文默认不落盘，harness 要把「可回放」做成显式选项而非默认行为。
