- **新增官方插件库**：可直接通过 slug 从 `github.com/cline/plugins` 集合安装插件，简化了 Agent 生态集成流程。
- **插件技能分组**：插件现在可以捆绑技能，并在设置中分组显示，这优化了复杂 Agent 的功能管理界面。
- **增强供应商配置**：为 Anthropic 类供应商支持自定义基础 URL，并修复了 OAuth 令牌迁移问题，提高了 Agent 部署的灵活性。
