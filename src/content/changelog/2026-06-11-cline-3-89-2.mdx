- **升级 Anthropic SDK**：修复了在 VS Code 1.123+ 上 Anthropic 提供商的问题，确保与 Node 24 运行时兼容。这意味着 agent harness 必须保持核心依赖的及时更新，以避免运行时环境升级导致的意外中断。
- **同步 Vertex AI SDK**：更新了 Vertex AI 提供商，使其与升级后的 Anthropic SDK 兼容。这表明当底层服务 SDK 变更时，相关的集成提供商需要同步更新，以维持整个工具链的功能一致性。
- **聚焦依赖管理**：此次发布专注于修复因依赖版本不匹配导致的特定问题。这强调了在 agent harness 设计中，需要建立严格的依赖版本控制和兼容性测试流程，以快速响应上游变化。
