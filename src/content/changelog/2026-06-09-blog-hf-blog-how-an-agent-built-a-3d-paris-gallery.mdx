本文演示了一个智能体如何通过连接两个独立的 Hugging Face Space 应用，自动生成一个 3D 巴黎艺术画廊。
- **智能体协调流程**：智能体首先调用一个文生图模型生成巴黎场景的图片，随后将图片传递给另一个 3D 场景生成器。这展示了智能体可以编排不同专长模型的工作流。
- **降低开发门槛**：开发者无需从头构建复杂的多模态系统，而是可以像搭积木一样复用社区已有的成熟 Space。这极大地加速了创意应用的开发周期。
- **空间即服务接口**：每个 Hugging Face Space 本身就是一个可调用的 API 端点。这种设计使得任何模型都能被轻松集成到智能体驱动的工具链中，促进了模块化与协作。
