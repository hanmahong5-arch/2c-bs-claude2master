- 新增 `llm openai endpoint add` 命令，可配置使用 OpenAI 兼容接口的额外模型；这意味着接入自建或第三方推理服务时，不必再改代码，只需增加一条配置。
- 默认模型切换为 gpt-6-luna，价格是旧默认 gpt-5.6-luna 的一半；对长期运行 CLI 或批量调用 embedding 的开发者来说，成本直接减半。
- embedding 支持按内容区分 content-type，以适配 Gemini Embedding 2 这类可嵌入文本、音频、图像、视频的模型；多模态检索工具链不必再为不同媒体类型分别建管道。
- 作者称 AI 辅助 PR 并未成为负担，他用 Opus 5.5 / GPT-6 Astra 辅助分诊，把这类 PR 当作“附带示例的 bug 报告”；这提示维护者可把 AI 用在评审入口，而非直接合并。
