- 无 API key 的本地/自托管 provider（LM Studio、Ollama、vLLM 等）恢复可用，此前每轮都报 "Missing API key"；harness 需把"无密钥"视为合法配置而非错误分支。
- Hub 连接中断后自动重连最多一分钟，排队消息在恢复后补发，失败则以提示结束该轮；harness 应把连接恢复与消息队列纳入会话状态机，而非直接抛错。
- Windows 上 `npx`/`uvx` 启动的 MCP server 默认超时从 3 秒提到 10 秒，此前常被静默丢弃；harness 的进程启动超时应按平台与包管理器差异调优，并避免静默失败。
