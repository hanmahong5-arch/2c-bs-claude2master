- 文件写入工具创建的新文件现在使用平台原生换行符，避免跨平台不一致。
- 修复 `search_codebase` 在包含超长单行文件时崩溃的问题，提升稳定性。
- Git 远程 URL 中的凭据从系统提示中的工作区信息中移除，增强安全性。
- Claude Code 被标记为订阅计费，宿主可隐藏其按 token 价格和 API 成本估算。
- `installMcpServer` 不再将 `--` 分隔符视为 stdio 命令的一部分。
- `tasks` 工具可配置为仅提供计划任务，禁用 Todo 类型但保留 Agenda 后端。
- 模型目录刷新，新增 7 个提供商，并更新模型列表和价格，多个默认模型变更。
