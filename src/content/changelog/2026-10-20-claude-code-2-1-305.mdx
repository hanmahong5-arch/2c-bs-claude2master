- 新增 `sandbox.allowNestedUserNamespaces`，Linux 沙箱内命令可创建 user namespace（Chromium、rootless podman），但这也让它们绕过沙箱文件保护：harness 需把该开关当作显式信任升级，默认关闭并审计。
- 修复 2.1.304 回归：端点或网关拒绝 tool search 时，Vertex、Bedrock 等所有请求都失败；现在会自动去掉该能力重试：harness 应把可选能力做成可降级路径，而非硬依赖。
- 新增 `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`，让无人值守重试模式能察觉提前解除的用量限制：长时无人运行需主动轮询外部配额状态，不能只等重置时刻。
