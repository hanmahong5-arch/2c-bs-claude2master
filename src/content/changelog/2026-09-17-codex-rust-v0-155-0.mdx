- 新增实验性 `/voice` 语音对话，带实时转录与麦克风控制，需通过 `/experimental` 开启；对 agent harness 的含义是语音输入成为可插拔的会话通道，而非独立应用。
- 本地 TUI 会话中 MCP 请求支持 Touch ID 验证（限支持的 Mac）；含义是敏感工具调用可在 harness 层插入原生身份确认，而不只依赖 token。
- 守护进程更新可配置调度，并新增 `codex app-server daemon update`，重启后已保存线程与活跃目标可恢复；含义是长时任务的状态持久化成为 harness 的默认契约。
