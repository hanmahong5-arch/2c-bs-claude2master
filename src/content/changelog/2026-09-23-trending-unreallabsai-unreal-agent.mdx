- **是什么**：unreal-agent 是一个用 Go 实现的 agent harness，核心设计是 async-first，即把异步作为默认执行模型而非事后补丁。
- **为什么值得关注**：Go 生态里 agent 框架相对稀缺，1229 星说明社区对高性能、并发友好的 agent 运行时需求真实存在；async-first 的定位也区别于多数 Python 同步式方案。
- **参考价值**：对 agent 基础设施、工具链和后端开发者有直接参考意义，尤其是需要在 Go 服务里嵌入 agent 循环、关注并发与吞吐的场景。
