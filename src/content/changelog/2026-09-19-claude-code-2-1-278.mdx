- 自动模式对 Claude API、Enterprise 及 Bedrock、Vertex、Foundry、网关用户默认改用服务端分类器，分类器开销不再计费；Bedrock 等平台可用 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 退出，回退到计费路径时会给出警告。含义：harness 可把分类决策外移，成本模型与本地执行解耦。
- `/status` 新增 `Auto mode server` 行，显示当前会话的自动模式分类器是否运行在服务端。含义：agent harness 需要把「决策在哪执行」作为可观测状态暴露给用户。
- 计费回退会显式警告，而非静默切换。含义：harness 在降级路径上应保留提示，避免用户对成本来源失去感知。
