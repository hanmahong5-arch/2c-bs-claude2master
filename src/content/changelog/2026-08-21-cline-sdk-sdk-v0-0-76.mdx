- 新增模型驱动的图像生成，图像持久化到会话历史与导出，需模型支持。
- 代理可创建定时任务与持久化待办议程，作用域限定工作区。
- 技能斜杠命令改为通过 skills 工具加载，记录输入而非 SKILL.md 全文，避免重复注入。
- 修复 provider 执行工具活动被丢弃，现以观察事件呈现。
- PreToolUse 的 contextModification 现在会传递给模型，PostToolUse 钩子被等待并支持取消。
