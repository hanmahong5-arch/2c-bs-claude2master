- hub 支持排空与升级，拒绝新变更但完成运行中任务，持久事件日志让重连客户端重放，事件按 id 去重，避免重复投递。
- 修复自定义 OpenAI 兼容模型因能力列表推断导致工具调用被静默禁用的问题，显式能力列表仍生效。
- Langfuse 追踪增加会话与客户端身份，hub 会话从请求头重建，委托代理归入父会话。
- 模型目录刷新，多个提供商默认模型变更，未固定模型的用户将受影响。
