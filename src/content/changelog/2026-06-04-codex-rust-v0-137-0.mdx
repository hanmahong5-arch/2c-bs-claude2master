- **多智能体 V2 运行时选择与元数据**：每个线程保留运行时选择，并默认隐藏生成的智能体元数据。这意味着智能体编排系统需要支持更细粒度的运行时环境管理和更简洁的协作界面。
- **企业级配置与信用额度管理**：支持云端管理的配置包（包括 EDU 工作区）并显示月度信用额度。这表明平台正在强化集中式、可审计的企业部署和资源管控能力。
- **插件工作流与工具增强**：插件列表支持 JSON 输出，且托管网络/图像工具在更多代码模式中可用。这要求智能体工具集成框架提供结构化的插件发现接口和并行化执行能力。
