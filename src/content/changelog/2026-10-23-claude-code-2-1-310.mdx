- 网关拒绝 `effort-2025-11-24` beta 值或中途 system 消息时，Claude Code 自动去掉后重试；harness 需把能力协商失败当作可降级路径而非硬错误。
- 修复 "Prompt is too long" 后压缩仍保留大量 base64/SVG 密集文本导致再次失败；压缩策略应按 token 密度裁剪，而非只按消息数。
- 非交互会话（`-p`、Agent SDK）在超大 transcript 压缩时内存占用改善；长跑批处理 harness 可减少 OOM 风险。
