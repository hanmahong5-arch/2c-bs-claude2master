- Anthropic 宣布从 8 月 14 日起，Claude Code 的 Pro、Max 和 Team 计划新会话默认启用自动模式，内部几乎全员使用。
- 内部测试显示，人类仅拒绝 13.6% 的危险操作，而自动模式可拦截 89%，凸显确认疲劳问题。
- 第三方评估称 720 次间接提示注入攻击均未成功，但作者质疑恶意包指令等场景，认为需更多独立验证。

对开发者而言，自动模式减少人工确认，但安全边界仍需谨慎设计，尤其在工具链中限制数据访问。
