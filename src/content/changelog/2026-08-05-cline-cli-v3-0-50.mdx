- 新增 TUI 主题选择（/theme 或设置），支持 11 种内置主题，CLINE_THEME 可覆盖。
  - 含义：harness 可让用户自定义界面，提升可辨识度。
- Plan 模式硬拦截文件编辑命令（sed -i、重定向等），仅允许只读命令。
  - 含义：harness 需区分命令类型，严格限制写操作，增强安全性。
- 空模型响应在所有 provider 上重试，不再直接失败。
  - 含义：harness 应实现重试逻辑，提高鲁棒性。
- 上下文耗尽时自动压缩并重试一次，而非报错。
  - 含义：harness 需处理长对话，自动压缩策略。
- 修复 Telegram 斜杠命令被拦截、竞态连接、Bedrock 缓存等问题。
  - 含义：harness 需注意集成细节，避免静默失败。
