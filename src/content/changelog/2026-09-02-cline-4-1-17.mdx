- 修复 Hub 进程内存膨胀：状态更新不再广播完整对话，只传状态快照。
  - 对 agent harness 设计：长会话中应避免全量状态广播，采用增量或快照以控制内存。
- 修复工具调用被静默禁用：Dify、SAP AI Core 等模型目录能力列表为空被误读为禁用。
  - 对 agent harness 设计：能力列表为空时应视为未知而非禁用，需显式声明不支持。
- 修复恢复检查点后丢失提交：若之后有提交则拒绝恢复，避免静默丢失。
  - 对 agent harness 设计：恢复操作需检查状态一致性，防止覆盖后续变更。
