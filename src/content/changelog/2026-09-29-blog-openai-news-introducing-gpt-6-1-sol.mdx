- 定位：GPT-6.1 Sol 面向编码、computer use 与专业工作场景，官方称其具备接近 Astra 的智能水平。
- 价格：标准 API 的输入与输出 token 单价均为 Astra 的五分之一，直接压低高强度 agent 调用的成本门槛。
- 含义：对依赖多轮工具调用和长上下文的 agent 工具链来说，单位任务成本可能显著下降，值得重新评估模型路由与预算分配。
