- **新增 Snowflake Cortex 外部浏览器 OAuth**：简化了与 Snowflake 服务的认证流程，意味着 agent harness 需要支持更灵活的外部身份验证集成。
- **修复 MCP 会话管理与工具输出**：恢复了过期会话、清理了陈旧连接并结构化工具输出，要求 agent harness 具备更健壮的长连接和状态管理能力。
- **修复 TUI 渲染与命令注入问题**：解决了重复渲染 ID 和 `$ARGUMENTS` 导致的文件内容重复注入，强调 agent harness 的 UI 层需要稳定的组件标识和安全的参数传递机制。
