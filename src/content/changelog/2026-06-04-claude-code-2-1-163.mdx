- **新增版本范围管控设置**：管理员可设定 Claude Code 的允许运行版本范围，版本不符将拒绝启动并引导用户使用批准版本，强化了企业环境下的版本合规与安全管控。
- **新增插件列表命令**：通过 `/plugin list` 命令可列出已安装插件，并支持按启用/禁用状态筛选，便于开发者集中管理和排查插件依赖问题。
- **优化后台进程与会话管理**：修复了 `claude -p` 在后台命令不退出时可能永久挂起的问题，并确保后台代理会话在 Claude Code 更新后能在后台静默升级，提升了长时间运行任务的可靠性。
