- **自动模式扩展至三大云平台**：Bedrock、Vertex 和 Foundry 现已支持自动模式。
  - 含义：为多平台用户提供了统一的自动化体验，简化了跨云部署流程。
- **支持 Opus 4.7 和 Opus 4.8 模型**：自动模式功能适用于这两个最新模型版本。
  - 含义：确保用户能立即利用最新的模型能力，无需等待功能适配。
- **通过环境变量手动启用**：需设置 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 来激活此功能。
  - 含义：保留了用户的选择权，允许根据具体需求逐步采用新特性。
