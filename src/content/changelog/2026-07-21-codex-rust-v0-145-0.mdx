- 稳定多智能体 V2 体验，支持可配置子智能体模型、推理级别、并发、角色恢复与导航改进。
  - 设计含义：Agent harness 需支持多智能体编排、角色管理与并发控制。
- 新增实验性分页线程历史，支持高效恢复、搜索、持久化名称、子智能体与记忆。
  - 设计含义：Agent harness 需管理长对话状态、分页存储与子智能体上下文隔离。
- 扩展 `/import` 支持迁移 Cursor 和 Claude Code 设置、MCP 服务器、插件、会话、命令及项目级记忆。
  - 设计含义：Agent harness 需提供标准导入接口以兼容第三方工具配置与记忆。
- 新增音频输入/输出与流式实时 V3 对话，支持常见本地音频格式。
  - 设计含义：Agent harness 需处理多模态输入输出与实时流式通信。
- 改进终端响应性能：增量 Markdown 渲染、减少重绘、缓存、有界命令输出。
  - 设计含义：Agent harness 需优化流式输出渲染与 UI 响应性。
