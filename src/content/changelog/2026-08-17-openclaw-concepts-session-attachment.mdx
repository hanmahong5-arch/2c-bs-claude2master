- **Gateway 统一会话状态**：所有客户端（TUI、移动端、ACP）通过 Gateway 协议读写同一会话，避免独立副本。
- **短链接解析**：短 ID 是权威标识，客户端可请求更长前缀解决歧义，提升链接稳定性。
- **attach 临时 MCP 授权**：`openclaw attach` 为编码工具生成会话级临时授权，退出即撤销，安全且灵活。
