- **插件命令现可向代理提交提示词**：扩展了插件的交互能力，使外部工具能更灵活地驱动代理行为。
- **支持覆盖 API 基础 URL**：允许用户自定义后端服务地址，增强了部署和测试的灵活性。
- **设备认证时自动打开验证 URL**：简化了登录流程，减少了手动操作步骤，提升了用户体验。
