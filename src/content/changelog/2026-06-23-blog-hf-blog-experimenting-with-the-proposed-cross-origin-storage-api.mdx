- 浏览器中加载大型 AI 模型受限于存储配额，Cross-Origin Storage API 允许跨域共享存储空间，减少重复下载。
- 该 API 仍处于提案阶段，Hugging Face 通过 Transformers.js 提前实验，为开发者提供实际使用反馈。
- 对开发者而言，这意味着未来浏览器端 AI 应用可更高效地缓存模型，降低带宽和加载时间。
