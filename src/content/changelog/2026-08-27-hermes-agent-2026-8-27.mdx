- 新增 consent-gated 真实浏览器配置浏览，支持 Windows 关闭审批流；桌面浏览器独立 OS 窗口，SSH 远程更新引擎。
  - 对 harness 设计：需处理用户授权边界与远程控制安全。
- 远程 MCP 目录扩展至 50+ 供应商托管服务器，web_search/web_extract 支持 TTL 缓存，默认 lean-tail 压缩。
  - 对 harness 设计：缓存与压缩策略影响工具调用延迟与 token 成本。
- 多查询 tool_search 带词干提取，OS 钥匙串加密存储 secrets，更新器通过控制套接字暂停网关。
  - 对 harness 设计：增强工具发现与密钥管理，更新流程更安全。
