- LSVP 为生命科学团队提供 Mythos、Opus、Sonnet 模型，解除一般模型对生物任务的封锁，覆盖药物发现、临床开发等。对 agent 开发者意味着在合规领域可调用更强模型，但需通过机构验证。
- 验证后分 Standard Use 和 High-risk Use 两类授权，后者移除所有生命科学防护，仅限单个项目且每半年续期。这提示工具链需支持细粒度权限与项目级隔离。
- 安全策略从实时拦截转向离线监控，要求保留 30 天数据，并针对访问劫持、内部威胁和 agent 滥用设计共享责任模型。对 agent 系统而言，长时任务和 swarm 行为需纳入可审计范围。
