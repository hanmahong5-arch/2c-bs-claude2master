Cohere 发布 North Mini Code，这是其首个专门为开发者设计的代码模型，旨在提升代码生成、理解和编辑的效率。

- **专为代码任务优化**：模型在大量代码数据上训练，针对生成、补全和解释代码进行了专门优化，这意味着开发者能获得更准确、上下文相关的代码建议。
- **轻量级与高效性**：作为“Mini”版本，它平衡了性能与资源消耗，适合集成到开发工具链中，帮助 agent 或自动化流程减少延迟和计算开销。
- **支持多语言与框架**：模型涵盖多种编程语言和流行框架，增强了通用性，对工具链开发者而言，这简化了跨技术栈的代码处理需求。
