- Legora 基于 OpenAI 模型、ChatGPT 与 Codex 构建面向法律工作的 agentic 操作系统，用于加速法律工作流——对 agent 开发者而言，这说明垂直行业的智能体平台正把通用模型封装成领域工作流。
- 该平台用于扩展合同分析能力，让律师从重复性审阅中解放出来，专注于更高价值的工作——对工具链的含义是，合同审阅这类高结构化任务适合作为 agent 的落地场景。
- 案例同时用到 ChatGPT 与 Codex，表明法律智能体并非单一模型调用，而是组合多种 OpenAI 能力——对开发者的含义是，产品设计需考虑多模型/多入口的编排。
