- 通过 `strings` 命令检查 Claude Code 二进制文件，发现其包含 Bun v1.4.0 版本号，而公开 Bun 最新版为 v1.3.14，说明 Anthropic 使用了未发布的预览版。
- 在二进制中找到了 563 个 `.rs` 源文件路径，如 `src/runtime/bake/dev_server/mod.rs`，证实 Rust 移植版 Bun 已集成到 Claude Code 中。
- 这一改动对开发者意味着：底层运行时替换可以做到“无感升级”，只要性能提升（如启动快 10%）且不破坏兼容性，用户几乎不会察觉。
