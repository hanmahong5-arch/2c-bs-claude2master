- GPT-5.6 家族分 Luna、Terra、Sol 三档，定价 $1–$5/百万输入 token，推理 token 消耗差异使价格比较复杂。
- 在 Agent's Last Exam 上，Sol 以 53.6 分超越 Claude Fable 5 的 40.5 分，且中等推理时成本仅约四分之一，表明小模型也能高效完成复杂 agent 任务。
- 新增 Programmatic Tool Calling 允许模型编写 JavaScript 编排工具调用，Multi-agent 支持原生子 agent 并行工作，这些 API 特性将简化多步骤 agent 工作流的构建。
