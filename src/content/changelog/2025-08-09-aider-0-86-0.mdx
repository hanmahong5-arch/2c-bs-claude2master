- **支持 GPT-5、Grok-4 和 Gemini 2.5 Flash Lite 等新模型**：扩展了模型生态，意味着 Agent Harness 需要设计更灵活的模型适配层。
- **优化 `/clear` 和 `/undo` 命令的反馈与显示**：提升了交互清晰度，要求 Agent Harness 提供明确的状态确认与简洁的历史视图。
- **修复模型设置更新与依赖兼容性问题**：确保了配置的实时生效和 SDK 兼容，强调 Agent Harness 需具备稳健的配置管理和向后兼容能力。
