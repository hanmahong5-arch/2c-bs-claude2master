- 插件新增 `ctx.session.instructions.entry.put/list/remove`：指令以增量条目在下一步注入，不再改系统提示，因此不触发 prompt 缓存失效；条目在压缩与回滚后仍保留，也不额外消耗一轮模型调用。含义：harness 应把动态上下文做成可追加的层，而非重写系统提示。
- `@opencode/ai` 根导出改为 Promise API，Effect API 移至 `@opencode/ai/effect`，`/promise` 子路径移除；GitHub Action 不再发布。含义：插件与集成需按显式入口重构导入，避免依赖通配导出。
- 新增可配置的按 provider/model 的 prompt 缓存 TTL，并新增实验性图像与决策生成 API。含义：缓存生命周期成为 harness 可调参数，多模型路由可按成本与命中率分别设定。
