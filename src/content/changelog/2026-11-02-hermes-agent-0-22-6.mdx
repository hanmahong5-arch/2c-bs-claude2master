- 新增 `pre_llm_call` 钩子，可在推理前阻断一轮对话：harness 需要在调用模型前预留可插拔的拦截点，而不是只在工具层做校验。
- 新增 `/model reset`，清除会话的模型固定但保留历史：会话状态与模型选择应解耦，便于中途切换而不丢上下文。
- 新增按技能写锁，可从 Desktop Capabilities 面板锁定：自主写入需要细粒度权限边界，防止 agent 自行改写自身能力配置。
