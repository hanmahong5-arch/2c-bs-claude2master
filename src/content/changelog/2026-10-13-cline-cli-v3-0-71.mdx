- 插件加载从独立 node/bun 子进程移入 hub，CLI 不再需要 PATH 上的 JavaScript 运行时；加载失败会打印插件名与错误，`cline config tools --json` 标记为 `plugin_failure`，`cline hub plugins` 可查状态与最后错误并支持 `--reload`。含义：插件失败从静默丢工具变为可观测状态，harness 需把插件生命周期纳入统一进程与状态面。
- `--thinking` 现在在 ACP 模式（`--acp`）生效，此前 ACP 会话始终关闭推理。含义：推理开关需按会话模式统一传递，而非只在交互 TUI 路径生效。
- 截图等图片不再计入 token 估算，此前会提前触发自动压缩；自动压缩在目录无上下文窗口时改用所选模型的窗口。含义：token 估算应区分文本与图像负载，压缩阈值需绑定真实模型窗口。
