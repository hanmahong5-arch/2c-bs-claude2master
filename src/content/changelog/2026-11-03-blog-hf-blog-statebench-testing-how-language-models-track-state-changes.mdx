- 文章发布在 Hugging Face 博客，由 allenai 带来名为 StateBench 的基准，主题是检验语言模型在长文档中跟踪状态变化的能力。
- 从标题与定位看，评测关注的是模型能否随文档推进持续更新对状态的理解，而非只做一次性信息抽取；这对需要多步推理的 agent 是核心能力。
- 对开发者而言，这类基准提示长上下文工具链不能只看检索命中率，还要验证模型在状态更新上的可靠性。
