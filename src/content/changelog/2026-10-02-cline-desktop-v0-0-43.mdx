- 现有用户首次收到一次性 **What's new** 弹窗，介绍 Connectors，含连接器 logo、可点击示例 prompt 和 **Open Connectors** 按钮；对 harness 的含义是引导入口可放在会话外，降低新能力发现成本。
- 弹窗可从 **Settings → About → Show what's new** 重播；对 harness 的含义是引导状态需可重置，便于用户回看而不必依赖首次触发。
- 该版本未提及 Connectors 本身的功能细节，仅涉及引导弹窗；对 harness 的含义是能力发布与引导发布可解耦，先做可发现性再补能力说明。
