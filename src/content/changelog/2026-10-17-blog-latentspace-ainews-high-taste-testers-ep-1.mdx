- Meta 发布 816B 总参、42B 激活的开源 MoE「Muse Spark Open」，AA 智能指数 39 为美国开源模型最高，但四项 agentic 评测在九个开源模型中垫底——说明通用能力与 agent 任务表现并不同步，选型不能只看综合分。
- Reflection 的 Beam 1.0（501B/23B 激活、Apache 2.0）附带训练用的 Mirror CLI harness，vLLM 与 SkyRL 首日支持——开放训练/推理工具链正成为开源发布的标配，降低复现门槛。
- 文章提出「决策模型」这一类别：Liquid d1-ultra 在 AA Decision Index 得 65 居首，单任务 92ms、每百万输入 token 仅 $0.042——面向快速工具委派的一次性分类器，可能替代部分 agent 子调用中的大模型。
