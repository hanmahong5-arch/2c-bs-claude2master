- **调度器直接发出工具调用分组**：core 与 cli 重构后，工具调用分组由 scheduler 统一发出，UI 侧的前瞻逻辑被移除；harness 应把分组事件当作唯一事实来源，避免 UI 与执行层各自推断导致状态不一致。
- **getSafeGitEnv 禁用交互式凭据与 SSH 提示**：git 环境不再弹出交互提示；harness 在无人值守执行 git 操作时，需自行预置凭据或明确失败路径，不能依赖交互回退。
- **SKILL.md frontmatter 解析加固**：支持单行 description 的解析；harness 加载技能元数据时，对格式变体的容错提升，但仍应校验字段完整性。
