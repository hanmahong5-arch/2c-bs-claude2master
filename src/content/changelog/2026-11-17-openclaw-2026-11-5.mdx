- **重启安全会话**：排队消息、发送权限与最终聊天写入在 Gateway 重启后保留；harness 设计需把会话状态持久化到可恢复存储，而非仅存内存。
- **更新失败回滚**：Doctor 或 Gateway 启动失败会回滚已激活更新；agent harness 的升级流程应内置健康检查与原子回退，避免半升级状态。
- **破坏性 harness/插件会话控制**：第三方 harness 必须在 host runAttempt 回调内注册按 session key 的活动运行并保留返回的清理函数，插件 RPC 需改用授权 Gateway 方法分发；harness 设计需把运行生命周期绑定到宿主回调，而非自管全局控制器。
