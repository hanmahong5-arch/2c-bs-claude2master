- World Labs 被 AMD 以 82 亿美元收购，其 Atlas 模型通过结合生成模型与多视图几何，解决了计算机视觉中长期存在的稀疏重建问题，能像 LLM 预测下一个 token 一样从 2D 图像预测新视角。对 agent 而言，这意味着空间智能可作为机器人仿真和 RL 环境的基础能力。
- Atlas 是首个此类全模态架构，从零训练，在视角预测任务上超越了专用模型的最优结果。对工具链开发者，这提示多模态生成模型与几何方法的融合可能成为机器人、设计和科学领域的新范式。
- 文章还提到 Anthropic 发布 Claude Sonnet 5.5，速度提升超 30%、成本降低达 30%，并扩展了“保留思考”功能以防止通过账户切换进行蒸馏。对开发者，模型迭代加速和反蒸馏机制将影响多 agent 系统的部署策略。
