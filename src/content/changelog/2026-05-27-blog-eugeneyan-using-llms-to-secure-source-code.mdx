- 威胁建模：LLM可自动生成系统威胁模型，识别攻击面，帮助开发者提前防御。
- 漏洞发现：LLM能扫描代码库，发现SQL注入、XSS等常见漏洞，减少人工审计成本。
- 补丁生成：LLM不仅发现漏洞，还能自动生成修复代码，加速安全修复流程。
