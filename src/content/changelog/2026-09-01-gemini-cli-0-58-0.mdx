- **沙箱隔离加固**：macOS Seatbelt 现在隔离 Docker 与容器运行时 socket 和二进制，降低逃逸风险，harness 需适配更严的沙箱路径。
- **忽略路径处理修复**：统一符号链接评估，避免忽略规则误判，harness 应确保路径解析一致。
- **历史回滚优化**：修复回滚与重试提示，提升交互可靠性，harness 可依赖更稳定的会话状态。
