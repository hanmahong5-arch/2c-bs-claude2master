- 修复 2.1.265 回归：`CLAUDE_CODE_USE_GATEWAY` 单独设置时不再强制 Cloud-gateway 登录，需与 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN` 同时设置才生效。
- 该变量与 API key、`apiKeyHelper` 或自定义认证头共存时，请求不再失败，无需更改配置。
- 对 harness 设计：环境变量应保持明确组合语义，避免单变量触发意外行为；回归测试需覆盖代理和网关场景。
