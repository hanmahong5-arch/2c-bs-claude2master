- SQLite 3.54.1 修正了子查询返回值的语义：`(select json_array(1))` 现在返回 SQL 文本而非 JSON，因此 `json_object` 会把结果包成字符串 `"[1]"`；作者指出这是文档规定的正确行为，3.54.0 才是 bug。对开发者的含义：依赖 SQLite JSON 函数拼接日志或结构化数据的工具链，升级底层库时需要重新验证输出类型。
- 触发点是 Homebrew 直接打包了最新 SQLite，LLM 的日志代码随之出错，于是有了 0.37.3 这个纯 bug fix 版本。对 agent 工具链的含义：发行版或包管理器替用户升级依赖，会把上游语义变更直接传导到应用层。
- 作者给出的绕行方案是在子查询外再套一层 `json()`，即 `json_object('a', json((select json_array(1))))`，显式把 SQL 文本转回 JSON。对开发者的含义：跨 SQLite 版本兼容时，显式类型转换比依赖隐式行为更稳妥。
