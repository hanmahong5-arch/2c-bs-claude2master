- 使用本地运行的 Llama 3.1 8B 模型对 OpenClaw 仓库的 PR 和 issue 进行自动分类，无需 API 费用。
- 模型通过 few-shot 提示学习仓库标签体系，准确率接近人工水平，减少维护者手动分类负担。
- 该方案可推广至其他开源项目，降低社区维护门槛，让开发者更专注核心代码工作。
