- ChatGPT Wallet 面向 ChatGPT Work、Codex 和 dots 中的 agent，让它们能在用户批准后完成购买，并沿用现有银行卡保护机制。
- 购买动作需要用户批准，意味着 agent 的支付权限被设计成显式授权，而非默认放行；对构建 agent 工具链的开发者来说，支付环节需要预留人工确认节点。
- 该钱包复用了现有卡片的保护体系，而非另建一套支付风控；对接支付的 agent 项目可参考这种在既有支付保障之上叠加 agent 授权的做法。
