- **GPT-6 Astra 支持**：可用 OpenAI API-key 或符合条件的 ChatGPT/Codex 账号选择 `openai/gpt-6-astra`，支持文本图像输入与 Responses 工具调用；含义是 harness 需按账号发现结果动态决定模型可用性，而非硬编码模型清单。
- **Swarm 默认开启**：并发子 agent 编排默认启用，保留显式退出、工具限制与独立的 Code Mode 开关；含义是 harness 默认要处理多子 agent 的结构化结果与实时进度，同时保留逐项降级路径。
- **回复跨重启存活**：Gateway 重启后可恢复活跃、排队与委派的回复，且一条完成的回复不会丢弃另一条的恢复标记；含义是 harness 需把恢复标记做成按回复独立持久化，而非全局单点状态。
