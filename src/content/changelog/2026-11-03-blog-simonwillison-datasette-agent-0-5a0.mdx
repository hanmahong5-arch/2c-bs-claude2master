- 新增 **panel** 功能：agent 聊天窗口打开后可常驻在 Datasette 的表格页、查询页旁边，而不是独立对话界面。对 agent 工具链的含义是，交互入口从「单独聊天框」转向「嵌入工作现场」，上下文与操作对象同屏。
- 与 **datasette-apps** 结合后，可以用提示词生成一个由数据库支撑的应用，再通过旁边这个聊天持续修改它。对开发者的含义是，应用从一次性生成变成可迭代的产物，修改成本落在对话里。
- 作者给出可直接体验的入口：用 GitHub 账号登录 agent.datasette.io 试用。对 agent 产品的含义是，这类能力已开放到可公开试用的 alpha 阶段，而非仅停留在演示。
