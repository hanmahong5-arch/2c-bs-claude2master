- 该版本主要兼容 anthropic Python 库 v1.0.0，后者从 httpx 切换到 httpx2，OpenAI 的 v3.0.0 也做了同样变更。
- 迁移过程借助 Claude Code 中的 Fable 5 模型，通过提示词读取官方迁移指南并让测试通过，最终生成 PR。
- 对开发者而言，AI 辅助迁移可显著降低升级第三方库时的重复劳动，但需人工审查确保正确性。
