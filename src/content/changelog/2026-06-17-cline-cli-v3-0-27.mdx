- 新增 `cline skill` 命令，用于安装和管理技能，其功能与现有的插件和 MCP 管理命令对齐。这意味着 Agent 的技能生态管理接口得到了统一和简化。
- 增加了预填充的 MCP 安装向导命令，以加速 MCP 服务器的设置过程。这表明工具链在提升开发者体验和降低配置复杂度上持续投入。
- 改进了插件 MCP OAuth 授权失败时的错误处理和消息提示，并且 CLI 现在会对未知命令或未加引号的多词输入给出明确错误，而非将其误认为提示。这强化了 CLI 的健壮性和用户友好性，减少了因错误输入导致的困惑。
