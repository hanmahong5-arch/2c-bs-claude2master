- 作者指出，如果你跑的是 Claude Code、Codex 这类拥有无限制网络访问的完整终端 agent，确实几乎没理由用 MCP——直接让它调 API 就行。含义：MCP 的价值不在「能不能调工具」，而在权限受限的部署形态。
- 一旦你想做得比「YOLO 式全权限」更收敛，就会需要四样东西：精确控制 agent 能访问哪些外部服务、不让 agent 直接接触 API key 的认证方式、让用户连接并授权更多服务的合理 UI、以及完整的审计日志。含义：这些正是企业级 agent 工具链的刚需，MCP 让它们更容易实现。
- 作者认为，因为完整编码 agent 用不上 MCP 就判定它过时，忽略了人们可能想构建的其他东西。含义：评估协议价值时，别只盯着最激进的 agent 形态。
