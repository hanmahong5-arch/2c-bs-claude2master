- 桌面 UI 新增毛玻璃/半透明效果，含磨砂玻璃、取色器及 macOS 预选，提升视觉一致性。
  - 对 agent harness 设计：UI 层需考虑跨平台窗口材质与系统集成。
- 侧栏改为 SESSIONS|BOTS 标签式，支持按 bot 隐藏/显示，优化多 bot 管理。
  - 对 agent harness 设计：会话与 bot 导航需更灵活的可视化控制。
- Bot Mode 修复群聊长轮次、Markdown 渲染及跨机器路由问题。
  - 对 agent harness 设计：群聊场景需强化状态同步与渲染稳定性。
- NVIDIA SkillEvaluator 在技能安装时执行 Tier 1 许可与安全扫描。
  - 对 agent harness 设计：技能安装流程应集成自动安全审查。
- cron 媒体发送加固：可配置超时、手动运行附件、错失触发提示。
  - 对 agent harness 设计：定时任务需提供更健壮的故障恢复与可见性。
- SessionDB 修复事件循环线程竞争，提升稳定性。
  - 对 agent harness 设计：底层存储需避免并发冲突，保证数据一致。
