- Kuken Industries 把 70 年积累的冷却塔图纸接入 OpenAI API 做检索，工程师定位一张维修所需图纸的时间从近 1 小时缩短到 4.5 分钟。对 agent 的含义：非结构化历史文档（扫描图纸、PDF）是检索增强最直接见效的场景。
- 场景是维修找图，不是通用问答：输入是工程师的具体维修需求，输出是那一张对应图纸。对工具链的含义：垂直领域检索要围绕单一高频任务设计，而不是做宽泛的文档搜索。
- 落地方式是调用 OpenAI API，而非自建模型。对开发者的含义：传统制造企业的历史资料数字化，可以先从 API 集成切入，不必先投入模型训练。
