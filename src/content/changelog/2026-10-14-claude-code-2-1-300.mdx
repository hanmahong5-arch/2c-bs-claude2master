- `agent.spawn` mod 钩子现在可重写 workflow agent 的 `prompt` 和 `model`，此前只能拒绝：harness 需把 agent 生成参数暴露为可拦截、可改写的中间态，而非一次性构造。
- 新增 `prompt.change` 钩子，在历史召回、清空、撤销或插件填充等非键入编辑时触发：harness 要区分「用户键入」与「程序性变更」，否则审计与遥测会把改写当成用户输入。
- OpenTelemetry `api_request` 事件新增 `cache_creation_5m_tokens` 与 `cache_creation_1h_tokens`，按缓存寿命拆分写入：harness 的缓存策略需按 TTL 分层计量，才能判断长短期缓存的实际收益。
