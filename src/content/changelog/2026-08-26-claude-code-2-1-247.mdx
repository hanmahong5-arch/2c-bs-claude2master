- 新增 SendFeedback 工具，Claude 可起草反馈报告供用户审查发送，可用 feedbackDrafts 设置关闭。
- 新增 /claude-api cost-optimize 命令，分析项目 API 支出并逐步优化缓存、token、批处理等。
- 修复子代理在模型 404 时使用会话回退模型链，错误信息更完整。
- 修复非拉丁键盘布局下 Ctrl 快捷键失效，以及鼠标报告拆分读取导致的文本注入。
- 加固插件市场，拒绝控制字符，转义输出；改进 Bedrock/Vertex 等会话的 MCP 错误提示。
