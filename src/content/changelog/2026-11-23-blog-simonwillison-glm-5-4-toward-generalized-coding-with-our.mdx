- GLM-5.4 是 Z.ai 首个采用循环 Transformer 的模型：一组共享权重的层多次迭代、精炼隐藏状态，从而在不增加参数量的前提下加深网络。这意味着开发者可以用更小显存预算换取更强推理深度，部署成本结构可能改变。
- 作者注意到一周内第二次见到循环 Transformer：Thinking Machines Lab 的 Inkling 2 Mini 将中间层对每个 token 跑三次，称可在 agentic coding 等依赖推理质量的任务上以更少 token 得到正确答案。对 agent 工具链而言，token 效率直接影响多步任务的成本与延迟。
- GLM-5.4 暂未开放权重，作者通过 Z.ai 的 Coding Plan 订阅访问，发现其与常规 API 共用 OpenAI 兼容的 Responses 端点，并据此写了 llm-glm 插件（已有 llm-zai 但尚不支持新模型）。这提示接入新模型时先验证端点兼容性，可复用现有 OpenAI 生态工具。
