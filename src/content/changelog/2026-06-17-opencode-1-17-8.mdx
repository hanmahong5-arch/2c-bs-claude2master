- **MCP 工具兼容性修复**：OpenAI 兼容提供者现在能正确处理 MCP 工具模式，Cloudflare AI Gateway 正确接收 API 密钥。这意味着 Agent Harness 能更稳定地集成第三方工具。
- **MCP 工具错误处理改进**：工具失败时显示服务器原始错误信息，长运行工具在报告进度时保持超时计时器活跃。这有助于开发者更快诊断和调试工具链问题。
- **桌面端交互优化**：新增主页标签页切换按钮，文件/文件夹选择器在 v2 布局中更快更易导航。这优化了开发者在桌面环境下的工作流效率。
