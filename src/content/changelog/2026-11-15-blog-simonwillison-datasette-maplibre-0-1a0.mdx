- 新插件 datasette-maplibre 0.1a0 把 MapLibre GL 与免费矢量地图服务 OpenFreeMap 结合，补上 Datasette 久违的地理空间可视化能力；对工具链意味着自托管地图栈可以少依赖商业瓦片服务。
- 作者主要靠单条提示词完成：让 Claude 参考 datasette-cluster-map 与 datasette-leaflet-geojson 两个插件再自由发挥；说明现有插件代码可作为 agent 的上下文范本。
- “跳出框架”的产出之一是按需渲染：先显示 GeoJSON 形状的 SVG 预览，滚动进入视口才加载 WebGL；对前端 agent 工具而言，这是可借鉴的性能取舍模式。
