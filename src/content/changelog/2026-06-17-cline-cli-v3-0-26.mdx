- 撤销了可展开的模型选择器分区和 ClinePass 模型列表，恢复为之前的模型选择界面。
  - 这意味着在 agent harness 设计中，界面稳定性优先于实验性功能，避免用户因频繁变更而产生困惑。
- 本次更新专注于 UI 回退，未引入新功能或底层逻辑改动。
  - 表明在 agent 工具链中，用户体验的连贯性比界面创新更重要，确保核心工作流不受干扰。
- 变更仅涉及前端交互层，不影响后端模型调用或配置逻辑。
  - 提示在构建 agent 系统时，前端与后端应保持解耦，以便独立调整界面而不影响核心功能。
