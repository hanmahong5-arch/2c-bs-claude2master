- 修复 Windows 下 Codex 启动后台进程与沙箱命令时控制台窗口闪烁的问题（#49385）。含义：harness 派生子进程时应默认隐藏控制台，避免每次工具调用都打断用户视线。
- 该修复以 backport 形式进入 0.159.2 补丁版本。含义：稳定分支的体验类修复值得单独发版，harness 应把进程启动的 UI 副作用当作可回归项管理。
- 变更仅涉及 Windows 控制台抑制，未提及新功能或行为改动。含义：跨平台 harness 需按平台分别处理子进程可见性，而非依赖统一默认值。
