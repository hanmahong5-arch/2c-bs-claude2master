- 该版本新增对默认分支以外分支的支持，可通过 `uvx commit-rewriter --branch other` 指定其他分支运行（#3）。对开发者的含义：在 feature 分支上也能直接使用该工具重写提交，不必先切回主分支。
- 工具以 `uvx` 方式调用，说明它作为可即时运行的 Python 包分发。对工具链的含义：无需预先安装即可在 CI 或本地一次性执行，降低了试用与集成成本。
- 变更记录以 issue 编号 #3 标注，标签为 git。对 agent 的含义：这类小而明确的 CLI 能力容易被 agent 包装成可调用的 git 操作步骤。
