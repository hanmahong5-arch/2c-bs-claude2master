- 中断的提示队列现在保留并应用编辑，会话停止语义一致，上下文持久化，失败任务报告为 run.failed。
- MCP 服务器挂起不再阻塞会话创建，stdio 服务器有 30 秒初始化预算，远程 SSE 支持 OAuth 授权提示。
- LiteLLM 请求改走 Chat Completions，网络中断重试，Vertex ADC 刷新支持代理，检查点包含未跟踪文件。
