- 开启 `localModelLean: true` 会移除 browser、cron、message 等 9 个重型工具，仅保留核心编码工具，减少模型因工具描述过长导致的上下文溢出或格式错误。
- 该模式默认将插件/MCP/客户端目录切换为结构化 Tool Search（tool_search、tool_describe、tool_call），避免小模型因过多相似 schema 产生错误调用。
- 仅当后端能正常对话但完整 agent 轮次失败（如工具调用格式错误）时才启用，稳定路径优先使用 tools.profile 或 tools.allow/deny。
