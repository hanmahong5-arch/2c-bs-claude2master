- **Pi 1.0 新增 Codemode 与延迟工具加载**：原生支持 MCP、Jev 和图像模型，并支持虚拟模型扩展、Anthropic 缓存预热、对话中途插入系统消息。对工具链的含义是：prompt 与工具集可以在会话进行中动态调整，而不必重启 agent。
- **Pi Durable 把 Pi 移植到 TypeScript 并外置全部有状态组件**：每一步都记录为带检查点的任务，进程失败或重启后 agent 与子 agent 从上次精确状态自动恢复；可运行在 Node、Bun、Cloudflare 等 JS 运行时，存储后端可插拔（Memory、SQLite、JSONL）。含义是 agent 的可靠性从「重试」转向「断点续跑」。
- **并发、多人协作与热插拔**：单个 harness 可并行运行分支对话；应用状态（如待办列表）与对话记录存在同一文档中，多个用户或 UI 可同时观察和操控同一 agent；工具与扩展代码可在运行时更新，下一次调用即生效。含义是 agent 正从单人 CLI 走向可共享、可在线升级的服务形态。
