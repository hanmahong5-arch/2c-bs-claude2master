- 文章介绍 OpenAI 采用分层监控（layered monitoring）来检测前沿模型的失准（misalignment）和未授权 agent 行为，目标是让响应者在事件升级前介入。
- 监控覆盖的不只是模型输出本身，还包括 agent 的实际行为，这意味着 agent 工具链需要可观测性设计，把行为日志作为安全基础设施而非事后审计。
- 检测与响应被串成一条链路：先发现异常，再由响应者干预，对开发者的含义是告警必须能触发可执行的动作，而不只是仪表盘上的数字。
