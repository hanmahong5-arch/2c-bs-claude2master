- 新增 ZeroRelay 与 ZeroRouter，提供盲转发、mTLS 注册和托管路由预设，为 agent 通信提供更安全的传输层。
- 插件和技能安全大幅收紧：强制类型化实例配置、作用域密钥、主机拥有出口、路径遍历防护，技能 HTTP 执行默认失败关闭，agent 设计需遵循更严格的边界。
- 修复 Wasmtime 沙箱逃逸（RUSTSEC-2026-0222）及插件 wasm_path 遍历漏洞（GHSA-93f6-34w8-5g98），升级安全栈。
