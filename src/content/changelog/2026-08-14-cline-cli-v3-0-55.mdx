- 自动更新不再在 CLI 连接 Hub 时安装，改为退出时安装，避免后台更新导致会话中断。
  - 对 agent harness：需确保更新流程不会影响正在运行的会话，可参考此机制。
- 修复两个 CLI 实例互相关闭对方 Hub 守护进程的问题，通过构建身份全序比较解决。
  - 对 agent harness：多实例共存时需防止资源竞争，确保稳定性。
- 流式 markdown 不再闪烁回原始文本，保持渲染状态。
  - 对 agent harness：流式输出应保持格式稳定，提升用户体验。
