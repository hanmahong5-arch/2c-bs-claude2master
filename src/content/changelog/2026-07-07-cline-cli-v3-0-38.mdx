- 新增 plan/act 模式调色板：act 模式蓝色，plan 模式琥珀色，应用于对话框、模型选择器等，并优化浅色主题对比度。
  - 含义：Agent 状态视觉区分更清晰，便于用户快速识别当前模式。
- 重新设计聊天输入框：采用极简边框、全宽水平线和加粗提示符号，用户消息气泡更紧凑。
  - 含义：输入区域更简洁，减少视觉干扰，提升专注度。
- `read_files` 工具现在能容忍弱模型格式错误的输入：将作为独立数组项发送的行范围条目合并回文件路径。
  - 含义：Agent 对弱模型的鲁棒性提升，减少因输入格式问题导致的失败。
