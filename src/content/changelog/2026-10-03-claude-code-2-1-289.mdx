- 修复 Bash deny/ask 规则在环境变量前缀（如 `TZ="$HOME" rm -rf build`）或裸赋值前置时被沙箱自动放行跳过；含义是权限判定需在命令解析后、变量展开后执行，而非仅匹配字面前缀。
- 新增 `agent.spawn` 供 teammates 使用，插件 hook 事件共享同一 agent id，`$.agent.list()` 暴露 idle 与 waiting 状态；含义是 harness 需把 agent 生命周期与插件事件流统一到可观测的单一标识下。
- 修复用户安装插件可改写组织托管 MCP 服务器登录工具描述，以及 mod 的 `ui.render` 抛错导致会话以不可恢复接口错误终止；含义是插件渲染与元数据写入必须与宿主状态隔离，失败应局部化并上报 `ui.fault`。
