- tasks 工具（持久待办、一次性或周期调度）现在按客户端类型限定可用性，宿主声明客户端类型，核心工具目录集中解析。
- CLI 和 VS Code 会话不再注册无法执行的工具，减少无效调用。
- Hub 会话从请求客户端元数据解析相同逻辑，确保工具可用性与客户端匹配，对 harness 设计意味着工具注册需考虑运行环境。
