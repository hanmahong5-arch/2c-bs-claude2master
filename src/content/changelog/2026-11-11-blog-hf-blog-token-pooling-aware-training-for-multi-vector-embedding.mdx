- 文章聚焦多向量嵌入模型的 token pooling-aware 训练：在训练阶段就引入池化，而非只在推理时压缩 token 表示，让模型学会适配后续的池化操作。
- 对 agent 与检索工具链的含义：多向量检索的存储与延迟成本主要来自每文档保留大量 token 向量，训练期对齐池化可减少向量数量而不牺牲检索质量。
- 对开发者的含义：若自建 RAG 或嵌入服务，选型与微调时应把池化策略纳入训练目标，而不是把压缩当作事后优化。
