- 通过 Codex Desktop 的“宠物”功能，用户可创建自定义动画角色，Simon 用 GPT-5.6 Sol 和 gpt-image-2 生成了“Pedalican”的精灵图。
  - 这意味着 LLM 驱动的图像生成已能直接产出游戏级动画资产，降低独立开发者的美术门槛。
- 关键实现细节开源（hatch-pet 和 imagegen 技能），包括从参考图到动画帧的完整流程。
  - 开源技能链让开发者可复用并定制 AI 生成动画的管线，加速创意原型。
- 生成过程涉及多轮提示工程，从角色描述到最终精灵图，每一步都记录在 GitHub 仓库中。
  - 提示工程的可复现性成为 AI 辅助创作的核心，开发者需重视中间步骤的透明化。
