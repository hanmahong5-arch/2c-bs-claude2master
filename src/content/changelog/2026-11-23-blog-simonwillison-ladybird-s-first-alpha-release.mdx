- **首个 alpha 可安装**：macOS/Linux 用户无需自行编译即可试用；作者实测加载多数网站正常，但 Datasette Lite 因 `navigator.serviceWorker.startMessages` 缺失而报错，说明新引擎在 service worker 等边缘 API 上仍有缺口。
- **多进程隔离已就位**：每个标签页独立进程，作者开七个标签后 WebContent 进程内存从 60MB 到 819MB 不等；对 agent 工具链意味着浏览器自动化需按进程粒度管理资源与崩溃恢复。
- **AI 编码代理带来测试跃升**：十月五天内 web-platform-tests 通过数从约 212 万涨到 218 万，靠代理针对 WPT 做大量小修复累积；对开发者而言，这是把测试套件当作 agent 可执行任务清单的实证案例。
