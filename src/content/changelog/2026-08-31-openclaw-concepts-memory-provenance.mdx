- OpenClaw 记录会话来源谱系，`memory forget` 按会话 ID 精准删除相关记忆条目和工件，但不会删除原始转录或外部副本。
- 删除前必须用 `--dry-run` 预览，检查 `sessionResolutions`、`entryKeys` 等字段，确认影响范围；预览不保存为计划，需重新运行。
- 准入策略（`excludeSessions`）可阻止特定来源（如 Gmail）进入记忆，但仅前瞻性，不删除已有数据；遗忘记录会永久排除该会话。
- 对 agent harness 设计：记忆删除需明确边界，提供预览和干跑模式，且准入与删除分离，避免误删和恢复。
