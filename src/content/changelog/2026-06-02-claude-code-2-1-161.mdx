- **OTEL_RESOURCE_ATTRIBUTES 值现作为指标标签**：允许按团队或仓库等自定义维度切分使用指标，便于监控粒度细化。
- **并行工具调用中失败命令不再取消同批次其他调用**：每个工具独立返回结果，提升了 Agent 任务执行的鲁棒性和容错性。
- **claude agents 行在任务分发时显示 done/total 进度**：peek 视图展示最长运行项目，优化了复杂工作流的进度监控体验。
