- 桌面应用新增实时语音对话（#12093），意味着 agent harness 需处理音频流输入输出，可能需扩展会话状态管理。
- Recipe 参数限制强制执行（最多 32 参数、200 选项、128 KiB，#12259），要求 harness 在加载 recipe 时做前置校验，避免资源滥用。
- 新增 Decisions provider crate 及 Z.AI Coding Plan 流式工具调用（#12418, #12205），提示 harness 应抽象 provider 接口以支持多后端和流式工具调用。
