- 权限系统性能与文档改进：优化了权限检查逻辑，减少查询开销，并补充了权限配置的文档说明，使开发者更易理解权限模型。
- 回滚破坏性 API 变更：因一次外观性 API 改动导致几乎所有现有插件测试套件失败，作者选择回滚，强调向后兼容性对生态的重要性。
- 对开发者的含义：插件生态的稳定性优先于界面一致性，API 变更需谨慎评估影响；权限系统的优化降低了大规模数据集下的管理复杂度。
