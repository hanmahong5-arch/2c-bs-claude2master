- **声明支持的客户端能力**：OpenCode 现在会明确声明其支持的 MCP 客户端能力。
  - *对 Agent Harness 设计的含义*：这要求 harness 在集成 MCP 服务器时，需要具备能力协商机制，确保只调用双方都支持的功能。
- **修复 MCP 服务器兼容性问题**：此改动旨在解决与某些 MCP 客户端的兼容性问题。
  - *对 Agent Harness 设计的含义*：Harness 需要能够处理服务器能力声明，并在能力不匹配时优雅降级或提供明确错误。
- **核心功能稳定性提升**：此次更新属于核心模块的 bug 修复。
  - *对 Agent Harness 设计的含义*：在设计依赖 MCP 协议的 harness 时，应优先考虑使用已明确声明能力的稳定服务器，以减少集成风险。
