- Anthropic 本月早些时候先宣布：Max 和 Team 订阅中每月 $100、$200、$500 的档位，可获得等额（会过期）的 Anthropic API credits；OpenAI 随后推出几乎相同的方案，同样档位可把等额 credits 用于自己的某个 API organization。对同时订阅两家的开发者来说，API 成本已被订阅覆盖。
- 作者 Simon Willison 同时持有两家订阅，他认为这是好消息，并表示既然 credits 已由现有订阅覆盖，他可能因此发布一些面向公众的 demo。这说明订阅制正在改变个人开发者做公开演示的成本门槛。
