- Composio 连接器现在拉取全部工具而非前 20 个，工具缓存会刷新而非永久陈旧；对 agent harness 的含义是工具清单必须按真实全量暴露，否则模型会在被截断的能力空间里做选择。
- Mac 桌面端现在可 SSH 连接到 Mac 主机，使用自带签名后端作为 helper，覆盖 Apple Silicon 与 Intel；含义是远程执行后端需按宿主平台提供匹配的 helper，而非依赖通用目标。
- 会话错误现在会留在 transcript 中，跨会话切换或换客户端打开都不丢失，重试耗尽后的失败也会记录，且这些纯错误条目不参与压缩；含义是错误状态应作为持久上下文的一部分，避免 agent 在恢复会话时丢失失败历史。
