- 网关两条刷新路径（cookie 与 Desktop bearer）现在合并携带同一轮换 refresh token 的并发请求，避免唤醒突发把已轮换 token 重放进 Portal 复用检测而吊销整个会话；对 harness 的含义是刷新必须做并发去重与宽限窗口，而非逐请求直通。
- 刷新移出事件循环执行，慢身份提供方不再阻塞 /api/status；含义是认证路径要与状态接口解耦，避免单点拖垮健康检查。
- gateway、dashboard/Desktop 后端、ACP 与 CLI 读取端改为只读挂载，进程内写入者共享注册表句柄，健康拓扑下不再出现重复 SessionDB 句柄；含义是读写句柄需按角色分离并集中管理。
