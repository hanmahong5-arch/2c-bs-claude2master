- Claude Code provider 现在声明自己的原生工具，会话锚定工作目录，加载用户权限配置，工作区内文件编辑自动批准，命令执行仍受 Claude 设置约束。
- 工具调用 JSON 截断时不再错误修复，而是拒绝，避免参数错误。
- 修复流式工具调用索引非连续导致的崩溃，更新 AI SDK 包。
- Hub 守护进程升级方向性，避免互相淘汰，旧版本仍被替换。
- 修复关闭时未处理的拒绝，退出码干净。
- `run.started` 事件携带 requestId 和 clientId，便于多客户端关联。
- Token 遥测改为分桶报告，避免重复计数，降低约 5 倍膨胀。
- 非自愿登出（刷新令牌被拒）现在报告，临时网络失败不再算登出。
- 流式 token 增量不再镜像到遥测，减少 97% 事件量。
