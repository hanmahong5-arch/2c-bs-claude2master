- Plan 模式硬性阻止文件编辑命令（如 sed -i、重定向、git 修改等），仅允许只读命令，提升 agent 安全性。
- 上下文溢出自动检测并强制压缩重试，无需额外 LLM 调用，失败时给出可操作错误。
- 会话记录新增 mode 字段，根会话持久化改为惰性，避免空历史记录。
- 空响应在所有 provider 上重试，不再仅限 Ollama，但工具调用空响应不重试。
- 自适应 Claude 模型不再发送手动思考 wire shape，模型目录携带推理元数据。
- Bedrock 提示缓存修复，使用 Converse cachePoint 标记，缓存读写恢复正常。
