- 新增手动 API 密钥逃生口：Cline OAuth 提供商支持从设置手动输入密钥，为自动化流程提供备用认证方式。
- 修复切换模型时提供商配置不重新加载的问题：确保 agent 在动态调整模型时能正确更新配置。
- 修复自动更新在 Bun 全局安装后因符号链接解析失败的问题：提升 agent 自动更新机制的可靠性。
- 修复令牌刷新时因网络或服务器错误导致意外登出：增强 agent 会话的持久性。
- ClinePass 用量限制错误现在清晰显示：帮助 agent 在达到限制时快速定位问题。
- 同一会话中继续时保留会话 ID：确保 agent 在长会话中上下文连续。
- 强化上下文压缩预算处理：提升 agent 在资源受限时的稳定性。
