- 修复了会话运行一段时间后，Bash 中只读 git 命令意外请求权限的问题（2.1.269 引入的回归）。
- 含义：权限判定若依赖会话内可变状态，会随时间漂移，harness 应让只读命令的判定保持无状态、可复现。
- 含义：回归出现在相邻小版本，说明权限层需要针对长会话场景的持续测试，而非仅冷启动验证。
