- 浏览器路由、DNS 目标、自定义源及回环端点拒绝不安全访问路径，强化沙箱边界。
  - 对 agent harness 设计：需在 harness 层统一实施访问控制，防止绕过沙箱。
- 会话写入、provider 回退、流进度处理及 stdio 失败可恢复，不再静默终止任务。
  - 对 agent harness 设计：harness 应内置重试与状态恢复机制，确保长任务韧性。
- 待处理通道工作可恢复，确认幂等，Discord 网关突发流量有界。
  - 对 agent harness 设计：通道层需支持幂等操作与背压控制，避免消息丢失或过载。
