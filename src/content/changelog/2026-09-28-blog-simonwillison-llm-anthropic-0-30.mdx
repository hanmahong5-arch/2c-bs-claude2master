- 新增 `llm anthropic refresh`，可直接从 Anthropic API 拉取最新模型列表，因此新模型发布后无需再发新版插件即可支持。对工具链的含义是：把模型清单从硬编码改为运行时同步，能显著降低维护成本。
- 新增 `llm anthropic count`，调用 Anthropic 免费的 token 计数 API，在发送 prompt 之前先返回该 prompt 将消耗的 token 数。对 agent 开发者的含义是：可在调用前做成本与上下文预算控制，避免超限或超支。
- 该版本同时加入对 Claude Sonnet 5.5 的支持，属于 llm 生态下 Anthropic 接入层的常规迭代。对开发者的含义是：模型接入与用量预估被收敛到同一 CLI 入口，便于脚本化。
