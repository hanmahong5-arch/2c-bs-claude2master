- **新增 ClinePass 引导流程与模型选择**：改进了错误处理，意味着用户配置代理的入门体验更顺畅。
- **新增 Hub 原始目录与定制化面板**：仪表板设计更新，便于开发者管理和复用核心组件。
- **默认截断大型工具结果**：自动控制 MCP 及自定义工具的输出长度，确保上下文不超限，优化了代理的预算管理。
