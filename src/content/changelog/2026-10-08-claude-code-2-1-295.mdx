- 新增 `onFailure: "block"`：命令与 HTTP hook 无法启动、超时或异常退出时直接阻断动作，而非放行。含义：harness 的失败策略应可显式声明为 fail-closed，安全类 hook 必须默认阻断。
- 新增 OSC 7501 程序状态协议：支持的终端可显示 Claude Code 正在工作、等待输入或已完成。含义：harness 可把内部状态外化为终端可读信号，便于外部监控与自动化编排。
- 新增 `timeouts.upstream_ttfb_ms`：限制云上游流式响应开始前的等待时长，超时后故障转移或返回 502。含义：harness 需为上游首字节延迟设独立超时，避免慢启动拖垮整条链路。
