- **单网关拥有每个会话**：CLI、TUI、Desktop、编辑器、机器人和 cron 都作为客户端接入同一网关，一个会话只有一条队列和一份历史，避免重复写入或消息丢失。harness 设计上，会话所有权必须集中，多入口只能做客户端。
- **Webapp 默认关闭**：开启 `webapp.enabled` 后，网关在自有监听端口提供完整 Desktop 工作区，Docker 与 Nix 包已内置。harness 可把 UI 与运行时解耦，但需默认关闭并加登录保护。
- **付费 MCP 工具标价与限额**：工具可声明单次调用费用，审批提示显示价格与聊天累计花费，超限先询问，YOLO 模式也不例外。harness 应把成本作为审批门控的一等信号。
