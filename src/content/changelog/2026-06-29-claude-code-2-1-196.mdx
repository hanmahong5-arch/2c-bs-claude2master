- 组织默认模型支持：管理员可在控制台设置，未选择时显示为“Org default”。
  - 含义：agent 可统一遵循组织模型策略，减少配置分散。
- 安全改进：`claude mcp list`/`get` 不再自动启动仓库自批准的 MCP 服务器，未信任工作区显示“Pending approval”。
  - 含义：agent 需显式批准 MCP 服务器，防止恶意代码自动执行。
- 后台会话可靠性提升：长时间运行的命令在进程重启后仍能存活，Windows 下后台 shell 被移交而非终止。
  - 含义：agent 后台任务更健壮，减少因进程重启导致的工作丢失。
- 流式空闲看门狗默认开启：5 分钟无事件则中止并重试。
  - 含义：agent 响应超时自动恢复，提升长任务稳定性。
