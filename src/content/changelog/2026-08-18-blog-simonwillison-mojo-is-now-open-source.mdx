- Mojo 语言在 2023 年 5 月承诺开源，上周发布 1.0 版本，本周将编译器和工具链以 Apache 2 许可证开源。
- 最初目标是成为 Python 超集，但 2025 年 8 月改变计划，不再强求完全兼容，而是作为独立语言，专注于 GPU 编程。
- AI 辅助编码工具已能帮助将 Python 迁移到 Mojo，未来工具和生态成熟将让迁移更顺畅，这对开发者意味着新的高性能计算选项。
