- 文章介绍 Google Antigravity 与 Cheminformatics Skills 结合，用于加速药物发现工作流：智能体可执行化合物检索等化学信息学任务，把原本需要人工串联的步骤交给 agent 编排。对开发者的含义是，领域专用 skill 封装是让通用 agent 落地垂直场景的关键路径。
- 文中提到该智能体能够提出新颖的刚性化大环（rigidified macrocycles）结构，即不只做检索，还参与分子设计提议。这意味着 agent 在科学工作流中的角色从工具调用者扩展到候选方案生成者。
- 整体定位是面向药物发现流程的 agentic 工作流，而非单一模型能力展示。对工具链的启示是，化学信息学工具需要以 agent 可调用的形式暴露接口，才能被这类系统组合使用。
