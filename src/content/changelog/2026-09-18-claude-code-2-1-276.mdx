- 修复了当 `ANTHROPIC_BASE_URL` 指向代理或网关时，所有请求因 `400 … Input tag 'advisor_20260301'` 失败的问题，该问题为 2.1.275 引入的回归。
- 含义：harness 不应假设请求会直达官方端点，任何新增的输入标签或字段都需在代理链路上保持兼容。
- 含义：回归修复提示 harness 设计需把自定义 base URL 场景纳入发布前的验证路径。
