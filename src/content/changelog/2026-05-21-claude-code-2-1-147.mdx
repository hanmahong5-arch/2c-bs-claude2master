- **固定背景会话现在保持空闲存活**：固定会话（`Ctrl+T`）在空闲时不再被终止，更新时原地重启，内存压力下最后被释放。这意味着为长期运行的代理任务提供了更可靠的执行环境。
- **`/simplify` 重命名为 `/code-review` 并增强**：该命令现在专注于报告正确性错误，并可选择审查力度（如`/code-review high`），支持通过 `--comment` 将结果发布为 GitHub PR 评论。这标志着工具从通用清理转向了更专业的代码质量保障。
- **多项修复提升健壮性与用户体验**：包括修复企业登录限制、`&` 符号在命令输出中的转义问题、未知斜杠命令的静默失败、PowerShell 工具的多项输出和匹配问题，以及各种界面布局和粘贴文本的显示问题。这些修复共同减少了代理开发流程中的摩擦和意外错误。
