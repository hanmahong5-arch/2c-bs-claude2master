- **新增 Cline Hub 网页应用**：提供客户端监控、会话查看与驱动、助手输出流式传输及本地 Hub 重启功能，通过房间密钥控制本地、局域网和隧道访问。这意味着 Agent Harness 设计需支持集中式可视化监控与远程会话管理。
- **支持全局 AGENTS 规则**：智能体规则现可应用于所有会话，而不仅是单个项目。这要求设计时考虑跨会话的规则优先级与冲突解决机制。
- **插件可贡献静态或动态规则内容**：插件在沙箱中安装时能提供规则，增强了扩展性。设计需允许插件安全地注入规则，并处理动态内容的生命周期。
