- 该 tag 汇总 v0.21.4 以来的约 460 个已合并 PR（1,610 个非合并提交、4,828 个文件变更），作为下游 Docker 镜像、Hermes Cloud 与托管部署的稳定发布点；含义是 harness 的版本边界应与下游消费节奏对齐，而非逐 PR 跟进。
- 完整整理版说明被有意推迟到 v0.22.0，覆盖 v0.21.0 起的全部内容；含义是补丁标签只承担可复现构建职责，功能叙事需另设文档通道。
- 更新方式为 `hermes update`（git 安装）或重跑安装脚本，Docker/云镜像从该 tag 构建；含义是 harness 需保证 tag 到镜像的确定性映射，便于回滚与灰度。
