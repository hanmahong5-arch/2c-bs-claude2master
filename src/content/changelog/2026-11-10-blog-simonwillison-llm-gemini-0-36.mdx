- **定价与时间窗**：Gemini 4 Carbon 今日向所有人开放，输入 $2/百万、输出 $10/百万，与 GPT-6.1 Sol、Claude Sonnet 5.5 同档，但 12 月 1 日起翻倍到 $4/$20。对 agent 工具链意味着：批量跑评测或长任务前，成本模型要按涨价后重算。
- **编码实测**：作者在 Google Antigravity IDE 里让它用 Three.js + OpenStreetMap 数据做「巨型机甲在纽约走动」的动画，需追加一句提示才产出无外部依赖的独立 HTML。说明 agent 产物默认带依赖，交付前要显式约束可移植性。
- **子 agent 协作**：官方演示用 Antigravity 的 /swarm 功能，让 Carbon 协调子 agent 在 Blender 建模、写 Three.js/WebGL 着色器、配 Web Audio 与 Lyria 音乐，做出可玩的 3D 校园游戏。对开发者而言，多 agent 编排已进入 IDE 内置能力层面。
