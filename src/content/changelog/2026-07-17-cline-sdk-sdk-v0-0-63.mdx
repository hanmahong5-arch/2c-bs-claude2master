- 会话运行时在达到连续错误限制时发出 `task.mistake_limit_reached` 遥测事件。
  - 所有宿主（CLI、VS Code 扩展、hub daemon）均可捕获该事件，包括未配置宿主提示时的自动停止。
  - 设计含义：agent 可通过该事件统一处理错误限制逻辑，无需各宿主自行实现。
