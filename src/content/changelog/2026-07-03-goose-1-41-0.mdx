- 新增 iFlytek Spark、Astron MaaS、Fireworks AI 等 20+ 提供商，扩展 agent 可接入的模型生态。
- 引入 `--edit` 会话标志、`/status` 斜杠命令、钩子系统及全局提示加载，增强 agent 交互与可编程性。
- ACP 支持 TLS、思考力度配置、工具暴露及会话摘要，提升 agent 通信的安全性与灵活性。
