- 作者称入职大公司半个月，规格、代码、测试、PRD、工单及其解决、报告全部由 Claude Code 产出，团队里没人喜欢这种方式，只是被要求尽量多交付。
- 高层反复强调「推代码不是瓶颈」，于是人们每天工作 12 到 13 小时，只为按回车；从 L1 到 L7 的工程师都在做同一件事——和 Claude 对话。
- 对 agent 与工具链的含义：当生成速度被当成唯一指标，评审、测试与理解环节被跳过，交付量上升并不等于工程质量或团队能力提升。
