- 自动模式在遥测/特性开关关闭或 LLM 网关后，服务端无法检查的调用改为询问或拒绝，不再回退内置分类器；`CLAUDE_CODE_AUTO_MODE_SERVER=0` 可保留旧行为。含义：harness 需把“检查不可用”当作显式状态处理，而非默认放行。
- 终端新增 MCP 任务支持：工具调用作为任务时立即转后台，完成后再告知 Claude；`CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` 可改为同步等待。含义：harness 要区分长任务的后台化与结果回传时序。
- 新增 `permissions.denyInsteadOfPrompting`：本会等待权限提示的调用直接拒绝并继续回合，覆盖终端、子代理与队友。含义：无人值守场景可用拒绝替代阻塞式提示。
