- Hub 重启时拒绝新任务，完成当前任务后交接，断线重连会重放未完成工作，确保 agent 状态不丢失。
  - 对 harness 设计：需实现任务队列和断点续传机制，保证跨实例状态一致性。
- 修复了自定义 OpenAI 兼容模型因能力列表推断错误导致工具调用被静默禁用的问题。
  - 对 harness 设计：能力检测应基于显式声明而非便捷标志，避免误判。
- 更新模型目录，调整多家提供商（如 DeepSeek、Eden AI）的默认模型和定价。
  - 对 harness 设计：需动态同步模型配置，确保默认模型选择与最新目录一致。
