- **Bot Mode 内置**：桌面应用内每个 agent 有名字、头像和群聊，支持 @提及，多 agent 协作从管道变成团队聊天。对 harness 设计：需支持持久化 agent 身份与群组会话管理。
- **Cron 记忆与连续性**：定时任务现在有持久记忆和 notepad，`continuity=true` 传递上次输出，monitor 模式无变化时跳过 LLM。对 harness 设计：调度任务需考虑状态持久化与去重。
- **实时子代理编排**：`delegate_task` 支持列出、中途修正、提前停止并保留部分结果，默认迭代 250 次、并发 10。对 harness 设计：需要更细粒度的任务控制与结果回收机制。
