- OpenAI 与 Ironclad 合作，把复杂的合同工作流作为训练与评测 AI agent 的场景，目标是推进面向专业工作的 computer use 能力。对 agent 开发者而言，这意味着高价值垂直流程正成为能力验证的试验场。
- 文章强调的不只是模型能力，而是"训练 + 评测"并重：在真实专业任务上同时打磨和衡量 agent 表现。对工具链的含义是，评测集需要贴近真实业务流程，而非通用基准。
- 场景选在合同这类高专业度、多步骤的工作流上，说明 computer use 的下一步是处理长链路、有领域规则的任务。对开发者而言，接入此类流程时需考虑领域约束与可验证性。
