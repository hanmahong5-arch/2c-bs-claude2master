- **原理**：webframe 用 Go 写在 glaze 之上，直接调用系统浏览器（macOS 的 WKWebView、Linux 的 WebKitGTK、Windows 的 WebView2），不打包浏览器引擎；把 `console.log()` 输出到 stdout、异常输出到 stderr。对工具链的含义：轻量替代 Playwright 依赖成为可能。
- **定位**：Simon 把它类比自己的 shot-scraper javascript 工具，但体积更小、不依赖 Playwright。对开发者的含义：抓取脚本的分发成本可以显著降低。
- **评估方式**：他让 Claude Opus 5.5 实际运行 webframe、搭建探索性原型，再从「沙箱工具」和「按 shot-scraper JavaScript 模式抓网页」两个角度评估。对 agent 的含义：模型可独立完成工具试用与报告，但结论需看报告本身。
