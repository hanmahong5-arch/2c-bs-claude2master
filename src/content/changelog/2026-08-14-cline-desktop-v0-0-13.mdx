- 新增字体大小设置，启动前应用，避免闪烁。
  - 对 harness 设计：需在窗口绘制前读取并应用用户偏好，避免视觉跳变。
- 支持联网搜索的模型可开启 Web Search，结果记录在 transcript 中。
  - 对 harness 设计：需将外部工具调用及其结果持久化到会话记录，保证可回溯。
- 修复 Cline Pass 下 extended thinking 预算未生效的问题。
  - 对 harness 设计：需确保所有 API 路径（包括网关）都正确传递推理参数。
- 修复多实例 Hub 互杀问题，新实例会附加到现有 Hub 而非替换。
  - 对 harness 设计：需实现优雅的进程协调，避免资源竞争和会话中断。
- 空闲的插件沙箱进程会被回收，不再残留。
  - 对 harness 设计：需管理子进程生命周期，及时清理空闲资源。
- 模型目录更新，新增 Crusoe 提供商。
  - 对 harness 设计：需保持模型列表动态更新，支持新提供商。
