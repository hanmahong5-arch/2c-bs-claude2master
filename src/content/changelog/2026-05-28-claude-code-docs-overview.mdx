Claude Code 是一个代理式编码工具，它通过理解整个代码库来帮助构建功能、修复错误和自动化任务。
*   **多环境集成**：它可在终端、IDE、桌面应用和浏览器中使用，这意味着提示设计需要考虑不同环境的上下文获取能力。
*   **与工具链连接**：通过 Model Context Protocol (MCP) 连接 Google Drive、Jira 等外部数据源，这要求代理的提示能有效利用这些扩展的上下文。
*   **项目级定制与自动化**：通过 CLAUDE.md 文件设置项目规范，并支持创建可重复使用的技能和钩子，这强调了在提示中嵌入持久化、结构化的项目知识的重要性。
