- Windows 正式支持：提供签名安装包，自动更新与 macOS 同步；后台进程不再弹窗，MCP 路径回退 USERPROFILE。
- 工具返回的图片（截图等）内联显示，可点击展开、轮播查看，替代 base64 文本。
- 会话搜索覆盖全量历史，侧边栏搜索图标打开命令栏（Cmd/Ctrl+P），服务端排序结果。
- 新增 GitHub 集成引导步骤。
- 修复更新后定时任务丢失；agent 创建的调度统一存于 `~/.cline/schedules`，并在 Schedules 页显示。
- 完成的调度会话自动展开最终答案，标记为“Scheduled task completed”或失败，摘要渲染为 markdown。
- 建议的例程模板要求最终报告，使调度运行结果可读。
- 修复凭据显示与 Codex 登录问题，OAuth 错误明确提示。
- 检查点恢复拒绝在提交后重置工作区。
- 全局规则路径扩展至 `~/Cline/Rules`，修复 WSL 问题。
- `apply_patch` 保留 CRLF 行尾。
