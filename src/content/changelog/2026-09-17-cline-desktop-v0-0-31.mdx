- **SSH 远程主机**：在 Settings → Remote 添加并测试主机，从欢迎屏环境选择器切换；连接后 agent 工具、工作区发现、Git 元数据、会话持久化都在远端运行，仅经认证的 Cline Hub 协议隧道回传审批与实时事件。含义：harness 需把执行面与 UI 面解耦，本地只保留控制通道。
- **首次连接自动部署 helper**：上传自包含 helper 到 `~/.cline/remote/` 并缓存，无需 apt、npm、root、全局 CLI 或公网端口，且不影响该账户已有的 Cline CLI hub。含义：远程引导应零依赖、可缓存、不破坏既有环境。
- **同一步子代理并行**：同一步生成的子代理同时运行而非串行，三个独立任务耗时等于最慢者；必须按序的工具仍按序，仅相邻并行调用重叠。含义：调度器需区分可并行与有依赖的调用。
