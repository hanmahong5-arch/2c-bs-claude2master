- 新增 `claude_code.safety_event` OTel 事件，覆盖权限规则、auto 模式、安全检查、hook 与沙箱的拦截/提示/回退；harness 可据此把每次工具调用的决策链路变成可观测数据。
- HTTP MCP 调用在连接中断时不再盲目重发，仅对只读或幂等工具重试；harness 设计需显式标注工具幂等性，否则会丢调用或重复副作用。
- 无法解析的工具调用现在最多重试两次再报错结束回合；harness 应把解析失败当作可恢复状态，而非立即终止。
