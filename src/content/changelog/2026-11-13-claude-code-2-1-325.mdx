- 沙箱 Bash 默认走正常权限流程，需显式设 `sandbox.autoAllowBashIfSandboxed: true` 才免提示；harness 设计上应把「免提示」当作显式授权而非沙箱副作用。
- 修复子代理自带模型被 opusplan/haiku 拉去 plan-mode 模型，以及用主会话模型估算文件读取与 MCP 结果；多模型 harness 需按子代理自身模型计上下文预算。
- 修复第三方网关与 Foundry 每轮报上下文超限而不压缩；压缩触发应基于实际模型窗口，而非硬编码默认值。
