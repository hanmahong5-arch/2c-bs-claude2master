- 新增 `/new` 和 `/clear` 命名会话、固定线程、切换侧边对话不关闭，提升多会话管理能力。
- 支持 Agent Plugins 清单、工作区插件发布及 Amazon Bedrock/Claude Code 插件市场，扩展 agent 工具生态。
- 支持分页历史线程分叉（含临时分叉），WebSocket 连接远程 Code Mode 主机，增强 agent 执行环境灵活性。
