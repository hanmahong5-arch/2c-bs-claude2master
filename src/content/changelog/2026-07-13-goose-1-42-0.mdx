- 新增 OllamaCloudProvider，支持动态模型发现和上下文限制，使 agent 可自动适配不同模型能力。
- 每条消息显示 token、成本、TTFT、tok/s 等使用统计，并汇总会话总计，便于 agent 成本监控和优化。
- 聊天会话按项目分组导航，目录切换器显示项目名，提升多项目 agent 工作流组织效率。
