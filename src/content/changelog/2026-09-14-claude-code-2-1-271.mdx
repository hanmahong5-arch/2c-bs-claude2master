- Bash/PowerShell/Monitor 在自动模式加沙箱下新增按命令的 `allowed_domains`：只放行该命令评审过的域名，其余拒绝。含义是 harness 的网络授权从会话级下沉到命令级。
- 子代理 frontmatter 与 `--agents` JSON 新增 `omitClaudeMd`，可让自定义与插件子代理不加载用户、项目、本地 CLAUDE.md，托管策略文件仍加载。含义是上下文注入可按代理裁剪，减少无关指令干扰。
- Monitor watches 取消无超时的 `persistent`，改为始终带截止时间（最长 30 分钟，单次 `-p` 为 10 分钟），到期通知 Claude 重新武装。含义是长驻监听需显式续期，避免失控挂起。
