- 配置存储位置不会自动备份或迁移数据，且 OpenClaw 从不创建配置的根目录，必须先用绝对路径建好目录再 `storage init`。含义：harness 的持久化层要把「声明」与「副作用」分开，初始化应是显式动作而非隐式兜底。
- 加密用 passphrase 时，核心层在 provider 收到对象前加密、读取时解密；改 passphrase 不会重加密已有数据，丢失 passphrase 或位置标记都会导致对象不可读。含义：prompt/harness 设计里密钥与状态标记属于不可再生资源，需在流程外单独保管。
- 多安装共享同一位置时用 `backups/<namespace>/`，首次上传写入 owner.json 声明设备 ID，不同设备 ID 会拒绝备份；恢复是只读的，不改变声明。含义：多 agent 共享存储要显式划分命名空间，避免 hostname 冲突导致保留策略互相覆盖。
