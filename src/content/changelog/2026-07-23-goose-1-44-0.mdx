- 新增 Gemini、GPT-5.6、Muse Spark 1.1 等模型支持，agent 可接入更多 LLM 后端。
- 新增 `--edit` 会话标志，允许在分支前编辑对话，提升 agent 交互灵活性。
- 新增法语、德语等 8 种桌面语言，扩大 agent 全球化部署能力。
