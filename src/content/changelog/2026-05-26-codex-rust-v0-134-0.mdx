- **新增本地对话历史搜索**：支持不区分大小写的内容匹配和结果预览，便于快速回顾上下文，意味着 agent harness 需内置高效的本地数据检索能力。
- **统一配置管理**：`--profile` 成为 CLI、TUI 和沙盒流程的主要配置选择器，旧配置需迁移，表明 agent harness 应提供清晰的配置升级路径。
- **MCP 服务器环境隔离**：支持按服务器设置环境目标和 OAuth 选项，用于可流式传输的 HTTP 服务器，要求 agent harness 能灵活管理多环境下的工具集成。
