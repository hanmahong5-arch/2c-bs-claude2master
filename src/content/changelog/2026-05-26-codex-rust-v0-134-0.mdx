- **新增本地对话历史搜索**：支持不区分大小写的内容匹配和结果预览，让 agent 能快速回顾上下文，提升交互连贯性。
- **统一配置管理**：`--profile` 成为 CLI、TUI 和沙盒流程的主要配置选择器，旧配置通过迁移指南引导更新，简化了 agent 环境管理。
- **提升 MCP 工具可靠性**：保留本地 `$ref`/`$defs` 结构并压缩过大模式，确保工具模式稳定，同时允许只读工具并发执行，优化 agent 工具调用效率。
