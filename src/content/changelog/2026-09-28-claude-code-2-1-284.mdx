- 新增 `claude-sonnet-5-5` 并设为 Anthropic API 默认 Sonnet：1M 上下文、$2/$10 每 Mtok、缓存读 $0.20/Mtok。含义：harness 可放宽单次注入的上下文上限，但需重新校准缓存命中策略以吃到低价读。
- 自动模式在读取工作目录外文件时新增“Yes, but ask again next time”选项。含义：权限提示可按单次授权而非永久放行，harness 的审批状态机要支持一次性许可。
- 交互终端与 VS Code 在未配置权限模式时默认以 auto 模式启动，`permissions.defaultMode` 仍可覆盖。含义：默认权限姿态更宽松，harness 需确保显式配置能可靠压过默认值。
