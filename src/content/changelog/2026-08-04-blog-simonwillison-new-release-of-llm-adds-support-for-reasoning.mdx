- 新增推理轨迹显示：运行推理模型时，思考过程输出到 stderr，不影响 stdout 管道，可用 -R 隐藏。对开发者意味着可观察性提升，便于调试和审计。
- 支持服务端工具：OpenAI 的 CodeInterpreter、WebSearch，Anthropic 的 WebSearch、WebFetch、CodeExecution、AnthropicMCP，可通过一行命令调用。这简化了工具集成，让 CLI 成为强大的 agent 前端。
- 内容寻址日志存储：基于 Git 模型，避免重复 JSON 日志，提升存储效率。对构建复杂 agent 系统的开发者，提供了可扩展的日志基础。
