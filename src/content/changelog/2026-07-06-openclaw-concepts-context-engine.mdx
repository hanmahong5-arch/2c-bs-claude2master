- **四阶段生命周期**：ingest（存储消息）、assemble（按 token 预算组装消息）、compact（压缩历史）、after turn（持久化状态），引擎可接管或跳过任意阶段。
  - 含义：agent harness 应提供明确的上下文管理钩子，让插件控制消息选择与压缩策略，而非硬编码。
- **系统提示追加**：assemble 可返回 `systemPromptAddition`，OpenClaw 将其前置到系统提示中，用于动态注入记忆或检索指令。
  - 含义：prompt 构建应支持运行时追加上下文相关指令，无需修改静态 workspace 文件。
- **子代理生命周期钩子**：`prepareSubagentSpawn` 在子代理启动前准备共享上下文，`onSubagentEnded` 在子代理结束时清理。
  - 含义：跨 agent 边界时，harness 应提供上下文传递与清理机制，避免状态泄漏或重复。
