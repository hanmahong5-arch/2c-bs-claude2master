- 遥测辅助导出从 `@cline/llms`、`@cline/shared`、`@cline/core` 移除，`@cline/llms` 依赖减少；harness 应停止依赖这些内部符号，改用公开 API。
- `writeGlobalSettings`、`setTelemetryOptOutGlobally`、`setAutoUpdateEnabledGlobally` 不再接收 options 参数；调用方需同步改签名，避免静默失效。
- 内置模型目录刷新：新增 `concentrate`、`primalabs` 两个 provider，28 个 provider 的默认模型变更，OpenAI 多个 gpt-4o/gpt-5/o3 系列 id 被移除；harness 不应硬编码模型 id，需从目录动态解析默认值。
