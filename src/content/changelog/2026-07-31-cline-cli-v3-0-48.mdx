- `cline history` 在现有 TUI 内打开，支持恢复和删除，不再渲染第二个视图，简化了交互流程。
- 连接器线程（Slack、Discord 等）在绑定会话丢失时自动丢弃旧绑定并重放到新会话，无需手动编辑 `threads.json`，增强了健壮性。
- MCP 服务器的 `timeout` 设置现在对 `initialize`、`tools/list`、`tools/call` 生效，替代硬编码 5 秒限制，慢服务器不再失败。
- 推理控制从 models.dev 目录路由，预算受限且编码正确，跨提供商一致。
- OpenRouter 默认模型改为 `anthropic/claude-sonnet-5`，影响默认行为。
