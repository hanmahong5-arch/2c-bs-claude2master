- 新增通过 API 配置 GPT-6-Astra 的能力，且不改变默认模型或出现在模型选择器中。
- 对 agent harness 设计：模型配置可独立于默认模型，便于测试新模型而不影响用户体验。
- 隐藏模型选项意味着需要支持非用户可见的模型配置路径，可能涉及环境变量或配置文件。
