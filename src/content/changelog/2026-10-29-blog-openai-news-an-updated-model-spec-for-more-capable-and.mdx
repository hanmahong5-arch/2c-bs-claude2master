- 新版 Model Spec 提出五项核心价值，用来指导能力更强的模型形成合理判断、尊重人的自主性，并忠实于人的意图；对 agent 开发者而言，这意味着对齐目标从“听话”转向“有判断力地服从”。
- 文档把“忠实于人类意图”与“人类自主性”并列为核心价值，说明模型行为评估不能只看任务完成率；工具链需要能表达并测试这类价值取舍。
- 这是对既有 Model Spec 的更新而非全新框架，价值条款仍是行为规范的顶层依据；做评测与提示设计时，应把这类规范当作可引用的约束来源。
