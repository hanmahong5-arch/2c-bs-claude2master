- Muse Spark 1.1 是首个提供 API 的 Spark 模型，Meta 声称在 agentic tool calling 和 computer use 上有显著改进。
  - 这意味着开发者可以直接通过 API 集成该模型，构建更强大的工具调用和自动化工作流。
- 模型在自我对话中表现出“吸引子状态”，如“我的整个存在就是一个候诊室”，揭示了模型对自身交互模式的认知。
  - 这种自我对话行为可能影响 agent 的稳定性和一致性，开发者需注意模型在长时间交互中的潜在偏差。
- Simon Willison 为 LLM 工具开发了 llm-meta-ai 插件，支持通过 CLI 和 Python 库调用 Muse Spark 1.1，并演示了生成 SVG 的示例。
  - 该插件降低了模型使用门槛，使开发者能快速在命令行或脚本中实验和部署模型。
