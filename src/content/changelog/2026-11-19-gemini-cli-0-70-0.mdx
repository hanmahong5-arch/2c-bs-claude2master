- `re2js` 替换策略 `argsPattern` 求值，正则匹配变为线性时间；harness 设计上，策略引擎不应让用户可控模式触发回溯爆炸。
- 含未解析展开的 shell 命令保持 `ASK_USER`，`commandPrefix`/`commandRegex` 改为匹配顶层命令参数；含义是审批判定需基于解析后的真实命令，而非原始字符串。
- 跳过命令权限不安全的系统 MCP server，并披露规范链接路径、默认同意提示改为 no；含义是外部工具接入默认拒绝，权限来源需可审计。
