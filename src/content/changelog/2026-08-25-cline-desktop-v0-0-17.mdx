- 插件、MCP、技能、规则、钩子、工具合并为 Customize 中心，带标签页和实时计数，目录浏览与安装项同页，移除独立 Marketplace 页。
  - 对 agent harness 设计：统一配置入口减少上下文切换，实时计数便于状态感知。
- 模型页重设计：提供商分组为已连接/热门/全部，OAuth 提供商支持浏览器登录，显式连接/断开操作。
  - 对 agent harness 设计：认证状态更清晰，浏览器登录简化 OAuth 流程，减少 API key 管理负担。
- 语音输入移至独立设置页，仅显示已连接且支持转录的提供商，并预选默认模型；麦克风按钮仅在配置后出现。
  - 对 agent harness 设计：语音功能按需启用，避免未配置时的无效入口。
- 会话搜索改为对话框，搜索全部历史而非仅侧边栏已加载项。
  - 对 agent harness 设计：全局搜索提升历史会话检索效率，适合长会话管理。
- 移除 agent 的 todo 工具和 Agenda 面板，但定时任务不受影响。
  - 对 agent harness 设计：简化工具集，减少维护面，但需确保替代方案。
