- 新增 `claude-fable-5-2` 并设为默认 Fable 模型：1M 上下文、$8/$40 每 Mtok、缓存读取 $0.20/Mtok。harness 需按新模型重估上下文预算与成本上限。
- `claude remote-control` 新增 `--settings <file>`，对每个新会话生效；文件变更后需重启才起新会话。批量会话的配置注入因此可集中管理，但热更新不可依赖。
- 修复 MCP OAuth 在服务器重定向时把 refresh token 等密钥发往其他主机，以及只读 Bash 命令绕过沙箱、无提示执行。凭据与沙箱边界是 harness 的信任根，此类修复应视为回归测试的必测项。
