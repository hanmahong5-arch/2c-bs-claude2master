- **长周期任务需要持久记忆**：Arca 的 agent 任务可长达十天，涉及多次交接和决策点，因此自建记忆系统跟踪每个客户的进展、待办和责任人。对 agent 工具链的启示是：长任务编排必须内置状态持久化，而非依赖单次会话。
- **自建 harness 以灵活换模型**：Arca 基于内部基准自动选择最佳模型（主要用 Claude），并因拥有 harness 而能随时更换供应商。这意味着开发者应把模型路由和评估层握在自己手里，避免被托管 agent 框架锁定。
- **安全靠确定性护栏而非 agent 自觉**：交易和资金流动完全由人类顾问处理，agent 只做分析和提议；代码在沙箱中查询数据前会被转成严格格式并丢弃原代码。对开发者的含义是：高风险操作应移出 agent 决策范围，用确定性规则和格式校验兜底。
