- **Windows 代理绕过**：新增 `ensureLoopbackProxyBypass()`，在每次探测、drain、shutdown 前把回环地址写入 `NO_PROXY`。含义：harness 的本地守护进程发现逻辑不能假设环境无代理，需显式声明回环豁免。
- **Token 计数修正**：`outputTokens` 不再包含 reasoning tokens，避免会话总量与遥测重复统计，成本仍按完整总量计算。含义：harness 的用量归一化层要区分「计费口径」与「展示口径」。
- **网关模型协议保留**：配置模型不再丢失 per-model `apiProtocol`，避免回退到 provider 默认 API。含义：多端点 provider 的模型覆盖必须保留协议字段，否则路由会静默降级。
