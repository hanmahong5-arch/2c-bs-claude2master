- MCP 服务器支持 OAuth 认证，可查看状态、取消/重试，支持预注册客户端，配置变更时令牌失效。
  - 对 agent harness：需处理 OAuth 流程和令牌生命周期管理。
- MCP 错误显示在单个服务器上，配置无效的服务器不再静默消失。
  - 对 agent harness：错误定位更精准，便于调试。
- 发送消息无模型凭据或队列失败时，在转录中显示错误及原因，并指向设置。
  - 对 agent harness：失败不再静默，需捕获并展示错误。
- 修复首条消息重复渲染、composer 卡在“工作中”等问题。
  - 对 agent harness：提升 UI 稳定性。
- 欢迎屏新增“连接模型”提示，实时识别已连接的 Bedrock/Vertex 等。
  - 对 agent harness：引导用户配置模型，减少配置错误。
- 新增快捷键：Cmd/Ctrl+N 新会话，Cmd/Ctrl+, 设置，Esc 停止。
  - 对 agent harness：提供快捷操作，提升效率。
- 推理控制跨 AI SDK 提供商一致，包括 Ollama。
  - 对 agent harness：确保推理设置正确传递。
- Vertex AI 凭据刷新使用配置的 fetch，修复代理问题。
  - 对 agent harness：网络环境兼容性增强。
