- AI SDK 统一到 `ai` 7.0.120 与 `@ai-sdk/provider-utils` 5.0.50，替代此前逐个升级的方式；harness 需按包版本对齐依赖，避免混用导致的参数行为不一致。
- 关闭推理时不再向无法关闭的 OpenAI 模型（GPT-6 Astra、GPT-6.1 Sol）发送 `reasoning.effort: "none"`，Claude Fable 5、Opus 5.5 也不再收到 `thinking: {type: "disabled"}`；harness 应按模型能力决定是否下发禁用参数，而非全局统一。
- Stdio MCP 客户端处理服务器提前退出导致的 EPIPE，SAP AI Core provider 不再安装 winston 的进程级 `uncaughtException` 处理器；harness 应把子进程断连当作可恢复错误，而非让宿主进程退出。
