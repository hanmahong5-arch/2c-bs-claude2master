- Vim 模式支持 `/` 和 `?` 搜索草稿，高亮匹配，`n`/`N` 循环导航。
  - 对 agent harness 设计：可提升文本编辑效率，但需注意与现有键位冲突。
- 限流横幅提供操作入口，如检查用量、管理积分、重置限制。
  - 对 agent harness 设计：需处理限流状态，引导用户采取行动。
- MCP 服务器名支持 `:`、`@`、`/`、`.`，并支持包风格命名；单个 MCP 工具可设置 `output_token_limit`。
  - 对 agent harness 设计：命名更灵活，但需确保解析正确；输出限制可防止 token 溢出。
- 凭据刷新进度在 TUI 和 `codex exec` 中显示，包括 Bedrock 重新认证。
  - 对 agent harness 设计：需向用户透明展示认证状态。
- 修复：自动批准审查保留更长消息和更大对话记录，且跨历史压缩保留用户指令。
  - 对 agent harness 设计：确保关键上下文不丢失。
