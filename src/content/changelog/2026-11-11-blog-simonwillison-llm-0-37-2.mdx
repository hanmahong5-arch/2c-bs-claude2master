- 问题出在 `extra-openai-models.yaml` 机制上（0.37 起由 `llm openai endpoint add` 命令管理），用于接入其他厂商的 OpenAI 兼容 API。报告者 Daniel de Araujo 指出两条泄露路径：`api_key_name` 指定的 key 从未被存储时，以及 `responses: true` 的模型带 `-o chat_completions 1` 运行时。
- 含义：多端点配置下，凭据路由必须按端点严格隔离，不能靠“找不到就回退”的隐式逻辑。
- 含义：对 agent 工具链而言，模型参数覆盖（如强制切换 API 形态）会改变鉴权路径，属于需要测试覆盖的边界。
- 含义：这类问题由外部报告者发现并走 GHSA 流程披露，说明插件式端点扩展应默认假设配置可能残缺。
