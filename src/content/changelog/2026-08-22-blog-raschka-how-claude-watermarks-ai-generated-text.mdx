- 水印不是附加在文本上的额外步骤，而是嵌入在 LLM 常规文本生成过程中的一个微小调整，不影响生成质量。
- 理解水印需要先理解 LLM 的 token 生成机制：文本先被 token 化，再经模型预测下一个 token，水印就在这个采样环节起作用。
- 水印对用户不可见，只有 Anthropic 能解码，用于识别文本是否由 Claude 生成，这依赖于其内部实现细节。
