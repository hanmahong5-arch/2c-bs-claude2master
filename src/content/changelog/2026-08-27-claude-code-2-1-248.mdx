- 新增 `--restricted` 模式，移除执行命令/代码及 WebFetch 工具，限制文件操作于工作目录，并忽略用户/项目/本地设置，适合高安全环境。
- 新增 `experimental.cacheTtl` 到 agent frontmatter，可设置每 agent 的 prompt 缓存 TTL，优化子代理缓存策略。
- 新增 `claude self-hosted-runner --client-label` 覆盖 runner 注册标签，便于多 runner 管理。
- 修复长会话中因 OAuth token 刷新导致的 prompt 缓存 miss，提升长时间运行稳定性。
- 修复 `claude agents` 在 CI 环境跳过工作区信任提示，确保安全流程不被绕过。
