- 所有 DM 自动归入主会话，实现跨设备连续对话；这意味着 agent harness 应默认提供统一上下文入口，降低用户心智负担。
- 主会话自动监控群组和后台活动，以合并通知而非逐条唤醒；提示设计应利用这种“延迟感知”模式，避免实时响应压力。
- 通过 MEMORY.md、每日笔记和压缩机制实现滚动会话，重置时保存历史摘要；这启示 prompt 工程需显式管理长期记忆与短期上下文的衔接。
