- macOS/Linux 沙箱命令此前会在沙箱外先执行 shell 启动文件，现已修正；harness 需把初始化脚本也纳入隔离边界。
- 沙箱命令与自动接受的编辑可改写 `--mcp-config` 指定的 MCP 配置文件，现已封堵；工具权限应覆盖配置文件本身，而非只覆盖工作区。
- `Edit(path)` 拒绝规则在含子 shell 的命令中未能阻止 Bash 重定向到该路径，现已修复；路径级拒绝需同时约束重定向等间接写入。
