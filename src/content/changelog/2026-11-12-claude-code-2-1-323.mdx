- 新增实验性 Code Mode（需手动开启）：Claude 改为写 JavaScript 调用工具，harness 需考虑代码执行沙箱与工具调用边界。
- `plugin.json` 新增 `engines["claude-code"]` 版本范围，超范围插件不安装、不加载，安装时选最新兼容版本；harness 需在加载前做版本门控。
- 大量 Bash 权限修复：`Bash(ls*)` 等通配规则此前会跳过提示，`sudo`/`env` 包装命令漏检，现统一收紧；harness 的权限判定需按实际执行形态而非字面规则匹配。
