- 新增工具注册发现机制，便于动态扩展工具集，对 harness 设计意味着需支持运行时工具注册与发现。
- 修复敏感路径拦截不区分大小写及符号链接目录逃逸，强化沙箱安全，harness 应严格校验路径并遵循最小权限。
- 修复 ReAct 循环与提示注入导致的无限循环，并过滤思考内容，harness 需设计循环检测与上下文清理机制。
- 新增评估覆盖率报告命令，支持本地报告，harness 可集成评估工具以量化测试覆盖。
