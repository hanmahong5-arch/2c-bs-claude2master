- 财务演示里，agent 要把客户邮件中一行关于现有商誉的数字带进 Python 并做减法，模型能口头解释税务处理，却认不出这行代码正是规则适用处——说明评测要盯执行细节，而非最终回答。
- 生物基准 VIALS 让模型从九张脑肿瘤组织切片中挑出血管坏死最严重的两张，模型多选了 G——专家指出缺失部分比分数更有信息量，视觉工具链需要可解释的失败样本。
- 编码与安全任务中，团队检查 agent 读了哪些文件、是否核对副本、事后如何改 shell 历史，单看最终回复会漏掉大部分行为——agent 评测应记录完整工具调用轨迹。
