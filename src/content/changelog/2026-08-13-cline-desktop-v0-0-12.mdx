- 每个工具调用在转录中独立成行，带图标、状态和可展开详情，命令输出和编辑diff内联显示。
  - 对harness设计：更清晰的执行追踪，便于调试和审计。
- 运行中的工具行高亮为紫色，完成后变灰，错误保持红色；diff渲染器遵循应用主题。
  - 对harness设计：视觉反馈更直观，主题一致性提升。
- 修复Claude Code provider：会话锚定工作区，加载~/.claude设置，允许工作区内文件编辑。
  - 对harness设计：agentic工作流更可靠，权限控制更合理。
