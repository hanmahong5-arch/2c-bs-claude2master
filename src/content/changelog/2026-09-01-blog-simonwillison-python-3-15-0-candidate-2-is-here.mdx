- Python 3.15.0 RC2发布，进入RC阶段后仅允许修复bug，正式版预计10月发布。
- 作者建议第三方项目在RC阶段测试并发布wheel，因为RC构建的wheel兼容未来正式版。
- 作者回顾2021年因未在RC期测试导致bug流入正式版，强调RC测试价值，并分享GitHub Actions配置，使用allow-prereleases和check-latest自动测试最新RC。
