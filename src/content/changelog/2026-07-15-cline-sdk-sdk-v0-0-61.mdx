- 上下文压缩现在报告进度状态，便于监控长时间运行的任务。
- 工作区 git 信息（分支/远程）持久化并跨会话刷新，避免重复初始化。
- 修复良性 git 状态被误报为初始化错误，提升错误报告准确性。
- 系统提示中添加 Plan/Act 模式指导，切换模式时提供提示。
- 恢复 SDK 编辑工具的编辑器差异视图，增强代码审查体验。
- 模型 ID 从 OpenAI 兼容端点自动建议，简化配置。
- VS Code 终端可靠性改进（OSC 633 解析、退出码、超时处理）。
- 提供者特定请求头集中到 LLM 层，便于统一管理。
- 遥测附加组织上下文，增强身份识别。
- 新增共享 `@cline/ui` 主题包，促进 UI 一致性。
