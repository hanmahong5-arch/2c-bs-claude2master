- **多模型押注早于共识**：文章回顾 Llama、Alpaca、Mistral 出现时，OpenRouter 就判断没有单一模型会通吃，因此做中立路由层而非绑定某家模型。对 agent 开发者意味着模型可替换性应作为架构前提，而非事后补丁。
- **分发比训练更难**：文中指出模型实验室能花数十亿训练 checkpoint，却仍难把模型送到开发者手里，Mistral 价格战验证了竞争性推理市场的价值。这解释了为何推理网关会成为工具链里的关键卡位。
- **token 经济催生 agentic 欺诈**：Alex 与 Anjney 认为推理网关正成为欺诈目标，下一波攻击不只来自人类，还来自自主 agent 攻击高价值 token 流。对做 agent 支付与配额系统的团队，风控需按机器速度设计。
