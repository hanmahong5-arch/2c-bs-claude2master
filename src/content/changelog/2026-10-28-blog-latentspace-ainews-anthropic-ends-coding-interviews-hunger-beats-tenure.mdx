- Anthropic 招聘经理 Felix Reiseberg 停止用 React 小挑战等传统编程面试筛人，理由是 Claude 在这类测试上已更强，而最有产出的工程师未必擅长这些题。对开发者的含义：刷题信号与真实工程能力进一步脱钩，招聘与自评标准需重写。
- 他给初级工程师的建议是先选业务影响而非 backlog，挑一个激进想法，用一个周末做出可运行原型，绕开 PRD 与排期流程；并只聚焦一个好想法，避免把三个好点子埋进 20 个坏点子里。对 agent 工具链的含义：原型成本下降后，验证想法的最短路径就是让 agent 快速产出可演示版本。
- 同期 Google DeepMind 发布 Genie 4 实时世界模型，基于 Gemini 在环内规划多步事件，首次加入原生音频与物理模拟，并首次通过 Gemini API 开放。对 agent 开发者的含义：可交互仿真环境开始成为测试 agent 与机器人的候选基础设施。
