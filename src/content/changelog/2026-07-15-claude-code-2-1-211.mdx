- 新增 `--forward-subagent-text` 标志和环境变量，可在 stream-json 输出中包含子代理文本和思考过程，便于外部工具捕获完整推理链。
- 修复权限预览中未中和双向覆盖、零宽字符等问题，防止工具输入视觉篡改审批消息，增强安全审计可靠性。
- 修复自动模式覆盖 PreToolUse hook 的 `ask` 决策，hook 的 `ask` 现在会降级为提示，确保用户始终有确认机会。
- 修复多个共享凭据存储的 Claude Code 会话在唤醒后同时登出，以及插件 MCP 服务器在空闲 Web 会话唤醒后未重连，提升后台任务持久性。
- 修复子代理在恢复或后续消息时模型覆盖被重置为父模型，确保子代理独立模型配置生效。
- 修复 `/clear` 未重置会话成本计数器，状态栏成本现在从 $0 开始，便于准确追踪。
