- **模型定位与可用性**：Muse Wonder 是快速前沿模型，通过 Meta Model API 和 Muse Code 提供；Wonder Full 是完整版，仅限 Muse Code 订阅者。这意味着开发者在选择模型时需权衡访问权限与性能需求。
- **性能提升**：Artificial Analysis 显示 Wonder Full 在 Intelligence Index 上得分 56，接近 Opus 5.5 的 58，且在 Terminal-Bench 等 agentic 任务上大幅提升（33%→57%）。这表明 agent 工具链可受益于更强的长程任务执行能力。
- **成本与效率**：Wonder 每次索引任务成本 $4.52，输入 token 使用量高；但输出 token 减少约 10%。开发者需关注 token 效率，优化调用策略以控制成本。
