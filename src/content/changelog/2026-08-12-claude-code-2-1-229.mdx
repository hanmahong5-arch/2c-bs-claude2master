- 新增插件市场 `command` 源：本地命令输出插件目录，每次会话重新解析，无需重启即可生效。
- 网关流式响应增加 SSE keepalive 心跳，避免长思考时 Vertex/Bedrock 空闲超时断开。
- 修复工具调用含非字符串 `glob`/`file_path`/`command` 时崩溃，以及窄终端渲染进度条/表格的 RangeError。
- 修复 Windows 上扩展长度路径引用崩溃，以及禁用 attribution 头时 auto 模式每次工具调用失败。
- 改进工作流扇出：错开同前缀兄弟 agent 启动，让后续 agent 读取缓存前缀，减少重复计算。
