- 新增插件市场 `command` 源，支持本地命令输出插件目录，每次会话重新解析，无需重启。
- 网关流式响应增加 SSE keepalive 心跳，避免长思考时 Vertex/Bedrock 空闲超时断连。
- 修复窄终端下进度条/表格渲染导致的 RangeError 崩溃，影响 `--continue`/`--resume`。
- 修复工具调用参数非字符串（如 glob）导致的崩溃，以及 Windows 扩展路径/UNC 路径崩溃。
- 修复禁用 attribution header 时 auto mode 每次工具调用失败的问题。
- 修复 MCP OAuth 重定向 URI 使用 `localhost` 被严格授权服务器拒绝，改用 `127.0.0.1`。
- 修复 IDE 诊断数千条时 UI 卡顿，以及文件监视器句柄泄漏。
- 改进工作流扇出，错开同前缀兄弟代理，利用缓存提示前缀。
