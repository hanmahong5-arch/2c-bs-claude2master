- 新增 `sandbox.credentials` 设置，阻止沙箱命令读取凭据文件和秘密环境变量，提升 agent 执行安全性。
- 修复 `--json-schema` 和 `agent({schema})` 中模型无限重调 `StructuredOutput` 的问题，后续轮次可靠返回结构化输出，确保 agent 工具调用链稳定。
- 修复远程 MCP 工具调用无响应 5 分钟阻塞的问题，改为超时报错（可配置），避免 agent 流程永久挂起。
