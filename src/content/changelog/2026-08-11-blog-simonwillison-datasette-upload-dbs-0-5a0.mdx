- 该插件允许用户向托管的 Datasette 实例上传新的 SQLite 数据库，并立即开始服务。
- 新版本增加了正式 API，可通过 curl 命令上传或替换数据库，支持在 GitHub Actions 等环境中构建后自动部署。
- 对开发者而言，这意味着数据库的更新可以自动化，无需手动干预，简化了部署流程。
