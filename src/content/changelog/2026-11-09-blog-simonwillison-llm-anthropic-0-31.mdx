- 作者把 Fable 5.2 加进 `llm-anthropic` 0.31，用 `llm -m claude-fable-5.2` 即可调用；对 agent 工具链而言，新模型上线当天就能在 CLI 里跑通，说明插件式封装比等官方 SDK 更快。
- 他在 low 到 max 五档推理强度下各生成一张“骑自行车的鹈鹕”图，xhigh 效果最好，max 档在花掉 128,000 thinking token 后直接没返回图像；这提醒开发者，高推理档位要预留 token 预算并做失败兜底。
- 定价 $8/$40 每百万输入/输出 token，比 Fable 5.1 的 $10/$50 便宜 20%；对成本敏感的批量 agent 任务，换模型前值得重算一遍单价。
