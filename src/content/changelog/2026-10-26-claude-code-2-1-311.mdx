- 标准上下文会话超 200K token 不再报“需要 1M 上下文额度”，改为自动压缩后继续；harness 需把上下文溢出当作可恢复事件而非终止条件。
- 中断操作此前要等 MCP 资源读取或技能下载超时才生效，现在即时响应；harness 的取消路径必须独立于外部 I/O 阻塞。
- 子代理现在能用启动后才连上的 MCP 服务器工具，且 SubagentStop 钩子从每分钟约两次改为完成时一次；harness 需支持工具集延迟注册与钩子幂等触发。
