- 定位是开源、厂商中立的平台，专门管理敏感环境里的持久化 agent，而不是一次性任务脚本。对开发者的含义：agent 的部署与治理开始被当作独立基础设施层来对待。
- 强调 vendor neutral，意味着不绑定某一家模型或云厂商。对工具链的含义：接入层与运行时需要可替换，避免把业务逻辑写死在单一供应商 SDK 上。
- 目标场景是 sensitive environments，即对合规与数据边界有要求的部署环境。对 agent 落地的含义：权限、审计与隔离能力会比模型能力更早成为选型门槛。
