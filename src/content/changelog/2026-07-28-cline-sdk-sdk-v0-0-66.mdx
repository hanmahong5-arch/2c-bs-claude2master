- 新增 `cline-free` 免费模型，定价为零，超限返回专用错误含重置时间，适合低成本测试场景。
- Agentic compaction 成为默认策略，修复在 OpenAI Compatible 提供商上回退到 basic compaction 的 bug，确保压缩始终使用模型真实上下文窗口。
- 修复工具密集对话中 agentic compaction 找不到切割点导致上下文无限增长的问题，现在 assistant 消息可作为有效切割边界。
