- 自动模式先执行策略，低风险遗漏再审查，而非完全阻止。这意味着 agent 工具链可在安全框架内更自主运行，减少人工中断。
- 策略引擎支持细粒度规则，如按命令、主机或用户分级。开发者可定义更灵活的自动化边界，避免一刀切限制。
- 人类始终保留最终审批权，自动模式仅处理预授权操作。这为 agent 部署提供了可审计的信任基线，降低合规风险。
