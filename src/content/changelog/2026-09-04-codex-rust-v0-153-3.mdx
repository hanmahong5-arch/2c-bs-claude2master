- 在 Amazon Bedrock 模型选择器中新增 GPT-6-Astra，支持 Mantle 和 Runtime 全球/美国路由。
  - 对 agent harness 设计：需更新模型列表，确保新模型可被选用。
- 修正 GPT-6-Astra 的异步澄清问题指引，明确其仅接受文本，并使用受支持的工具。
  - 对 agent harness 设计：需调整工具调用逻辑，避免向模型发送非文本内容。
