- **新增 `claude agents --json` 命令**：以 JSON 格式列出活跃 Claude 会话，便于与 tmux-resurrect、状态栏等工具集成。
- **为 `claude_code.tool` OTEL spans 添加 `agent_id` 与 `parent_agent_id` 属性**：修复追踪父子关系，使后台子 Agent 的 spans 正确嵌套在调度 Agent 的工具 span 下，提升分布式调试能力。
- **状态行 JSON 输入现包含检测到的 GitHub 仓库与 PR 信息**：为外部状态显示工具提供更丰富的上下文数据。
