- OpenAI 测量编码 agent 对 AI 研究的加速效果，并指出其表现并不均衡，存在明显的能力参差。对开发者的含义：评估 agent 时不能只看平均分，要按任务类型分场景看短板。
- 文章把这种不均衡称为「锯齿状前沿」，即 agent 在某些研究任务上很强、在另一些上明显偏弱。对工具链的含义：编排层需要按任务难度动态路由，而不是默认一个 agent 通吃。
- OpenAI 将这一现象与递归自我改进联系起来，讨论它意味着什么。对 agent 研发的含义：自我改进的前提是能力可被稳定测量，参差不齐会直接限制自动化研究的上限。
