- 修复了 MCP OAuth 登录时重定向 URI 不匹配的问题，影响使用预注册 OAuth 客户端的服务器（如 Slack）。
- 对 agent harness 设计：集成 MCP 服务器时需注意 OAuth 重定向 URI 的配置，确保与服务器预注册的 URI 一致。
- 对 agent harness 设计：测试 OAuth 流程时，应覆盖使用预注册客户端的场景，避免登录失败。
