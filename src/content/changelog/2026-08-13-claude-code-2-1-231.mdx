- 修复了 MCP OAuth 登录时重定向 URI 不匹配的问题，影响使用预注册 OAuth 客户端的服务器（如 Slack）。
- 对 agent harness 设计：需确保 OAuth 回调 URI 与服务器预注册的 URI 完全一致，避免集成失败。
- 对 agent harness 设计：测试时需覆盖预注册 OAuth 客户端的场景，确保兼容性。
