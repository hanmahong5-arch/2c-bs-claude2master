- 新增 `CLAUDE_CODE_DISABLE_WEB_FETCH` 与 `allowedProviders` 托管设置，可分别关闭 WebFetch、限制机器可用的 API provider；harness 需把工具开关与 provider 白名单当作启动期策略，而非运行时临时判断。
- 修复 fork 子代理不继承父会话的 plan/dontAsk 权限模式，以及 `claude -p --permission-prompt-tool` 下后台子代理权限请求被自动拒绝；子代理的权限上下文必须显式继承，否则会静默绕过或误拒。
- 非流式回退请求超时重试新增 `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` 上限，并让回退共享原请求的重试预算；重试预算应统一核算，避免流式失败后回退再放大请求量。
