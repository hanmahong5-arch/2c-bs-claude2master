- 修复了某些 Mac 上 Bash 命令因任务目录移动或链接而失败的问题，确保工具执行稳定性。
- 修复了无本地设置文件时“始终允许”权限不保存的问题，简化项目配置流程。
- 修复了远程控制会话在 claude.ai 连接降级时工具完成后卡顿数分钟的问题，提升响应性。
- 修复了后台任务大量错误输出导致对话超限的问题，避免 API 请求失败。
