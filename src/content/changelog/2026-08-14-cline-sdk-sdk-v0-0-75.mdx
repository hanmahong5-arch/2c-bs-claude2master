- 新增 provider 执行的网络搜索，模型可在对话中搜索，结果持久化，默认关闭，需在设置中启用 `web_search` 工具。
  - 对 harness 设计：需支持工具调用和结果回放，确保会话恢复时搜索状态一致。
- Cline 网关新增专用 provider，修复 `cline-pass` 扩展思考预算未生效的问题。
  - 对 harness 设计：需区分不同 provider 的配置传递，确保参数正确到达模型。
- 修复多实例 Hub 互杀问题，通过构建 ID 全序比较避免冲突；新构建不再抢占活跃 Hub，空闲时再切换。
  - 对 harness 设计：需实现优雅的进程协调和版本兼容，避免会话中断。
