- 新增 `/diff` 面板，全屏模式并排显示未提交更改，便于观察 agent 编辑过程。
- `/cost` 和状态行现在提示缓存未命中的可能原因（如工具定义或系统提示变更、超过 TTL），有助于优化 token 成本。
- 修复了路径含括号的权限规则失效、正则错误导致编辑失败、zsh 命令隐藏命令替换绕过 Bash 权限检查等问题，强化了沙箱安全。
- 修复了 `/rewind` 误报成功、残留文件读取跟踪等问题，确保回滚可靠。
- 改进了结构化输出，拒绝无法满足的 JSON Schema，并优化了 1M 上下文模型的自动压缩时机。
