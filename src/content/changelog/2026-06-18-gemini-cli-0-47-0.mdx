* **尊重后端定义并更新自动模式**：当启用标志时，自动模式现在会使用 Gemini 3.5 Flash 模型。这意味着 Agent Harness 需要正确解析和传递后端配置标志，以确保模型选择的准确性。
* **实现 MCP 工具发现的原子更新**：修复了核心中 MCP 工具发现的竞态条件问题。这要求 Agent Harness 的工具发现机制必须是原子操作，以保证工具列表的一致性和可靠性。
* **避免持久化空的恢复会话**：优化了会话管理，不再保存空的恢复会话。这提示 Agent Harness 在设计和实现状态持久化逻辑时，应包含对无效或空状态的过滤机制，以节省存储并提高效率。
