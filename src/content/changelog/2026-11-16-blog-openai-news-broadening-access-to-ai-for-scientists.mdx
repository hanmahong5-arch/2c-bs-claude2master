- OpenAI 将 ChatGPT for Academic Researchers 项目扩展到全球 20 万名研究人员，提供前沿模型的免费使用权限。对 agent 开发者而言，这意味着学术场景下的模型调用成本和准入限制被进一步压低。
- 该消息来自 OpenAI 官方公告，正文仅说明扩容规模与免费开放范围，未披露具体模型版本、申请条件或使用条款细节。工具链团队若要接入，仍需等待官方后续说明。
- 面向科研群体的定向开放，反映模型厂商正按行业切分访问计划。开发者可关注同类学术计划是否附带 API 或数据接口，以判断能否纳入自有 agent 工作流。
