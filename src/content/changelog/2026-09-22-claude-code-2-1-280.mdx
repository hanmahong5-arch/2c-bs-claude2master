- 新增 `claude-opus-5-5` 并设为默认 Opus 模型：1M 上下文、$4/$20 per Mtok、缓存读取 $0.20/Mtok。含义：harness 可默认假设更长上下文，减少主动截断策略。
- 修复恢复的 fork 子代理重建工具列表而非复用首次列表，导致该代理 prompt 缓存失效。含义：子代理需持久化初始工具集以保住缓存命中。
- 修复后台子代理在无头与 SDK 会话中收尾时消息被静默丢弃，以及启动它的对话被压缩后报告丢失。含义：子代理消息与报告需独立于父对话生命周期落盘。
