- 模型回合在调用工具前耗尽输出额度时，不再直接报错结束，而是最多重试三次，并附带“精简表达、拆分到多次工具调用”的提醒，三次后才判定失败。含义：harness 应把输出上限视为可恢复状态，而非终止条件。
- 输出上限较大的模型默认预算从固定 32,000 提升为上限的 30%（取较大者），约 107k 输出 token 以下的模型不受影响。含义：预算策略需按模型能力动态计算，并接受更长响应带来的单轮成本与延迟。
- 模型目录由 6,188 更新至 6,237，覆盖同一批 209 个 provider；Cline Pass 新增 MiMo V2.6 Flash 与 Pro，10 个 provider 的默认模型变更（六个改为 MiMo V2.6 Flash）。含义：未固定模型的用户默认行为会变，harness 需明确默认模型来源与可覆盖性。
