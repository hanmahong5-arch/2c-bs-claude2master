- OpenAI 兼容请求对 GPT-6 系列改用 `max_completion_tokens`，Azure 的 `gpt-35-turbo` 仍用 `max_tokens`：harness 需按模型 id 分支选择参数名，而非统一写死。
- hub daemon 记录启动它的客户端信息（`CLINE_HUB_LAUNCHER_CLIENT`/`VERSION`/`TRANSPORT`）并作为 OTel 资源属性上报，SSH 远程 hub 标记 transport 为 `ssh`：多客户端场景下可追溯来源，便于定位问题。
- 模型目录从 6,952 增至 7,041，新增 CommandCode 与 Reflection 供应商，`cline` 默认模型回到 Claude Sonnet 5.5：默认模型与供应商列表变动意味着 harness 不应硬编码默认值。
