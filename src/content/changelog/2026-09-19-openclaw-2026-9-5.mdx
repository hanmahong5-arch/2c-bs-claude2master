- 发布包含 64 次直接提交、4,179 个 PR、503 位贡献者，规模巨大，说明 harness 需要能处理高频合并与多贡献者协作的发布节奏。
- 提供面向 AI agent 的纯 Markdown changelog，与人类可读的 release notes 内容相同但格式不同，意味着 agent harness 应优先消费结构化纯文本而非渲染页面。
- Android APK 被跳过，因为 apps/android/version.json 为 2026.8.2 而发布列车是 2026.9.5，提示 harness 需在打 tag 前校验各平台版本文件一致性。
