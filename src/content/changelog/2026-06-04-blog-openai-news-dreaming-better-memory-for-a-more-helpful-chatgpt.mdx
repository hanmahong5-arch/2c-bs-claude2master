OpenAI 宣布为 ChatGPT 引入新的记忆功能，旨在提升对话的连贯性和个性化体验。
- **记忆用户偏好**：ChatGPT 可以记住用户在对话中提到的具体细节和偏好，例如喜欢的写作风格或常用设置，这意味着 AI 助手能更精准地适应个体需求，减少重复输入。
- **保持上下文新鲜**：系统能在多次对话中维持相关背景信息，确保互动不中断，这对开发者来说，有助于构建更流畅、自然的工具链，提升用户体验。
- **跨会话应用**：记忆功能支持在不同会话间调用存储的信息，使 ChatGPT 更像一个持续学习的伙伴，为 agent 开发提供了长期个性化交互的基础。
