- **新增 `skipLfs` 选项**：GitHub/Git 插件市场源在克隆和更新时可跳过 Git LFS 下载，减少大型文件传输时间。
- **代理调度输入自动补全增强**：现在会建议原生斜杠命令和捆绑技能，而不仅仅是项目技能，提升工具发现效率。
- **修复多项关键问题**：包括修复状态化 MCP 服务器的重连循环、自定义 API 网关的令牌混淆、子代理 MCP 服务器配置忽略，以及 Windows 更新失败后的可恢复性，增强了系统稳定性和安全性。
