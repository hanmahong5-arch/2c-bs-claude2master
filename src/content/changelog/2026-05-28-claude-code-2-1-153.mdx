- 为 GitHub/Git 插件市场源添加 `skipLfs` 选项，克隆更新时可跳过 LFS 下载，减少大型文件传输时间。
- macOS 后台代理现以“Claude Code”名称统一申请系统权限，且权限在升级后得以保留，提升安全性与用户体验。
- 修复恢复会话时因存储会话过多导致内存占用数 GB 的问题，并修正 Windows 更新失败后的回滚机制，确保更新可靠性。
