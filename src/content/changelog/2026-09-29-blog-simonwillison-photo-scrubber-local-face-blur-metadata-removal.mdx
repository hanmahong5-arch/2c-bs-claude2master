- 作者拍下抗议者照片后，不愿分享陌生人可识别的面孔，于是让 GPT-6 Astra 构建了这个实验性工具，自动检测并模糊人脸。对开发者的含义：隐私需求常来自具体场景，小而专的工具比通用方案更实用。
- 实现依赖 Google 的 MediaPipe C++ 库，通过 @mediapipe/tasks-vision 编译为 WebAssembly，并使用 BlazeFace 人脸检测模型。对工具链的含义：WASM 让浏览器端跑本地模型成为可行路径，无需上传图片到服务器。
- 工具同时处理元数据移除，人脸模糊与元数据清理在本地一次完成。对 agent 的含义：这类端侧处理能力可被 agent 直接调用，减少敏感数据外流。
