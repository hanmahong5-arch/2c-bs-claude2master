- 修复 token 刷新后仍因旧 token 过期而失败的问题，确保长空闲后首次请求成功。
- 修复迁移任务误报成功和静默登出问题，现在会明确报告登出原因。
- SDK 版修复 Claude Code 原生工具、工作目录锚定、权限规则加载，并拒绝截断的 tool-call JSON。
- 修复流式 tool call 索引崩溃和 token 计数虚高（缓存会话约 5 倍）。
