- **Hub 守护进程指纹**：CLI 升级后通过运行时构建指纹识别并重启旧守护进程，避免连接过期代码。
  - 对 harness 设计：升级流程需考虑进程生命周期管理，确保新代码生效。
- **推理模型压缩修复**：摘要器不再硬编码 1024 token 上限，遵循 max output tokens 设置，默认 4096，并在空摘要时记录诊断。
  - 对 harness 设计：需动态适配模型输出限制，并增强日志可观测性。
- **Vertex 模型目录新增 Fable 5**：定价因区域而异，故成本显示为未知而非错误。
  - 对 harness 设计：处理区域相关定价时，应避免错误估算，明确标注未知。
- **自定义 Vertex 模型 ID 透传**：Claude 风格 ID 路由到 Anthropic-on-Vertex 路径，不再被改写。
  - 对 harness 设计：支持自定义模型 ID 的透明传递，保持兼容性。
