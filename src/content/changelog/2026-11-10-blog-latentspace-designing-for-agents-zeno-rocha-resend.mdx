- 在一项 AEO 研究中，Claude Code 在 102 次邮件推荐里有 64 次首选 Resend，SendGrid 仅 7 次居首却 55 次作为备选；开发者接受 agent 给的方案后很少再试第二选择，意味着 agent 的默认推荐几乎等于分发渠道。
- Resend 的定价页有滑块供人拖动，URL 加 .md 后 agent 一次请求就能拿到可读表格；对做开发者工具的团队，这意味着同一页面要同时为人和模型准备可解析版本。
- 其 MCP server 从约 20 个工具涨到 80 多个，但 Zeno 发现单次调用返回结果可能大到塞不进上下文；减少工具数量并不能缩小单条响应，设计 MCP 时应展开日常调用的返回值，看模型真正需要多少。
