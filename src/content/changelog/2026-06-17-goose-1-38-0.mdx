- **新增 ACP 会话摘要与筛选功能**：支持获取会话最后消息片段、按关键词和类型筛选会话列表，便于 Agent 系统快速检索和上下文管理。
- **统一跨提供商的思考模式与 OTLP 日志模式**：规范了不同 AI 服务的推理输出格式和遥测数据，为多模型 Agent 的稳定监控和切换奠定基础。
- **扩展提供商支持与工具增强**：新增 Perplexity、Alibaba Qwen、xAI SuperGrok 等声明式提供商，并引入图像读取工具和工具输出大小限制配置，丰富了 Agent 的感知与执行选项。
