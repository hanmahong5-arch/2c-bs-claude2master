- **Opus 4.8 默认高推理强度**：为最困难的任务默认启用 `/effort xhigh`，意味着智能体在执行复杂指令时会投入更多计算资源。
- **引入动态工作流**：Claude 可创建并协调数十至数百个后台智能体，允许用户处理更大、更复杂的项目，通过 `/workflows` 查看运行状态。
- **简化代码审查流程**：`/simplify` 命令现在只运行清理审查（重用、简化、效率、高度），并应用修复，而非完整的错误审查，优化了日常代码优化流程。
