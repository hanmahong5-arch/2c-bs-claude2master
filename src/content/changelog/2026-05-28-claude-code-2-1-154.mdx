- **Opus 4.8 默认高推理强度**：为困难任务预设 `/effort xhigh`，意味着智能体在复杂推理上默认投入更多计算资源。
- **新增动态工作流功能**：用户可指令 Claude 创建后台工作流，协调数十至数百个智能体，这标志着智能体编排能力从单任务扩展到复杂项目级。
- **多项指令与体验优化**：`/simplify` 改为仅做代码清理评审；`/effort` 标签更名；`claude agents` 支持后台会话命令；修复了包括后台会话管理、渲染、路径解析在内的多个问题，提升了智能体系统的稳定性和用户体验。
