- OpenAI 正在测试在 ChatGPT 中展示广告，目的是为了支持免费用户的访问成本，同时保持广告的清晰标识。
- 广告将明确标注，且不会影响模型回答的独立性，确保内容生成不受广告商影响。
- 公司承诺加强隐私保护，并提供用户控制选项，例如管理广告偏好或关闭个性化广告。
- 对开发者而言，这意味着 AI 平台可能引入新的商业化模式，需关注广告集成对用户体验和 API 生态的潜在影响。
