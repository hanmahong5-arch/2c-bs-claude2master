- 远程压缩现在默认将保留图像计入 token 预算，超出时修剪旧图像。
- 这意味着 agent 在远程会话中需要更谨慎地管理图像资源，避免超出预算。
- 设计 harness 时，应预留图像清理机制，或提示用户及时清理。
