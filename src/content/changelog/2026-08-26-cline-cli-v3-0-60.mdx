- 修复后台 hub 进程内存暴涨：长会话中状态更新向所有客户端广播完整对话副本，可致进程达数十 GB。升级后需重启命令生效，对 agent harness 意味着需管理长会话广播开销。
- 新文件使用平台原生行尾，代码搜索工具不再因超长单行崩溃，提升跨平台文件处理与搜索稳定性。
- 不再为 Claude Code 显示成本估算（其用量通常由订阅覆盖），并移除 git 远程 URL 中的凭据，避免泄露给模型。
- 修复 MCP 服务器安装参数中 `--` 分隔符的解析错误，并更新模型目录：新增 7 家提供商，多个默认模型变更（如 ClinePass 改为 GLM 5.3），未固定模型的用户将获得新默认值。
