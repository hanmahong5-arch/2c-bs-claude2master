- 新增可选 `spellcheck` 设置，利用 aspell/hunspell/ispell 在输入时下划线标出拼写错误，便于 agent 开发中快速发现提示词拼写问题。
- 修复语言服务器断连重连导致整个提示词缓存失效的问题，减少不必要的重算，对依赖缓存的 agent 工作流更友好。
- 修复权限对话框中 Shift+Tab 误批准编辑并授予全局权限的问题，现在正确关闭字段，避免意外授权。
- 改进 Agent 工具在不可用时的错误提示，明确列出可用 agent，帮助开发者快速定位配置问题。
- 优化后台云会话（如 /ultrareview）的内存和 CPU 占用，不再重复扫描事件流，提升长时间运行时的资源效率。
