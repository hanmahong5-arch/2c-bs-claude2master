- 新增可选 `spellcheck` 设置，利用 aspell/hunspell/ispell 在输入时下划线标出拼写错误，提升提示词质量。
- 修复语言服务器重连导致整个提示词缓存失效的问题，确保缓存命中率稳定。
- 修复权限对话框中的 Shift+Tab 误操作，避免意外批准编辑权限，增强安全性。
- 改进 Agent 工具在不可用时的错误提示，明确列出可用代理，减少混淆。
- 优化后台云会话（如 /ultrareview）的内存和 CPU 占用，不再重复扫描事件流。
- 修复 Vim 模式下切换详细转录或关闭面板时保持 NORMAL 模式和光标位置。
