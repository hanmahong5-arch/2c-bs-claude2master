- 新增 `/config` 中的 "Dynamic workflow size" 设置，可控制工作流中 agent 数量（小/中/大），作为建议性指导而非硬性限制，便于根据任务复杂度调整资源分配。
- 工作流生成的 agent 现在会携带 `workflow.run_id` 和 `workflow.name` 的 OpenTelemetry 属性，使工作流运行活动可从 OTel 数据中重建，增强可观测性。
- 修复了远程控制（移动端/网页）发送命令时提示 "Unknown command"、无标题图片/文件被静默丢弃等问题，确保多端交互一致性。
