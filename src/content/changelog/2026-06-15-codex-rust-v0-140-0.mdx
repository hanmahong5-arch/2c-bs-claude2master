- **新增会话永久删除功能**，通过命令行和 API 提供带确认的保护机制，并自动清理子代理，意味着代理系统需要设计安全的生命周期管理。
- **支持从 Claude Code 选择性导入配置和最近对话**，通过 `/import` 命令实现，表明代理框架需考虑用户数据迁移与生态集成。
- **为 Amazon Bedrock 和 CLI/MCP OAuth 添加托管 API 密钥认证与本地加密存储**，强化了多环境下的凭证安全管理，要求代理基础设施支持可插拔的认证后端。
