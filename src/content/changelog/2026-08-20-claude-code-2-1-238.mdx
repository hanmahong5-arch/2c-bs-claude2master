- 新增 `keybindingFlavor: "readline"` 设置，使 Ctrl+W 按 Bash 方式删除至空白；默认 classic 不变。对 harness 设计：需支持可配置键位绑定，并保持默认行为稳定。
- 插件市场支持 `headersHelper` 生成临时 HTTP 头，安装/更新时需确认（`-y` 跳过）。对 harness 设计：需在插件安装流程中集成动态认证，并提示用户确认。
- 新增 `self-hosted-runner --defer-shutdown-max-min` 和 `--proxy-authorization-command/file`，增强优雅退出与代理认证。对 harness 设计：需支持延迟关闭和动态代理头，确保长任务不中断。
- 修复子代理工具结果内存无限增长，现离开显示窗口即释放。对 harness 设计：需管理工具结果生命周期，避免长会话内存泄漏。
- 修复 MCP `headersHelper` 不继承凭据环境变量，且需信任目录。对 harness 设计：需隔离凭据，并强制信任确认。
