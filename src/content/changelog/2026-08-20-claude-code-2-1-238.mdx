- 新增 `keybindingFlavor` 设置，可切换 readline 风格 Ctrl+W，影响提示符交互设计。
- 插件 marketplace 支持 `headersHelper` 动态生成 HTTP 头，安装/更新时需确认，注意凭证隔离。
- 自托管 runner 新增延迟关闭和代理授权命令，增强网络边缘场景的可靠性。
- 修复子代理结果内存释放、输出风格漂移、远程控制会话恢复等问题，提升长会话稳定性。
