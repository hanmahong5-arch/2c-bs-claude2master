- 新增 `eval:inventory` 命令，支持 JSON 输出，便于自动化评估流程。
  - 含义：Agent 可调用此命令获取评估清单，实现自检与报告生成。
- 修复技能安装中的路径遍历漏洞，并增强零配额快速失败机制。
  - 含义：Agent 在安装第三方技能时更安全，且资源耗尽时能及时报错而非死循环。
- 标准化工具输出格式，迁移 `coreTools` 配置至 `tools.core`。
  - 含义：Agent 工具调用输出更一致，配置结构更清晰，便于扩展。
