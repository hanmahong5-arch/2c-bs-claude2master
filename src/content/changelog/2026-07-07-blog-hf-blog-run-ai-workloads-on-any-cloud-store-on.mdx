- SkyPilot 与 Hugging Face 存储集成，允许用户在任意云上运行 AI 工作负载，同时将数据存储在 Hugging Face 上，实现零出口费用。
- 用户可通过 SkyPilot 的 `sky launch` 命令指定 Hugging Face 仓库作为存储后端，自动挂载并同步数据，简化多云环境下的数据管理。
- 该方案对开发者意味着更灵活的基础设施选择，避免被单一云服务商锁定，同时降低数据迁移成本。
