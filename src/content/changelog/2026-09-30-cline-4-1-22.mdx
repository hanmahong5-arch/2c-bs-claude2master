- Anthropic 直连启用服务端 refusal fallback，OpenRouter/Cline 上 Anthropic 模型可故障转移到其他上游，而非直接失败。含义：harness 应把「模型拒答」当作可路由事件，而非终态错误。
- 内容过滤拦截时改为明确提示并建议改写，替代原先的「Model returned empty response」。含义：错误分类要区分过滤与空输出，才能给 agent 可执行的恢复动作。
- API 报错后可直接输入并发送新消息，恢复期输入的 `/compact`、`/smol`、`/newtask` 留在输入框而不被当文本发给模型。含义：恢复态需保留命令语义，避免把控制指令降级为普通 prompt。
