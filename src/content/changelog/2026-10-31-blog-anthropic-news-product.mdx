- Anthropic 将 Agent Skills 这一开放标准捐给 Agentic AI Foundation，自 2025 年 12 月发布以来已有 ChatGPT、Cursor、GitHub Copilot、VS Code 等 70 多个 agent 平台接入；对开发者而言，技能定义正从单一厂商资产变成可跨平台复用的公共层。
- 产品线按行业切分：金融服务业推出 10 个 Cowork 与 Claude Code 插件、Microsoft 365 集成、新连接器及一个 MCP 应用；医疗与生命科学则提供 HIPAA-ready 基础设施，并连接 CMS、Medidata、ClinicalTrials.gov。这意味着 agent 落地靠的是连接器与合规基建，而非模型本身。
- Claude Code 获得原生 VS Code 扩展、终端体验更新与面向自主开发的 checkpoint；Claude Science 则强调产出可审计的 artifact，并灵活接入算力。对工具链的含义是：可回滚、可审计正成为 agent 产品的默认要求。
