- Rust 扩展体积明显更大：Rusqlite 版 321 KB、sqlite-loadable-rs 版 298 KB，而 C 版仅 14 KB，说明分发小型 SQLite 扩展时 C 的体积优势显著。
- 初版 Rust 更快，原因是其等价于 C strtod 的解析实现速度约为两倍；作者随后让模型自写 C 解析函数，用 Clinger 快速路径追平并反超。
- 200 万行基准中，新 C 版每行净开销在混合数据 19 ns、纯整数 16 ns、纯小数 18 ns，均优于 rusqlite 与 sqlite-loadable 版本，提示性能敏感扩展仍值得手写 C 热路径。
