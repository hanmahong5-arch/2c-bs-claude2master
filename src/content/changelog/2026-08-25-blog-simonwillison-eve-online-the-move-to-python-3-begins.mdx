- EVE Online 自 2003 年上线以来一直使用 Stackless Python，最近一次大升级是 2010 年迁移到 Python 2.7。此次迁移将使用 futurize 脚本处理 240 万行代码，并人工审查约 2 万个 Python 2/3 行为差异点（如整数除法）。
- 对开发者而言，这展示了大型代码库迁移的务实路径：自动化工具 + 人工审查，而非一次性重写。
- 公告未提及 Stackless 的替代方案，但去年 EVE Frontier 已用开源库 carbonengine/scheduler 取代了 Stackless，这可能为 EVE Online 提供迁移方向。
- 对 agent 工具链的启示：代码迁移可借助自动化脚本，但语义差异仍需人工判断，agent 可辅助定位差异点。
