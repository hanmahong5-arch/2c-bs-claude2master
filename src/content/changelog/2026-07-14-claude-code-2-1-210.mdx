- 新增实时耗时计数器，长时工具调用不再看似卡死；agent harness 可借此判断工具是否仍在运行。
- 弃用 `Write(path)` 等权限规则，改用 `Edit(path)` 或 `Read(path)`；agent 权限模型需统一为更安全的读写分离。
- 修复 `isolation: 'worktree'` 子 agent 能对主仓库执行 git 命令的漏洞；隔离机制需确保子 agent 操作范围严格受限。
- 修复 `ultracode` 关键词在非人类输入（如 webhook）中误触发；agent 的 opt-in 机制应仅响应人类意图。
