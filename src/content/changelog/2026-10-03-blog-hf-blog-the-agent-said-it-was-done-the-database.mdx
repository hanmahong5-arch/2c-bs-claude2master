- 文章标题点出核心矛盾：agent 声称任务完成，但数据库状态并不一致，说明仅凭模型自述无法判断任务是否真正成功。
- 微软提出的 ThinkingBox 把验证落到外部状态上，让 agent 的完成声明必须与数据库等真实系统对账，而非依赖语言层面的自我确认。
- 对 agent 与工具链开发者而言，这意味着评测和编排需要引入可观测的外部校验环节，把"完成"变成可验证的事实而非模型的断言。
