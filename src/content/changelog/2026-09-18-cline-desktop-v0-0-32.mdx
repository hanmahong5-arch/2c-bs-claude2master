- 修复启动失败：0.0.31 中应用可能以 "desktop backend exited before publishing its endpoint" 退出，无法进入工作区选择器；原因是后台 Cline Hub 与应用由同一代码的不同副本构建，Hub 声明的构建身份与应用预期不符，应用会关掉自己刚启动的 Hub，最终超时报 "No compatible hub runtime is available"。含义：harness 中自启子进程的版本/身份校验必须与主进程同源，否则启动握手会自毁。
- 两侧现在加载同一份代码：Hub 与应用不再各自持有代码副本。含义：多进程 harness 应把共享运行时收敛为单一构建产物，避免身份漂移。
- CI 每次变更都端到端启动真实编译后端。含义：把启动握手纳入 CI 冒烟测试，才能防止两侧再次分叉。
