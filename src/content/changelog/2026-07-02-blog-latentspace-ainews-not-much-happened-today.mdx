- Anthropic 重新上线 Claude Fable 5，但增加了安全回退机制，部分请求可能路由到 Opus 4.8。开发者转向多模型编排，仅将 Fable 5 用于高价值推理，其他任务委托给更便宜的模型。
- Z.ai 围绕 GLM-5.2 构建产品生态，推出 ZCode 开发环境，LangChain 发布集成指南。开源模型在特定编码基准上缩小差距，但整体前沿性能仍落后。
- Agent 基础设施出现新模式：Wiki 结构记忆、记忆维护与协调、结构化技能组合。Cognition 的 Devin Security Swarm 使用 Agentic MapReduce 进行企业级安全审计。
