- **远程执行器使用加密的 Noise 中继通道**：增强了远程代理间通信的安全性和隐私性，意味着代理执行环境的数据传输更可信。
- **跨平台远程执行保留原生工作目录和 Shell**：确保了文件系统权限和路径在不同服务器间的一致性，这对构建跨环境稳定运行的代理工作流至关重要。
- **插件可按线程激活 MCP 服务器并新增市场**：提供了更灵活的插件管理和发现机制，允许代理系统根据认证模式动态加载工具，提升了模块化与安全性。
- **大型会话中缓存工具搜索并减少内存复制**：显著降低了延迟和内存占用，优化了工具密集型代理任务的响应速度和资源效率。
