- 新增 `on_failure` 块用于 PreToolUse 钩子，使工具调用失败时可执行自定义逻辑，对 agent 的错误处理流程设计有参考价值。
- 引入 `PreToolUseResult` 事件和稳定的 `tool_call_id`，贯穿工具生命周期，便于追踪和关联工具调用结果。
- 大量安全修复，如强制每轮模型工具白名单、限制代码模式回调输出、防止 secret 泄露等，提示 agent 设计需内置权限与数据保护机制。
- 扩展后台加载，CLI 提示符立即可用，改善启动体验；新增多个声明式 provider，简化模型接入。
