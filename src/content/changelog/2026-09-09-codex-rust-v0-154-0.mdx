- **GPT-6-Astra 进入模型选择器与 Bedrock 目录**：模型目录新增 GPT-6-Astra，意味着 harness 需支持多模型路由与能力声明，而非硬编码单一后端。
- **实验性 worktree 支持**：通过 `--worktree` 或 `/worktree` 创建隔离检出，可浏览与恢复，提示 harness 应把会话状态与文件系统快照解耦，便于 fork 与回滚。
- **异步内联问答**：Codex 工作时可用建议选项或自定义文本回答，不丢失主草稿，说明 harness 需支持非阻塞的用户输入通道与草稿保护。
