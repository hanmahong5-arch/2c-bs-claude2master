- `sessions_search` 支持对历史会话原文进行精确搜索，返回 `sessionKey`、时间戳、角色和匹配片段，可配合 `sessions_history` 获取上下文。
- 搜索结果受可见性规则限制，且摘要在返回前会被脱敏，确保安全。
- 索引与消息持久化在同一事务中，保证实时性，但重索引时结果可能不完整，需重试。

对 agent harness 设计：提供精确搜索接口，与语义记忆互补，可提升 Agent 对历史经验的利用效率。
