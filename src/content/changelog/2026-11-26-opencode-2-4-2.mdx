- `generate_image`/`generate_video` 移入 Code Mode，不再作为顶层工具，每次请求少约 700 token 定义；harness 应把低频工具收进代码模式，只暴露高频入口。
- web fetch 的 "Always allow" 改为仅放行该站点，旧审批保持原样；权限粒度从全局收窄到单站点，harness 的授权模型需按资源而非按工具类型设计。
- 插件可给 agent 注入 `instructions`，切换 agent 或中途改指令只发增量更新，不重写 system prompt；harness 应把动态指令做成可增量下发的层，避免破坏 prompt 缓存。
