- 新增 `claude-haiku-5-5` 并设为 Anthropic API 默认 Haiku 模型：1M 上下文，$0.10/$0.50 每 Mtok（超 100K 提示词为 $0.50/$2.50）。含义：harness 可把长上下文任务默认下放给更便宜的模型层。
- `subagentStatusLine` 载荷新增 `agentType`，脚本可区分自定义 subagent 类型。含义：状态栏与监控脚本能按 agent 类型做差异化展示或路由。
- `$.tool.register` 新增 `isDeferred`：设为 `false` 时工具 schema 从一开始就列在提示词中，而非藏在工具搜索后。含义：mod 作者可显式控制工具可见性，减少模型先搜索再调用的往返。
