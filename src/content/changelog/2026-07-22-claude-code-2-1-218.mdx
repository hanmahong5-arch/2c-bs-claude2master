- `/code-review` 改为后台子代理运行，不再填充对话，且仍以堆叠的斜杠命令为审查目标。
- 自动模式中危险操作（如 `rm`、后台 `&`、可疑 Windows 路径）不再弹出权限对话框，改由自动模式分类器裁决。
- 修复了 Windows 路径中 `\u` 前缀段被错误转换为 CJK 字符导致文件不可访问的问题。
