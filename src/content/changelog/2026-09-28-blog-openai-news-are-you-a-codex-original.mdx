- OpenAI 通过表单收集开发者、研究者与创作者使用 Codex 的真实项目故事，目标是筛选进入 Codex Originals 项目的人选。对 agent 工具链开发者而言，这是一条官方曝光渠道，值得把已有 Codex 用例整理成可提交的案例。
- 征集对象明确覆盖 builders、tinkerers、researchers、creators 四类人群，说明官方关注的不只是工程效率场景，也包括探索性和创意性用法。做 agent 产品的人可据此判断官方叙事偏好，调整自己案例的呈现角度。
- 参与方式是填写表单并描述自己的故事与项目，原文未披露评选标准、时间线或权益细节。开发者若打算提交，需自行准备项目说明，且不应把未公开的承诺当作预期。
