- 插件目录 `plugin-catalog.json` 超过客户端 2 MiB 上限，安装时静默回退到随版本内置的旧目录；本次将上限提高到 16 MiB，恢复使用线上目录（#151860）。含义：harness 拉取远程清单需显式暴露回退状态，避免静默降级。
- 回退期间 `hermes plugins install <name>` 找不到上次更新后新增的插件，并安装发布版锁定的版本而非当前版本。含义：插件解析应区分“锁定版本”与“最新版本”，并在安装结果中标注来源。
- 回退还会漏掉目录中较新的 `removed` 条目；停留在 v0.23.0 及更早版本的安装会持续回退，直到升级。含义：harness 需对清单版本做兼容性检查，并在过期时提示升级。
