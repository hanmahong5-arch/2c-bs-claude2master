- 新增 `bashOutputMaxChars` 和 `taskOutputMaxChars` 设置，可将命令及后台任务输出上限提升至 128K 字符，内联输出更多，减少文件切换。
- 新增 `/skill-doctor` 命令，展示未使用技能及其上下文成本，便于裁剪，优化 token 使用。
- 新增 `--append-subagent-system-prompt-file`，支持从文件读取子代理系统提示，适合超长提示场景。
- 修复快速输入时字符乱序或丢失的问题，提升交互可靠性。
- 修复恢复会话时并行工具调用的 hook 输出丢失，确保上下文完整。
