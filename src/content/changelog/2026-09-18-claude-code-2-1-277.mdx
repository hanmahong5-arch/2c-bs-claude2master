- 新增 AGENTS.md 支持：项目无 CLAUDE.md 时改读 AGENTS.md，可在 `/config` 的 Project instructions 切换（Bedrock/Vertex/Foundry 暂不支持）。含义：harness 需把项目指令来源抽象成可配置优先级，而非硬编码单一文件名。
- 修复 `claude -p` 与 Agent SDK 会话在内部错误后无结果挂起，现改为报错并以退出码 1 结束。含义：headless harness 必须保证失败可观测，不能静默挂起。
- 修复恢复会话时重渲染已加载的 MCP 工具定义、以及重放历史附件导致 prompt cache 失效。含义：会话持久化设计要区分「已发送内容」与「重放内容」，避免破坏缓存前缀。
