- 用 `pnpm qa:lab:up` 起双栏 QA 站点：左栏 Gateway 控制台跑 agent，右栏 QA Lab 展示 Slack 式对话与场景计划，操作员或自动化循环可下发任务并记录成功/失败/阻塞。含义：harness 应把「执行环境」与「观察面板」分离，让 prompt 调试有可回放的证据面。
- 配置里 Provider lane、模型、Execution channel、Channel driver、Runtime pair 相互独立，服务端在启动前解析 taxonomy 成员资格与执行类型；未知、空显式、profile 或 lane 不兼容的选择一律 fail closed，而不是回退到默认套件。含义：prompt/harness 的配置解析要显式失败，避免静默降级掩盖问题。
- 可观测性 smoke 断言 trace 必须含 `openclaw.run`、`openclaw.harness.run`、GenAI 语义约定 model-call span、`openclaw.context.assembled`、`openclaw.message.delivery`，且原始 OTLP 载荷不得含固定标记、密钥或场景派生 session key。含义：把「哪些 span 必须存在、哪些内容绝不能外泄」写成断言，是 prompt 与上下文组装的可测契约。
