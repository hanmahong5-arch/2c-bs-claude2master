- 免费模型端到端支持：显示“(free)”标识，达到限额时显示重置时间卡片，方便用户管理免费额度。
- `/settings` 中的通用开关（plan/act模式、工具自动批准、压缩模式）重启后保持，提升agent配置持久性。
- Agentic压缩成为默认上下文压缩策略，修复了静默回退到基础压缩和工具密集记录无法找到切割点的问题，使agent能更智能地管理上下文窗口。
