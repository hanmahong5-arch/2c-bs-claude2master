- 直接从各 provider 用量端点拉取配额，不估算计费；配额窗口统一显示为 X% left，无窗口则显示摘要文本。
- /status 和 session_status 在实时快照缺 token/model 数据时，回退到会话 transcript 日志，补全缺失计数并恢复模型标签。
- /usage 支持 off/tokens/full 三态，显式 off 持久化后不可被配置默认值覆盖；/usage reset 才清除覆盖。
- 自定义 footer 模板支持 JSON 文件热加载，无效模板静默回退内置样式并告警。
- 对 agent harness 设计：用量追踪需区分 provider 报告与本地估算，且状态覆盖需明确优先级。
