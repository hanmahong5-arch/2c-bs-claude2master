- 新增：支持模型在任务中生成图片，并内联显示在对话中。
  - 对 harness 设计：需处理图片消息的渲染与存储，确保多模态交互流畅。
- 修复：代码操作在 VS Code 1.134 上“命令未找到”的问题；@文件提及在含空格路径下失效；CRLF 行尾的多行编辑 diff 视图。
  - 对 harness 设计：需兼容不同编辑器版本和文件编码，提升健壮性。
- 修复：恢复任务时保留存活会话而非重建；任务级设置覆盖不再泄漏；LiteLLM 输入 token 限制不再被覆盖；Gemini 自定义 base URL 恢复。
  - 对 harness 设计：需确保会话状态隔离和配置持久化，避免跨任务污染。
