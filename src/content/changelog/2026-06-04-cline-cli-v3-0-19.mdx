- 将 CLI 自动更新从 `npm install` 改为 `npm update`，提升更新成功率
  - 对 agent harness 设计：更新逻辑应优先使用包管理器的标准更新命令，而非重新安装
- 更新过程中保持原有的发布渠道（如 nightly）不变
  - 对 agent harness 设计：渠道配置应作为持久化元数据，在系统操作中保持不变
- 修复了之前版本中更新可能失败或意外切换渠道的问题
  - 对 agent harness 设计：关键运维操作（如更新）需要明确边界和回滚策略，避免副作用
