- 大会胸牌本身就是一台带彩色屏幕的小型计算机，作者去年就折腾过，今年继续在上面做硬件改造。对开发者的含义：可编程硬件正在变成会议周边，动手门槛比想象中低。
- Steve Francia 借助 Gemini 先让胸牌跑起完整的 NES 模拟器，又进一步部署了 Game Boy 与 Game Boy Color 模拟器。对 agent 工具链的含义：LLM 已被用来啃模拟器移植这类底层工程活。
- 只要拿到 ROM，就能在胸牌上玩《塞尔达传说：织梦岛》；胸牌还能倒过来，用机身内置的触控按键当手柄。对硬件开发的含义：外设形态可以围绕使用场景重新设计，而不必照搬传统手柄。
