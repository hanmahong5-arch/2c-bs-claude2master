- Cloudflare 收购 Deno，目标是基于 Deno 团队 8 月开源的 celld（Cloudflare Workers Durable Objects 模式的开源实现），让 workerd 自托管成为一等支持的 Workers 应用运行方式。对 agent 工具链而言，这意味着 Workers 编程模型可能脱离 Cloudflare 平台本身运行。
- Deno 运行时只再获一年支持，含月度 bug 修复与安全更新，之后 Cloudflare 停止开发；Deno 保持开源，欢迎他人接手。开发者若把 Deno 作为长期运行时依赖，需要评估迁移路径。
- Ryan Dahl 在 Hacker News 解释称这是共同决定，他认为 Deno 被 Node 兼容性引力捕获、被迫与 Node 行为一致，边际性能或体验收益不足，而 celld 只依赖对象存储做协调与持久化，是全新的服务端开发模型。这提示 agent 基础设施的差异化更可能来自新抽象而非兼容层。
