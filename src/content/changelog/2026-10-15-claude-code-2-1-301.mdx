- 新增 `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`：无人值守重试模式遇到重置时间过远的用量限制时直接结束请求，而非无限等待。对 agent harness 的含义是长时间无人值守运行需要可配置的放弃阈值，否则会静默挂起。
- OpenTelemetry 的 `tool_decision` 事件新增 `classifier_verdict`、`permission_mode` 和 `classifier_category`，可区分自动模式分类器决策与权限规则。含义是权限决策链路需要可观测性，才能定位自动模式为何放行或拦截。
- 修复工作流 agent 读到 harness 说明后有时跳过步骤却仍报告成功；以及消息中途打断权限检查时工具调用被误报为用户拒绝。含义是 harness 必须让跳过与拒绝在状态上可区分，否则上层编排会误判执行结果。
