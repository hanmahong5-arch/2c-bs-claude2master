- OpenAI 发布 Agents API，定位为托管服务，让开发者构建并上线云端 agent，无需自建编排层。对工具链的含义：agent 运行时正被平台化，编排与调度逐渐变成基础设施而非自研代码。
- 该服务由 Codex harness 驱动，负责编排、长时运行会话与工具使用。对开发者的含义：长会话状态与工具调用由平台托管，团队可以把精力放在任务定义与工具接入上。
- 官方给出的能力边界集中在三点：orchestration、long-running sessions、tool use。对 agent 工程的含义：评估这类托管 API 时，应重点验证会话持久性与工具调用的可控性，而非只看模型本身。
