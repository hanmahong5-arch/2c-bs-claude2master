- 支持无项目文件夹直接聊天，降低 agent 启动门槛，适合快速问答场景。
- 拖拽文件到聊天窗口即可附加，简化多模态输入流程，agent 可即时处理附件。
- 默认启用 agentic compaction 智能压缩长对话上下文，提升 agent 在持续交互中的记忆效率。
