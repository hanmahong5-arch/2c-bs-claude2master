- OpenAI 构建了名为 Performance Factory 的系统，由 Codex 驱动的多条工作流组成，目标是找出并修复性能问题，从而保持 ChatGPT 的响应速度。对开发者的含义是：性能优化正在被组织成可复用的自动化流水线，而非一次性人工排查。
- 该系统以 Codex 为核心执行引擎，把代码层面的分析与修复纳入工作流。对 agent 工具链的含义是：代码模型不只是补全工具，还能承担定位性能瓶颈、生成修复这类闭环任务。
- 文章将 Performance Factory 定位为持续维持 ChatGPT 速度的机制，而非单次优化项目。对工程团队的含义是：性能治理需要常设的自动化系统，把发现与修复变成常态流程。
