- 桌面版改为通用 macOS 下载，自动迁移旧架构安装，简化分发。
- 会话历史可按来源过滤，新增侧边栏过滤控件，便于管理多入口会话。
- 编辑器显示 token 用量环和累计成本，接近限制时变色，提醒上下文管理。
- 技能加入斜杠命令菜单，同名命令消除歧义，避免覆盖。
- 插件显示真实包名，不再统一为 "index"，提升可识别性。
- 计划模式硬阻止文件编辑 shell 命令，仅允许只读操作，增强安全。
- 上下文耗尽时自动压缩并重试一次，而非直接失败。
- 空模型响应在所有提供商上重试，修复 OpenRouter 等硬失败。
- Bedrock 提示缓存修复，缓存读写不再为 0，并支持地理推断。
