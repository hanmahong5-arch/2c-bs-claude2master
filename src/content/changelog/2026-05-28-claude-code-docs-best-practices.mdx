- **提供可验证的检查点**：让 Claude 运行测试、构建或截图对比，形成自主闭环，而非依赖人工检查。这意味着设计提示时需包含明确的通过/失败标准。
- **探索、规划、编码分阶段进行**：使用计划模式先调研再实施，避免解决错误问题。这要求为复杂任务设计分步执行的提示流程。
- **提供具体上下文**：在提示中引用特定文件、约束和现有模式，减少纠正次数。这表明提示设计应精确指向代码库中的具体资源。
