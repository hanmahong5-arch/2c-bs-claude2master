- 他因 Chrome 里 `<select>` 默认样式难看、各浏览器表现不一致而动手，让 Claude Fable 5.2 生成一个展示 select 所有可样式化方式的页面，计划在桌面和移动端各浏览器截图对比。含义：把「跨浏览器视觉验证」这类重复劳动交给 agent 生成基线页面，人只做截图与判断。
- 他最终选定的方案用 `appearance: none` 去掉原生外观，再用内联 SVG data URI 作背景画下拉箭头，配合 padding、边框与圆角统一观感。含义：data URI 内联图标免去额外请求与资源依赖，适合作为可复用的组件样式片段。
- 文中只给出这段 CSS 在三个浏览器下的效果，没有更多结论。含义：样式结论仍需人工在多端实测确认，agent 产出的是候选与样本，不是最终答案。
