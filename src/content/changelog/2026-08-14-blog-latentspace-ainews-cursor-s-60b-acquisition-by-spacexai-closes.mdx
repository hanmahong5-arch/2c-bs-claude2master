- Z.ai 发布 GLM-5.3，能力提升主要来自规模化后训练和强化学习，而非更大基座模型，表明长时程可执行任务训练是提升 agent 能力的关键路径。
- DeepSeek Harness 被视为基础设施，其插件化运行时支持热替换组件，甚至允许 agent 修改自身运行时，这挑战了传统固定核心的 harness 设计，提示开发者应关注运行时架构的灵活性。
- 多个新评测和讨论强调 harness 层对性能的影响，如 AutoDesign 通过元优化器重写 harness 带来收益，同时评测基准受到质疑，开发者应自建评测而非轻信厂商数据。
