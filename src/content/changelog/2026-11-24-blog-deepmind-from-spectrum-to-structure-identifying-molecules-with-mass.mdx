- **把质谱解读做成可调用的技能**：Mass Spec Skills 面向使用 Google Antigravity 的科学家，用于解读串联质谱（tandem mass spectra），把原本依赖专家经验的谱图判读交给 agent 执行。对工具链的含义是：领域专用能力可以按“技能”封装进通用 agent 平台，而不必自建整套系统。
- **从谱图到结构**：标题点明任务是“从 spectrum 到 structure”，即由质谱数据推断分子结构，属于化学分析中的核心环节。对开发者的含义是：agent 的价值在于承接高门槛的专业判断流程，而非只做文本问答。
- **落地形态是平台内技能**：该能力以 Skills 形式挂在 Google Antigravity 之下，说明 DeepMind 正把科研能力嵌入 agent 产品界面。对 agent 生态的含义是：科研场景的竞争点正从模型能力转向“可被调用的专业工作流”。
