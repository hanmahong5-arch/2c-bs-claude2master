- `session.updated` 等事件不再包含完整对话记录，仅含状态快照（状态、用量、模型、工作区、检查点）。
- 需要对话内容时，通过 `session.messages` 命令主动获取，避免每次事件都传输大量数据。
- 修复了因事件携带完整对话导致的内存膨胀问题（曾出现 25GB 进程），对 agent harness 设计意味着事件流更轻量，但需按需拉取消息。
